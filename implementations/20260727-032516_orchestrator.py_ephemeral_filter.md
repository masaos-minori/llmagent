## Design

Based on inspection of `orchestrator.py`:
```python
# Current (vulnerable to key manipulation):
ctx.conv.history = [
    m
    for m in ctx.conv.history
    if not m.get("_ephemeral") and not m.get("_memory_injected")
]

# Proposed fix:
_EPHEMERAL_KEYS = frozenset({"_ephemeral", "_memory_injected"})
ctx.conv.history = [
    m
    for m in ctx.conv.history
    if not any(k in _EPHEMERAL_KEYS for k in m.keys())
]
```
