## Goal

Add an autouse fixture to `tests/conftest.py` that resets `ConfigLoader`'s state via REQ-002's new test-only reset classmethod after every test.

## Scope

- Modify `tests/conftest.py`: add an autouse fixture using `_reset_for_testing()`.

## Assumptions

- REQ-002's `_reset_for_testing()` classmethod exists (covered in previous row).
- The fixture should run after every test (autouse=True).

## Design decisions

- Use `pytest.fixture(autouse=True)` decorator.
- Place the fixture in `tests/conftest.py` so it applies to all tests in the suite.

## Alternatives considered

- Adding the fixture to each individual test file — rejected: defeats the purpose of a global safety net.
- Using `pytest_configure` hook — rejected: fixture is more idiomatic and easier to reason about.

## Implementation

### Method

- **Step 1**: Add the fixture:

```python
@pytest.fixture(autouse=True)
def _reset_config_loader_state() -> None:
    """Reset ConfigLoader's allowed-file state after every test.

    This is necessary because REQ-001 makes AgentContext.__init__ set
    ConfigLoader._allowed_files unconditionally for the remainder of any
    pytest process that constructs one. Without this fixture, cross-test
    ConfigLoader state leakage would occur.
    """
    yield
    try:
        from shared.config_loader import ConfigLoader
        ConfigLoader._reset_for_testing()
    except ImportError:
        # ConfigLoader may not be available during early test setup phases
        pass
```
