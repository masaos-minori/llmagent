# Implementation Procedure: scripts/agent/orchestrator.py

## Goal

Rewrite `orchestrator.py` as a thin composition facade (< 200 lines) that delegates to six extracted concern classes, preserving all existing public method signatures, return types, and backward-compatible import paths.

## Scope

- Rewrite `scripts/agent/orchestrator.py` only. No other source file is modified by this document.
- The Orchestrator class becomes a pure composition layer; its methods forward calls to injected components.
- Module-level functions `_mode_hint`, `_format_session_id`, `_build_turn_end_metadata`, `_build_turn_end_llm_stats` are moved to `audit_event_emitter.py`.
- Class attribute `_EPHEMERAL_KEYS` is moved to `conversation_state_manager.py`.
- Constant `BG_FAILURE_THRESHOLD` is moved to `bg_task_monitor.py`.
- Inline import `from agent.tool_output import emit_approval_pending_notice` in `_handle_workflow_approval_pending` is replaced by a top-level import in `workflow_engine_adapter.py`.

## Assumptions

- `ToolLoopGuard` remains shared between Orchestrator and LLMTurnRunner (per Issue constraint: "Do NOT rewrite unrelated files").
- `DiagnosticStore` ownership remains in Orchestrator (per Issue constraint: "Do NOT rewrite unrelated files").
- The 200-line target for Orchestrator is reasonable given it will become a pure composition layer.
- `BG_FAILURE_THRESHOLD` constant scope is limited to first-turn session-title-generation; do not generalize it.
- The `pause_on_critical_failure` opt-in flag and `_bg_pause_state` dict remain in BgTaskMonitor.
- All six extracted components receive dependencies via constructor injection (AgentContext, callbacks, etc.).

## Design decisions

1. **Composition over inheritance**: Orchestrator becomes a thin facade delegating to extracted components. No inheritance hierarchy -- each component receives dependencies via constructor injection.
2. **Dependency injection pattern**: Each extracted component receives only the dependencies it needs (AgentContext, callbacks, etc.). This enables independent instantiation and testing.
3. **Callback preservation**: All callback signatures (`on_turn_start`, `on_turn_end`, `on_error`, `on_first_turn`, `on_llm_wait_start`, `on_llm_wait_end`) are preserved on Orchestrator and forwarded to the appropriate component during turn execution.
4. **No inline imports**: Remove `from agent.tool_output import emit_approval_pending_notice` from `_handle_workflow_approval_pending`; move to top-level import in WorkflowEngineAdapter.
5. **Constant scoping**: `BG_FAILURE_THRESHOLD` moves to BgTaskMonitor as a class attribute; `_EPHEMERAL_KEYS` moves to ConversationStateManager as a class attribute.

## Alternatives considered

1. **Keep module-level functions in orchestrator.py**: Would reduce refactoring effort but leaves the file at > 700 lines. Rejected because it defeats the purpose of the refactor.
2. **Merge some concerns into fewer components** (e.g., combine TurnCoordinator + ConversationStateManager): Would reduce the number of new files but violates the Single Responsibility Principle that motivated this refactor. Rejected per plan's design intent.
3. **Make Orchestrator a mixin or base class**: Would introduce inheritance complexity without benefit. Composition is simpler and more testable. Rejected.

```python
class Orchestrator:
    """Turn-level coordinator: compression -> LLM loop -> tool dispatch.

    Thin composition facade delegating to:
      turnd_coordinator.TurnCoordinator       -- turn lifecycle
      workflow_engine_adapter.WorkflowEngineAdapter -- workflow engine integration
      bg_task_monitor.BgTaskMonitor           -- background task failure tracking
      llm_turn_executor.LlmTurnExecutor       -- LLM streaming and result processing
      audit_event_emitter.AuditEventEmitter   -- audit event construction and emission
      conversation_state_manager.ConversationStateManager -- conversation history manipulation
    """

    def __init__(
        self,
        ctx: AgentContext,
        *,
        allowed_tools: list[str] | None = None,
        on_turn_start: Callable[[], None] | None = None,
        on_turn_end: Callable[[], None] | None = None,
        on_error: Callable[[Exception], None] | None = None,
        on_first_turn: Callable[[str], Any] | None = None,
        on_llm_wait_start: Callable[[], Any] | None = None,
        on_llm_wait_end: Callable[[], None] | None = None,
        tracer: Any = None,
        pause_on_critical_failure: bool = False,
    ) -> None:
        self._turn_coordinator = TurnCoordinator(...)
        self._workflow_adapter = WorkflowEngineAdapter(...)
        self._bg_monitor = BgTaskMonitor(...)
        self._llm_executor = LlmTurnExecutor(...)
        self._audit_emitter = AuditEventEmitter(...)
        self._state_manager = ConversationStateManager(...)
        # DiagnosticStore ownership remains here (per Issue constraint)
        self._diagnostic_store = DiagnosticStore()
        ctx.diagnostics = self._diagnostic_store
        # ToolLoopGuard remains shared (per Issue constraint)
        self._guard = ToolLoopGuard(ctx)
        self._background_tasks: set[asyncio.Task[object]] = set()
        # Startup recovery for stale running attempts
        self._state_store = StateStore()
        self._state_store.recover_stale_attempts(self._state_store.get_connection())
        # Scoped to a single background-task type today
        self._consecutive_bg_failures: int = 0
        self._llm_runner = LLMTurnRunner(ctx, self._guard, tracer=tracer)
        try:
            self._workflow_def: WorkflowDef | None = WorkflowLoader().load()
        except (WorkflowLoadError, FileNotFoundError) as exc:
            raise RuntimeError(
                f"{OutputTag.WORKFLOW} WorkflowLoader failed: {exc}. Expected definition at: {WORKFLOWS_DIR / 'default.json'}."
            ) from exc
        # Store callbacks for forwarding
        self._on_first_turn = on_first_turn
        self._on_llm_wait_start = on_llm_wait_start
        self._on_llm_wait_end = on_llm_wait_end
        self._on_turn_start = on_turn_start
        self._on_turn_end = on_turn_end
        self._on_error = on_error
        self._allowed_tools = allowed_tools
        self._tracer = tracer
        self._pause_on_critical_failure = pause_on_critical_failure

    async def handle_turn(self, line: str) -> None:
        ctx = self._ctx
        if ctx.workflow.approval_pending:
            logger.warning("Turn blocked: workflow pending approval...")
            if self._on_error:
                self._on_error(RuntimeError(...))
            return
        if any(self._bg_monitor._bg_pause_state.values()):
            paused = [name for name, is_paused in self._bg_monitor._bg_pause_state.items() if is_paused]
            logger.warning("Turn blocked: agent paused due to background task failures: %s", paused)
            if self._on_error:
                self._on_error(RuntimeError(...))
            return
        turn_started_at = time.perf_counter()
        await self._turn_coordinator.handle_turn_start(line)
        await self._workflow_adapter.handle_workflow_engine(line, ctx, turn_started_at)

    def workflow_status(self) -> dict[str, str]:
        return self._workflow_adapter.workflow_status()
```

Key points:
- `handle_turn` retains its two guard conditions (approval_pending, bg_pause_state).
- Callback forwarding: `on_turn_start`/`on_turn_end`/`on_error`/`on_first_turn`/`on_llm_wait_start`/`on_llm_wait_end` are stored on Orchestrator and forwarded to the appropriate component during turn execution.
- `_process_turn` logic is delegated to WorkflowEngineAdapter which composes TurnCoordinator, ConversationStateManager, and LlmTurnExecutor internally.
- `_handle_turn_end` logic is delegated to WorkflowEngineAdapter which composes TurnCoordinator and AuditEventEmitter internally.
