# Implementation Procedure: Config injection + dead branch removal

## Goal

Two changes to `scripts/mcp_servers/git/git_service.py`:
1. Pass `self._config` to `format_pull()`/`format_push()` in `_pull_op`/`_push_op` — REQ-007.
2. Remove unreachable `[DENIED]` returns inside `_checkout_op`/`_pull_op`/`_push_op` — REQ-008.

## Scope

- Modify `scripts/mcp_servers/git/git_service.py`:
  - `_pull_op` (line 410): pass `self._config` to `format_pull(state, req, self._config)`.
  - `_push_op` (line 445): pass `self._config` to `format_push(state, req, self._config)`.
  - `_checkout_op` (lines 369-372): remove `[DENIED]` worktree/detached HEAD returns.
  - `_pull_op` (lines 406-409): remove `[DENIED]` worktree/detached HEAD returns.
  - `_push_op` (lines 441-444): remove `[DENIED]` worktree/detached HEAD returns.

## Assumptions

- `GitService._config` is set by `build_service()` (confirmed in `git_service.py` lines 461-479).
- The `[DENIED]` returns are unreachable because `WriteProtectionPipeline.verify_preconditions()` rejects dirty/detached state before the op runs (confirmed in `repository_state.py`).
- `format_pull()`/`format_push()` will receive `cfg` from the caller (covered in `format_output.py` document).

## Design decisions

- **Config injection**: Add `self._config` as the third argument to `format_pull()` and `format_push()` calls in the op closures.
- **Dead branch removal**: Remove the `if not req.dry_run:` blocks that return `[DENIED]` strings inside the op closures. These checks are redundant because the pipeline's Stage 5 precondition check already rejects dirty/detached state before the op runs.

## Alternatives considered

- Keeping the `[DENIED]` returns as a belt-and-suspenders approach: rejected because they are unreachable (pipeline rejects first) and create a false sense of protection.
- Adding a `cfg` parameter to the op closure signature: rejected because the closure already has access to `self._config` via closure capture.

## Rollback considerations

- Reverting the config injection adds back the `GitConfig.load()` fallback.
- Reverting the dead branch removal adds back the unreachable `[DENIED]` returns.
