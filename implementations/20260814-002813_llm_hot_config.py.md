# Implementation Procedure: Remove unused `kwarg` parameter from `LlmHotConfigHandler.apply_one`

## Goal
Simplify `LlmHotConfigHandler.apply_one`'s signature from 4 parameters to 3 by
dropping the unused `kwarg: str` parameter, since only `instance`, `field`, and
`value` are read inside the method body (`setattr(instance, field, value)`).

## Scope
- In scope: `scripts/shared/llm_hot_config.py` — `apply_one`'s signature and the
  single call site inside `apply_config`'s loop.
- Out of scope: `apply_config`'s own public keyword-only signature; the
  `HOT_CONFIG_FIELDS` tuple contents/shape; `scripts/shared/llm_client.py`'s
  `LLMClient.apply_config` (calls `apply_config`, not `apply_one`, unaffected);
  any other module's unrelated `apply_config` method
  (`scripts/agent/services/config_reload.py`, `scripts/agent/history.py`,
  `scripts/shared/tool_executor.py`).

## Assumptions
- `apply_one` has no callers outside `scripts/shared/llm_hot_config.py` and
  `tests/shared/test_llm_hot_config.py` — confirmed via repo-wide
  `rg "apply_one"` immediately before writing this procedure (see grep output
  below); only re-check needed is a fresh repeat of the same command right
  before editing, in case a new caller appeared in the interim.
- No reflective dispatch (e.g. `getattr`) targets `apply_one` anywhere in the
  codebase — the class is a plain internal helper with two static methods,
  both called directly by name.

## Design decisions
- Drop only the trailing argument passed *into* `apply_one`; the loop variable
  `kwarg` in `for attr, kwarg in LlmHotConfigHandler.HOT_CONFIG_FIELDS:` stays,
  since it is still needed as the `args.get(kwarg)` dict lookup key on the line
  above the `apply_one` call.
- No import-boundary or layering change: `apply_one` is not exported/
  re-exported elsewhere.

## Alternatives considered
N/A — the plan specifies this exact minimal signature change; no alternative
approaches were proposed in the source plan.

        ("_temperature", "temperature"),
        ("_max_tokens", "max_tokens"),
        ("_max_retries", "max_retries"),
        ("_retry_base_delay", "retry_base_delay"),
        ("_sse_heartbeat_timeout", "sse_heartbeat_timeout"),
        ("_sse_malformed_retry", "sse_malformed_retry"),

        ("_llm_stream_retry_on_malformed_chunk", "stream_retry_on_malformed_chunk"),
    )

    @staticmethod
    def apply_one(instance: object, field: str, kwarg: str, value: Any) -> None:
        """Set a single config field on an instance."""
        setattr(instance, field, value)

    @staticmethod
    def apply_config(
        instance: object,
        *,
        temperature: float | None = None,
        ...  # (remaining keyword-only params unchanged, 9 total)

        """Update hot-reloadable configuration fields without recreating the instance."""
        args = dict(
