# Implementation Procedure: `config/agent.toml` (set `embed_url` to a reachable embedding endpoint)

## Goal

Update `embed_url` in `config/agent.toml` (line 10) to point to a reachable embedding service — or enable local embedding mode — so that the embed-llm health check succeeds at startup and RAG embedding functionality (semantic search, memory retrieval) is restored (REQ-001, REQ-002).

## Scope

Line 10 of `config/agent.toml` only: the `embed_url` value (and, for Option B, adding `memory_local_only = true`). No other key, section, or file changes. All other RAG configuration must remain byte-for-byte unchanged (REQ-003).

## Assumptions

- Either a reachable external embedding service exists at a known host/port (Option A), or a local embedding service is available and can be enabled via `memory_local_only` (Option B). The concrete choice depends on UNK-01 / UNK-02, resolved in Phase 1.
- The startup health check probes `<embed_url-netloc>/health` (path stripped), so whatever endpoint is chosen MUST respond successfully at `/health`.
- For Option B, `embedding_client.py` rejects a non-local `embed_url` when `memory_local_only = true` (`embedding_client.py:116-121`), so the URL must be `http://localhost:<port>` or `http://127.0.0.1:<port>`, and a local embedding service must be running on that port.

## Design decisions

- Minimal single-value substitution on `embed_url` (Option A) — preserves the existing architecture and requires no client-side code change.
- Load-bearing health-check detail: `scripts/agent/services/mcp_health.py:82` derives the probe URL as `f"{scheme}://{netloc}/health"`, i.e. it strips any path from `embed_url`. The actual embedding API calls append `EMBEDDING_PATH = "/embedding"` (`scripts/shared/llm_client.py:28,44`). Therefore the chosen endpoint must serve **both** `/health` (startup probe) **and** `/embedding` (real calls). Verify both before relying on the change.
- Option B (`memory_local_only = true`) is viable only with a confirmed local embedding service; otherwise it rejects all non-local URLs and re-disables RAG.

## Alternatives considered

- **Option A — external reachable service**: preferred by the Plan when a known-good endpoint exists; no local infra required.
- **Option B — local embedding** (`embed_url = "http://localhost:<port>"` + `memory_local_only = true`): used only when a local embedding service is confirmed running. Chosen over A when the external host (`192.168.11.238:8081`) is unreachable from the deploy host.

- `embed_url` is read at startup by every environment; changing it affects all deployments, not just this host. Choose an endpoint that is reachable from wherever the agent runs.
