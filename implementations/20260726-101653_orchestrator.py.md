## Design decisions

- Retain `BG_FAILURE_THRESHOLD` as a plain module-level `int` constant;
  document the deferred-configurability decision in its own comment rather
  than introducing an `AgentConfig` field, per the plan's Design section
  (only 1 production file touched vs. 5 for full config wiring).
- Use comments/docstrings only — no new function, class, or parameter is
  introduced; this keeps the change mechanically a documentation diff,
  verifiable by inspecting the diff for logic-line changes.
- Prefer asserting on log *level* (e.g. `caplog.records[i].levelname` or
  mock call site) in new tests rather than exact message text, to reduce
  coupling between tests and wording that may still evolve.
