## Design decisions

- Layout mirrors existing small config files (e.g. `config/eventbus.toml`): flat top-level
  keys + a `[retry_class]` table mapping tool name → `"retryable"` / `"non_retryable"`.
- Shipped retry_class map per REQ-006 owner classification:
  `file_write`, `file_delete`, `git`, `github`, `mdq`, `rag_pipeline` → `retryable`;
  `shell`, `web_search` → `non_retryable` (new).
- `db_path = "/opt/llm/db/mcp_dedup.sqlite"` (deployed default; loader in row 02 allows an
  env/test override the same way other config defaults do — no new override mechanism
  invented here).

## Alternatives considered

- Embedding defaults in `scripts/shared/mcp_dedup.py` only — rejected: project rule puts
  policy in config (row 02 keeps matching fallback defaults for a missing file).
- One TOML per server process — rejected: dedup is dispatcher-global (REQ-002/REQ-003).
