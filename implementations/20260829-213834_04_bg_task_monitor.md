# Implementation Procedure: scripts/agent/bg_task_monitor.py

## Goal

Create `bg_task_monitor.py` as a new module containing the BgTaskMonitor class, which encapsulates the background task failure monitoring logic currently scattered across Orchestrator's `_discard_and_log`, `_notify_bg_failure_threshold`, `_bg_pause_state`, and `BG_FAILURE_THRESHOLD` constant.

## Scope

- Create `scripts/agent/bg_task_monitor.py` only. No other source file is modified by this document.
- The BgTaskMonitor class receives dependencies via constructor injection.
- Orchestrator will forward its background-task callbacks to BgTaskMonitor after this file exists.

## Assumptions

- BgTaskMonitor needs access to AgentContext, on_error callback, and pause_on_critical_failure flag.
- The `BG_FAILURE_THRESHOLD` constant scope is limited to first-turn session-title-generation; do not generalize it.
- The `pause_on_critical_failure` opt-in flag and `_bg_pause_state` dict remain in BgTaskMonitor.
- BgTaskMonitor does NOT own DiagnosticStore or ToolLoopGuard (per Issue constraint).

## Design decisions

1. **BgTaskMonitor owns background task failure monitoring**: All background task failure tracking moves here. This includes consecutive failure counting, log-level selection, and pause-on-critical-failure behavior.
2. **Dependency injection**: BgTaskMonitor receives AgentContext, on_error callback, and pause_on_critical_failure flag via constructor.
3. **Constant scoping**: `BG_FAILURE_THRESHOLD` is defined as a class attribute in BgTaskMonitor, scoped to this specific concern.
4. **Pause state ownership**: `_bg_pause_state` dict remains in BgTaskMonitor -- it is keyed by `asyncio.Task.get_name()` and used to block further `handle_turn()` processing.

## Alternatives considered

1. **Keep background task methods in Orchestrator**: Would reduce refactoring effort but leaves Orchestrator with > 700 lines. Rejected.
2. **Merge BgTaskMonitor into WorkflowEngineAdapter**: Would violate separation of concerns -- background task monitoring is orthogonal to workflow engine integration. Rejected per plan intent.
3. **Make BgTaskMonitor a mixin**: Would introduce inheritance complexity without benefit. Composition is simpler. Rejected.

```python
"""scripts/agent/bg_task_monitor.py

BgTaskMonitor: background task failure monitoring and pause management.

Encapsulates:
  - Consecutive failure counting with log-level selection
  - User notification when failure threshold is breached
  - Pause-on-critical-failure behavior (opt-in)
  - Per-task-type pause state management
"""

from __future__ import annotations

import asyncio
import logging
from typing import TYPE_CHECKING, Any

if TYPE_CHECKING:
    from agent.context import AgentContext

logger = logging.getLogger(__name__)

class BgTaskMonitor:
    """Monitors background task failures and manages pause-on-critical-failure behavior.

    Receives dependencies via constructor injection. Does NOT own
    DiagnosticStore or ToolLoopGuard (per Issue constraint).
    """

    # Threshold for the first-turn background task's consecutive-failure counter
    # (see `_discard_and_log`). Effect: log-level selection only. Below this
    # threshold, failures log via `logger.warning`; at or above it, they log
    # via `logger.error`. There is no circuit-breaking or task-disabling
    # behavior.
    BG_FAILURE_THRESHOLD: int = 10

    def __init__(
        self,
        ctx: AgentContext,
        *,
        on_error: Any | None = None,
        pause_on_critical_failure: bool = False,
    ) -> None:
        self._ctx = ctx
        self._on_error = on_error
        self._pause_on_critical_failure = pause_on_critical_failure
        # Per-task-type pause flags, keyed by `asyncio.Task.get_name()`. A
        # `True` entry blocks further `handle_turn()` processing until the
        # process is restarted.
        self._bg_pause_state: dict[str, bool] = {}
        # Scoped to a single background-task type today (the first-turn
        # session-title-generation task handled by `_discard_and_log`). Do not
        # reuse this single counter for a second, distinct background-task
        # type.
        self._consecutive_bg_failures: int = 0

    def is_paused(self, task_name: str) -> bool:
        """Check if a background task type is paused."""
        return self._bg_pause_state.get(task_name, False)

    def reset_pause(self, task_name: str) -> None:
        """Clear pause for a background task type."""
        self._bg_pause_state.pop(task_name, None)

    def _discard_and_log(self, task: asyncio.Task[Any]) -> None:
        """Callback for first-turn background task completion.

        Cross-session accumulation: `self._consecutive_bg_failures` can span
        multiple `/clear` / `/session load` cycles within one process
        lifetime. `Orchestrator` is a long-lived singleton constructed once
        (`startup.py:117`) and reused across
        `conversation_service.clear_conversation` and
        `agent/services/session_restore.py:46` — neither of those reset
        points touches this counter, so a failure streak that started before
        a `/clear` or session switch continues to count toward
        `BG_FAILURE_THRESHOLD` afterward. Only a successful
        completion or an `asyncio.CancelledError` completion of this
        callback resets it to 0.
        """
        task_name = task.get_name()
        exc = task.exception()
        if exc is not None:
            if isinstance(exc, asyncio.CancelledError):
                # Task was cancelled — reset counter, do not log as error.
                self._consecutive_bg_failures = 0
            else:
                self._consecutive_bg_failures += 1
                if self._consecutive_bg_failures == 1:
                    logger.warning(
                        "First background task failure (%s): %s", task_name, exc
                    )
                    # Surface first-turn failure to user immediately
                    if isinstance(exc, Exception) and self._on_error is not None:
                        try:
                            self._on_error(exc)
                        except Exception as notif_err:  # noqa: BLE001 — caller-supplied error callback must not raise and crash the background-task monitor
                            logger.error(
                                "Failed to notify user of background task failure: %s",
                                notif_err,
                            )
                elif self._consecutive_bg_failures >= self.BG_FAILURE_THRESHOLD:
                    if (
                        self._consecutive_bg_failures == self.BG_FAILURE_THRESHOLD
                        or (self._consecutive_bg_failures - self.BG_FAILURE_THRESHOLD) % 5
                        == 0
                    ):
                        logger.error(
                            "Consecutive background task failures (%d) for '%s': %s",
                            self._consecutive_bg_failures,
                            task_name,
                            exc,
                        )
                        if self._consecutive_bg_failures == self.BG_FAILURE_THRESHOLD:
                            self._notify_bg_failure_threshold(
                                task_name, self._consecutive_bg_failures
                            )
                    else:
                        logger.warning(
                            "Background task failure #%d (%s): %s",
                            self._consecutive_bg_failures,
                            task_name,
                            exc,
                        )
        else:
            # Task completed successfully — reset counter
            self._consecutive_bg_failures = 0

    def _notify_bg_failure_threshold(self, task_name: str, count: int) -> None:
        """Guarantee the user is notified when a background task hits the failure threshold."""
        message = RuntimeError(
            f"Background task '{task_name}' has failed {count} consecutive times "
            f"(threshold: {self.BG_FAILURE_THRESHOLD})."
        )
        if self._on_error is not None:
            try:
                self._on_error(message)
            except Exception as notif_err:  # noqa: BLE001 — caller-supplied error callback must not raise and crash the background-task monitor
                logger.critical(
                    "Failed to notify user of threshold breach for '%s': %s",
                    task_name,
                    notif_err,
                )
        else:
            logger.critical(str(message))
        if self._pause_on_critical_failure:
            self._bg_pause_state[task_name] = True
            logger.warning(
                "Background task type '%s' paused after reaching threshold.", task_name
            )
```
