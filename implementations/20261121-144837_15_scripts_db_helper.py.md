## Goal

Remove `scripts/db/helper.py`'s implicit `agent.toml` load: path resolution and the `sqlite_vec_so` default come from the injected typed configuration (REQ-003, AC-004).

## Scope
**Release unit**: RU-2

## Assumptions
- `tests/db/test_sqlite_helper.py` is run as an affected test and is not a target row; no assertion changes were proven.
- The explicit-path constructor path (`db_path` supplied) keeps bypassing configuration, as documented in the current docstring.

## Design decisions
- `SQLiteHelper` receives the typed configuration defined by Plan row 8 at construction; the error wording that currently says "not configured in agent.toml or DB config" is reworded to name the supplied configuration, because the file is no longer read here.
- The fail-closed behaviour is preserved: a configuration that cannot supply a path raises before any connection is opened.

## Alternatives considered
- Keep `build_db_config()` as a zero-argument fallback inside `helper.py`: rejected by AC-004, which allows no config load inside `scripts/db/`.

## Implementation

`scripts/db/helper.py`
