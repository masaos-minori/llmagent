# Implementation Procedure: scripts/agent/llm_turn_executor.py

## Goal

Create `llm_turn_executor.py` as a new module containing the LlmTurnExecutor class, which encapsulates the LLM streaming and inner tool-call loop logic currently scattered across Orchestrator's `_handle_llm_turn`, `_call_on_llm_wait_end`, and related methods.

## Scope

- Create `scripts/agent/llm_turn_executor.py` only. No other source file is modified by this document.
- The LlmTurnExecutor class receives dependencies via constructor injection.
- Orchestrator will forward its LLM-turn callbacks to LlmTurnExecutor after this file exists.

## Assumptions

- LlmTurnExecutor needs access to AgentContext, LLMTurnRunner, ToolLoopGuard, and on_llm_wait_end/on_turn_end/on_error callbacks.
- The `_call_on_llm_wait_end`, `_call_on_turn_end`, and `_call_on_error` helper methods are moved to LlmTurnExecutor.
- LlmTurnExecutor does NOT own DiagnosticStore or ToolLoopGuard (per Issue constraint).
- The `handle_llm_transport_error` function from `agent.llm_transport_errors` is used for LLM transport error handling.

## Design decisions

1. **LlmTurnExecutor owns LLM streaming and tool-call loop**: All LLM turn execution moves here. This includes invoking callbacks, running the LLM stream, and handling transport errors.
2. **Dependency injection**: LlmTurnExecutor receives AgentContext, LLMTurnRunner, ToolLoopGuard, and callbacks via constructor.
3. **Delegation pattern**: LlmTurnExecutor delegates event construction to AuditEventEmitter and conversation manipulation to ConversationStateManager.

## Alternatives considered

1. **Keep LLM turn methods in Orchestrator**: Would reduce refactoring effort but leaves Orchestrator with > 700 lines. Rejected.
2. **Merge LlmTurnExecutor into WorkflowEngineAdapter**: Would violate separation of concerns -- LLM streaming is orthogonal to workflow engine integration. Rejected per plan intent.
3. **Make LlmTurnExecutor a mixin**: Would introduce inheritance complexity without benefit. Composition is simpler. Rejected.

```python
"""scripts/agent/llm_turn_executor.py

LlmTurnExecutor: LLM streaming and inner tool-call loop for one agent turn.

Encapsulates:
  - Executing LLM streaming turns with wait/start/end callbacks
  - Handling LLM transport errors
  - Returning TurnResult objects
"""

from __future__ import annotations

import logging
from typing import TYPE_CHECKING, Any

from shared.json_utils import dumps as json_dumps
from shared.llm_exceptions import LLMTransportError

from agent.diagnostic_store import DiagnosticStore
from agent.llm_transport_errors import handle_llm_transport_error
from agent.llm_turn_runner import LLMTurnRunner
from agent.tool_loop_guard import ToolLoopGuard
from agent.turn_result import TurnResult

if TYPE_CHECKING:
    from agent.context import AgentContext

logger = logging.getLogger(__name__)

class LlmTurnExecutor:
    """Manages LLM streaming and inner tool-call loop for one agent turn.

    Receives dependencies via constructor injection. Does NOT own
    DiagnosticStore or ToolLoopGuard (per Issue constraint).
    """

    def __init__(
        self,
        ctx: AgentContext,
        *,
        llm_runner: LLMTurnRunner,
        guard: ToolLoopGuard,
        tracer: Any = None,
        on_llm_wait_end: Any | None = None,
        on_turn_end: Any | None = None,
        on_error: Any | None = None,
        diagnostic_store: DiagnosticStore | None = None,
    ) -> None:
        self._ctx = ctx
        self._llm_runner = llm_runner
        self._guard = guard
        self._tracer = tracer
        self._on_llm_wait_end = on_llm_wait_end
        self._on_turn_end = on_turn_end
        self._on_error = on_error
        self._diagnostic_store = diagnostic_store

    async def execute(self, llm_url: str) -> TurnResult:
        """Execute an LLM streaming turn with wait/start/end callbacks and error handling."""
        ctx = self._ctx
        try:
            if self._on_llm_wait_start:
                await self._on_llm_wait_start()
            if self._on_turn_start:
                self._on_turn_start()
            with self._llm_runner._span_ctx("llm") as llm_span:
                llm_span.set_attribute("model_url", llm_url)
                result = await self._llm_runner.run(
                    llm_url,
                    workflow_id=ctx.workflow.workflow_id or "",
                    task_id=ctx.workflow.current_task_id or "",
                    stage_id="execute",
                    attempt_id=ctx.turn.current_turn_id or "",
                )
                logger.info("LLM response: %s", result.answer)
                if result.persist_as_assistant:
                    ctx.session.save("assistant", result.answer)
                if result.exception is not None:
                    # run() caught LLMTransportError internally; propagate callbacks
                    handle_llm_transport_error(
                        result.exception, ctx, self._diagnostic_store
                    )
                    self.invoke_llm_wait_end()
                    self.invoke_error(result.exception)
                    self.invoke_turn_end()
                else:
                    self.invoke_llm_wait_end()
                    self.invoke_turn_end()
                return result
        except LLMTransportError as e:
            # Reached when run() is mocked with side_effect=e (tests) or re-raises
            handle_llm_transport_error(e, ctx, self._diagnostic_store)
            self.invoke_llm_wait_end()
            self.invoke_error(e)
            return TurnResult(
                action="fail",
                answer="",
                error_kind=str(e),
                exception=e,
                persist_as_assistant=False,
            )

    def invoke_llm_wait_end(self) -> None:
        """Invoke on_llm_wait_end if configured."""
        if self._on_llm_wait_end:
            self._on_llm_wait_end()

    def invoke_turn_end(self) -> None:
        """Invoke on_turn_end if configured."""
        if self._on_turn_end:
            self._on_turn_end()

    def invoke_error(self, exc: Exception) -> None:
        """Invoke on_error with exc if configured."""
        if self._on_error:
            self._on_error(exc)
```
