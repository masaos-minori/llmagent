# Implementation Procedure

## Goal

Update references in eventbus documentation from the old filename `index.md` to the new filename `00_index.md`, ensuring all cross-references resolve to the correct location after the rename.

## Scope

- Modify `docs/00_index.md`: Update any internal references that may still point to the old `index.md` name
- Verify that eventbus endpoint documents (`docs/eventbus/ack-nack-endpoints.md`, `docs/eventbus/dlq-endpoint.md`, `docs/eventbus/health-endpoint.md`, `docs/eventbus/replay-endpoint.md`) reference `00_index.md` instead of `index.md`

## Assumptions

- The rename from `docs/index.md` to `docs/00_index.md` was confirmed via git history
- Eventbus endpoint documents currently contain stale references to `index.md` that need updating
- No semantic meaning of existing Front Matter values is changed

## Design decisions

- Use directory path as primary signal for area inference when adding missing `area` fields
- For stale references, prefer removing over guessing intent
- Prefer removing references to deleted files rather than keeping them

## Alternatives considered

- Keeping both `index.md` and `00_index.md` — rejected because the rename was intentional and confirmed by git history
- Updating only the eventbus docs without verifying `docs/00_index.md` — rejected because `docs/00_index.md` may also contain stale internal references

## Implementation

### Target file

`docs/00_index.md`

### Procedure

1. Read `docs/00_index.md` to identify any internal references to the old `index.md` name
2. Update any stale references from `index.md` to `00_index.md`
3. Add missing `area` field if absent (infer from directory path: `docs/` → `governance` or appropriate default)
4. Add missing `related` field if absent (use empty array `[]` if no specific references exist)
5. Add `## Keywords` section if missing
6. Add `## Related Documents` section if missing

### Method

Search for occurrences of `index.md` within `docs/00_index.md` using grep, then replace with `00_index.md` where appropriate. Validate against schema.

### Details

1. Run: `grep -n "index\.md" docs/00_index.md` to find stale references
2. Replace each occurrence of `index.md` with `00_index.md` in link/reference contexts
3. Check Front Matter for required fields (`area`, `related`):
   - If `area` is missing: add `area: governance` (default for root-level index documents)
   - If `related` is missing: add `related: []`
4. Check for `## Keywords` section; if missing, add:
   ```markdown
   ## Keywords
   
   <placeholder>
   ```
5. Check for `## Related Documents` section; if missing, add:
   ```markdown
   ## Related Documents
   
   <placeholder>
   ```
6. Validate YAML Front Matter parses without errors
