## Goal

Implement REQ-001 (include decorator lines in the `measure` and `_node_index` node span so `extract` moves decorated nodes verbatim) and REQ-002 (make `compare` report a moved function/class whose decorators differ) in `tools/module_nodes.py`, with no change to public signatures, option names, or exit codes.

## Scope
**Release unit**: N/A: not part of a release unit
In scope: modify the private helpers `measure`, `_node_index`, and `_normalize` in `tools/module_nodes.py`. No public API, option name, or exit-code change.

## Assumptions
- `node.decorator_list` is non-empty exactly when the node has decorators, and decorator line numbers are 1-based like `node.lineno` (Plan assumption 1).
- Not every top-level node carries `decorator_list` (only class/function nodes do), so the span clamp must use `getattr(node, "decorator_list", [])` to stay safe for other module-body statement kinds.
- Including the decorator list in `compare`'s normalized dump does not regress undecorated nodes: both sides keep an empty `decorator_list` and take the body-only dump path, so their dumps stay equal. This corrects the Plan's original "preserve the decorator list" wording after adversarial verification showed `_normalize` dumps only `node.body`, making the original assignment a no-op on the output.
- Decorators that transfer verbatim on a move apply equally at the destination, so identical decorators do not produce a false `DIFFERS` (Plan assumption 3).

## Design decisions
- Clamp the span start down to the earliest decorator line in both `measure` and `_node_index`: `start = node.lineno` when there are no decorators, else `min(node.lineno, min(d.lineno for d in node.decorator_list))`.
- In `_normalize`, drop the no-op `node.decorator_list = []` and prepend `ast.dump(node.decorator_list, indent=1)` to the body dump only when `node.decorator_list` is non-empty, so differing decorators change the dump while undecorated nodes keep the unchanged body-only dump.

### Method
- `measure` (`tools/module_nodes.py`, line 68): replace `start = node.lineno` with a decorator-aware start using `getattr(node, "decorator_list", [])`.
- `_node_index` (`tools/module_nodes.py`, line 112): replace the `node.lineno` start in the returned tuple with the same decorator-aware start. `_extract_lines` inherits this because it reads `_node_index` and slices `lines[start - 1 : end]`.
- `_normalize` (`tools/module_nodes.py`, lines 322-331): remove `node.decorator_list = []`; build the body dump once; return the decorator-prefixed dump when `node.decorator_list` is non-empty, else the body dump.
### Details
- `measure` — replace line 68 `start = node.lineno` with:
  ```python
  decorators = getattr(node, "decorator_list", [])
  start = node.lineno if not decorators else min(node.lineno, min(d.lineno for d in decorators))
  ```
  Keep `end = node.end_lineno or start` and the rest of `measure` unchanged.
- `_node_index` — replace line 112 `index[node.name] = (node.lineno, node.end_lineno or node.lineno)` with:
  ```python
  decorators = getattr(node, "decorator_list", [])
  start = node.lineno if not decorators else min(node.lineno, min(d.lineno for d in decorators))
  index[node.name] = (start, node.end_lineno or start)
  ```
- `_normalize` — remove the `node.decorator_list = []` line (line 325) and replace the final `return` (line 331) with:
  ```python
  def _normalize(node: ast.FunctionDef, injected: set[str]) -> str:
      node.args.args = [a for a in node.args.args if a.arg != "self"]
      node.body = _strip_docstring(node.body)
      for stmt in node.body:
          _SelfToName().visit(stmt)
          if injected:
              _DropInjectedArgs(injected).visit(stmt)
      ast.fix_missing_locations(node)
      body_dump = ast.dump(ast.Module(body=node.body, type_ignores=[]), indent=1)
      if node.decorator_list:
          return f"{ast.dump(node.decorator_list, indent=1)}\n{body_dump}"
      return body_dump
  ```
  Existing compare tests use undecorated functions, so both sides take the body-only branch and their dumps are byte-identical to before (no regression). Identical moved decorators produce identical prefixes (no false `DIFFERS`).
