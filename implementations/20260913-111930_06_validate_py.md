## Goal

Route FATAL error output in validate.py to stderr via `write_stderr()` method from the unified `OutputPort` Protocol.

## Scope

- Modify `scripts/agent/workflow/validate.py`: Route FATAL error output to stderr via `write_stderr()`

## Assumptions

- validate.py:L45 contains `print(..., file=sys.stderr)` for FATAL error output
- Only FATAL errors currently go to stderr in validate.py; OK messages go to stdout
- The scope is limited to error output, not all output
- `OutputPort.write_stderr(text)` will be added as part of the protocol merge (handled in output_port.py document)

## Design decisions

- Replace `print(error_msg, file=sys.stderr)` with `self._out.write_stderr(error_msg)`
- Default `write_stderr` implementation writes to `sys.stderr` — preserves current behavior
- Note: only FATAL errors go to stderr; OK messages continue going to stdout

## Alternatives considered

- Keeping `print(..., file=sys.stderr)` for stderr routing: rejected because it bypasses the unified `OutputPort` Protocol and creates inconsistency
- Having all output go through stderr: rejected because it would change user-facing behavior and break existing expectations
