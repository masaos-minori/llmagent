## Design decisions

- **Keep the invariant set (INV-01..INV-04) stable.** The ADR keeps the same four
  invariants; only their backing controls/tests change. So the index row still reads
  "INV-01 to INV-04" — the refresh is in the verification-status cell, not the
  invariant list.
- **Make the verification cell name the new controls.** Replace the generic
  "covering INV-01 through INV-04" note with the specific new coverage: the write-tool
  allow-list (INV-01) and the destination-based protected-branch rejection (INV-03),
  plus the retained INV-02/INV-04 coverage.

## Alternatives considered

- **Add new index rows for INV-01/INV-03.** Rejected: ADR-012 is one invariant group
  (INV-01 to INV-04) on one row; the plan asks to refresh the existing entries, not
  split them.
