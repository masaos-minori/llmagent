# Implementation Procedure: scripts/shared/tool_constants.py

## Goal
Unify the derivation direction of the `RAG_*` and `CICD_*` TOOLS/READ/WRITE frozenset groups
in `scripts/shared/tool_constants.py` so they derive the umbrella `*_TOOLS` set from literal
READ/WRITE subsets — matching the pattern already used by `GIT_TOOLS` and `GITHUB_TOOLS` —
with zero membership change to any exported frozenset or to `get_all_mcp_tool_names()`.

## Scope
- In scope: rewrite the `RAG_*` block (current lines 52-59, 73-74) and the `CICD_*` block
  (current lines 61-71) in `scripts/shared/tool_constants.py` so `RAG_READ_TOOLS` /
  `CICD_READ_TOOLS` become the literal frozensets and `RAG_TOOLS` / `CICD_TOOLS` become the
  derived unions (`RAG_READ_TOOLS | RAG_WRITE_TOOLS`, `CICD_READ_TOOLS | CICD_WRITE_TOOLS`).
  Add a short inline comment near `MDQ_TOOLS`/`MDQ_WRITE_TOOLS` (currently lines 76-89)
  documenting that it was reviewed and intentionally left as a two-set group.
- Out of scope: `GIT_*` (lines 92-112), `GITHUB_*` (lines 128-166), `READ_TOOLS`,
  `WRITE_TOOLS`, `DELETE_TOOLS`, `SHELL_TOOLS`, `WEB_SEARCH_TOOLS`, and
  `get_all_mcp_tool_names()` (lines 169-186) — none of these change shape or membership.
  No consumer file (`scripts/agent/tool_policy.py`, `scripts/shared/tool_registry.py`,
  `scripts/shared/tool_executor_helpers.py`, `scripts/shared/route_resolver.py`, etc.) is
  edited; they only consume frozenset values, which are unchanged.

## Assumptions
- The canonical direction is "derive the umbrella `*_TOOLS` set from the literal READ/WRITE
  subsets," matching the majority shape already present (`GIT_TOOLS`, `GITHUB_TOOLS`).
- No new `MDQ_READ_TOOLS` is introduced — `MDQ_TOOLS`/`MDQ_WRITE_TOOLS` is a two-set group,
  not a three-set TOOLS/READ/WRITE triple, so there is nothing to unify there.
- Zero membership change is a hard constraint: every exported frozenset must contain exactly
  the same elements before and after the edit.

## Design decisions
- Transcribe `RAG_READ_TOOLS` as the literal `{"rag_run_pipeline", "rag_debug_pipeline",
  "rag_list_documents"}` (the current result of `RAG_TOOLS - RAG_WRITE_TOOLS`), keep
  `RAG_WRITE_TOOLS = frozenset({"rag_delete_document"})` unchanged, and set
  `RAG_TOOLS = RAG_READ_TOOLS | RAG_WRITE_TOOLS`.
- Transcribe `CICD_READ_TOOLS` as the literal `{"get_workflow_runs", "get_workflow_status",
  "get_workflow_logs"}` (the current result of `CICD_TOOLS - CICD_WRITE_TOOLS`), keep
  `CICD_WRITE_TOOLS = frozenset({"trigger_workflow"})` unchanged, and set
  `CICD_TOOLS = CICD_READ_TOOLS | CICD_WRITE_TOOLS`.
- Preserve the existing top-to-bottom ordering convention (READ/WRITE literals defined before
  the derived umbrella), matching how `GIT_READ_TOOLS`/`GIT_WRITE_TOOLS`/`GIT_TOOLS` are
  ordered at lines 92-112.

## Alternatives considered
- N/A — the plan explicitly specifies the union-of-literals direction as the target; the
  opposite direction (deriving READ by subtraction, the current state) is what is being
  removed, not an alternative to weigh.
