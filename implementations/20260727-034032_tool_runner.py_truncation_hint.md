## Goal

## Design

Based on inspection of `tool_runner.py`:
```python
# Current (already dynamic):
def _apply_turn_char_limit(llm_text, turn_chars, limit):
    if limit > 0 and (turn_chars + len(llm_text)) > limit:
        omitted_chars = len(llm_text)
        omitted_lines = len(llm_text.splitlines())
        return turn_limit_hint(omitted_chars, omitted_lines, limit)
    return llm_text

# turn_limit_hint already generates:
f"[Result omitted: per-turn tool result limit reached. Omitted result: {omitted_chars} chars, {omitted_lines} lines. Configured per-turn limit: {limit} chars.]"
```

The code already calculates omitted characters and lines dynamically. The implementation procedure confirms this behavior is correct.
