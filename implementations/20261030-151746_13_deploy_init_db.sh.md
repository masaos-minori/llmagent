## Design decisions

- Insert two `--apply` calls with the same `uv run "${UV_PROD_FLAGS[@]}" python` pattern as the existing invocations: `eventbus/migrate.py --apply` and `db/migrate_db.py --apply`, before the table and shape checks.
- Add an optional, off-by-default drill hook gated by an environment variable (for example `RUN_RECOVERY_DRILL=1`) that runs `db/recovery_drill.py` and prints the artifact path; frequency and ownership stay open (UNK-01).

## Alternatives considered

- Always run the drill: rejected, `rotate_all_dbs` writes archives of every database on each deploy and the schedule is an open owner decision.

## Compatibility considerations

- With no registered path beyond the ledger baseline, a fresh deployment is a no-op migration; an existing deployment migrates eventbus 3 to 4 behind a verified backup.

## Security considerations

- The CLIs use local files only; the drill hook is opt-in and writes inside the archive directory.

## Rollback considerations
