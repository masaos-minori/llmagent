## Goal

Register the two taxonomy markers so the suite can be selected by kind (REQ-001 — markers
selectable with `-m` under the existing parallel run).

## Scope
**Release unit**: taxonomy mechanism

## Assumptions

- Confirmed in Step 3a: the `markers` list is `pyproject.toml:145-148` and registers only
  `integration` and `repo_scan`.
- Registration happens only here; `tests/conftest.py`'s `pytest_configure` (`:298-304`) is a reference
  file and stays unchanged, so there is one source of marker registration.

## Design decisions

- Marker names are `characterization` and `contract`, matching the Plan's vocabulary, and each entry
  carries a one-line description in the same style as the existing entries so `-m` help output stays
  readable.

## Alternatives considered

- Registering in `tests/conftest.py`'s `pytest_configure` — rejected: two registration sources drift,
  and the Plan keeps conftest unchanged.

## Implementation
### Target file
`pyproject.toml`
### Procedure

  `characterization: tests that record observed behavior with no requirement source` and
  `contract: tests whose assertions are traceable to a requirement source and carry that citation`.

### Method
