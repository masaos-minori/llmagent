### Method

   ```
   1. Before creating an ad hoc script or using an equivalent generic command, `tools/`
      MUST be inspected for a tool that already covers the need.
   ```

2. Append:
   ```

      that the workflow's `Toolchain` section does not cover.
   ```

workflow... MAY be considered — every tool under `tools/` MUST NOT be run indiscriminately") —
rule 2 bounds which tools may be *run*; this clarification only bounds how often the
*inspection* itself must be repeated.
