## Assumptions
- Verified on 2026-11-06 (Step 3a): the `check-module-size` hook runs `uv run python -m tools.check_module_size` with `pass_filenames: false` and `files: ^(scripts/.*\.py|tools/check_module_size(_baseline\.txt|\.py))$`; the `drift` hook runs `uv run python -m tools.run_validation_gates drift` with `files: ^(\.pre-commit-config\.yaml|routing\.md|tools/run_validation_gates\.py)$`. `drift` derives a checker id from each hook entry by rewriting `python -m tools.<name>` to `tools/<name>.py`; the new hook's id is `check_module_size:tools`, equal to the new gate's id, so hook parity holds only when the gate and the `routing.md` row from the sibling procedures land in the same commit.
- Sequencing: this Plan lands last among the `tools/` Plans; the procedures of `toolcommon001` and `toolwrite001` (archived with their procedures generated) are expected to have executed first, because they edit `run_validation_gates.py` and `manage_workitem_stage.py` before this Plan moves code from them.
- No other open Plan targets this file.
