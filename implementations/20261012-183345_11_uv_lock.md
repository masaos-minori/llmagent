## Goal

Lock `PyYAML` as a direct dependency of `llmagent` in `uv.lock` so the declaration added to `pyproject.toml` (its own row) is reflected in the resolved lockfile. Implements `REQ-005` / AC-07.

## Scope

Regenerates the `llmagent` package entry in `uv.lock` only. The regeneration must not otherwise change the lockfile graph.

## Assumptions

- `uv.lock` lists the `llmagent` package with 13 direct dependencies and no `pyyaml` (confirmed: `pyyaml` appears only as a transitive dependency of `bandit`/`libcst`/`pre-commit`/`schemathesis`).
- `pyproject.toml` gains `PyYAML>=6.0` in `[project] dependencies` in its own row before this step runs.

## Design decisions

- Regenerate with `uv lock` (the project's lock tool) rather than hand-editing the TOML, so the full dependency graph stays consistent and `uv lock --check` passes.

## Alternatives considered

- Hand-inserting a `pyyaml` entry into the `llmagent` dependencies array: rejected — it would desynchronize the lockfile from the resolver graph and fail `uv lock --check`.

## Implementation

### Target file

`uv.lock`

### Procedure

Regenerate the lockfile after the `pyproject.toml` change, then confirm the new direct dependency.

### Method

1. Ensure `pyproject.toml` contains `PyYAML>=6.0` in `[project] dependencies` (its own row).
2. Run `uv lock` to regenerate `uv.lock`.
3. Confirm the `llmagent` package entry now lists `pyyaml` among its direct dependencies.

### Details

- On a low-memory host, prefer `uv lock --no-sync` (or run after `uv sync`) to avoid materializing the full environment; the lockfile update does not require a sync.

## Compatibility considerations

- Regenerating the lock may reorder or re-resolve unrelated entries if the resolver picks different transitive versions; review the diff and keep it minimal. If unrelated churn appears, pin the offending transitive version in `pyproject.toml` or revert and retry.

## Validation plan

- `uv lock --check` passes.

- `uv run python -c "import yaml"` resolves in the project environment.

## Completion criteria

- `uv.lock` lists `pyyaml` as a direct dependency of `llmagent`; `uv lock --check` passes; the diff is limited to the dependency graph around the new entry.
