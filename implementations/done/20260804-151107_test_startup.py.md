# Implementation Procedure: tests/agent/test_startup.py

## Goal
Extend the `_make_startup()` helper to accept an optional `shutdown_event`, and add tests
covering: pre-loop shutdown check, mid-retry-delay shutdown interruption, no-behavior-change
when `shutdown_event` is passed but never set, and `StartupInterrupted` propagating through
`run()`'s existing rollback `except` block like any other setup exception.

## Design decisions
- Extend `_make_startup()` with `shutdown_event: asyncio.Event | None = None` as a new trailing
  keyword parameter, forwarded to `StartupOrchestrator(ctx, view, shutdown_event=shutdown_event)`
  — mirrors the production constructor change 1:1 and keeps all ~9 existing call sites
  unmodified (default `None`).
- Use a real `asyncio.Event` (not a `MagicMock`) for the new shutdown-interruption tests, since
  `_interruptible_sleep()` calls `.wait()`/`.is_set()` on it directly and the production code's
  `asyncio.wait({...})` race requires an awaitable, not a mock.
- Simulate "shutdown fires mid-delay" via a short `asyncio.sleep()`-based background task (e.g.
  `asyncio.get_event_loop().call_later` or a small helper coroutine that sleeps briefly then
  calls `event.set()`) racing against the production code's own delay, rather than a mocked
  `start_http_subprocess` side effect — keeps the test focused on the delay-race behavior itself.

## Alternatives considered
- Patch `asyncio.sleep` globally to make the retry delay instant, then assert
  `StartupInterrupted` is raised when `shutdown_event` is pre-set: viable for the pre-loop-check
  test (event set before the call) but insufficient alone for the mid-delay case, since a
  pre-patched `asyncio.sleep` would make the "full delay elapses" branch indistinguishable from
  the "shutdown fires first" branch. Both approaches are used together: pre-set for the
  simple case, a background timer for the promptness assertion.
- Mock `_interruptible_sleep()` directly to return `True`/`False`: rejected for the primary
  interruption tests — would test the mock, not the actual race logic; reserved only for tests
  where the sleep behavior itself is not under test (none currently needed).

     `asyncio.Event()`; assert `_start_servers()` behaves identically to the `shutdown_event=None`
