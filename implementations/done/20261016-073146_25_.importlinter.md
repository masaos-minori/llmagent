## Design decisions

- Remove the exception, not the contract. The exception is the `ignore_imports` block; the contract is the
  guard `REQ-017` is meant to leave standing. Deleting the whole block would drop the only static check
  that stops a future Agent module from importing a server's config model, and the reverse-direction
  contract (`mcp_servers-no-agent`, `:49-55`) does not cover that direction.
- Restate the `name` line (`:69`) as `No agent module imports MCP server config models`. The current text
  asserts the existence of a security audit loader that row `20` deletes, so leaving it would make the
  contract's own description false.
- Keep the contract id `[importlinter:contract:agent-mcp-config-models]` unchanged. The id appears only in
  `.importlinter:68` and in ADR prose; keeping it stable minimizes churn in `docs/10_adr/adr_02_002_*`
  (row `37`). **Needs confirmation**: whether the project prefers the id renamed to
  `agent-no-mcp-config-models` for readability, which row `37` would then mirror.
- The Plan's validation wording at `plans/20261015-112526_plan.md:408` ("Passes with
  `agent-mcp-config-models` removed") is amended to "Passes with the `agent-mcp-config-models`
  `ignore_imports` grant removed" so the table matches this decision before execution.

## Alternatives considered

- Delete the whole contract block (`:68-82`) — rejected: it is the static enforcement of `INV-06`/`REQ-017`,
  and the rewritten `tests/agent/test_security_audit_config_isolation.py` (row `27`) is a source-text scan
  that a rename or a dynamic import could evade, while import-linter analyzes real import graphs.
- Keep `ignore_imports` but narrow it to a test-only module — rejected: no test imports those models
  through `agent`, and a grant with no user is dead configuration.
- Move the guard into `shared-is-leaf` (`:19-28`) — rejected: that contract's source module is `shared`,
  not `agent`, and widening it would not cover `agent`.
- Add a new `forbidden` contract for all of `mcp_servers` against `agent` — rejected: the dependency
  hierarchy comment at `.importlinter:13` documents `agent → mcp_servers (installer only)` as permitted,
  and `mcp_tool_discovery.py:49` already relies on `mcp_servers.server`.
