# Implementation Procedure: Fix SIGINT Handler Race Condition During Shutdown

## Goal

Fix both race conditions in signal handler management during shutdown_all(): prevent restoring a handler that was never replaced, and avoid invalid `signal.signal(signal.SIGINT, None)` call.

## Scope

**In-Scope:**
- Track whether the new handler was successfully installed before attempting restoration
- Only restore the original handler if replacement succeeded

**Out-of-Scope:**
- Modifying the `_absorb_sigint_during_shutdown` handler itself
- Adding additional signal handlers
- Changing the subprocess termination logic

## Assumptions

1. When `signal.signal()` raises ValueError, the original handler remains unchanged
2. When `signal.getsignal()` returns None, it means the default handler is active and cannot be restored
3. The existing try-except around `signal.getsignal()` already handles non-main-thread cases

## Design decisions

- Add `handler_installed = False` variable before signal handler setup
- Set `handler_installed = True` only after successful `signal.signal()` installation
- In finally block, change from `if old_sigint is not None:` to `if handler_installed and old_sigint is not None:`
- This ensures we only restore when we actually replaced the handler AND have a valid handler to restore

## Alternatives considered

- Using context manager for signal handler lifecycle → rejected; adds complexity without clear benefit
- Making signal handler management a separate class → deferred; low priority given current usage
- Ignoring ValueError from signal.signal() entirely → rejected; masks real issues

### Method

Add `handler_installed` flag in `shutdown_all()`:

```python
async def shutdown_all(self) -> None:
    """Terminate all HTTP subprocess servers and clear internal state.

    Absorbs a second SIGINT that arrives while cleanup is already running so a user
    pressing Ctrl-C twice cannot abort the loop and orphan the remaining subprocesses.
    """
    old_sigint: object | None = None
    handler_installed = False  # NEW: track whether handler was successfully installed
    try:
        old_sigint = signal.getsignal(signal.SIGINT)
    except ValueError:
        # Not on the main thread — proceed without the guard rather than fail shutdown.
        old_sigint = None

    if old_sigint is not None:
        try:
            signal.signal(signal.SIGINT, self._absorb_sigint_during_shutdown)
            handler_installed = True  # NEW: mark handler as installed
        except ValueError as exc:
            # signal.signal() failed — do not install the guard handler.
            # Keep old_sigint intact so the finally block can restore the original handler.
            logger.debug(
                "Lifecycle: could not install SIGINT guard handler: %s",
                exc,
            )

    try:
        keys = list(self._http_procs.keys())
        for key in keys:
            proc = self._http_procs.pop(key, None)
            if proc is None:
                continue
            if proc.poll() is not None:
                logger.debug("Lifecycle: %r already exited; removing entry", key)
            else:
                try:
                    await self._terminate_with_timeout(proc, key, timeout=5.0)
                except (OSError, TimeoutError) as e:
                    logger.warning(
                        "Lifecycle: error stopping HTTP subprocess %r: %s", key, e
                    )
            self._http_pgids.pop(key, None)
            stderr_fh = self._stderr_files.pop(key, None)
            if stderr_fh is not None:
                try:
                    stderr_fh.close()
                except OSError as close_err:
                    logger.warning(
                        "Lifecycle: error closing stderr log for %r: %s",
                        key,
                        close_err,
                    )
        self._stderr_log_paths.clear()
        self._last_health_check.clear()
    finally:
        if handler_installed and old_sigint is not None:  # CHANGED: use handler_installed flag
            signal.signal(signal.SIGINT, old_sigint)
```
