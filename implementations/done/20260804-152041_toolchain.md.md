# Implementation: rules/toolchain.md (correct stale "MCP documentation consistency" section)

## Goal

Replace `rules/toolchain.md` lines 111-127 (the `## MCP documentation consistency` section) so
its example `--skip` command and check-list description match the current
`tools/check_mcp_docs_consistency.py` implementation. Documentation-only; no source or config
file changes.

## Scope

**Out:**

- Any change to `docs/*.md`.

## Assumptions

1. `tools/check_mcp_docs_consistency.py`'s `skip_choices` list (grep-verified at line 241) is the
   current, authoritative set of valid `--skip` values: `links`, `removedfiles`, `commanddrift`,
   `portdrift`, `tooldrift`, `filerefs`, `funcrefs`. Re-verify with
   `grep -n "skip_choices" -A 10 tools/check_mcp_docs_consistency.py` immediately before editing,
   in case the list has changed again since this document was written.
2. `check_agent_docs_consistency.py` imports only `check_broken_internal_links`,
   `check_command_drift`, `check_removed_file_references` from `tools/_docs_consistency_lib.py`
   (grep-verified) — it does NOT also use `check_file_path_references`/`check_function_references`.
   The replacement text below must not claim all generic checks are shared between both modules.

## Design decisions

- Use `portdrift`/`tooldrift` as the concrete example `--skip` values (the two domain-specific,
  ERROR/WARNING checks), matching the source requirement's suggested example.
- List checks by their actual Python function name (`check_port_drift`, `check_tool_name_drift`)
  with their real severity (`ERROR` for port drift, `WARNING` for tool-name drift, per source),
  and group the generic library checks separately with an accurate (not overclaiming) note about
  which of them `check_agent_docs_consistency.py` actually shares.

## Alternatives considered

- Listing every one of the 7 `skip_choices` values in the example command — rejected as noisy;
  2 concrete examples plus the full checklist below is sufficient for a reference doc.

## Implementation

### Target file

`rules/toolchain.md`

### Procedure

1. Re-run `grep -n "skip_choices" -A 10 tools/check_mcp_docs_consistency.py` to reconfirm the
   valid `--skip` choices have not drifted since this document was written.
2. Open `rules/toolchain.md` and locate the `## MCP documentation consistency` section
   (currently lines 111-127).
3. Replace the section body with:

   ```markdown
   ## MCP documentation consistency

   \`\`\`bash
   # Run all checks
   uv run check-mcp-docs

   # Skip specific checks
   uv run check-mcp-docs --skip portdrift --skip tooldrift
   \`\`\`

   The `check-mcp-docs` entry point is registered in `pyproject.toml`. It verifies:
   - `check_port_drift` (ERROR) — doc-mentioned port next to a `<name>-mcp` token vs. the port
     assigned in `config/agent.toml`'s `[mcp_servers.*]` sections
   - `check_tool_name_drift` (WARNING) — backtick-quoted tool name on a "Tools:"/"ツール:" line vs.
     live `"name": "..."` entries in `scripts/mcp_servers/**/*.py` `TOOL_LIST` definitions
   - Generic checks provided via `tools/_docs_consistency_lib.py` (also used by
     `tools/check_agent_docs_consistency.py` for the links/removed-file/command-drift checks):
     broken internal Markdown links, removed-legacy-doc-file references, slash-command drift vs.
     `command_defs_list.py`, `scripts/`-path reference existence, and backtick-quoted
     function-reference existence
   ```

### Method

Direct text replacement of the identified line range (no scripting required — single-file,
single-section edit).
