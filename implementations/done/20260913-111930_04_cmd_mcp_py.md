## Design decisions

- Replace string-based table formatting with structured `write_table()` calls — pass headers and row data directly to the Protocol
- `write_table()` already exists on `OutputPort` Protocol and is tested — reuse it rather than maintaining custom formatting logic
- The visual output format must remain identical to pre-refactor (REQ-009)

## Alternatives considered

- Keeping both `_format_*` functions and just changing how they write output: rejected because custom formatting logic duplicates what `write_table()` already does
- Creating a new MCP-specific table formatter: rejected because adds unnecessary complexity when `write_table()` covers the need
