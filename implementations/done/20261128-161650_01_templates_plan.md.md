## Goal

Add the row-order rule to `templates/plan.md` so a Plan's `Implementation Target Files`
row order carries the implementation sequence (REQ-001: rows ordered by implementation
sequence, `Implementation steps` cites rows in that order, canonical order lives in the
table).

## Scope
**Release unit**: N/A: not part of a release unit

- **In-Scope**: three text-only additions inside existing sections of `templates/plan.md`:
  the `Implementation Target Files` rules, the `Implementation steps` guidance, and the
  `Scope` section's `Dependencies` bullet.
- Text-only edit: no new section, heading, table column, tool, or test.

## Assumptions

- The 7884 B headroom (`templates/plan.md` 12596 B, ceiling 20480 B, measured
  2026-11-28, `tools/check_skill_size.py --headroom`) fits the three additions (~500-700 B).

  against this template's fenced block; all additions are inside existing sections.
- Mechanical row-order checking stays out of scope (Plan UNK-01: follow-up Issue).

## Design decisions

- State the rule where Plan writers read it: the `Implementation Target Files` rules
  bullet list, matching the consumer wording in
  `skills/plan-to-implementation-procedure/workflow.md` "Workflow position" (`seq` =
  1-indexed, zero-padded row position).
- Deferral is placed in the `Scope` section's `Dependencies` bullet: `Dependencies`
  records ordering dependencies between Plans, never a per-file execution order that
  contradicts the table.

### Procedure
1. Measure `wc -c templates/plan.md` (before).
2. Add one bullet to the `Implementation Target Files` rules list stating the row-order rule.
3. Add one sentence to the `Implementation steps` guidance requiring row-order citations.
4. Extend the `Scope` section's `Dependencies` bullet with the deferral clause.
5. Re-measure `wc -c templates/plan.md` (after) and confirm it is at or under 20480 B.

### Method
Insert text with targeted edits inside the three existing locations; do not touch
headings, the table header row, the fenced-block structure, or any other section. Keep
every new path citation in backticks (`tools/check_workitem_structure.py` reports
plain-path citations).

### Details
- New rule bullet (append to the rules list after the backtick-rule bullet):
  `- Order rows by implementation sequence: row N is the Nth implementation unit, and`
  `plan-to-implementation-procedure` derives each procedure's `seq` from this 1-indexed
  position, so the rows of a `Frozen` table MUST NOT be reordered. Canonical
  implementation order lives in this table.`
- `Implementation steps` guidance: add to the existing paragraph: "Cite rows of
  `Implementation Target Files` in 1-indexed row order; the step sequence MUST match the
  table's row order."
- `Scope` `Dependencies` bullet: append to the bracketed guidance: "Canonical per-file
  implementation order lives in `Implementation Target Files` row order; this line and
  its `Depends on` bullets record only ordering between Plans and Issues."
