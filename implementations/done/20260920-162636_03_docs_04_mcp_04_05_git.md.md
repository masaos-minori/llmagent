independent statements joined by a semicolon: (a) `git_show` is truncated at 8000
characters — not stated anywhere else in this file, must be retained; (b) `git_log`'s

wording ("remove the duplicate default-value sentence") from a whole-sentence removal
to a narrower edit: keep both independent facts, but replace the repeated literal `50`
with a reference to "the table above" so the config default is stated exactly once in
this file.
