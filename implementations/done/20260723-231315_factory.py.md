## Goal

Add public API method `_ServerLifecycleRouter.get_subprocess_server_configs()` to expose `(key, McpServerConfig)` pairs for HTTP subprocess-mode servers. This enables post-startup health verification without traversing private attributes.

## Scope

**In-Scope**:
- Add `get_subprocess_server_configs()` method to `_ServerLifecycleRouter` class
- Return list of `(server_key, McpServerConfig)` tuples for all HTTP subprocess-mode servers

**Out-of-Scope**:
- Modifying existing lifecycle methods
- Adding health check logic (covered in startup.py document)
- Changing any other public API surface

## Assumptions

1. The method only needs to filter by `transport == TransportType.HTTP` and `startup_mode == StartupMode.SUBPROCESS`.
2. No additional filtering (e.g., by running state) is needed at this stage.
3. `McpServerConfig`, `StartupMode`, and `TransportType` are already imported in factory.py.

## Design decisions

- **Return tuple list instead of dict**: Using `list[tuple[str, McpServerConfig]]` avoids exposing internal dict structure and allows future reordering without breaking callers.
- **No caching**: The method filters the config dict each call; the number of servers is small so performance impact is negligible.
- **Private class method**: Method stays on `_ServerLifecycleRouter` (private class) since it's an internal API used only by `StartupOrchestrator`.

## Alternatives considered

- **Expose via `AgentContext.services_required.lifecycle` property**: Would require changing the type annotation of the lifecycle service interface. Rejected because it adds unnecessary coupling.
- **Filter in caller (`StartupOrchestrator`)**: Would duplicate the filter logic across multiple callers. Rejected because the filter criteria is lifecycle-specific and should be encapsulated.
- **Return `dict[str, McpServerConfig]`**: Simpler than tuple list but exposes internal dict structure. Chose tuple list for better abstraction.

     ```python
     def get_subprocess_server_configs(self) -> list[tuple[str, McpServerConfig]]:
         """Return (key, config) pairs for all HTTP subprocess-mode servers."""
         return [
             (key, cfg)
             for key, cfg in self._server_configs.items()
             if cfg.transport == TransportType.HTTP
             and cfg.startup_mode == StartupMode.SUBPROCESS
         ]
     ```
