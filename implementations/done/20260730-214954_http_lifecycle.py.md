# Implementation Procedure: Deduplicate File Handle Cleanup Logic in Health Check Paths

## Goal

Extract shared file handle cleanup logic from early-exit and timeout paths into a dedicated private method `_cleanup_server_resources()` to eliminate duplication.

## Scope

**In-Scope:**
- Create `_cleanup_server_resources(server_key)` method in `HttpServerLifecycleManager`
- Replace inline cleanup code in both early-exit path (lines 333-336) and timeout path (lines 366-370) with calls to this method
- Ensure the method returns stderr content so callers can log it before cleanup

**Out-of-Scope:**
- Modifying the getpgid failure path cleanup (separate issue)
- Adding retry logic to either path
- Changing the order of cleanup operations

## Assumptions

1. The three cleanup operations (read stderr tail, pop/close stderr file handle, pop log path) must always execute in the current order
2. The method should return the stderr content string so callers can include it in error logs
3. Both callers already read stderr tail before cleanup, so the method could optionally do this internally

## Design decisions

- Method name: `_cleanup_server_resources(server_key: str) -> str` returning stderr content
- Method performs three operations in order: read stderr tail, pop/close stderr file handle, pop log path
- Method returns stderr content to allow callers to log it after cleanup
- getpgid failure path (lines 318-320) excluded from refactoring per plan scope

## Alternatives considered

- Inline helper that only closes handles without reading stderr → rejected; callers need stderr content for logging
- Shared context manager for cleanup → deferred; adds complexity for simple sequential operations
- Merge getpgid failure path into same method → deferred; different cleanup semantics (no stderr read needed there)

### Method

Add new private method to `HttpServerLifecycleManager`:

```python
def _cleanup_server_resources(self, server_key: str) -> str:
    """Read stderr tail, close stderr file handle, and remove log path for a server.
    
    Returns the stderr content string for caller logging.
    """
    stderr_content = self._read_stderr_tail(server_key)
    fh = self._stderr_files.pop(server_key, None)
    if fh is not None:
        fh.close()
    self._stderr_log_paths.pop(server_key, None)
    return stderr_content
```
