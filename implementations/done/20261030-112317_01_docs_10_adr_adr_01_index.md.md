## Design decisions
- Vocabulary and exception process live in prose paragraphs before the table so the
  checker can parse rules without re-parsing narrative; the exception is referenced
  from the row's Verification Status cell as a named marker `Exception: <id>`.
- Cadence/expected-evidence are appended inside the existing Verification Status cell
  text (`Cadence: ...; Expected evidence: ...`) instead of new table columns — the
  checker splits cells already (`_split_row` in `tools/check_adr_invariant_matrix.py:217`),
  and new columns would reflow all 37 data rows.

## Alternatives considered

  the other three plans that touch this file, and body↔index containment rules compare
  cell text.
