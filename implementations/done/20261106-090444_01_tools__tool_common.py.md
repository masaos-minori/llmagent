## Design decisions
- The module starts with `from __future__ import annotations` and uses only the standard library, because `deploy/*.sh` runs `tools/manage_binaries.py` (an importer after migration) with the system `python3`, which must be able to import it.
- Module surface is exactly `REPO_ROOT`, `run_git` (new), `EXIT_OK`, `EXIT_FINDINGS` (new), `EXIT_ERROR` (new) (all `(new)`), standard library only, so it creates no import cycle (`tools/` is outside `.importlinter`).
- `run_git` (new) has two `typing.overload` signatures keyed on `binary: Literal[False]` and `Literal[True]` so mypy types `stdout` as `str` or `bytes` at each call site; the body has the single `subprocess.run` of `["git", *args]` with `shell=False`, carrying the one `# nosec B603 B607` justification that the eight tools carry today.

## Alternatives considered
- A class wrapping git state: rejected, more surface than the Plan asks for.
- Resolving `git` through `shutil.which` inside the helper: rejected, `manage_binaries.py` keeps that behavior in its own thin adapter (its procedure), so other tools do not change.

5. Run the validation sequence for `tools/` files (`routing.md` "Adding a new tool").

### Method
- Text mode: `subprocess.run(["git", *args], cwd=cwd, capture_output=True, text=True, encoding="utf-8", errors="replace", check=check, timeout=timeout)`.
- Bytes mode: the same call without `text`, `encoding`, and `errors`.
- No `try/except`: `check=True` raises `CalledProcessError`, a missing git raises `FileNotFoundError`, a timeout raises `TimeoutExpired`; the helper never logs or prints.
- The docstring states the policy in four lines: modes, replacement of undecodable bytes in text mode, `cwd=None` meaning the process working directory, and exceptions propagating.

### Details
- Keep the nosec text in the existing form: `# nosec B603 B607 — fixed git argv, no shell, no user-built command` (`tools/check_suppression_justification.py` requires a rule code and an em-dash justification).
- No logging, no module-level state besides the constants, no function other than `run_git` (new) (the helper is not a dumping ground; Plan Risks).

### Companion test files
