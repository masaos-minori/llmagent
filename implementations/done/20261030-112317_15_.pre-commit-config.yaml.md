# Implementation Procedure: .pre-commit-config.yaml manifest-check hook

## Goal

Add a local pre-commit hook mirroring the adr hooks' pattern so manifest drift fails
before push (REQ-008).

## Scope

**In scope:**
- One new hook `manifest-check` in `.pre-commit-config.yaml`, following the
  `adr-invariant-matrix` (`:54-58`) / `adr-reference-scoped` (`:60-64`) shape:
  `language: system`, `pass_filenames: false`.

**Out of scope:**
- CI (doc 14); generator implementation (doc 05).

## Assumptions
- Verified at HEAD `124e340b4`: 131 lines; adr hooks at `:54` and `:60`; hook ids are
  also referenced by `tool-descriptions-sync` file filters (`:30-34`) — a new hook
  needs no change there because it reuses an existing tool entry point.
- Hook runs `python -m tools.generate_reference_table --check` extended manifest mode;
  entry uses the `python -m tools.<module>` convention of the neighboring hooks.

## Design decisions
- Reuse the generator's `--check` (extended per doc 05) rather than a new
  `tools/check_manifests.py` module: keeps one implementation of manifest drift logic
  and avoids a new `tools/` registration surface.

## Alternatives considered
- New dedicated checker module + hook: rejected — second implementation of the same
  comparison; plan row explicitly asks for a hook mirroring `:56`/`:62` pattern on the
  existing generator.

## Implementation
### Target file
`.pre-commit-config.yaml`

### Procedure
1. Insert after the `adr-structure` hook block (`:66-71`):

   ```yaml
   - id: manifest-check
     name: Check contract manifests against live sources
     entry: python -m tools.generate_reference_table --check
     language: system
     pass_filenames: false
     files: ^(registry/manifests/.*\.yaml|schemas/contract_manifest\.json|tools/generate_reference_table\.py|tools/_contract_manifests\.py|tools/check_adr_invariant_matrix\.py|config/agent\.toml|scripts/.*|docs/.*\.md)$
   ```

### Method
Config-only edit.

### Details
- `files:` filter limits the hook to paths that can invalidate a manifest; widened
  2026-10-31 to include `schemas/contract_manifest.json`, `tools/_contract_manifests.py`
  (doc 05 helper module) and `tools/check_adr_invariant_matrix.py` (source of the
  invariant_coverage manifest) alongside the original paths.

## Compatibility considerations
`uv run pre-commit run --all-files` already runs in CI (`.github/workflows/ci.yml`);
`--check` treats a missing committed manifest for a registered domain as drift (doc 05),
so this hook must land after the manifests are committed (implemented order: docs
05-13 first).
