## Goal
Remove the now-redundant `00_governance/` prefix from `docs/00_governance/00_index.md`'s
4 links to its now-sibling governance files, broken because `00_index.md` itself moved
into the same `docs/00_governance/` directory as those 4 files, implementing `REQ-005`.

## Scope
In scope: exactly the 4 links whose target starts with `00_governance/` and names one
of the 4 sibling governance files (`00_governance_01_documentation-policy.md`,
`00_governance_02_documentation-metadata.md`,
`00_governance_03_issue-and-uncertainty-management.md`,
`00_governance_04_documentation-checks.md`). Out of scope: this file's other links to
not-yet-created subfolders (`01_overview/`, `90_deployment/`, `21_rag/`, `22_mcp/`,
`23_agent/`, `24_eventbus/`, `40_shared/`, `10_adr/`) — confirmed pre-existing and
unrelated (those target subfolders belong to `docsreorg06`-`docsreorg16`, none of which
have landed; these links were already broken before this Plan's move and remain
out of scope for it).

## Assumptions
- The 4 sibling files (`00_governance_01`/`02`/`03`/`04`) now live in the same
  directory as `00_index.md` (`docs/00_governance/`) — confirmed via `ls
  docs/00_governance/`.
- `tools/check_docs_structure.py` resolves a `/`-containing link via plain
  `(path.parent / target).resolve()` — confirmed via Read — so
  `00_governance/00_governance_01_documentation-policy.md` resolves to
  `docs/00_governance/00_governance/00_governance_01_documentation-policy.md` (does not
  exist), while the bare filename `00_governance_01_documentation-policy.md` resolves
  correctly to the sibling file in the same directory.

## Design decisions
Use a bare filename for each of the 4 fixed links (not a `./`-prefixed relative path) —
matches this file's own other same-directory-sibling link style once the prefix is
removed, and is the simplest correct form for a same-directory reference.

## Alternatives considered
- Prefix with `./` instead of removing the directory component entirely (e.g.
  `./00_governance_01_documentation-policy.md`): rejected — functionally equivalent but
  unnecessary; a bare filename in the same directory is the established convention
  elsewhere in this repository's docs.
