## Goal
Secure command execution by resolving symlinks and validating against whitelist, and ensure empty commands raise an error.

## Scope
- `scripts/agent/http_lifecycle.py`

## Assumptions
- The current `_ALLOWED_COMMANDS` whitelist exists but doesn't resolve symlinks.
- Adding symlink resolution won't break existing functionality.
- Raising errors for empty/invalid commands is acceptable behavior.

## Design decisions
- Use `os.path.realpath()` to resolve symlinks before performing the whitelist check.
- Perform the empty command check at the beginning of the validation logic.

## Implementation
### Target file
`scripts/agent/http_lifecycle.py`

### Procedure
1. In `_start_http_server()`, add a check for `not cfg.cmd or not cfg.cmd[0]` and raise `HttpStartupError("Empty command configuration")` if true.
2. In the command validation section, replace the basename-based check with:
    a. Resolve the command path using `os.path.realpath(cfg.cmd[0])`.
    b. Verify the resolved path exists and is a regular file using `os.path.isfile()`. Raise `HttpStartupError` if not.
    c. Check if the resolved path is in `self._ALLOWED_COMMANDS`. Raise `HttpStartupError` if not.

### Method
Implement explicit validation for command presence, existence, type (regular file), and whitelist membership using absolute paths.

### Details
1. Ensure `import os` is present.
2. Update the validation block in `_start_http_server()` to include:
```python
        if not cfg.cmd or not cfg.cmd[0]:
            raise HttpStartupError("Empty command configuration")

        # Resolve symlinks to prevent bypass and get absolute path
        cmd_path = os.path.realpath(cfg.cmd[0])

        # Verify the resolved path exists and is a regular file
        if not os.path.isfile(cmd_path):
            raise HttpStartupError(
                f"Command not found or not a regular file: {cfg.cmd[0]}"
            )

        # Check against whitelist using the full absolute path
        if cmd_path not in self._ALLOWED_COMMANDS:
            raise HttpStartupError(
                f"Command '{cfg.cmd[0]}' (resolved to '{cmd_path}') is not in the allowed commands list."
            )
```
