## Goal

Add `[tool.mutmut]` `source_paths` configuration to `pyproject.toml` to unblock mutation testing.

## Scope

- **In-Scope**:
  - Verify `mutmut` configuration format against installed version's docs/help
  - Add `[tool.mutmut]` section with `source_paths = ["scripts"]` to `pyproject.toml`
  - Smoke test with `uv run mutmut run --paths-to-mutate scripts/mcp_servers/git/git_security.py`
  - Confirm mutation report is produced (killed/surviving/equivalent counts)
- **Out-of-Scope**:
  - Adding mutation tests for specific modules
  - Configuring mutation thresholds or exclusion patterns
  - Changes to any other `pyproject.toml` sections

## Assumptions

- `mutmut` 3.6.0+ reads `[tool.mutmut]` section from `pyproject.toml` when present
- `source_paths` is the correct key name (not deprecated `paths_to_mutate`)
- `["scripts"]` is the appropriate value for the project's layout

## Design decisions
