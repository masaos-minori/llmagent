## Implementation

### Target file

`docs/22_mcp/mcp_03_02_tool-registry.md`

### Procedure

1. In the "RuntimeToolRegistry and Live Discovery" paragraph, replace the final sentence
   "`status`, legacy singular `resource_scope`, and `enabled` are validated only if present."
   with: "`status` and `enabled` are validated only if present. A legacy singular
   `resource_scope` key on an entry is rejected as a schema error: it is no longer a valid
   field, and entries emitted by servers that still carry it are excluded per entry."

   known kinds, and that `resource_scope_keys` exist in `inputSchema.properties` — one enforcement
   point, matching AC-6's "names where presence is enforced".
