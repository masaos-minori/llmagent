## Goal

Make RAG ingestion safe under partial failure: ensure consistency checks run against an open DB connection, keep failed embedding chunks retryable, and provide operators with clear visibility into ingestion failures.

## Scope

**In-Scope:**
- Move `check_consistency()` inside the active DB context in `RagIngester.ingest_all()`
- Treat failed consistency checks as explicit error states
- Only move successfully ingested chunk files to `registered/`
- Keep embedding-failed chunks in `chunk/` or move them to `retry/`
- Optionally move invalid, non-retryable chunks to `failed/`
- Emit structured logs for failed chunks with URL, chunk_index, source_file, failure reason
- Consider writing `.error.json` metadata for failed chunks
- Ensure `embed_failed > 0` is visible in ingestion summary and operational logs

**Out-of-Scope:**
- Changes to existing successful ingestion behavior
- Changes to embedding service itself
- Changes to document parsing logic
- Changes to the SQLite schema

## Assumptions

1. Chunk files that fail embedding should remain in `chunk/` so they can be retried on the next ingestion run.
2. Invalid chunks (parse errors, validation failures) should be moved to `failed/` since they cannot be retried without manual intervention.
3. The `.error.json` metadata format should include: URL, chunk_index, source_file, failure reason, timestamp.
4. Consistency check failure should cause the entire ingestion to report an error state but not crash the process.

## Design decisions

- **Directory structure**: Create `retry/` and `failed/` subdirectories at same level as `chunk/` and `registered/` within `rag-src/`
- **Consistency check contract**: `check_consistency()` returns `RagConsistencyReport`; callers inspect `is_consistent()` method to determine success/failure
- **File routing**: Only move successfully ingested chunk files to `registered/`; failed chunks stay in `chunk/` or move to `retry/`/`failed/`

## Alternatives considered

- **Single retry/ directory**: Could put all failed chunks in one directory. Rejected because retryable vs non-retryable failures need different handling.
- **Raise exception on consistency failure**: Could make consistency failure fatal. Rejected because operator needs visibility into partial failures.

#### Phase 2: Separate successful and failed chunk file routing

1. Modify `_ingest_chunk_files()` to track which chunk files succeeded and which failed (return `(success_paths, embed_failed_paths, parse_failed_paths)`):
   ```python
   def _ingest_chunk_files(
       self, doc_id: int, chunk_files: list[Path]
   ) -> tuple[list[Path], list[Path], list[Path]]:
       """Embed and insert chunk files in parallel via ThreadPoolExecutor; returns (success_paths, embed_failed_paths, parse_failed_paths)."""
       success_paths: list[Path] = []
       embed_failed_paths: list[Path] = []
       parse_failed_paths: list[Path] = []
       with ThreadPoolExecutor(max_workers=self._embed_workers) as executor:
           futures = {
               executor.submit(self._embed_and_store, doc_id, path): path
               for path in chunk_files
           }
           for future in as_completed(futures):
               path = futures[future]
               try:
                   chunk_ok, embed_ok = future.result()
                   if chunk_ok:
                       success_paths.append(path)
                   else:
                       if not embed_ok:
                           embed_failed_paths.append(path)
                       else:
                           parse_failed_paths.append(path)
               except (
                   httpx.HTTPStatusError,
                   httpx.RequestError,
                   OSError,
                   ValueError,
                   TypeError,
               ) as e:
                   self._log_ingest_failure(doc_id, path, e)
                   parse_failed_paths.append(path)
       return success_paths, embed_failed_paths, parse_failed_paths
   ```

   ```python
   def _write_error_metadata(self, path: Path, doc_id: int, reason: str) -> None:
       """Write .error.json metadata for a failed chunk."""
       import json
       from datetime import datetime, timezone
       
       data = self._read_chunk_json(path)
       if data is None:
           return
       
       error_meta = {
           "url": data.get("url", ""),
           "chunk_index": data.get("chunk_index", 0),
           "source_file": data.get("source_file", ""),
           "failure_reason": reason,
           "timestamp": datetime.now(timezone.utc).isoformat(),
       }
       
       error_path = path.with_suffix(".error.json")
       try:
           with open(error_path, "w") as f:
               json.dump(error_meta, f, indent=2)
       except OSError as e:
           logger.error("Failed to write error metadata for %s: %s", path, e)
   ```
