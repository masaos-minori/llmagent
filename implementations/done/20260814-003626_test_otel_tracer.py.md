# Implementation Procedure: tests/shared/test_otel_tracer.py

## Goal
Add characterization tests that lock the exact current log text and log level produced by
`_attach_console_exporter` and by the OTLP-unavailable fallback branch inside
`_attach_otlp_exporter`, run *before* the `_attach_console_processor` extraction in
`scripts/shared/otel_tracer.py` (companion implementation procedure document), so the extraction
is provably behavior-preserving.

## Scope
- In scope: `tests/shared/test_otel_tracer.py` — add a new test that calls
  `_attach_console_exporter` directly and asserts its exact log output; tighten
  `TestAttachOtlpExporter.test_falls_back_to_console_when_otlp_unavailable` (currently lines
  165-174) to add an exact-match assertion alongside the existing substring check; add
  `_attach_console_exporter` to the existing import from `shared.otel_tracer` (line 28-34).
- Out of scope: any change to production code (`scripts/shared/otel_tracer.py`) — that is a
  separate, later step performed only after this file's tests pass against current code; removal
  of the existing substring assertion in `test_falls_back_to_console_when_otlp_unavailable` (kept
  alongside the new exact-match assertion, per the source plan).

## Assumptions
- `caplog.at_level(logging.INFO, logger="shared.otel_tracer")` correctly scopes capture to this
  module's logger, consistent with the existing `caplog.at_level(logging.WARNING, logger="shared.otel_tracer")`
  pattern already used in `TestImportSdkFallback` (line 131) and `TestAttachOtlpExporter`
  (line 170).
- `caplog.records[-1].getMessage()` returns the fully `%`-substituted message text, matching the
  "byte-identical" acceptance criterion interpretation used in the companion production-code
  procedure.
- No other assertion in `test_falls_back_to_console_when_otlp_unavailable` depends on
  substring-style matching, so adding an exact-match assertion alongside the existing one is a
  strict addition with no interaction (confirmed by reading lines 165-174 in full).

## Design decisions
- Use the existing `_FakeProvider` class (already defined at line 149) for the new
  `_attach_console_exporter` test, exactly as `TestAttachOtlpExporter` already does, rather than
  introducing a second fake-provider class.
- Keep the existing substring assertion in `test_falls_back_to_console_when_otlp_unavailable`
  rather than replacing it, so a partial-match regression is still caught even if the exact-match
  assertion is ever loosened by mistake.

## Alternatives considered
- Replacing the substring assertion outright instead of adding an exact-match assertion alongside
  it. Rejected: the source plan calls for keeping both ("keep both, per the requirement's
  'add a companion exact-match assertion' option").

       def test_logs_exact_message_and_attaches_one_console_processor(

       ) -> None:
           provider = _FakeProvider()

           assert len(provider.processors) == 1

   ```python
   def test_falls_back_to_console_when_otlp_unavailable(
       self, monkeypatch: pytest.MonkeyPatch, caplog: pytest.LogCaptureFixture
   ) -> None:
       monkeypatch.setattr("shared.otel_tracer._import_otlp", lambda: None)
       provider = _FakeProvider()
       with caplog.at_level(logging.WARNING, logger="shared.otel_tracer"):
           _attach_otlp_exporter(provider, "http://localhost:4318", "svc")
       assert len(provider.processors) == 1
       assert isinstance(provider.processors[0], _ConsoleProcessor)
       assert "opentelemetry-exporter-otlp not installed" in caplog.text
       assert (
           caplog.records[-1].getMessage()
           == "opentelemetry-exporter-otlp not installed; falling back to ConsoleSpanExporter"
       )
   ```
4. Run `uv run pytest tests/shared/test_otel_tracer.py -v` and confirm every test (18 existing +
   1 new) passes against the *current*, pre-refactor `scripts/shared/otel_tracer.py` — this step
   must pass before the companion production-code procedure is carried out.
5. After the production-code extraction (companion procedure) is applied, re-run the same command
   and confirm identical pass results with no test modification needed.
