## Goal

Make RAG ingestion safe under partial failure: ensure consistency checks run against an open DB connection, keep failed embedding chunks retryable, and provide operators with clear visibility into ingestion failures.

## Scope

**In-Scope:**
- Move `check_consistency()` inside the active DB context in `RagIngester.ingest_all()`
- Treat failed consistency checks as explicit error states
- Only move successfully ingested chunk files to `registered/`
- Keep embedding-failed chunks in `chunk/` or move them to `retry/`
- Optionally move invalid, non-retryable chunks to `failed/`
- Emit structured logs for failed chunks with URL, chunk_index, source_file, failure reason
- Consider writing `.error.json` metadata for failed chunks
- Ensure `embed_failed > 0` is visible in ingestion summary and operational logs

**Out-of-Scope:**
- Changes to existing successful ingestion behavior
- Changes to embedding service itself
- Changes to document parsing logic
- Changes to the SQLite schema

## Assumptions

1. Chunk files that fail embedding should remain in `chunk/` so they can be retried on the next ingestion run.
2. Invalid chunks (parse errors, validation failures) should be moved to `failed/` since they cannot be retried without manual intervention.
3. The `.error.json` metadata format should include: URL, chunk_index, source_file, failure reason, timestamp.
4. Consistency check failure should cause the entire ingestion to report an error state but not crash the process.

## Design decisions

- **Test isolation**: Use in-memory SQLite database (_FakeSQLiteHelper) following existing patterns
- **File system isolation**: Use tmp_path fixture for chunk file isolation
- **Comprehensive coverage**: Test each new scenario individually plus combined scenarios

## Alternatives considered

- **Integration tests only**: Could rely solely on integration tests. Rejected because unit tests provide faster feedback and clearer failure diagnostics.
- **Parametrized tests**: Could use pytest parametrization for all new scenarios. Rejected because separate test functions provide better error messages.

   def test_consistency_check_runs_with_closed_connection(self, tmp_path: Path) -> None:
       """Consistency check should run while DB connection is open, not after."""
       conn, fake_db = _make_db()
       
       # Create a real SQLiteHelper that will close on __exit__
       from rag.ingestion.ingester import RagIngester
       ingester = _make_ingester(tmp_path)
       path = _write_chunk(tmp_path / "chunk", "c.json")
       
       # Patch SQLiteHelper to use a real connection that closes properly
       with (
           patch.object(ingester._client, "post", return_value=_fake_embed_resp()),
           patch("rag.ingestion.ingester.SQLiteHelper") as mock_helper,
       ):
           real_conn = sqlite3.connect(":memory:", check_same_thread=False)
           real_conn.executescript(_SCHEMA_SQL)
           
           class _RealHelper:
               def __init__(self, *args, **kwargs):
                   self.conn = real_conn
                   
               def open(self, *, write_mode: bool = False, row_factory: bool = False):
                   self.conn.row_factory = sqlite3.Row if row_factory else None
                   return self
               
               def __enter__(self):
                   return self
               
               def __exit__(self, *args):
                   self.conn.close()
                   
               def execute(self, sql, params=()):
                   return self.conn.execute(sql, params)
               
               def fetchall(self, sql, params=()):
                   return self.conn.execute(sql, params).fetchall()
               
               def commit(self):
                   self.conn.commit()
           
           mock_helper.return_value = _RealHelper()
           
           result = ingester.ingest_all(force=False)
       
       # Consistency check should have succeeded (not returned None due to closed connection)
       assert result is not None
   ```

   def test_mixed_success_and_failure_only_moves_successful(self, tmp_path: Path) -> None:
       """Only successfully ingested chunks should be moved to registered/."""
       conn, fake_db = _make_db()
       url = "https://example.com/doc"
       chunk_dir = tmp_path / "chunk"
       
       path_ok = _write_chunk(chunk_dir, "c_ok.json")
       path_fail = _write_chunk(chunk_dir, "c_fail.json")
       
       ingester = _make_ingester(tmp_path)
       
       def _side_effect(*args, **kwargs):
           resp = MagicMock()
           resp.raise_for_status.return_value = None
           if args[1].get("content", "").startswith("passage: c_ok"):
               resp.content = orjson.dumps({"embedding": [0.1] * 384})
           else:
               resp.content = orjson.dumps({"embedding": []})
           return resp
       
       with (
           patch.object(ingester._client, "post", side_effect=_side_effect),
           patch("rag.ingestion.ingester.SQLiteHelper", return_value=fake_db),
       ):
           result = ingester.ingest_url_group(
               DocumentManager(fake_db),
               fake_db,
               url,
               [path_ok, path_fail],
               force=False,
           )
       
       assert result.n_success == 1
       assert result.n_embed_failed == 1
       assert not path_ok.exists()  # Successful chunk moved to registered/
       assert path_fail.exists()    # Failed chunk stays in chunk/
   ```
