## Goal

Restrict environment variable overrides for subprocesses to prevent potential subversion of MCP server behavior through environment variable manipulation.

## Scope

**In-Scope:**
- Define a set of protected environment variable names (PATH, PYTHONPATH, LD_LIBRARY_PATH, HOME, USER)
- Filter out protected variables before merging in `scripts/agent/http_lifecycle.py:224-226`
- Log a warning when a protected variable is attempted to be overridden

**Out-of-Scope:**
- Changes to other subprocess configuration beyond environment variables
- Adding new protection mechanisms beyond environment variable filtering

## Assumptions

1. The list of protected environment variables specified in the requirement covers all critical cases
2. Logging a warning is sufficient; blocking silently would cause hard-to-debug failures

## Design

Based on inspection of `http_lifecycle.py`:
```python
# Current (no protection):
if cfg.env:
    env = {**os.environ, **cfg.env}

# Proposed:
_PROTECTED_ENV_VARS = frozenset({"PATH", "PYTHONPATH", "LD_LIBRARY_PATH", "HOME", "USER"})

if cfg.env:
    env = dict(os.environ)
    for key, value in cfg.env.items():
        if key in _PROTECTED_ENV_VARS:
            logger.warning("Blocked protected env var override: %s=%s", key, value)
        else:
            env[key] = value
```
