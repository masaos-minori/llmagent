## Design decisions

- Line 20: replace "`ToolRegistry` is still maintained for two production uses: (a)...,
  and (b) the fail-safe membership check that `agent/tool_policy.py::classify_operation_type()`
  references via `get_all_tool_names()` to determine whether a tool is known at all."
  with "`ToolRegistry` is still maintained for one production use: input data for
  `McpToolDiscoveryService`'s drift detection. (As of 2026-08-25, it is no longer
  consulted by `agent/tool_policy.py::classify_operation_type()` — that function now
  uses `RuntimeToolRegistry` exclusively, per ADR-003 Decision #8.)"
- Line 122: replace "and as the fail-safe membership check for
  `agent/tool_policy.py::classify_operation_type()` (see the explanation at the
  beginning of this document)" with "(see the explanation at the beginning of this
  document; `agent/tool_policy.py::classify_operation_type()` no longer consults
  `ToolRegistry` — see ADR-003 Decision #8)".

## Alternatives considered

  from `ADR-003`'s Known Deviations or the sibling `tool_registry.py` docstring) benefits
  from an explicit statement that the role was removed, not silence.
