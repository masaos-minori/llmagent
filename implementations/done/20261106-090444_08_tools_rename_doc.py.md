## Implementation
### Target file
`tools/rename_doc.py`

### Procedure
1. Add the guarded bootstrap and `from tools._tool_common import run_git` (`sys` is already imported).
2. In `scan_outside_docs` replace the `subprocess.run([...git ls-files...])` call with `run_git("ls-files", "-z", cwd=repo_root, check=True).stdout`; keep the `except (subprocess.CalledProcessError, OSError)` clause.
3. In `git_mv` replace the `subprocess.run([...git mv...])` call with `run_git("mv", str(old_path), str(new_path), cwd=repo_root, check=True)`; keep both `except` clauses.
4. Keep `import subprocess` (needed for the exception type); remove the long bandit comment blocks above the two old calls.

### Method
- No behavior mapping is needed: the helper's text mode populates `stdout` and `stderr` as `str`, and `check=True` raises the same exception type.

### Details
- Text decoding changes from the locale encoding to UTF-8 with replacement for tracked file names; `git ls-files -z` already prints names verbatim, so only the decoding of non-UTF-8 names differs (replacement instead of locale-dependent decode).
- Do not touch `find_repo_root`.
