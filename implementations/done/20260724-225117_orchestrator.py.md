## Goal

Ensure only one StateStore instance is used per workflow execution, eliminating duplicate database connections.

## Scope

**In**: `scripts/agent/orchestrator.py` (Orchestrator._handle_workflow_engine(), _init_workflow_task())
**Out**: Changes to StateStore internals, other callers of create_task/get_task_by_id outside this code path

## Assumptions

1. Only `_handle_workflow_engine` calls `_init_workflow_task`
2. The store passed to `_init_workflow_task` must remain open until after `create_task()` or `get_task_by_id()` completes
3. `store.close()` at line 249 is the single cleanup point for the main store

## Design decisions

- Pass the outer `store` from `_handle_workflow_engine` into `_init_workflow_task` — eliminates duplicate StateStore creation without changing StateStore internals
- Make `store` parameter optional with default `None` — maintains backward compatibility if `_init_workflow_task` is called elsewhere
- Remove inner `store.close()` calls — outer scope owns the lifecycle; prevents double-close

## Alternatives considered

- Have `_init_workflow_task` reuse the outer store without passing it: requires storing it as an instance variable — adds unnecessary state
- Add a factory pattern to StateStore for connection pooling: overkill for a single duplicate connection issue
- Keep both stores but add a guard against double-close: doesn't solve the root cause of duplicate connections

```python
    def _init_workflow_task(
        self,
        ctx: AgentContext,
        session_id: str,
        existing_task_id: str | None = None,
        store: StateStore | None = None,
    ) -> tuple[str, TaskRecord]:
        """Create a workflow task and audit its start.

        If existing_task_id is provided, use that task instead of creating a new one.
        The caller may pass a pre-opened StateStore via the `store` parameter to avoid
        opening a second connection.
        """
        assert self._workflow_def is not None  # noqa: B101
        close_store = False
        if store is None:
            store = StateStore()
            close_store = True
        try:
            if existing_task_id is None:
                workflow_id = str(uuid.uuid4())
                task = create_task(
                    store._db,
                    session_id=session_id,
                    turn_number=ctx.stats.stat_turns,
                    workflow_version=self._workflow_def.version,
                    workflow_id=workflow_id,
                )
                audit_workflow_start(
                    ctx,
                    task.task_id,
                    self._workflow_def.version,
                    workflow_id=workflow_id,
                    session_id=session_id,
                )
            else:
                _fetched = get_task_by_id(store._db, existing_task_id)
                if _fetched is None:
                    raise RuntimeError(f"Task {existing_task_id} not found")
                task = _fetched
                workflow_id = task.workflow_id or str(uuid.uuid4())
        finally:
            if close_store:
                store.close()
        return workflow_id, task
```

Key points:
- Added `store: StateStore | None = None` parameter
- Added `close_store` boolean flag — only close the store if we created it ourselves
- Moved `store = StateStore()` out of each branch into a single conditional at the top
- Consolidated `store.close()` into the finally block — ensures cleanup regardless of exception path
- Removed duplicate `store.close()` from the else branch
