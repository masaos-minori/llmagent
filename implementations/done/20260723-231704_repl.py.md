## Goal

Add defensive WAL mode verification before performing WAL checkpoint during shutdown to prevent checkpoint failures when the database is not in WAL mode.

## Scope

**In-Scope**:
- Add PRAGMA journal_mode check before WAL checkpoint in `_close_resources()`

**Out-of-Scope**:
- Moving WAL checkpoint to session close method (Option B rejected per requirement recommendation)
- Changing session connection management (Option A rejected per requirement recommendation)
- Any other shutdown resource cleanup changes

## Assumptions

1. The PRAGMA journal_mode query returns "wal" when the database is in WAL mode, or another value otherwise.
2. Skipping the checkpoint silently when not in WAL mode is acceptable (the database will be consistent after a normal close).

## Design decisions

- **Use `.lower()` for case-insensitive comparison**: SQLite docs guarantee lowercase, but using `.lower()` provides defense-in-depth against platform differences.
- **Log debug message instead of warning when skipping**: Non-WAL mode is expected behavior — logging at DEBUG level avoids noise in production logs.
- **Keep same error handling pattern**: Existing try/except for sqlite3.Error preserved; only adds conditional logic inside the try block.

## Alternatives considered

- **Always attempt checkpoint regardless of journal mode**: Simpler but risks silent failures when not in WAL mode. Chose explicit check for clarity.
- **Raise error if not in WAL mode**: Would cause shutdown failures for databases not in WAL mode. Rejected because it breaks backward compatibility.
- **Check via `PRAGMA journal_mode == 'wal'` string comparison without .lower()**: Less defensive against edge cases. Added .lower() for robustness.

     try:
         with SQLiteHelper("session").open(write_mode=True) as db:
             wal_mode = db.execute("PRAGMA journal_mode").fetchone()[0]
             if wal_mode.lower() == "wal":
                 db.checkpoint("TRUNCATE")
                 logger.info("WAL checkpoint completed on shutdown")
             else:
                 logger.debug("WAL checkpoint skipped: journal mode is %r", wal_mode)
     except sqlite3.Error as e:
         errors.append(("wal_checkpoint", f"{type(e).__name__}: {e}"))
         logger.warning("WAL checkpoint failed on shutdown: %s", e)
