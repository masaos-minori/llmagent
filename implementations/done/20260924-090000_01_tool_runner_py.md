## Goal

Resolve the `tool_runner.py` gateway-bypass gap where tools execute directly via `tools.execute()` when `ctx.services_required.gateway is None`, bypassing the preflight gate at `repository_gateway.py:114`.

## Scope

- **In-Scope**: Investigate whether the gateway-bypass gap is a real security concern or safe; implement Option A (fix) or Option B (document as safe); add corresponding test.
- **Out-of-Scope**: Modifying the `check_preflight()` function logic itself; adding new gate conditions beyond what already exists; changes to MCP server preflight behavior; changes to Event Bus preflight behavior.

## Assumptions

- The gateway-bypass gap at `tool_runner.py` lines 116-119 represents a real security concern requiring resolution (per plan's assumption).
- The `repository_gateway.py` line 114 preflight gate is the primary write enforcement boundary.
- dry_run operations are intentionally preflight-exempt because they are read-only previews.
- READ operations are intentionally preflight-exempt per design (direct passthrough for read-only tools).

## Design decisions

- Start with Option B (document as safe) after investigation, escalating to Option A (fix) only if the gap is confirmed as a real security concern. This lowers the barrier to adoption and avoids unnecessary complexity.
- If Option B is chosen, document why the path is safe (e.g., gateway is always configured in production, or no tools are available when gateway is None).
- If Option A is chosen, add a preflight check in the `else` branch before calling `tools.execute()`.

##### Option B: Document as safe

If the investigation confirms the bypass is safe (e.g., gateway is always configured in production), add a comment explaining why:

```python
# Gateway-bypass safety justification:
# When ctx.services_required.gateway is None, no tools are available
# for execution in this context. The fallback to ctx.services_required.tools
# is a no-op because tools.execute() will raise an error if no tools
# are registered. This is intentional — it prevents unauthorized tool
# access while allowing the system to handle edge cases gracefully.
if ctx.services_required.gateway is not None:
    result = await ctx.services_required.gateway.execute(ctx, name, args)
else:
    result = await ctx.services_required.tools.execute(name, args)
```

##### Option A: Fix the gap

If the investigation confirms the bypass is a real security concern, add a preflight check in the `else` branch:

```python
if ctx.services_required.gateway is not None:
    result = await ctx.services_required.gateway.execute(ctx, name, args)
else:
    # Preflight check required when gateway is not configured
    from agent.tool_policy import check_preflight, classify_operation_type
    
    operation_type = classify_operation_type(tool_name)
    if operation_type.requires_preflight():
        check_preflight(ctx.cfg, tool_name, {})
    
    result = await ctx.services_required.tools.execute(name, args)
```
