## Assumptions

- Assumption: the prose at `:32` is the only human-written docs mention of `masked_fields`
  defaults. Verified (2026-10-25 re-check): the bullet is at `:32`, with sub-bullets at
  `:33` (preview exception) and `:34` ("The shipped default matches no current
  tool-argument key ..." — the sentence made obsolete by this change set).
- Assumption: GitHub file-write tools use `content` as an argument key, so naming GitHub
  file-write coverage is accurate. Verified: `scripts/mcp_servers/github/tools_file.py:108`
  and `:143` list `content` in required arguments.

## Design decisions

- Decision: rewrite the `:34` sub-bullet in place (it asserts the now-false inertness) and
  leave the `:32` mechanism sentence and `:33` preview-exception sub-bullet untouched —
  only the default-value claim changes.
- Decision: keep one bullet covering names + tools + logs/audit-only split, as the plan's
  Documentation Impact specifies; no new section.

## Alternatives considered

- Alternative: state only the list without naming tools. Rejected: the plan requires the
  bullet to name `write_file`/`edit_file` (and GitHub file-write) so readers can map keys
  to tools.
- Alternative: delete the `:34` sub-bullet entirely. Rejected: the key-names-to-tools
  mapping is exactly the knowledge the original issue lacked; replacing preserves it.

`docs/23_agent/agent_08_03_configuration-tools-memory.md`

### Procedure

### Method

Replace the line at `:34` (verified):

