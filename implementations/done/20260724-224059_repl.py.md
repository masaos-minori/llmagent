## Goal

Add validation to detect and report unexpected keys during the dict-to-HistoryMessage conversion, preventing silent data loss.

## Scope

**In**: `scripts/agent/repl.py` (AgentREPL._persist_session_memories()), `scripts/agent/memory/models.py` (HistoryMessage)
**Out**: Changes to message dict schema, other serialization paths

## Assumptions

1. HistoryMessage only accepts `role` and `content` as valid fields
2. Additional keys in message dicts (e.g., `_ephemeral`, `_memory_injected`) should be flagged, not silently dropped
3. Adding a metadata field to HistoryMessage is acceptable if needed

## Design decisions

- Add unexpected key detection in `_persist_session_memories()` using set difference — minimal change surface, leverages Python's built-in set operations
- Log full message dict alongside the warning for debugging — provides actionable information without requiring additional investigation
- Make metadata optional in HistoryMessage with default empty dict — avoids breaking existing consumers

## Alternatives considered

- Raise an exception on unexpected keys: too aggressive; would break sessions that contain ephemeral/memory-injected markers
- Silently drop unexpected keys: defeats the purpose of the validation — the goal is to prevent silent data loss
- Add a separate `_extra_keys` attribute to HistoryMessage: adds complexity for marginal benefit; logging alone suffices for visibility

#### Step A: Modify `AgentREPL._persist_session_memories()` — add unexpected key detection

Current code (lines 116-132):

    async def _persist_session_memories(self, ctx: AgentContext) -> None:
        """Extract and persist session memories before compression or resource close."""
        if ctx.services is not None and ctx.services.memory is not None:
            try:
                history = [

Change to:

```python
    async def _persist_session_memories(self, ctx: AgentContext) -> None:
        """Extract and persist session memories before compression or resource close."""
        if ctx.services is not None and ctx.services.memory is not None:
            try:
                history = []
                for m in ctx.conv.history:
                    expected_keys = {"role", "content"}
                    extra_keys = set(m.keys()) - expected_keys
                    if extra_keys:
                        logger.warning(
                            "Unexpected keys in history message: %s — full message: %s",
                            extra_keys,
                            m,
                        )
                    history.append(
                        HistoryMessage(role=m["role"], content=m.get("content") or "")
                    )
                await ctx.services.memory.on_session_stop(
                    session_id=ctx.session.session_id,
                    history=history,
                    turn_id=ctx.turn.current_turn_id,
                )
            except (RuntimeError, sqlite3.Error, OSError):
                logger.exception(
                    "Memory on_session_stop failed; session data may be incomplete"
                )
```

Key points:
- Changed from list comprehension to explicit loop to allow per-message key validation
- Extra keys logged alongside the full message dict for debugging
- No behavioral change to HistoryMessage creation — extra keys still silently dropped (detection only)
