## Goal

Add command whitelist validation for MCP subprocess execution to prevent potential command substitution attacks through config file modification.

## Scope

**In-Scope:**
- Define `ALLOWED_MCP_COMMANDS` constant with known valid executables
- Validate `cfg.cmd[0]` against whitelist before `subprocess.Popen()` call
- Reject non-whitelisted commands with clear error message

**Out-of-Scope:**
- Changes to `McpServerConfig` beyond what's needed for validation
- Any changes beyond the whitelist check logic

## Assumptions

1. The whitelist approach is appropriate for preventing unauthorized command execution
2. A fixed set of allowed commands covers all production use cases

## Design

Based on inspection of `http_lifecycle.py`:
```python
# Current (no whitelist):
proc = subprocess.Popen(cfg.cmd, ...)

# Proposed (with whitelist):
ALLOWED_MCP_COMMANDS: frozenset[str] = frozenset({
    "node", "npx", "uvx", "python", "pipx",
})

if cfg.cmd:
    cmd_basename = os.path.basename(cfg.cmd[0])
    if cmd_basename not in ALLOWED_MCP_COMMANDS:
        logger.error(
            "MCP subprocess rejected: command '%s' not in whitelist (%s)",
            cfg.cmd[0],
            ", ".join(sorted(ALLOWED_MCP_COMMANDS)),
        )
        return

proc = subprocess.Popen(cfg.cmd, ...)
```
