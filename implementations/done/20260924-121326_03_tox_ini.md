# Implementation Procedure: Add chunks_fts Invariant Check to tox.ini

## Goal

Add the chunks_fts invariant lint script as a new tox environment in `tox.ini`, per REQ-05.

## Scope

- Modify `tox.ini` to add a new `[testenv:lint-chunks-ftss]` environment
- The environment runs the lint script as part of CI

## Assumptions

- The lint script exists at `tools/check_chunks_fts_invariant.py` (created by companion implementation procedure)
- `rg` is available in the CI environment (already required by the lint script)
- The project uses `uv` for Python execution (confirmed by existing tox configuration)

## Design decisions

- Create a separate tox environment `[testenv:lint-chunks-ftss]` rather than extending the existing `lint` environment. This keeps the chunks_fts check isolated and allows it to be run independently during development.
- Use `uv run python tools/check_chunks_fts_invariant.py` as the command, consistent with the existing `lint` environment's pattern.

## Alternatives considered

- **Extending existing `lint` environment**: Would keep all lint checks in one place but couples the chunks_fts check to the general lint environment. Separate environment allows independent invocation.
- **Pre-commit hook**: Would provide faster feedback but adds local dependency burden. CI-only is lower barrier to adoption per REQ-05.

## Implementation

### Target file

`tox.ini`

### Procedure

1. Read the existing `tox.ini` content
2. Add a new `[testenv:lint-chunks-ftss]` section after the existing `[testenv]` section
3. The section should contain:
   - `deps`: inherit from `[testenv]` (or specify minimal deps if different)
   - `commands`: `uv run python tools/check_chunks_fts_invariant.py`

### Method

**Step 1: Append new tox environment**

Add the following section after line 29 (end of existing `[testenv]`):

```ini

description = Check for direct chunks_fts operations outside sanctioned paths
```
