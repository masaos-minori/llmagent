## Design decisions
- Public names (all new): `atomic_write_text(path, text, *, encoding="utf-8")`, `stage_write(path, text, *, encoding="utf-8")` returning a `StagedWrite` (new) with `commit()` and `discard()`, `render_diff(path, old, new)`, `print_dry_run(path, old, new)`, and `add_dry_run_argument(parser)`.
- `atomic_write_text` (new) is `stage_write(...).commit()`, so the single-file and two-file (`module_nodes.py extract`) paths share one implementation.

## Alternatives considered
- A journal file for multi-file writes: rejected, more machinery than the Plan asks for.
- `shutil.move`: rejected, it is not atomic across filesystems and does not copy the mode.

## Implementation
### Target file
`tools/_atomic_write.py` (new)

### Procedure
1. Write the module docstring (private, no `__main__`, stdlib only) and imports (`difflib`, `os`, `shutil`, `tempfile`, `argparse`, `dataclasses`, `pathlib`).
2. Define `StagedWrite` (new) (frozen dataclass of target and temporary path) with `commit()` (copy the mode of an existing target, else apply the default mode of a new file, then `os.replace`) and `discard()` (unlink the temporary file, ignoring a missing one).
3. Define `stage_write` (new) (`tempfile.mkstemp(dir=path.parent, prefix=f".{path.name}.", suffix=".tmp")`, write `text.encode(encoding)` through `os.fdopen(fd, "wb")`, remove the temporary file if writing fails).
4. Define `atomic_write_text` (new), `render_diff` (new) (`difflib.unified_diff` over `splitlines(keepends=True)` with `a/`/`b/` path labels, empty old text for a new file), `print_dry_run` (new) (prints the diff or `no change`, writes nothing), and `add_dry_run_argument` (new) (`--dry-run`, `action="store_true"`, help `Print the intended change as a diff and write nothing`).

### Method
- Bytes are written as given, so line endings and a missing trailing newline are preserved; the encoded text is never newline-translated.
- On any exception before `os.replace` the original target is untouched and the temporary file is removed (`try/finally`).

### Details
- The temporary file lives in the target's directory so `os.replace` stays on one filesystem; its name starts with a dot so a glob over `*.md` or `*.py` does not pick it up.
- No logging and no printing except `print_dry_run` (new).

### Companion test files

  - Procedure: add tests for success (content and UTF-8 bytes of non-ASCII text), mode preserved for an existing file, a new file's default mode, line endings and a missing trailing newline preserved, interruption before replace (monkeypatch `os.replace` to raise) leaving the original unchanged and no temporary file in the directory, `StagedWrite.discard`, `render_diff` (new) for change, no change, and a new file, `print_dry_run` (new) writing nothing (checksum), and `add_dry_run_argument` (new) default and flag.
