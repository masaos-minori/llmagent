## Goal

Establish graceful degradation policy for semantic cache dimension mismatches: treat mismatches as cache misses rather than fatal errors, and update callers accordingly.

## Scope

**In-Scope:**
- Modify `SemanticCache.lookup()` to return `None` instead of raising `ValueError` on dimension mismatch.
- Log the dimension mismatch event as a warning.
- Modify `SemanticCache.put()` to return `bool` (`False`) instead of raising `ValueError` on dimension mismatch.
- Update caller in `pipeline.py` to handle `put()` return value.
- Update tests to reflect the behavioral change.

**Out-of-Scope:**
- Modifying source code behavior beyond diagnostic improvements.
- Updating documentation (`docs/*.md`).
- Changing the core ingestion or pipeline orchestration logic.
- Search orchestration consolidation (no redundancy detected).

## Assumptions

- Callers of `SemanticCache.lookup()` expect `None` on cache miss, not exceptions.
- Dimension mismatches should be treated as cache misses rather than fatal errors.
- `RagPipeline.search_queries()` and `SearchStage.run()` serve different purposes (one is public API, other is pipeline stage); no consolidation needed.

## Design decisions

- **Treat dimension mismatch as cache miss**: Return `None` from `lookup()` instead of raising `ValueError`. This aligns with the Protocol contract which specifies `str | None` return type.
- **Add warning logging**: Log dimension mismatch events for observability without breaking callers.
- **Return `False` from `put()` on mismatch**: Change return type from `None` to `bool` to indicate failure without crashing.
- **Conservative approach for cache invalidation**: Don't invalidate entire cache on single mismatch — just skip the incompatible entry.

## Alternatives considered

- **Keep `ValueError` but add docstring clarification**: Adds cognitive overhead without solving the root problem. Rejected.
- **Use `None` for `put()` return value**: Breaks downstream consumers expecting boolean success/failure. Rejected.
- **Add separate `is_unexpected_failure` boolean flag**: Redundant with `failure_reason`; adds unnecessary complexity. Rejected.

def put(
    self, embedding: list[float], history_context: str, context_str: str
) -> None:
    """Add a new entry, then prune if over capacity.

    Raises ValueError if embedding dimension differs from previously stored entries.
    """
    with self._lock:
        if self._dim is None:
            self._dim = len(embedding)
        elif len(embedding) != self._dim:
            raise ValueError(
                f"SemanticCache dimension mismatch: expected {self._dim}, got {len(embedding)}",

                context_str=context_str,
                history_context=history_context,
                generation=self._generation,

        )
        self.prune()

def put(
    self, embedding: list[float], history_context: str, context_str: str
) -> bool:
    """Store an embedding-context pair in the cache.
    
    Returns True on success, False if dimension mismatch prevents insertion.
    """
    with self._lock:
        if self._dim is None:
            self._dim = len(embedding)
        elif len(embedding) != self._dim:
            logger.warning(
                "SemanticCache dimension mismatch during put: expected %d, got %d",
                self._dim, len(embedding),
            )
            return False  # Don't insert incompatible entry
        self._entries.append(
            CacheEntry(
                embedding=embedding,
                context_str=context_str,
                history_context=history_context,
                generation=self._generation,
            )
        )
        self.prune()
        return True
