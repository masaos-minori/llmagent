## Design decisions
Prefix each fixed link with `../` (not a bare filename, since
`tools/check_docs_structure.py`'s basename index only applies to bare-filename targets,
and this file's own established style for cross-area links is relative-path, not
bare-filename) — matches the same fix pattern this same Plan applies to seq 11/12.

## Alternatives considered
- Convert to a bare filename and rely on the basename index: rejected — inconsistent
  with this file's existing cross-area link style (every other entry in the same
  "Categories" list and "Document References by Task" table uses a directory-qualified
  relative path, not a bare filename); out of scope for this row.
