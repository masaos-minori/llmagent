# Implementation Procedure: pyproject.toml (Published-at ownership procedure 8)

## Goal

Add `rfc3339-validator` to the project dependencies so `jsonschema`'s `date-time`
format check is actually registered.

## Scope

- Add the `rfc3339-validator` dependency to `pyproject.toml` (main dependencies, not
  dev-only: `publish_route.py` needs it at runtime).

## Assumptions

- Owner decision (plan Plan Gap, resolved 2026-10-29): `jsonschema`'s `FormatChecker` (new)
  registers no `date-time` checker in the current environment (verified 2026-10-29:
  `'date-time' in jsonschema.FormatChecker().checkers` is `False`); adding
  `rfc3339-validator` (0.1.x) makes the check work — re-confirmed after install via the
  Validation plan command below.

## Design decisions

- Add as a runtime dependency because the route's FormatChecker depends on the
  registration side effect (plan dependency note: registration requires a jsonschema
  hook or explicit import path to be verified during implementation).

## Alternatives considered

- `datetime.fromisoformat` pre-check without a dependency (rejected: not full RFC 3339).
