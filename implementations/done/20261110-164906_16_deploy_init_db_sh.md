## Design decisions
- Replace the marker gate (lines 79-103) with a per-domain fingerprint gate (workflow, rag,
  session) using the generalized module and the `db.schema_sql` accessors; the exact-match
  comparison subsumes the marker-table query (a marker table is an extra table → refused).
- Replace the table-name-only workflow existence check (lines 60-77) with the same workflow
  fingerprint check (existence-only is the mechanism REQ-004 removes).
- Eventbus stays delegated to `eventbus.db_tools` (its generalized import is row 49's change);
  update the line 108 comment to name the new module.

## Alternatives considered
- Keeping per-deploy custom gates: rejected; one mechanism (REQ-004).
