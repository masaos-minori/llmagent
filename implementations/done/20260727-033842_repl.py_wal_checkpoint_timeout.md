## Goal

Add timeout to WAL checkpoint operations to prevent indefinite blocking during shutdown.

## Design

Based on inspection of `repl.py`:
```python
# Current (no timeout):
try:
    db.checkpoint("PASSIVE")
    logger.info("WAL checkpoint completed (PASSIVE) on shutdown")
    return True, errors
except sqlite3.Error as passive_err:
    logger.warning(...)

# Proposed:
WAL_CHECKPOINT_TIMEOUT_SEC = 5

try:
    await asyncio.wait_for(
        asyncio.to_thread(db.checkpoint, "PASSIVE"),
        timeout=WAL_CHECKPOINT_TIMEOUT_SEC,
    )
    logger.info("WAL checkpoint completed (PASSIVE) on shutdown")
    return True, errors
except asyncio.TimeoutError:
    logger.warning(
        "WAL PASSIVE checkpoint timed out after %d seconds, falling back to TRUNCATE",
        WAL_CHECKPOINT_TIMEOUT_SEC,
    )
except sqlite3.Error as passive_err:
    logger.warning(...)
```
