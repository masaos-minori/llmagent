# Implementation Procedure: ci.yml manifest drift-check step

## Goal

Make CI consume manifest drift checks so a stale manifest or hand-edited generated
block fails the pipeline (REQ-008; plan AC-4/AC-5).

## Design decisions
- `git diff --exit-code registry/manifests/` after regeneration is the drift signal:
  CI checkout is clean, so any diff means the committed manifest no longer matches
  live sources — no extra checker flag needed beyond doc 05.

## Alternatives considered
- `--check`-only (no regeneration step): rejected — `--check` compares committed
  manifest vs source, but the diff-based step also proves manifests are regenerable in
  CI's environment end to end.
