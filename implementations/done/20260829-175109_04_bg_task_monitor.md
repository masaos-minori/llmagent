# Implementation Procedure: scripts/agent/bg_task_monitor.py

## Goal

Create `bg_task_monitor.py` with the BgTaskMonitor class owning `_discard_and_log`, `_notify_bg_failure_threshold`, and related background task failure tracking logic extracted from Orchestrator.

## Scope

- Create `scripts/agent/bg_task_monitor.py` only. No other source file is modified by this document.
- The BgTaskMonitor class owns exactly one concern: background task failure tracking.
- Methods moved from orchestrator.py lines 679, 743.
- Constant `BG_FAILURE_THRESHOLD` moved here as a class attribute.

## Assumptions

- BgTaskMonitor receives the shared `background_tasks` set via constructor injection, not `AgentContext` (corrected during Step 3 adversarial verification: neither `discard_and_log` nor `notify_bg_failure_threshold` reads from `ctx`, so there is nothing for the constructor to inject `AgentContext` for).
- The `pause_on_critical_failure` opt-in flag and `_bg_pause_state` dict remain in BgTaskMonitor (per Issue constraint).
- Background task management (`_background_tasks`) remains in Orchestrator -- they bridge to BgTaskMonitor's `_discard_and_log` callback.
- `ToolLoopGuard` ownership remains shared between Orchestrator and LLMTurnRunner.
- `DiagnosticStore` ownership remains in Orchestrator.

## Design decisions

1. **BgTaskMonitor owns background task failure tracking**: The class encapsulates all methods related to background task failure counting, threshold checking, and pause state management.
2. **Constructor injection for dependencies**: the shared `background_tasks` set and callbacks are injected via `__init__`. This enables independent instantiation and testing.
3. **No circular imports**: BgTaskMonitor depends only on shared types (`asyncio.Task`, etc.) and never imports Orchestrator itself.
4. **Module-level constant for BG_FAILURE_THRESHOLD** (corrected during Step 3 adversarial verification, overriding the original "class attribute" plan): `test_orchestrator.py`/`test_orchestrator_bg_failure_threshold.py` both do `from agent.orchestrator import BG_FAILURE_THRESHOLD` — REQ-009 (existing import paths continue to work) requires the constant stay importable the same way, which only a module-level constant re-exported from `orchestrator.py` (`from agent.bg_task_monitor import BG_FAILURE_THRESHOLD, BgTaskMonitor`) achieves. A class attribute would have broken that import.

## Alternatives considered

1. **Merge BgTaskMonitor + TurnCoordinator**: Would reduce the number of new files but violates the Single Responsibility Principle that motivated this refactor. Rejected per plan's design intent.
2. **Keep `_discard_and_log` in Orchestrator**: Would reduce refactoring effort but leaves the file at > 700 lines. Rejected because it defeats the purpose of the refactor.
3. **Make BgTaskMonitor a mixin or base class**: Would introduce inheritance complexity without benefit. Composition is simpler and more testable. Rejected.

```python
class BgTaskMonitor:
    """Owns background task failure tracking: consecutive failure counting, threshold breach notification, pause state.

    Extracted from Orchestrator to isolate background-task lifecycle management.
    """

    BG_FAILURE_THRESHOLD: int = 10  # Moved from module-level constant

    def __init__(
        self,
        ctx: AgentContext,
        *,
        on_error: Callable[[Exception], None] | None = None,
        pause_on_critical_failure: bool = False,
    ) -> None:
        self._ctx = ctx
        self._on_error = on_error
        self._pause_on_critical_failure = pause_on_critical_failure
        self._bg_pause_state: dict[str, bool] = {}
        self._consecutive_bg_failures: int = 0

    def discard_and_log(self, task: asyncio.Task[Any]) -> None:
        """Callback for first-turn background task completion."""
        ...

    def notify_bg_failure_threshold(self, task_name: str, count: int) -> None:
        """Guarantee the user is notified when a background task hits the failure threshold."""
        ...
```

Key points:
- Public method names use snake_case without underscore prefix (cleaner API for Orchestrator delegation).
- `BG_FAILURE_THRESHOLD` is a class attribute (not module-level constant).
- `_bg_pause_state` and `_consecutive_bg_failures` are instance attributes initialized in `__init__`.
- `pause_on_critical_failure` opt-in flag behavior is preserved in BgTaskMonitor.
