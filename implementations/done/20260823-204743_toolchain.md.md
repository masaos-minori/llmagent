- The "Documentation consistency (per domain)" section (currently lines ~111-131) is the
  correct location — confirmed by direct read: it already documents the equivalent
  long-form command and the `--skip`/`--domain` argument set these shorthand commands
  wrap.

## Design decisions

- Add a short note directly after the existing code block showing `uv run python
  tools/check_docs_consistency.py --domain mcp [...]`, e.g.:
  ```
  `uv run check-mcp-docs` and `uv run check-agent-docs` are shorthand for `--domain
  mcp`/`--domain agent` (additional args like `--skip` still work — see
  tools/check_docs_consistency.py's main_mcp()/main_agent() wrappers).
  ```
- Do not duplicate the full `--skip`/`--domain` argument documentation already present
  — only note the shorthand's existence and that it forwards the same arguments,
  pointing back to the existing detailed documentation rather than restating it (per
  `skills/DESIGN.md` Avoid implementation-reference duplication).

## Alternatives considered

- Replace the long-form `uv run python tools/check_docs_consistency.py --domain mcp`
  example with the new shorthand as the primary documented form — rejected: the
  long-form remains necessary documentation for `rag`/`deployment`/`overview` domains,
  which have no shorthand command; keeping the long-form as primary and adding the
  shorthand as a note preserves a single consistent example pattern across all five
  domains.
