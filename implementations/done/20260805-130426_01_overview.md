  consistency): add the new doc to all three existing structures — front matter `related:`,

  instruction ("mentioning 'Deployment Topology' if appropriate"), so the link's purpose is

  canonical-premise item both designate `docs/02_deployment-part1.md` as canonical, so the index
  should point at the canonical file, not the part that only cross-references it.
