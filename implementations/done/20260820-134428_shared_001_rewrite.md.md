- **Type**: implementation-bug
- **Component**: shared/db/helper.py

- **Recommended Action**: Catch `BaseException` or explicitly handle `DatabaseError` in async wrappers in `scripts/shared/db/helper.py`.
- **Workaround**: None currently; sync paths work correctly.
- **Status Detail**: Open — no fix implemented yet.
- **Severity Justification**: High — affects all async DB operations; can cause silent failures.
- **Type Justification**: Implementation bug — exception hierarchy mismatch in async path.
- **Component Justification**: `scripts/shared/db/helper.py` is the shared DB helper used by all async DB operations.
- **Related Issues**: None
- **Resolution Target**: Next sprint
- **Blocking**: No
- **Evidence**: Explicit in code — `scripts/shared/db/helper.py` line 45 catches `sqlite3.Error` but async path raises `DatabaseError` not caught.
