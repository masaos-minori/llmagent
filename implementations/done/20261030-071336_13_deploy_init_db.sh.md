# Implementation Procedure: `deploy/init_db.sh` (ledger-compatible init; drill hook)

## Goal
Make deployment initialization produce and verify ledger-compatible baselines, and document/enable drill invocation on deployed databases (REQ-006 migration-compatible baselines, REQ-007 drill runbook at deploy time).

## Scope
- In scope: `deploy/init_db.sh` verification gates and an opt-in drill invocation section.
- Out of scope: Python-side baseline creation (row 08 `create_schema.py`, row 09 schema DDL), drill harness (row 11), test modules (row 22 in the Plan's Related Tests column maps this row's validation to `tests/deploy/`).

## Assumptions
- Database creation itself stays delegated to `scripts/db/create_schema.py` (`init_db.sh:22-24,32-34`); once rows 08/09 land, created databases already carry the `schema_migrations` ledger, so this script only verifies the result.
- Drill invocation stays opt-in (env flag, default off) until RPO/RTO targets and drill scheduling ownership are decided (Plan UNK-01, Blocker Log step 5).
- `tests/deploy/test_init_db_eventbus_schema.py` is the precedent for sandboxed integration tests that run this script against fixture DBs.

## Design decisions
- Ledger presence becomes a gate, not a warning: a baseline without `schema_migrations` fails init the same way the existing workflow table gate fails (`init_db.sh:44-61`) — fail-closed consistent with the Plan.
- Drill hook is a separate labeled section calling `scripts/db/recovery_drill.py --domain all` only when `RUN_RECOVERY_DRILL=1` is set, so no deployment run mutates production DBs without an operator's explicit opt-in (the drill itself never mutates live DBs, but init stays conservative).
Needs confirmation: whether the drill hook should default ON once UNK-01 is resolved; default stays OFF per the current Open Question.

## Alternatives considered
- Creating the ledger here with inline sqlite3 DDL — rejected: schema authority belongs to `schema_sql.py`/`schema.sql`/`create_schema.py` (rows 04, 08, 09); shell-side DDL duplicates the contract.
- Running the drill unconditionally at init — rejected: drill cadence is undecided (UNK-01) and CI runs of this script must not pay drill cost.
