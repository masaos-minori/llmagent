- Correction after adversarial verification: the checker compares, per (ADR, invariant), the union of the test files of every matrix row that names that invariant. Rows that share invariants therefore cannot be corrected by replacing one cell: adding a file for one invariant breaks its sibling (for example `ADR-006 INV-05, INV-09` and `ADR-008 INV-01 to INV-05`), and `ADR-002 INV-01, INV-02` has two different body sets. - Rows that share invariants: leave the existing row's cell unchanged and add one new row per invariant that needs more files, so each invariant's union equals its body set: ADR-002 INV-01 (adds `tests/mcp_servers/test_mcp_server_base.py`, `tests/mcp_servers/test_config_isolation_fail_closed.py`, `tests/agent/test_security_audit_config_isolation.py`), ADR-002 INV-02 (adds `tests/agent/test_config_permission_cross_server.py`), ADR-006 INV-09 (adds `tests/eventbus/test_eventbus_ack_nack.py`), ADR-008 INV-01 (adds `tests/db/test_create_schema.py`, `tests/db/test_db_recovery.py`).
