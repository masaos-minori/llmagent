## Goal

Create a new API reference directory for EventBus endpoint documentation. REQ-004, REQ-005, REQ-006, REQ-007.

## Scope

Create the `docs/eventbus/` directory and populate it with API reference documents for health, replay, DLQ, and ACK/NACK endpoints. This is a new file creation task.

## Assumptions

- `docs/eventbus/` does not exist yet (confirmed by glob returning empty)
- Health endpoint returns status_code 200 for ok, 503 for degraded
- Replay endpoint supports both SSE and JSON formats with pagination
- DLQ list endpoint supports pagination with total/limit/offset/items
- DLQ requeue endpoint returns {event_id, requeued, new_event_id, new_seq} on success, 409/404 on failure
- Role requirements are documented as the shipped model (eventbus02/eventbus03 have landed)

## Design decisions

- Create a new directory under `docs/` for EventBus-specific API reference
- Each endpoint group gets its own document within the directory
- An index/overview document ties the API reference together
- All examples use placeholder values (e.g., "Bearer ${TOKEN}") — no credentials or secrets

## Alternatives considered

- Consolidating into a single API reference document: rejected because the plan explicitly creates separate documents per endpoint group for clarity
- Placing under `docs/api/`: rejected because the plan specifies `docs/eventbus/` as the target directory
