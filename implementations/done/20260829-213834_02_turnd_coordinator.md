# Implementation Procedure: scripts/agent/turnd_coordinator.py

## Goal

Create `turnd_coordinator.py` as a new module containing the TurnCoordinator class, which encapsulates the turn-start and turn-end lifecycle logic currently scattered across Orchestrator's `_handle_turn_start`, `_handle_turn_end`, `_call_on_llm_wait_end`, `_call_on_turn_end`, and `_call_on_error` methods.

## Scope

- Create `scripts/agent/turnd_coordinator.py` only. No other source file is modified by this document.
- The TurnCoordinator class receives dependencies via constructor injection.
- Orchestrator will forward its turn-lifecycle callbacks to TurnCoordinator after this file exists.

## Assumptions

- TurnCoordinator needs access to AgentContext, audit_logger, on_llm_wait_end, on_turn_end, and on_error callbacks.
- The `_build_turn_end_event` method is moved to AuditEventEmitter; TurnCoordinator delegates to it.
- The `_format_session_id` helper is moved to AuditEventEmitter; TurnCoordinator delegates to it.
- TurnCoordinator does NOT own DiagnosticStore or ToolLoopGuard (per Issue constraint).

## Design decisions

1. **TurnCoordinator owns turn lifecycle**: All turn-start and turn-end logic moves here. This includes assigning turn IDs, emitting turn_start/turn_end events, and invoking callbacks.
2. **Dependency injection**: TurnCoordinator receives AgentContext, callbacks, and audit_logger via constructor.
3. **Delegation pattern**: TurnCoordinator delegates event construction to AuditEventEmitter and conversation manipulation to ConversationStateManager.

## Alternatives considered

1. **Keep callbacks in Orchestrator**: Would reduce refactoring effort but leaves Orchestrator with > 700 lines. Rejected.
2. **Merge TurnCoordinator into WorkflowEngineAdapter**: Would reduce component count but violates Single Responsibility Principle. Rejected per plan intent.
3. **Make TurnCoordinator a mixin**: Would introduce inheritance complexity without benefit. Composition is simpler. Rejected.

### Method

```python
"""scripts/agent/turnd_coordinator.py

TurnCoordinator: turn-start and turn-end lifecycle management.

Encapsulates:
  - Assigning turn IDs and emitting turn_start audit events
  - Emitting turn_end audit events and clearing current turn ID
  - Invoking on_llm_wait_end, on_turn_end, and on_error callbacks
"""

from __future__ import annotations

import logging
import time
import uuid
from typing import TYPE_CHECKING, Any

from agent.audit_event_emitter import AuditEventEmitter

if TYPE_CHECKING:
    from agent.context import AgentContext

logger = logging.getLogger(__name__)

class TurnCoordinator:
    """Manages turn-start and turn-end lifecycle events.

    Receives dependencies via constructor injection. Does NOT own
    DiagnosticStore or ToolLoopGuard (per Issue constraint).
    """

    def __init__(
        self,
        ctx: AgentContext,
        *,
        on_llm_wait_end: Any | None = None,
        on_turn_end: Any | None = None,
        on_error: Any | None = None,
        audit_logger: Any | None = None,
    ) -> None:
        self._ctx = ctx
        self._on_llm_wait_end = on_llm_wait_end
        self._on_turn_end = on_turn_end
        self._on_error = on_error
        self._audit_logger = audit_logger

    async def handle_turn_start(self, line: str) -> None:
        """Assign a turn ID and emit a turn_start audit event."""
        ctx = self._ctx
        ctx.turn.current_turn_id = str(uuid.uuid4())
        session_id = AuditEventEmitter.format_session_id(ctx.session.session_id) or "none"
        if self._audit_logger is not None:
            self._audit_logger.info(
                AuditEventEmitter.json_dumps({
                    "event": "turn_start",
                    "task_id": ctx.turn.current_turn_id,
                    "worker_id": session_id,
                    "event_id": str(uuid.uuid4()),
                    "ts": time.time(),
                }),
            )

    async def handle_turn_end(
        self,
        elapsed_ms: float,
        error_kind: str | None,
        is_partial: bool = False,
    ) -> None:
        """Emit a turn_end audit event and clear the current turn ID."""
        ctx = self._ctx
        if self._audit_logger is not None:
            event = AuditEventEmitter.build_turn_end_event(
                elapsed_ms, error_kind, ctx.turn.current_turn_id, is_partial
            )
            self._audit_logger.info(AuditEventEmitter.json_dumps(event))
        ctx.turn.current_turn_id = None

    def invoke_llm_wait_end(self) -> None:
        """Invoke on_llm_wait_end if configured."""
        if self._on_llm_wait_end:
            self._on_llm_wait_end()

    def invoke_turn_end(self) -> None:
        """Invoke on_turn_end if configured."""
        if self._on_turn_end:
            self._on_turn_end()

    def invoke_error(self, exc: Exception) -> None:
        """Invoke on_error with exc if configured."""
        if self._on_error:
            self._on_error(exc)
```
