- Overlap with `plans/20261027-104705_govrev004_adr-verification-evidence-sync.md` (same file): a sequencing dependency; this row is applied first.

## Design decisions

- Define four values in a compact list or table directly after the existing sentence "A row whose Verification Status is "Not verified" is Non-Blocking, ...", which stays unchanged:
  `Confirmed` (every part of the invariant is covered by cited automated tests or an explicit code reference; the Gate applies as stated), `Partial` (automated verification covers part of the invariant; the Gate is unchanged and the unverified scope is covered by manual review), `Manual` (no automated verification by design; the Gate is unchanged and the manual procedure is run as stated), `Not verified` (Non-Blocking, unchanged).
- Required row content: a `Partial` row names the unverified scope and an Owner; a `Manual` row with a Blocking or Deployment Blocking Gate names the manual procedure and an Owner.

## Alternatives considered

- Defining the vocabulary in `governance_01_documentation-policy.md`: rejected by the Plan (Design section), because that document delegates the matrix to the index and the definition would be split from the data.
- Treating Manual as a form of `Partial`: acceptable fallback per UNK-01, not the default.
