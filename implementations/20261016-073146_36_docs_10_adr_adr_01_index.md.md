## Design decisions

- Attach the posture guarantee to existing invariant ids instead of creating a new one. The matrix is keyed by
  `ADR-NNN INV-NN`, and `tools/check_adr_preservation.py:141-142` makes adding an `INV-NN` bullet in any ADR an
  ERROR. The new guarantee is therefore recorded as a new matrix row keyed to `ADR-002 INV-01, INV-02` and
  `ADR-004 INV-07, INV-10`, whose statements already cover "each process reads only its own configuration" and
  "Allowlist/auth failures are Fail-Closed at startup".
- Cite the new posture tests as bare file paths without `::`. Adding a `` `path.py::name` `` citation is an
  ERROR-level finding in `check_adr_preservation.py`, and `check_adr_invariant_matrix.py` only verifies
  `path.py::name`-shaped citations. A bare path such as `tests/agent/test_mcp_health_posture.py` is legal in
  both tools and still names the evidence.
- Update `:115`'s "Partial" status rather than claim full coverage. Row `29` adds a cross-cutting policy test,
  but posture coverage is per-server and per-check, so the honest status after this Plan is still Partial with a
  named gap; over-claiming here is exactly the stale-claim failure `tools/check_docs_consistency.py` exists to
  catch.
- Keep every existing citation byte-identical, including `tests/shared/test_config_loader.py::TestRestrictToIsolation`
  at `:111` and the six citations at `:125`. Removing any of them is an ERROR finding with no override flag
  (`tools/check_adr_preservation.py:260-268` exposes only `files`, `--base`, `--dir`).
- Do not add a new ADR row to `## ADR List`. This Plan changes existing decisions (rows `37`-`41` amend
  ADR-002, ADR-003, ADR-004, ADR-007, ADR-014); it does not record a new decision record.
