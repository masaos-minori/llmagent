## Design decisions
- Order of operations: compute `dest_code` and the kept source text; if `--dry-run`, print both diffs and return `0`; otherwise `stage_write` the destination and the source (a failure discards both and changes nothing, exit `1`), save the original destination text or note that it did not exist, commit the destination, then commit the source.
- If the source commit fails: restore the destination (`atomic_write_text` of the saved original, or unlink a destination this run created), discard the staged source, print the error, return `1`; if the restore fails too, print both paths, state that the moved code remains in both files, and return `1`.
- The destination is replaced first so a failure never loses code (Plan Design).

## Alternatives considered
- Replace the source first: rejected, a failure then loses moved code.
- A journal file: rejected, more machinery than the Plan asks for.
