# Implementation Procedure: scripts/agent/__init__.py

## Goal

Update `__init__.py` to export the six new concern classes so that existing import paths (`from agent.turnd_coordinator import TurnCoordinator`, etc.) continue to work.

## Scope

- Update `scripts/agent/__init__.py` only. No other source file is modified by this document.
- The purpose is to ensure backward-compatible import paths for the six new modules.

## Assumptions

- The six new modules exist: `turnd_coordinator`, `workflow_engine_adapter`, `bg_task_monitor`, `llm_turn_executor`, `audit_event_emitter`, `conversation_state_manager`.
- Each module exports exactly one public class matching its filename.
- Existing import paths (`from agent.turnd_coordinator import TurnCoordinator`, etc.) must continue to work.

## Design decisions

1. **Minimal updates**: Only add six new import statements to `__init__.py`. Do not modify any other file.
2. **No wildcard imports**: Use explicit `from X import Y` statements rather than `from X import *` to avoid namespace pollution.
3. **No re-export of existing classes**: The existing `Orchestrator` class remains exported as-is.

## Alternatives considered

1. **Merge some concerns into fewer components** (e.g., combine TurnCoordinator + ConversationStateManager): Would reduce the number of new files but violates the Single Responsibility Principle that motivated this refactor. Rejected per plan's design intent.
2. **Keep module-level functions in orchestrator.py**: Would reduce refactoring effort but leaves the file at > 700 lines. Rejected because it defeats the purpose of the refactor.
3. **Make Orchestrator a mixin or base class**: Would introduce inheritance complexity without benefit. Composition is simpler and more testable. Rejected.
