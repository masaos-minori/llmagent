## Design

Based on inspection of `orchestrator.py`:
```python
# Current (logs error at threshold and every subsequent failure):
elif self._consecutive_bg_failures >= BG_FAILURE_THRESHOLD:
    logger.error(...)

# Proposed (log error at threshold, then every 5th failure):
elif self._consecutive_bg_failures >= BG_FAILURE_THRESHOLD:
    if self._consecutive_bg_failures == BG_FAILURE_THRESHOLD or \
       (self._consecutive_bg_failures - BG_FAILURE_THRESHOLD) % 5 == 0:
        logger.error(...)
    else:
        logger.warning(...)
```
