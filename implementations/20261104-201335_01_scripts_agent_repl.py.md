## Goal

In `scripts/agent/repl.py`, make `main()` the single process entry that catches
`StartupInterrupted` raised by `asyncio.run(AgentREPL().run())` and returns normally, so a
startup interrupted by a shutdown request ends the process with exit status 0 and no
traceback, while a genuine startup failure keeps its non-zero exit and fatal message.
Implements REQ-001, REQ-003 of the source plan.

## Scope

- Modify only the body of `main()` (L160-162): wrap the existing
  `asyncio.run(AgentREPL().run())` in a `try/except StartupInterrupted` that returns
  normally.
- No signature change to `main()`; `StartupInterrupted` is already imported (L38), so no
  new import is added.
- Leave `AgentREPL.run()` (L97-152) untouched — it keeps its warn, clean up, re-raise
  contract (REQ-001).
- Leave the `if __name__ == "__main__": main()` guard (L165-166) unchanged.

## Assumptions

- The compiled binary launcher imports `main` from `agent.repl` and calls it without
  wrapping the return value (build_binaries.sh L246-249), so a normal return from
  `main()` yields exit status 0 for both `python -m agent` and the binary (plan
  Background item 1).
- `asyncio.run` cancels pending tasks before the exception leaves it, so catching
  `StartupInterrupted` outside `asyncio.run` is safe (plan Assumption).
- Exit status 0 is the owner's decision for both SIGTERM and SIGINT during startup
  (plan Assumption), so no signal-specific branch is needed.

## Design decisions

- Catch at the entry function, after `AgentREPL.run` has warned and cleaned up: this is
  the narrowest place that converts a requested shutdown into a normal return without
  touching the `run()` contract (REQ-001; plan Decision 1, alternative c).
- Return normally with no `SystemExit`: the owner chose status 0, so `main()` just
  returns; any non-`StartupInterrupted` exception is not caught and keeps its traceback
  and status 1 (REQ-003; plan Decision 2).

## Alternatives considered

- Handle inside `AgentREPL.run()`: rejected — would break the contract that `run()`
  re-raises and that cleanup precedes the exception leaving it.
- New entry module or function: rejected — adds a module for a three-line function;
  `main()` already exists and is what the launcher imports.

## Implementation

### Target file

`scripts/agent/repl.py`

### Procedure

1. In `main()` (L160-162), wrap the existing call:
   ```python
   def main() -> None:
       """Start the interactive REPL."""
       try:
           asyncio.run(AgentREPL().run())
       except StartupInterrupted:
           # A requested shutdown during startup is a normal operation, not a crash.
           return
   ```
2. Do not add a second `except` clause: any other exception (e.g. `RuntimeError`) must
   propagate unchanged (REQ-003).
3. Leave the `if __name__ == "__main__": main()` guard and `AgentREPL.run()` untouched.

### Method

Single inline edit to the body of `main()`; no signature change, no new import
(`StartupInterrupted` is already imported at L38), no new helper.

### Details

- The `except StartupInterrupted` binds no name: the non-fatal warning was already
  printed by `AgentREPL.run` before it re-raised, so nothing more is logged here; the
  process ends quietly (REQ-001).
- `StartupInterrupted` is a `BaseException` subclass; catching it explicitly (not a bare
  `except`) keeps broad handlers elsewhere from swallowing it differently (plan Risk
  mitigation).
- Vulture baseline for `repl.py` is 0 findings; the early `return` is reachable only via
  the new branch, so no dead-code finding.
