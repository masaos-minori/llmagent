## Goal

Rewrite the 10 MCP server `cmd` entries in `config/agent.toml` from the `uv run ... python /opt/llm/scripts/mcp_servers/<server>/<server>_server.py` form to the compiled binary form `/opt/llm/bin/<binary>`, so the agent starts MCP servers via the binary entries and passes the CommandValidator. Implements `REQ-007` / AC-09.

## Scope

Modifies the 10 `[mcp_servers.*]` `cmd` arrays in `config/agent.toml` only. Each entry currently reads e.g. `cmd = ["uv", "run", "--no-sync", "--directory", "/opt/llm", "python", "/opt/llm/scripts/mcp_servers/shell/shell_server.py"]` (verified at lines 365, 377, 386, 395, 404, 413, 430, 439, 448, 460).

## Assumptions

- The 11 binaries are built and present in `/opt/llm/bin/` (built by `deploy/build_binaries.sh`; this row is gated on the step 9 PoC gate passing).
- Each binary maps to a server key: `shell`→`shell`, `git`→`git`, `web_search`→`web_search`, `file_delete`→`file_delete`, `file_write`→`file_write`, `file_read`→`file_read`, `github`→`github`, `cicd`→`cicd`, `rag_pipeline`→`rag_pipeline`, `mdq`→`mdq`.
- The CommandValidator accepts these binaries because they are regular files directly inside the allowed binary directory (see the validator row).

## Design decisions

- Replace each 7-element `cmd` array with a single-element array containing the absolute binary path, e.g. `cmd = ["/opt/llm/bin/shell"]`. This removes the `uv run` indirection and the `--directory /opt/llm` wrapper.
- Keep the surrounding TOML structure (server keys, other keys) unchanged.

## Alternatives considered

- Keeping `uv run` for some servers: rejected — the plan switches all 10 MCP servers to binaries; peripheral `uv run` entry points are intentionally left alone (UNK-04).

## Implementation

### Target file

`config/agent.toml`

### Procedure

Replace each of the 10 `cmd` arrays with the absolute binary path.

### Method

1. For each of the 10 `[mcp_servers.*]` blocks, replace the existing `cmd = [...]` array with `cmd = ["/opt/llm/bin/<binary>"]`, mapping the server key to its binary name as listed above.
2. Leave every other key in each block unchanged.

### Details

- The binary names match the output names written by `deploy/build_binaries.sh`; keep them consistent across both rows.
- Because the binaries are self-contained, no `PYTHONPATH` or `--directory` argument is needed; `LLMAGENT_CONFIG_DIR` and `LLMAGENT_SUDACHI_DICT` are exported by the start script (its own row).

## Compatibility considerations

- Reverting these 10 arrays to their original `uv run` form and redeploying restores the pre-change path (AC-09). `scripts/` stays deployed, so the `uv run` path keeps working after rollback.

## Security considerations

- The rewritten entries point at fixed absolute paths under `/opt/llm/bin/`; the CommandValidator still enforces the real-path/regular-file/non-writable-directory rule on each start. Do not introduce a writable directory or symlink that would defeat the check.
