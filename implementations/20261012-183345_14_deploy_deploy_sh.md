## Goal

Update `deploy/deploy.sh` to place the 11 binaries into `/opt/llm/bin/` and the Sudachi dictionary into `/opt/llm/dict/system.dic`, so production has the compiled artifacts alongside the still-deployed `scripts/`. Implements `REQ-007` / AC-09.

## Scope

Modifies `deploy/deploy.sh`: add a binary-placement section and a dictionary-placement section. The rest of the script (workflow validation, `scripts/` rsync, `config/*.toml` copy, schemas, workflows, tests, `start_agent.sh` copy) is unchanged.

## Assumptions

- The binaries already exist in a build output directory (produced by `deploy/build_binaries.sh`); `deploy.sh` copies them into `/opt/llm/bin/`.
- The dictionary file exists in the build environment's `sudachipy` package resources or a known source path and is copied to `/opt/llm/dict/system.dic`.
- `/opt/llm/bin/` must be a directory not writable by group/others (Plan Assumptions), matching the CommandValidator's allowed-binary-directory rule.

## Design decisions

- Add a dedicated `DEPLOY_BIN="/opt/llm/bin"` and `DEPLOY_DICT="/opt/llm/dict"` section that creates the directories, copies the binaries, sets non-group/world-writable permissions, and copies the dictionary.
- Place this section after the existing `scripts/` rsync and before the start-script copy, keeping the script's existing ordering and checksum gates intact.

## Alternatives considered

- Having `deploy/build_binaries.sh` write directly to `/opt/llm/bin/`: rejected — the build script runs on the build host (not `/opt/llm`), while `deploy.sh` owns everything placed under `/opt/llm/`.

## Implementation

### Target file

`deploy/deploy.sh`

### Procedure

Add binary and dictionary placement to `deploy.sh`.

### Method

1. After the `scripts/` rsync section, add a `--- binaries + dict ---` section:
   - `mkdir -p "${DEPLOY_BIN}"` and `mkdir -p "${DEPLOY_DICT}"`.
   - Copy the 11 binaries from the build output directory into `${DEPLOY_BIN}/` (source path configurable via an env var such as `BUILD_OUTPUT_DIR`).
   - `chmod 0755` the binaries and `chmod 0755` `${DEPLOY_BIN}` so it is not group/world-writable.
   - Copy the Sudachi dictionary to `${DEPLOY_DICT}/system.dic` and ensure the directory is not group/world-writable.
2. Print a summary of the placed binaries and dictionary.

### Details

- Keep the existing `set -euo pipefail` and workflow checksum gate; do not reorder them.
- Make the build-output source path overridable so `deploy.sh` works whether the binaries were built on a remote host or locally.
