### Procedure

2. Add a new "Production-Only Migration Procedure" section documenting, in

   `loopbackonly`) and MCP authentication tokens (per `mcpauth`) together →
   verify `ProductionConfigValidator`'s unconditional strict validation (per
   `localremoval`) passes → perform a full process restart (not `/reload`,
   since auth/MCP-definition/bind-address changes are restart-only per
   `mcpauth` REQ-005) → verify authentication, discovery, routing,
   tool-visibility, and socket binding after restart → verify external
   connectivity is unavailable → delete any future Local-only overlay file
   only after the above verification succeeds, confirming its purpose and
   remaining references first (REQ-002).
3. Add a "Rollback Guidance" subsection: rollback means redeploying a prior
   release; explicitly state that rollback must never re-enable a Local
   runtime profile or restore a deleted override key (REQ-003).
4. State the precondition that `localremoval`, `loopbackonly`, and `mcpauth`
   must all be implemented and verified before this procedure is executed
   against a real deployment, with a re-verification reminder (per `UNK-01`)
   to re-run the zero-artifact inspection immediately before executing, not
   rely solely on this document's recorded finding (REQ-004).
