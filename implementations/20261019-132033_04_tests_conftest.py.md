## Goal
Isolate every test run from `/opt/llm`: build a temporary root at import time, point configuration and logs into it, add the production-path guard and its marker, and clean up at session end (`REQ-001`, `REQ-003`).

## Scope
- Module-level setup after the existing `sys.path` lines, one autouse fixture beside the existing ones, three hooks (`pytest_configure` (new), `pytest_collection_finish` (new), `pytest_sessionfinish`), and the helpers they use.

## Assumptions
- `scripts/shared/logger.py` already honors `LLMAGENT_LOG_DIR` (new) (sibling procedure, implemented first).
- No `pytest_*` hook exists in this file today, and `pyproject.toml` has no `--strict-markers`, so the marker is registered from `pytest_configure` (new).
- `tests/__init__.py` exists, so this file is imported as `tests.conftest`; setup is made idempotent with `LLMAGENT_TEST_ROOT` (new) so a second import reuses the same root.

## Design decisions
- Set the environment at module import, not in a fixture: `Logger` instances and several MCP server modules read configuration while `scripts/` modules are imported during collection.
- Rewrite only writable-state prefixes (`db`, `storage`, `offsets`, `deadletter`, `rag-src`, `logs`, `memory`) so `sqlite_vec_so`, `bin`, `docs`, and `venv` keep their real read-only paths.
- The guard fails loudly with the offending path and test id instead of redirecting silently.

## Alternatives considered
Per-test fixtures that patch `build_db_config` were rejected: they miss `recovery`, `rotation`, `maintenance`, memory JSONL, and Event Bus paths and run too late for import-time loggers.

## Implementation
### Target file
`tests/conftest.py`

### Procedure
1. Add imports `atexit`, `logging`, `re`, `sqlite3`, `tempfile`.
2. After the `sys.path` lines, define `_build_isolated_root` (new) and run it once: copy `config/` and `schemas/` into a `tempfile.mkdtemp` root, rewrite the writable-state prefixes in every `*.toml` with a regular expression, and create the directories the rewritten paths need (for a path with a suffix its parent, otherwise the path).
3. Set `LLMAGENT_TEST_ROOT` (new), `LLMAGENT_CONFIG_DIR` (`<root>/config`), `EVENTBUS_CONFIG_PATH` (`<root>/config/eventbus.toml`), `EVENTBUS_SCHEMA_PATH` (`<root>/schemas/event_envelope.json`), and `LLMAGENT_LOG_DIR` (new) (`<root>/logs`); register `atexit` removal of the root only when this import created it.
4. Define `_is_production_path` (new) (resolved path equals or starts with `/opt/llm/`), `_cleanup_isolated_root` (new), and `_production_file_handlers` (new) (all `logging.FileHandler` objects of registered loggers whose `baseFilename` (new) is production).
5. Add the autouse fixture `_forbid_production_paths` (new): unless the test has the marker `production_paths_allowed` (new), patch `sqlite3.connect` and `logging.FileHandler.__init__` with wrappers that raise `AssertionError` naming the path and `request.node.nodeid`; otherwise yield without patching.
6. Add `pytest_configure` (new) to register the marker, `pytest_collection_finish` (new) to `pytest.exit` with a message and a non-zero code when `_production_file_handlers` (new) is non-empty, and `pytest_sessionfinish` to call `_cleanup_isolated_root` (new).

### Method
- Rewrite regular expression: `/opt/llm/(db|storage|offsets|deadletter|rag-src|logs|memory)\b` replaced with `<root>/\1`; apply to text of each `.toml` under the copied `config/` (including subdirectories).
- Guard wrappers resolve the argument with `os.path.realpath(os.fspath(path))`; `:memory:` and non-path arguments are ignored; the wrappers call the originals otherwise.
- Place the module-level setup before any import of a `scripts/` module (this file imports none at module level today).

### Details
- Document the two environment variables, the root, and the marker in a short module docstring addition.
- xdist workers import this file independently and each get their own root; the controller's `LLMAGENT_TEST_ROOT` (new) is reused only if it still exists.
- Update the fixture manifest in `tools/check_conftest_integrity.py` in the sibling procedure.
- Use only the new, production-safe test files until the conftest isolation exists; do not run the full suite (it writes to `/opt/llm`). After this change, run the affected suites named in the plan before any full run.

## Compatibility considerations
Every test now sees the redirected configuration; tests that asserted real `config/*.toml` values through `ConfigLoader` may need a local patch or the marker (Plan UNK-03). Tests that set or delete `LLMAGENT_CONFIG_DIR` with `monkeypatch` are restored to the conftest value afterwards.

## Security considerations
The root lives in the system temporary directory and holds only copies; the guard prevents opening production databases or log files; nothing is written to `/opt/llm`.
