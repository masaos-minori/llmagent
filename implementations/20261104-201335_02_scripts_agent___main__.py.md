## Goal

In `scripts/agent/__main__.py`, replace the duplicated `asyncio.run(AgentREPL().run())`
with a call to `agent.repl.main`, so both `python -m agent` and the compiled binary share
the single interrupted-startup handler. Implements REQ-002 of the source plan.

## Scope

- Modify the top-of-file imports (L9, L11): drop `import asyncio` and
  `from agent.repl import AgentREPL`, add `from agent.repl import main`.
- Replace the guard body (L13-14): call `agent.repl.main` instead of
  `asyncio.run(AgentREPL().run())`.

## Assumptions

- `main()` (row 01) runs `asyncio.run(...)` internally, so `__main__` no longer needs the
  event loop or `AgentREPL` directly.
- The compiled binary launcher imports `main` from `agent.repl`, not from `__main__`, so
  this file only affects the `python -m agent` path.

## Design decisions

- Delegate to `agent.repl.main`: one entry point handles the interrupt for both paths
  (REQ-002; plan Decision 1c).

## Alternatives considered

- Keep `asyncio.run(AgentREPL().run())` in `__main__`: rejected — duplicates the entry
  call and bypasses the single catch in `main()`.

### Method

### Details

- Removing `import asyncio` avoids an F401 unused-import error once the guard no longer
  calls `asyncio.run`.
- `main()` is defined in `scripts/agent/repl.py` (row 01), which now catches
  `StartupInterrupted`; `__main__` inherits that behavior by delegation.
