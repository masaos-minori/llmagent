## Goal

Provision the Agent-side control credential for each of the ten MCP servers with `control_auth_token = "${ENV:MCP_<NAME>_CONTROL_TOKEN}"` in every `[mcp_servers.*]` entry.

## Scope
**Release unit**: N/A: not part of a release unit

In scope: ten one-line additions after each entry's `auth_token` line. No other key changes.

## Assumptions

- Verified: entries use the aligned `key             = value` style and `auth_token = "${ENV:MCP_<NAME>_AUTH_TOKEN}"` for shell, git, web_search, file_delete, file_write, file_read, github, cicd, rag_pipeline, and mdq.
- An unset variable is tolerated by `resolve_control_token` (row 06), so deployment does not have to export the variables before this lands; recovery degrades to `outcome_unknown` until it does.
- `deploy.sh` stays unchanged (UNK-02): operators export the new variables on the deployment host.

## Design decisions

- Variable names: MCP_SHELL_CONTROL_TOKEN, MCP_GIT_CONTROL_TOKEN, MCP_WEB_SEARCH_CONTROL_TOKEN, MCP_FILE_DELETE_CONTROL_TOKEN, MCP_FILE_WRITE_CONTROL_TOKEN, MCP_FILE_READ_CONTROL_TOKEN, MCP_GITHUB_CONTROL_TOKEN, MCP_CICD_CONTROL_TOKEN, MCP_RAG_PIPELINE_CONTROL_TOKEN, MCP_MDQ_CONTROL_TOKEN.
