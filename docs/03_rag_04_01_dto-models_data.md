# 6.1 models_data.py (`scripts/rag/models_data.py`)

## Purpose of Data Structures

This file defines the data models shared throughout the RAG pipeline. All DTOs are defined as `@dataclass(frozen=True)`, prohibiting modification after creation.

## Key Fields for Design

### EmbeddingResponse — Response from Embedding API
- `embedding`: Embedding vector (Required)
- `model`: Model name (Optional)

### CrawlTarget — Target for WebCrawler
- `url`: URL to crawl (Required)
- `lang`: Language hint (`LanguageCode` enum, `"en"`/`"ja"`)

### ChunkDocument — Chunk data passed between pipeline stages
- `url`, `title`, `lang`, `content`: Required fields
- `etag`, `last_modified`: For change detection
- `normalized_content`: Sudachi-normalized text (Japanese only)
- `chunking_strategy`, `source_file`, `chunk_type`: Processing metadata

### ChunkRecord — Chunk with embedding vector (used by query pipeline)
- `chunk_id`, `url`, `title`, `lang`, `content`: Required fields
- `embedding`: Embedding vector

### CacheEntry — Semantic cache entry
- `embedding`, `context_str`: Required fields
- `history_context`: Related conversation history
- `generation`: Generation counter for cache invalidation

### TwoStageFetchResult — Result of HTTP RAG service call
- `hits`: `list[RagHit]` when in-process; `dict` when in HTTP mode (different types)
- `min_score_applied`, `max_chunks_per_doc`: Filtering parameters

### CrawlPayload — Output payload of WebCrawler
Example JSON payload generated by the WebCrawler:

```json
{
  "schema_version": "1",
  "artifact_type": "crawl",
  "created_by": "crawler",
  "url": "https://example.com/page",
  "title": "Page title",
  "lang": "ja",
  "fetched_at": "2024-01-01T12:00:00",
  "content": "body text",
  "code_blocks": ["block1", "block2"],
  "etag": "optional-http-etag",
  "last_modified": "optional-http-date"
}
```

- **Web:** `etag` is HTTP ETag, `last_modified` is HTTP Last-Modified
- **Local file:** `etag` is SHA-256 hash, `last_modified` is mtime
- **`.py` file:** Content stored in `code_blocks`, `content` is empty

- `url` is the target URL, `title` is the page title, `lang` is the language.
- For Web, `etag` is HTTP ETag, `last_modified` is HTTP Last-Modified.
- For local files, `etag` is the SHA-256 hash, and `last_modified` is the mtime.
- For `.py` files, content is stored in `code_blocks`, while `content` remains empty.

## Constraints Regarding Persistence, Search, and Compatibility

- `ChunkDocument.normalized_content` is valid for Japanese only.
- The element type of `TwoStageFetchResult.hits` differs depending on the execution mode (`RagHit` vs `dict`).
- `CrawlTarget.lang` uses the `LanguageCode` enum, whereas other DTOs use a plain `str` for `lang` (Note the type inconsistency).
