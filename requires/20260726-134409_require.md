## Background

Memory snippets obtained via on_user_prompt() are injected as "role": "system" messages into conversation history. This can influence LLM behavior based on user input. Additionally, when entry.summary doesn't exist, entry.content[:100] is used as prefix, cutting off content at only the first 100 characters and potentially losing important information.

## Problem

Memory snippets injected as system context can be manipulated by the LLM through intentional query triggering, leading to unwanted behavior changes.

## Reason for Change

Establish behavioral baseline through guard tests before any refactoring of these components.

## Implementation Intent

Create comprehensive guard tests covering:
- Sensitive data filtering verification
- Maximum snippet length enforcement
- System message priority verification
- Content truncation impact verification
