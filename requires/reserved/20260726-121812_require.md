# Fix eventbus layer isolation violation — remove dependencies on db.helper and shared.json_utils

## Priority

High

## Target Files

- `scripts/eventbus/db.py:8` — `from db.helper import apply_connection_pragmas`
- `scripts/eventbus/ack_route.py:8` — `from shared.json_utils import now_iso`
- `scripts/eventbus/dlq.py:11` — `from shared.json_utils import now_iso`
- `scripts/eventbus/publish_route.py:11` — `from shared.json_utils import dumps as json_dumps`
- `scripts/eventbus/replay_route.py:9` — `from shared.json_utils import dumps as json_dumps`
- `scripts/eventbus/subscribe_route.py:10` — `from shared.json_utils import dumps as json_dumps`
- `.importlinter` — `eventbus-is-isolated` contract
- `rules/env.md` — design policy documentation

## Background

The `.importlinter` contract `eventbus-is-isolated` requires that the eventbus layer be completely independent of all other layers. However, six imports violate this contract:

```
eventbus → db.helper (apply_connection_pragmas)
eventbus → shared.json_utils (now_iso, dumps)
```

These were introduced as side effects of DRY refactoring but contradict the original design intent documented in `rules/env.md`.

## Problem

```python
# scripts/eventbus/db.py:8
from db.helper import apply_connection_pragmas

# scripts/eventbus/ack_route.py:8
from shared.json_utils import now_iso

# scripts/eventbus/dlq.py:11
from shared.json_utils import now_iso

# scripts/eventbus/publish_route.py:11
from shared.json_utils import dumps as json_dumps

# scripts/eventbus/replay_route.py:9
from shared.json_utils import dumps as json_dumps

# scripts/eventbus/subscribe_route.py:10
from shared.json_utils import dumps as json_dumps
```

This creates a bidirectional dependency: eventbus depends on lower layers, violating the layering contract.

## Reason for Change

Architecture violations undermine the reliability guarantees provided by the layering model. If eventbus depends on db.helper, changes to db.helper could break eventbus without detection. The contract exists specifically to prevent this.

## Implementation Intent

Remove the two external dependencies by duplicating only the functions used by eventbus:

1. **db.helper → eventbus**: Copy `apply_connection_pragmas()` into `scripts/eventbus/db.py` as a local function
2. **shared.json_utils → eventbus**: Copy `now_iso()` and `dumps()` into `scripts/eventbus/json_helpers.py` as local functions

Do NOT copy the entire modules — only the specific functions used by eventbus.

## Implementation Instructions

### Step 1: Duplicate `apply_connection_pragmas`

1. Read `scripts/db/helper.py` and extract the `apply_connection_pragmas(conn)` function body
2. Add it to `scripts/eventbus/db.py` as a private `_apply_connection_pragmas(conn)` function
3. Replace the import with a call to the local function

### Step 2: Duplicate `now_iso` and `dumps`

1. Create `scripts/eventbus/json_helpers.py`
2. Copy `now_iso()` and `dumps()` from `shared/json_utils.py`
3. Update all six eventbus files to import from `json_helpers` instead of `shared.json_utils`

### Step 3: Verify

1. Run `PYTHONPATH=scripts uv run lint-imports` — confirm `eventbus-is-isolated` passes
2. Run existing eventbus tests — confirm no regressions
