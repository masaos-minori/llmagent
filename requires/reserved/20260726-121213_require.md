# Add dedicated unit tests for shared/json_utils.py, config_utils.py, and llm_hot_config.py

## Priority

Medium

## Target Files

- `scripts/shared/json_utils.py` — extract_llm_content 4-branch logic (no dedicated test)
- `scripts/shared/config_utils.py:16-23` — get_str type validation (no dedicated test)
- `scripts/shared/llm_hot_config.py` — apply_config/apply_one (no dedicated test)
- `tests/shared/test_json_utils.py` — new file
- `tests/shared/test_config_utils.py` — new file
- `tests/shared/test_llm_hot_config.py` — new file

## Background

Three critical shared modules used across all layers have no dedicated test files. The audit report confirmed zero coverage for these modules despite their wide usage.

## Problem

| File | Lines | Issue |
|---|---|---|
| `shared/json_utils.py` | 132 | extract_llm_content has 4 untested branches (missing choices / non-dict choices[0] / non-dict message / non-str content) |
| `shared/config_utils.py` | 23 | get_str type validation for non-string values untested |
| `shared/llm_hot_config.py` | 58 | apply_config/apply_one field application logic untested |

## Reason for Change

These modules are used by all layers but have no dedicated test protection. A regression in any branch would go undetected.

## Implementation Intent

Create three new test files under `tests/shared/`:

1. **test_json_utils.py**: Test all functions in json_utils.py, especially extract_llm_content's 4 branches
2. **test_config_utils.py**: Test get_str type validation including non-string input
3. **test_llm_hot_config.py**: Test apply_config/apply_one for all 9 fields

## Implementation Instructions

### test_json_utils.py
- Test `dumps()` with various types (dict, list, primitive)
- Test `now_iso()` and `now_iso_raw()` format correctness
- Test `tool_call_serialized_length()` and `serialized_length()`
- Test `parse_http_json()` success and error cases
- Test `extract_llm_content()` all 4 branches:
  - Empty choices list
  - Non-dict choices[0]
  - Non-dict message
  - Non-str content

### test_config_utils.py
- Test `get_str()` with string and non-string inputs
- Test `get_str()` with missing keys
- Test `get_str()` with default values

### test_llm_hot_config.py
- Test `apply_one()` for each of the 9 fields
- Test `apply_config()` applies all configured fields
- Test `apply_config()` skips non-existent fields gracefully
