# Add OSError injection test for dlq.py _atomic_write

## Priority

Medium

## Target Files

- `scripts/eventbus/dlq.py:147-162` — _atomic_write
- `tests/test_eventbus_dlq.py` — OSError injection test addition

## Background

The `_atomic_write` method has an inconsistency guarantee when JSON writing fails:

```python
def _atomic_write(self, path, data):
    try:
        with open(path, 'w') as f:
            json.dump(data, f)
    except OSError:
        return False  # DB row not updated
    return True
```

There's no test verifying that the DB row isn't updated when OSError occurs.

## Problem

The consistency guarantee is unverified. If an OSError occurs during write, there's no way to confirm the DB row remains unchanged.

## Reason for Change

Verify the consistency guarantee through an injection test.

## Implementation Intent

Add a test that injects OSError into `_atomic_write` and verifies:
1. The method returns False
2. The DB row isn't updated (consistency guarantee)

## Implementation Instructions

1. Add a test to `tests/test_eventbus_dlq.py`:
   ```python
   @patch("scripts.eventbus.dlq.DLQHandler._atomic_write")
   def test_atomic_write_oserror_returns_false_and_no_db_update(mock_write):
       mock_write.side_effect = OSError("disk full")
       handler = DLQHandler(...)
       result = handler.move_to_dlq(message_id="123", reason="test")
       assert result is False
       # Verify DB row wasn't updated
       db_row = get_db_row_for_message("123")
       assert db_row["dlq_status"] != "dead_letter"
   ```
2. Run tests to confirm no regressions
