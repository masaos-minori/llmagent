# Fix CI branch name mismatch between workflow and repository

## Priority

High

## Target Files

- `.github/workflows/ci.yml` — branch name specification
- `rules/toolchain.md` — `--compare-branch` documentation
- Repository default branch — currently `master`

## Background

The CI configuration references `main` as the default branch, but the repository's actual default branch is `master`. This causes two problems:

1. The `diff-cover --compare-branch=main` command fails locally with `fatal: ambiguous argument 'main...HEAD'`
2. GitHub Actions push/pull_request triggers may not fire if they reference a non-existent branch

## Problem

```yaml
# .github/workflows/ci.yml
on:
  push:
    branches: [main]     # main does not exist
  pull_request:
    branches: [main]     # main does not exist

steps:
  - name: diff-cover gate
    run: uv run diff-cover coverage.xml --compare-branch=main --fail-under=90
```

```bash
$ uv run diff-cover coverage.xml --compare-branch=main --fail-under=90
fatal: ambiguous argument 'main...HEAD'
```

## Reason for Change

CI jobs are likely not triggering on push/PR events. The diff-cover gate is completely broken, meaning code coverage regressions go undetected.

## Implementation Intent

**Decision required from human:** Choose between Option A and Option B below.

### Option A: Align CI config to existing `master` branch (recommended)

Change all `main` references to `master`:
1. `.github/workflows/ci.yml`: `branches: [main]` → `branches: [master]`
2. `rules/toolchain.md`: `--compare-branch=main` → `--compare-branch=master`

### Option B: Rename repository default branch to `main`

1. Rename `master` → `main` via GitHub UI
2. Update local clone: `git branch -m master main`
3. Update remote: `git push origin HEAD:main`
4. Set `main` as default branch in GitHub settings
5. Update branch protection rules

## Implementation Instructions

After human decides the option:

For Option A:
1. Edit `.github/workflows/ci.yml`, replace all `[main]` with `[master]`
2. Edit `rules/toolchain.md`, replace `--compare-branch=main` with `--compare-branch=master`
3. Verify: `uv run diff-cover coverage.xml --compare-branch=master --fail-under=90` runs without error

For Option B:
1. Follow GitHub branch rename procedure
2. Update all local clones
3. Update CI config to use `main` (already correct after rename)
4. Update branch protection rules
