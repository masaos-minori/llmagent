- `scripts/shared/tool_executor.py:91-134` — _raw_execute()

## Background

The _execute_with_stampede_protection() method uses a shared future to prevent stampede for concurrent requests. However, when _raw_execute() raises an exception, the exception propagates to all waiting requests via inflight.set_exception(exc). This means a temporary failure can affect multiple tool calls simultaneously. Additionally, _record_transport_error() records failures in the server health registry, potentially affecting other tool calls on the same server.

## Problem

A single transient network error causes all concurrent requests with the same cache key to fail together, and the server health registry may be affected.

## Reason for Change

Establish behavioral baseline through guard tests before any refactoring of these components.

- Concurrent request exception propagation verification

- Retry policy behavior verification
