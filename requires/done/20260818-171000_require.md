# Title: [REQ] Apply Repo-Wide Documentation Hygiene Policy
# Priority: Medium
# Target files: docs/**/*.md, *.py (docstrings)
# Background: Documentation currently suffers from hardcoded counts, line-number references, restated configuration values, and stale "Resolved/Deprecated" notes that lead to information drift.
# Problem: 
# 1. Maintained counts (e.g., "N tools") become inaccurate quickly.
# 2. Line-number references rot after edits.
# 3. Restating `config/*.toml` values creates multiple sources of truth.
# 4. Stale "Resolved/Deprecated" notes mislead readers.
# Reason for change: To improve documentation maintainability and prevent information drift.
# Implementation intent: Systematically remove problematic documentation patterns across the repository.
# Implementation instructions:
# 1. Scan all design docs and code docstrings to remove maintained counts (replace with enumeration).
# 2. Scan all documents to replace absolute line-number references with symbol/name references.
# 3. Audit design docs to remove concrete `config/*.toml` values, replacing them with references to the relevant dataclasses.
# 4. Identify and remove stale "Resolved/Deprecated" notes that no longer apply to current behavior.
# Acceptance criteria:
# - No design doc or docstring contains maintained counts.
# - No design doc contains absolute line-number references.
# - No design doc restates concrete `config/*.toml` values.
# - Stale "Resolved/Deprecated" notes are removed.
