# HttpStartupError RuntimeError message omits StartupFailure details

## Priority
Low

## Summary
HttpStartupError.__init__ calls super().__init__(failure.reason), so the RuntimeError message only contains the reason string. Full StartupFailure details (server_key, stderr_full) are accessible via the .failure attribute but not visible in print(exc).

## Reason for Change
When HttpStartupError is caught and printed, users see only the reason string. The full context (server_key, stderr_full) requires accessing the .failure attribute programmatically.

## Implementation Intent
Consider overriding __str__ or __repr__ to include full StartupFailure details in the error message.

## Target Files or Areas
- scripts/agent/http_lifecycle.py
- HttpStartupError class

## Required Changes
- Override __str__ or __repr__ to include full StartupFailure details
- Ensure error messages are user-friendly and actionable
- Document the error handling policy clearly
