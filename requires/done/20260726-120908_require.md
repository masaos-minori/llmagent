## Background

The WebCrawler has four critical code paths that are not tested by any unit or integration test:

1. **HTTP retry** (503→200 sequence): Lines 264-294
2. **304 Not Modified skip**: Lines 188-230
3. **max_pages boundary**: When exactly `max_pages` URLs have been crawled
4. **BFS queue / external link filtering**: Lines 367-403

These are covered by coverage omit in pyproject.toml, confirming they lack test coverage. Additionally, no E2E integration test exists despite the audit report noting "integration testで別途検証" as the intended approach.

## Problem

```python
# rag/ingestion/crawler.py:264-294
async def _fetch_with_retry(self, url, headers):
    for attempt in range(self.config.get("fetch_retry", 3)):
        try:
            resp = await self._client.get(url, headers=headers)
            if resp.status_code == 503:
                await asyncio.sleep(2 ** attempt)
                continue
            return resp
        except httpx.TimeoutException:
            ...
```

No test verifies the retry behavior when a server returns 503 followed by 200 on retry. Similar gaps exist for the other three code paths.

## Reason for Change

This component was classified as High-risk-refactor because it lacks test coverage. Without guard tests, any refactoring could introduce regressions undetected.

## Implementation Intent

Create `tests/test_crawler_retry_boundary.py` with four test methods using respx:

1. `test_retry_on_503_then_succeeds`: Mock 503→200 sequence, verify second attempt succeeds
2. `test_skip_304_response`: Mock 304 response, verify URL added to crawled set without re-fetching content
3. `test_max_pages_boundary`: Set max_pages=1, verify crawling stops after first page
4. `test_external_link_filter`: Verify external links are filtered based on skip_external config

## Implementation Instructions

1. Create `tests/test_crawler_retry_boundary.py`
2. Use `respx.mock()` to intercept HTTP requests at the httpx level
3. For each test:
   - Configure WebCrawler with appropriate settings
   - Set up respx routes matching the expected request patterns
   - Execute crawl and verify correct behavior
4. Run `uv run pytest tests/test_crawler_retry_boundary.py -v` to confirm all pass
