# Fix incorrect `-part1` filename reference for RAG known-issues doc in docs/00_index.md

## Priority
Low

## Target files
- `docs/00_index.md` (line ~128)

## Background
`docs/00_index.md` maintains a task-scope-to-reference-doc lookup table used by readers and
agents to find the correct documentation file for a given task. Several entries in this table
correctly reference files that are split into multiple parts (e.g. `02_deployment-part1.md` /
`02_deployment-part2.md`, which do exist as separate files). However, one entry incorrectly
applies the same `-part1` suffix pattern to a file that was never split.

## Problem
Line ~128 of `docs/00_index.md`, in the "RAG known bugs / inconsistencies" row of the RAG task
table, references `03_rag_90_inconsistencies_and_known_issues-part1.md`. This file does not
exist. Verified via `ls docs/`: only `03_rag_90_inconsistencies_and_known_issues.md` exists (no
`-part1` or `-part2` variant). The correct filename (without the `-part1` suffix) is already
used correctly elsewhere in the same document, in the "既知の問題" (Known Issues) list around
line 51 (`- [RAG](03_rag_90_inconsistencies_and_known_issues.md)`), and in
`docs/00_governance_08_known-issues-migration-plan.md` (line ~24,
`` `docs/03_rag_90_inconsistencies_and_known_issues.md` ``). This makes line 128 an isolated,
confirmed typo rather than a naming convention applied elsewhere.

## Reason for change
A broken file reference in the RAG "known bugs / inconsistencies" pointer misleads readers and
AI agents attempting to open the referenced file while doing RAG-related work, since the
referenced filename does not resolve to any real file in `docs/`.

## Implementation intent
Direct text correction only. No restructuring of the index table, no renaming of any actual
doc file, and no changes to any other `-part1`/`-part2` reference in the document (those other
references point to files that genuinely exist in split form and must remain unchanged).

## Implementation instructions
1. Open `docs/00_index.md`.
2. Locate the row (around line 128) in the RAG task-scope table:
   `| RAG known bugs / inconsistencies | \`03_rag_90_inconsistencies_and_known_issues-part1.md\` |`
3. Change the filename in that row from
   `03_rag_90_inconsistencies_and_known_issues-part1.md` to
   `03_rag_90_inconsistencies_and_known_issues.md` (remove the `-part1` suffix only).
4. Do not modify any other line in `docs/00_index.md`, including other `-part1`/`-part2`
   references (e.g. `02_deployment-part1.md`, `05_agent_*-part1.md` entries), which are correct
   as-is and out of scope for this change.
