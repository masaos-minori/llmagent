# Requirement: Preserve Messages on History Compression Failure

## Priority

High

## Target Files

- `scripts/agent/history.py`

## Background

When LLM-based conversation history compression fails, the original messages are lost because `_generate_summary()` can return `None` without being handled.

## Problem

In `history.py`:

```python
async def compress_history(self):
    summary = await self._generate_summary(messages)
    compressed = [summary] + recent_messages[-window_size:]
```

This means:

1. If `_generate_summary()` returns `None`, `compressed` becomes `[None, ...]` — corrupting the message list
2. If `_generate_summary()` raises an exception, no fallback is provided
3. Original messages are unrecoverably lost in both cases

## Reason for Change

Conversation history is critical user data. Losing it due to a transient LLM failure is unacceptable. The system must always preserve the original messages when compression fails.

## Implementation Intent

Ensure that when history compression fails (either by returning `None` or raising an exception), the original messages are preserved rather than discarded.

## Implementation Instructions

### Step 1: Handle None return from `_generate_summary()`

```python
async def compress_history(self) -> List[Message]:
    """Compress history, preserving original messages on failure."""
    try:
        summary = await self._generate_summary(messages)
        
        if summary is None:
            logger.warning("History compression returned None, keeping original messages")
            return messages
        
        compressed = [summary] + recent_messages[-window_size:]
        return compressed
    
    except Exception as e:
        logger.error(f"History compression failed: {e}")
        return messages
```

### Step 2: Ensure DB save only happens on success

Review where `compress_history()` result is saved to the database. Ensure the save operation is conditional on successful compression:

```python
compressed = await self.history.compress_history()
if compressed is not None:
    await self._save_to_db(compressed)
else:
    # Keep original messages in DB
    pass
```

## Acceptance Criteria

1. When `_generate_summary()` returns `None`, original messages are preserved
2. When `_generate_summary()` raises an exception, original messages are preserved
3. Database state remains consistent after compression failure
4. Normal compression operation is unaffected — no regression
