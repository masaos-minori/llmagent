# Requirement: Clean Up Tool Loop Guard State on Streaming Exception

## Priority

High

## Target Files

- `scripts/agent/orchestrator.py`
- `scripts/agent/tool_loop_guard.py`

## Background

When an exception occurs during LLM streaming in `orchestrator.py`, the `tool_loop_guard` retains its `running_tool` lock state. Without cleanup in a `finally` block, subsequent tool calls will be blocked indefinitely.

## Problem

In `orchestrator.py`, the streaming response handler lacks a `finally` block:

```python
try:
    async for chunk in response:
        yield chunk
except Exception as e:
    # Stream interrupted but guard state not cleaned up
```

This means:

1. LLM streaming begins and `tool_loop_guard.running_tool` is set
2. An exception occurs (network error, timeout, etc.)
3. The stream is interrupted
4. `running_tool` remains locked
5. Next tool call attempts to acquire the lock — hangs or times out
6. Agent REPL becomes unresponsive until restart

## Reason for Change

A hung agent REPL is a critical user-facing failure. The loop guard's lock must be released regardless of how the stream ends.

## Implementation Intent

Ensure that `tool_loop_guard` state is always cleaned up when streaming ends, whether normally or via exception.

## Implementation Instructions

### Step 1: Add `finally` block to `stream_response()`

In `orchestrator.py`:

```python
async def stream_response(self):
    try:
        async for chunk in response:
            yield chunk
    except Exception as e:
        logger.error(f"Streaming failed: {e}")
        raise
    finally:
        # Always clean up guard state
        if hasattr(self, '_guard') and self._guard:
            await self._guard.release_running_tool()
```

### Step 2: Verify `release_running_tool()` exists or add it

If `tool_loop_guard.py` does not have a `release_running_tool()` method, add one:

```python
class ToolLoopGuard:
    async def release_running_tool(self):
        """Release the running_tool lock, resetting guard state."""
        self.running_tool = None
        # Also reset any accumulated token count if needed
        # self.current_tokens = 0  # Only if appropriate
```

## Acceptance Criteria

1. When streaming ends normally, `running_tool` is released
2. When streaming fails with an exception, `running_tool` is still released
3. Subsequent tool calls after a streaming failure work correctly
4. No regression in normal streaming behavior
