## Title

Fix inconsistent signal handler installation on add_signal_handler failure

## Priority

Medium

## Target files

- scripts/agent/repl.py

## Background

When `loop.add_signal_handler()` fails with `NotImplementedError` (on Windows), the code falls back to using `signal.signal()` directly. However, this fallback has a race condition: if one `add_signal_handler` succeeds and the other fails, the handlers are installed inconsistently.

## Problem

`repl.py:486-492`: The try-except wraps both `add_signal_handler` calls together. If SIGTERM's `add_signal_handler` succeeds but SIGINT's fails, the except block installs BOTH handlers via `signal.signal()`. This means:
- SIGTERM has TWO handlers: one from `add_signal_handler` and one from `signal.signal()`.
- SIGINT has ONE handler: from `signal.signal()`.

Additionally, the lambda functions at line 491-492 ignore the signal arguments (`lambda *_:`), which may cause issues on some platforms.

## Reason for change

Ensure consistent signal handler installation regardless of which platform-specific mechanism succeeds or fails.

## Implementation intent

Install signal handlers one at a time, catching `NotImplementedError` for each individually. If any handler fails to install via `add_signal_handler`, fall back to `signal.signal()` for that specific handler only.

## Implementation instructions

Change the code from:

```python
# Before (repl.py ~line 485):
try:
    loop.add_signal_handler(signal.SIGTERM, _sigterm_handler)
    loop.add_signal_handler(signal.SIGINT, _sigterm_handler)
except NotImplementedError:
    import signal as _signal
    _signal.signal(_signal.SIGTERM, lambda *_: _sigterm_handler())
    _signal.signal(_signal.SIGINT, lambda *_: _sigterm_handler())
```

To:

```python
# After:
import signal as _signal

for sig in (signal.SIGTERM, signal.SIGINT):
    try:
        loop.add_signal_handler(sig, _sigterm_handler)
    except NotImplementedError:
        _signal.signal(sig, lambda *_: _sigterm_handler())
```

Alternatively, use a helper function for clarity:

```python
def _install_signal_handler(loop, sig, handler):
    """Install a signal handler, falling back to signal.signal() on NotImplementedError."""
    try:
        loop.add_signal_handler(sig, handler)
    except NotImplementedError:
        import signal as _signal
        _signal.signal(sig, lambda *_: handler())

_install_signal_handler(loop, signal.SIGTERM, _sigterm_handler)
_install_signal_handler(loop, signal.SIGINT, _sigterm_handler)
```
