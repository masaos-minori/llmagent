# Requirement: Fix WAL Backup Path Validation

## Priority

Medium

## Target Files

- `scripts/agent/repl.py`

## Background

The WAL backup path generation has two issues: the extension changes when appending `-wal`, and the `allowed_root` check applies to the DB path rather than the WAL file itself.

## Problem

In `repl.py`:

```python
wal_file = f"{db_path}-wal"  # Wrong: removes .db extension
backup_dir = os.path.dirname(db_path) or "/tmp"
```

When `db_path = "/opt/llm/data/session.db"`:
- Expected WAL path: `/opt/llm/data/session.db-wal`
- Actual WAL path: `/opt/llm/data/session-wal` (extension lost)

Additionally, `_is_db_path_allowed()` checks the DB path, not the WAL file path:

```python
if not self._is_db_path_allowed(wal_file):  # Checks db_path, not wal_file
    return
```

This means a WAL file could be copied outside the allowed root if the DB path passes the check but the WAL destination does not.

## Reason for Change

Incorrect WAL path construction leads to missing WAL backups. Insufficient path validation allows WAL files to be written outside the allowed directory.

## Implementation Intent

Fix the WAL file path construction and add proper `allowed_root` validation for both the source WAL file and its backup destination.

## Implementation Instructions

### Step 1: Fix WAL file path construction

```python
# Before:
wal_file = f"{db_path}-wal"

# After:
wal_file = f"{db_path}-wal"  # Keep as-is for SQLite convention
# But ensure the path is correct by using os.path.join
wal_file = os.path.join(os.path.dirname(db_path), f"{os.path.basename(db_path)}-wal")
```

Note: SQLite uses `{db_path}-wal` format (not `{db_path}.wal`). The current code may actually be correct for SQLite's naming convention. The real issue is ensuring the path exists before checking it.

### Step 2: Add allowed_root check for WAL file source

```python
def _is_wal_path_allowed(self, wal_path: str) -> bool:
    """Check that WAL file path is within allowed root."""
    wal_dir = os.path.dirname(wal_path)
    return self._is_path_in_allowed_root(wal_dir)
```

### Step 3: Add allowed_root check for WAL backup destination

```python
# In _save_session_diagnostic():
if not self._is_wal_path_allowed(wal_file):
    logger.error(f"WAL file path outside allowed root: {wal_file}")
    return

wal_backup_path = os.path.join(backup_dir, f"{session_id}-wal")
if not self._is_wal_path_allowed(wal_backup_path):
    logger.error(f"WAL backup path outside allowed root: {wal_backup_path}")
    return
```

## Acceptance Criteria

1. WAL file path is correctly constructed following SQLite naming convention
2. Source WAL file path is validated against allowed_root
3. Backup WAL file path is validated against allowed_root
4. Normal WAL backup operation is unaffected — no regression
