# Fix pyproject.toml console-script entries for consolidated docs consistency checker

## Priority
Medium

## Target files
- pyproject.toml
- tools/check_docs_consistency.py
- rules/toolchain.md

## Background
The repository consolidated per-domain documentation consistency checkers (check_agent_docs_consistency.py, check_mcp_docs_consistency.py, etc.) into a single unified tool: tools/check_docs_consistency.py. This consolidation was implemented in plans/20260820-102217_plan.md (source requirement: requires/done/20260819-215619_require.md), which updated the CI workflow files to use the new consolidated entry point with --domain argument.

However, pyproject.toml's [project.scripts] table still declares console-script entry points targeting the deleted per-domain modules:
- check-mcp-docs = "tools.check_mcp_docs_consistency:main"
- check-agent-docs = "tools.check_agent_docs_consistency:main"

Neither of these modules exists in the repository.

## Problem
Invoking the documented validation steps (uv run check-mcp-docs, uv run check-agent-docs) fails with a module-not-found error instead of performing the intended documentation consistency check. This is the same class of silent breakage that motivated fixing the CI workflow files.

## Reason for change
rules/toolchain.md documents uv run check-mcp-docs as a validation step engineers are expected to run. The entry points must resolve to importable targets that perform the correct domain-specific checks.

## Implementation intent
Update pyproject.toml's [project.scripts] table to point to the consolidated checker. Since the consolidated main() requires an explicit --domain argument, create small wrapper functions in tools/check_docs_consistency.py (or a companion module) that invoke main() with the appropriate default domain.

Proposed pyproject.toml changes:
```toml
check-mcp-docs = "tools.check_docs_consistency:main_mcp"
check-agent-docs = "tools.check_docs_consistency:main_agent"
```

Add wrapper functions in tools/check_docs_consistency.py:
```python
def main_mcp(argv: list[str] | None = None) -> int:
    return main((argv or []) + ["--domain", "mcp"])

def main_agent(argv: list[str] | None = None) -> int:
    return main((argv or []) + ["--domain", "agent"])
```

Also verify no other [project.scripts] entries reference deleted tools/ modules.
