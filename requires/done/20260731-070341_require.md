# Requirement: Add Tests for Workflow Engine Timeout Forced Transition

## Priority

Medium

## Target Files

- `scripts/agent/workflow/workflow_engine.py`
- `tests/test_workflow_engine.py` (new test file or add to existing)

## Background

The timeout forced transition code path in `_force_stage_transition()` is not covered by any tests. This means bugs in cleanup and state transition logic can go undetected until they cause failures in production.

## Problem

No tests exist for:

1. Timeout exceeding and triggering forced transition
2. Current stage resource cleanup during forced transition
3. Next stage initialization after forced transition
4. Workflow state update after forced transition

## Reason for Change

Without tests, regressions in the timeout forced transition path cannot be reliably detected. The previous requirement (20260731-065725_require.md) addresses adding the cleanup logic; this requirement ensures it is tested.

## Implementation Intent

Add comprehensive unit tests covering all aspects of the timeout forced transition flow.

## Implementation Instructions

### Step 1: Test forced transition triggers on timeout

```python
@pytest.mark.asyncio
async def test_force_stage_transition_on_timeout():
    engine = WorkflowEngine(session_id="test")
    
    with patch.object(engine, '_transition_to', new_callable=AsyncMock) as mock_transition:
        with patch.object(engine, '_cleanup_current_stage', new_callable=AsyncMock) as mock_cleanup:
            result = await engine._force_stage_transition(
                current_stage=WorkflowStage.EXECUTE,
                next_stage=WorkflowStage.APPROVAL,
                stage_timeout=0.001
            )
            
            mock_cleanup.assert_called_once_with(WorkflowStage.EXECUTE)
            mock_transition.assert_called_once_with(WorkflowStage.APPROVAL)
```

### Step 2: Test no resource leak after forced transition

```python
@pytest.mark.asyncio
async def test_force_stage_transition_no_resource_leak():
    engine = WorkflowEngine(session_id="test")
    
    # Simulate running tools before forced transition
    engine._running_tools = {"tool_1": MagicMock()}
    
    with patch.object(engine, '_transition_to', new_callable=AsyncMock):
        with patch.object(engine, '_cancel_running_tools', new_callable=AsyncMock) as mock_cancel:
            await engine._force_stage_transition(
                current_stage=WorkflowStage.EXECUTE,
                next_stage=WorkflowStage.APPROVAL,
                stage_timeout=0.001
            )
            
            mock_cancel.assert_called_once()
            assert len(engine._running_tools) == 0
```

### Step 3: Test database state consistency after forced transition

```python
@pytest.mark.asyncio
async def test_force_stage_transition_db_state_consistent():
    engine = WorkflowEngine(session_id="test")
    
    with patch.object(engine, '_transition_to', new_callable=AsyncMock):
        with patch.object(engine, '_save_intermediate_state', new_callable=AsyncMock) as mock_save:
            await engine._force_stage_transition(
                current_stage=WorkflowStage.EXECUTE,
                next_stage=WorkflowStage.APPROVAL,
                stage_timeout=0.001
            )
            
            mock_save.assert_called_once_with(WorkflowStage.EXECUTE)
```

### Step 4: Test normal transition (non-timeout) is unaffected

```python
@pytest.mark.asyncio
async def test_normal_transition_not_affected():
    """Ensure non-timeout transitions are unchanged."""
    engine = WorkflowEngine(session_id="test")
    
    with patch.object(engine, '_transition_to', new_callable=AsyncMock) as mock_transition:
        with patch.object(engine, '_cleanup_current_stage', new_callable=AsyncMock) as mock_cleanup:
            # Normal transition should NOT call cleanup
            await engine._transition_to(WorkflowStage.APPROVAL)
            
            mock_transition.assert_called_once_with(WorkflowStage.APPROVAL)
            mock_cleanup.assert_not_called()
```
