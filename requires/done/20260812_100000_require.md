# Remove or align unused RAG configuration DTOs and names

## Priority
Low

## Target files

- `scripts/rag/ingestion/`

- `scripts/rag/ingestion/ingester.py`

## Background
Configuration DTOs in `scripts/rag/models_config.py` describe fields such as `chunk_size` and `batch_size`, while the runtime implementation relies on different naming conventions like `min_chunk`/`max_chunk` and `embed_workers`. This mismatch can lead to confusion and documentation drift.

## Problem
Several dataclasses in `scripts/rag/models_config.py` (`MqeConfig`, `FusionConfig`, `RerankConfig`, `SearchConfig`, `ChunkSplitterConfig`, `IngesterConfig`, and `PipelineConfig`) appear to be unused, as configuration is currently handled via raw dictionary access from TOML files. Additionally, existing field names in some DTOs do not match their runtime counterparts.

## Reason for change
To clean up dead code and ensure consistency between configuration definitions and runtime usage.

## Implementation intent
Remove or refactor the RAG configuration DTOs in `scripts/rag/models_config.py` to either match active runtime settings or be removed if they have no consumers.

## Implementation instructions
1. Verify all consumers of `MqeConfig`, `FusionConfig`, `RerankConfig`, `SearchConfig`, `ChunkSplitterConfig`, `IngesterConfig`, and `PipelineConfig`.
2. If a DTO has no consumers, remove it.
3. For retained DTOs, align field names with runtime usage:
    - Align `chunk_size` with `min_chunk`/`max_chunk` model.
    - Align `batch_size` with `embed_workers` behavior.
4. Update all references, documentation, and tests accordingly.
5. Ensure no dimension configuration fields (like `embedding_dims`) are introduced.

## Acceptance criteria
- Every retained DTO has a concrete consumer.
- Runtime code, documentation, and DTOs use consistent naming for active settings.
- Unused or misleading fields are removed.
- No dimension configuration fields are introduced.

## Tests
- Import and type checks for `scripts/rag/models_config.py`.
- Configuration loading tests using examples/fixtures.
- Regression tests for RAG ingestion and search functionality.
