# Enhance TURN_LIMIT_HINT with actual line count and character count

## Priority

Medium

## Target Files

- `scripts/agent/tool_runner.py:246-258` — _apply_turn_char_limit() definition
- `scripts/agent/tool_result_formatter.py:13` — TURN_LIMIT_HINT definition

## Background

When a tool result exceeds the per-turn character limit, it's replaced with a generic hint:

```python
hint: str = TURN_LIMIT_HINT
return hint
```

The current hint text is simply:
```
"[Result omitted: per-turn tool result limit reached.]"
```

This provides no information about what was omitted, making it impossible for the LLM to reason about the result.

## Problem

No context provided when truncating tool results. The LLM doesn't know how much content was omitted or what kind of data was present.

## Reason for Change

Provide actionable information to the LLM when tool results are truncated so it can make informed decisions.

## Implementation Intent

Enhance the hint text to include the actual number of lines and characters that were omitted.

## Implementation Instructions

1. Modify `_apply_turn_char_limit()` to capture the original text length before truncation:
   ```python
   def _apply_turn_char_limit(
       llm_text: str,
       turn_chars: int,
       limit: int,
   ) -> str:
       if limit > 0 and (turn_chars + len(llm_text)) > limit:
           omitted_chars = (turn_chars + len(llm_text)) - limit
           omitted_lines = llm_text.count('\n')
           hint = f"[Result truncated: {omitted_chars} characters ({omitted_lines} lines) omitted due to per-turn limit of {limit} chars.]"
           return hint
       return llm_text
   ```
2. Run tests to confirm no regressions

## Acceptance Criteria

- [ ] Hint includes actual number of omitted characters
- [ ] Hint includes approximate number of omitted lines
- [ ] No regressions in normal (non-truncated) behavior
