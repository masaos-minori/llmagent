# Requirement: Complete Resource Cleanup on System Shutdown

## Priority

Medium

## Target Files

- `scripts/agent/repl.py`
- `scripts/agent/lifecycle.py`

## Background

When the system shuts down (e.g., via Ctrl+C), only MCP server disconnection is performed. Running turns, streaming tasks, and database sessions are not cleaned up, leading to resource leaks.

## Problem

In `repl.py`:

```python
def _cleanup(self):
    # Only disconnects MCP servers
    await self._disconnect_mcp_servers()
```

This means:

1. Running turn tasks are not cancelled — they may continue after shutdown
2. Streaming response tasks are not cancelled — memory leak
3. Database sessions are not committed or rolled back — connection leak
4. File descriptors may not be released — resource exhaustion across restarts

## Reason for Change

Incomplete cleanup causes resource leaks that accumulate over time, potentially exhausting system resources (PIDs, connections, file descriptors).

## Implementation Intent

Ensure all runtime resources are properly cleaned up during system shutdown, regardless of how shutdown is triggered.

## Implementation Instructions

### Step 1: Add comprehensive cleanup logic

```python
async def _cleanup(self):
    """Clean up all resources during shutdown."""
    try:
        # Cancel running turn
        if hasattr(self, '_current_turn_task') and self._current_turn_task:
            self._current_turn_task.cancel()
        
        # Cancel streaming task
        if hasattr(self, '_stream_response_task') and self._stream_response_task:
            self._stream_response_task.cancel()
            try:
                await self._stream_response_task
            except asyncio.CancelledError:
                pass
        
        # Commit or rollback DB session
        if hasattr(self, '_db_session') and self._db_session:
            try:
                await self._db_session.commit()
            except Exception:
                await self._db_session.rollback()
        
        # Disconnect MCP servers
        await self._disconnect_mcp_servers()
    
    finally:
        # Always run parent cleanup last
        await super()._cleanup()
```

### Step 2: Ensure signal handlers call `_cleanup()`

Verify that both SIGINT and SIGTERM handlers invoke `_cleanup()`:

```python
def _signal_handler(self, signum, frame):
    logger.info(f"Received signal {signum}, shutting down...")
    asyncio.create_task(self._cleanup())
```

## Acceptance Criteria

1. All running tasks are cancelled during shutdown
2. Database sessions are properly committed or rolled back
3. MCP servers are disconnected
4. No resource leaks occur after shutdown
5. Normal shutdown operation is unaffected — no regression
