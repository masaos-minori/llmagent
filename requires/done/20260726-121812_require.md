## Background

**Needs confirmation resolved (verified 2026-08-23):** this requirement originally asked
to fix an `eventbus-is-isolated` import-linter violation by duplicating `db.helper.
apply_connection_pragmas()` and `shared.json_utils.{now_iso,dumps}` into eventbus-local
code. That fix has already been implemented (by other work, exact commit not identified
from this review alone):

- `PYTHONPATH=scripts uv run lint-imports` currently reports "5 kept, 0 broken",
  including `eventbus-is-isolated`.
- `scripts/eventbus/json_utils.py` already exists, docstring "Minimal JSON helpers for
  eventbus — avoids importing from shared", providing local `dumps()` and `now_iso()`.
- `scripts/eventbus/db.py:15-24` already has a local `_apply_eventbus_pragmas()` function
  applying WAL/synchronous/busy_timeout/foreign_keys pragmas.
- All 6 originally-flagged files (`db.py`, `ack_route.py`, `dlq.py`, `publish_route.py`,
  `replay_route.py`, `subscribe_route.py`) already import from `eventbus.json_utils`, not
  `shared.json_utils`; `db.py` no longer imports `db.helper`.

This requirement is narrowed to the one Acceptance Criterion that is not yet met:
dedicated unit tests for the two duplicated/local pieces of code.

**Separately, and out of scope for the requirement itself:** this review also surfaced
that `AGENTS.md` used to contain a Global Rule 8 stating "eventbus に関連する実装は絶対
にしないこと（デバッグ・調査は可）" (never implement anything related to eventbus;
debug/investigation only), which `routing.md`'s Event Bus row still referenced
("implementation forbidden, see AGENTS.md Global Rule 8") until this review. That rule
text was overwritten by an unrelated Global Rule 8 (doc/tools checker execution) in
commit `a53e9c62d` ("docs: update ADRs, document guides, and fix code drift"), leaving
`routing.md`'s reference dangling. Per explicit user decision during this review, the
eventbus-implementation-forbidden policy is treated as no-longer-in-effect, and
`routing.md`'s Event Bus row has been corrected in the same review pass (see that file's
current Event Bus row) to route eventbus implementation work to
`skills/python-implementation/`. No AGENTS.md change was made — if the ban was intended
to stay, it would need to be re-added there as a deliberate policy decision, not a
byproduct of this test-only requirement.

## Problem

| File | Issue |
|---|---|
| `scripts/eventbus/json_utils.py` | `dumps()` and `now_iso()` have no dedicated test — a regression could silently reintroduce serialization or timestamp-format bugs |
| `scripts/eventbus/db.py::_apply_eventbus_pragmas()` | No dedicated test verifying all 4 pragmas (`journal_mode=WAL`, `synchronous=NORMAL`, `busy_timeout`, `foreign_keys=ON`) are actually applied to a connection |

## Reason for Change

These two pieces of code exist specifically because `shared.json_utils` and `db.helper`
were duplicated to satisfy `eventbus-is-isolated` — duplicated code carries the same
correctness risk as the original but starts with zero dedicated test coverage (the
original `shared.json_utils` functions are tested in `tests/shared/test_json_utils.py`;
that coverage does not transfer to the eventbus-local copy).

## Implementation Intent

1. Create `tests/eventbus/test_eventbus_json_utils.py` testing `dumps()` and `now_iso()`.
2. Add pragma-application tests — either as new test functions in the already-planned
   `tests/eventbus/test_eventbus_db_migration.py` (see
   `requires/done/20260726-121037_require.md`) or as a new
   `tests/eventbus/test_eventbus_db_pragmas.py`.

## Implementation Instructions

### test_eventbus_json_utils.py
- Test `dumps()` with a dict, list, and primitive value; confirm it returns `str` (not
  `bytes`) and defaults to sorted keys (matches `OPT_SORT_KEYS` default).
- Test `now_iso()` returns a string matching `YYYY-MM-DDTHH:MM:SSZ`.

### pragma test
- Open a connection via the same code path `db.py` uses, call
  `_apply_eventbus_pragmas(conn, busy_timeout_ms=<value>)`, then assert via `PRAGMA
  journal_mode`, `PRAGMA synchronous`, `PRAGMA busy_timeout`, `PRAGMA foreign_keys` that
  each value was actually applied to the connection.
