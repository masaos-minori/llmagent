# CLIView Writer Protocol partial test double risk

## Priority
Low

## Summary
Writer Protocol has 10 methods. Partial test doubles (mocking only some methods) will cause AttributeError at runtime due to @runtime_checkable enforcement.

## Reason for Change
Writer Protocol defines 10 methods (write_token, write_compress_notice, write_turn_start, write_turn_end, write_llm_error, write_progress, clear_progress, write_warning, write_fatal, write_startup_banner). If a test double implements only some methods, @runtime_checkable will reject it, but if someone bypasses the check, partial implementation causes AttributeError.

## Implementation Intent
Consider adding optional methods or default implementations where appropriate. Document the protocol requirements clearly.

## Target Files or Areas
- scripts/agent/cli_view.py
- Writer Protocol definition

## Required Changes
- Add optional methods or default implementations where appropriate
- Ensure protocol definitions are compatible with all possible test double implementations
- Document the protocol requirements clearly

## Acceptance Criteria
- [ ] Protocol definitions are compatible with all possible test double implementations
- [ ] No regressions in normal operation when registry is available

## Testing Expectations
- Unit test for Writer Protocol compliance with various field combinations
- Integration test verifying diagnostic output during startup/shutdown

## Documentation Impact
If DiagnosticsConfig is extended, update documentation to reflect the new state.

## Out of Scope
- Changing the registry initialization order
- Adding retry logic for health checks

## AI Implementation Instruction
Modify only _filter_sensitive_fields() in diagnostic_store.py. Add a new state to McpAvailability enum if needed. Update the fallback logic to use the new state instead of UNKNOWN when registry is None.
