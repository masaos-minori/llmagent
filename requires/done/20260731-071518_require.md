# Requirement: Fix Command Whitelist Symlink Bypass

## Priority

High

## Target Files

- `scripts/agent/http_lifecycle.py`

## Background

The command whitelist check only compares the basename of `cfg.cmd[0]`, allowing symlink-based bypasses where a malicious symlink points to an allowed binary but executes a different payload. Additionally, when `cfg.cmd[0]` is empty, the process fails silently without raising an error.

## Problem

In `http_lifecycle.py`:

```python
_ALLOWED_COMMANDS = frozenset({"node", "npm", "npx", "uvx", "python", "pipx"})

# ...

cmd_basename = os.path.basename(cfg.cmd[0])
if cmd_basename not in self._ALLOWED_COMMANDS:
    logger.warning(...)
    return  # Silent failure — no error raised
```

This means:

1. A symlink `/tmp/node -> /etc/passwd` would pass the basename check (`node`)
2. The actual binary executed could be anything the symlink points to
3. When `cfg.cmd[0]` is empty, no error is raised — just silent failure
4. No validation that the resolved path actually exists as a file

## Reason for Change

Symlink bypass is a security vulnerability. Silent failures make debugging difficult. Both issues need to be addressed.

## Implementation Intent

Resolve symlinks before checking against the whitelist, and raise an error when `cfg.cmd[0]` is empty or invalid.

## Implementation Instructions

### Step 1: Resolve symlinks before whitelist check

```python
async def start(self):
    if not cfg.cmd:
        raise HttpStartupError("Empty command configuration")
    
    # Resolve symlinks to prevent bypass
    cmd_path = os.path.realpath(cfg.cmd[0])
    
    # Verify the resolved path exists and is a regular file
    if not os.path.isfile(cmd_path):
        raise HttpStartupError(
            f"Command not found or not a regular file: {cfg.cmd[0]}"
        )
    
    # Check against whitelist using the resolved path's basename
    cmd_basename = os.path.basename(cmd_path)
    if cmd_basename not in self._ALLOWED_COMMANDS:
        raise HttpStartupError(
            f"Command not allowed by whitelist: {cfg.cmd[0]} (resolved: {cmd_path})"
        )
```

### Step 2: Raise error instead of silent failure

Replace the `return` statement with an explicit error:

```python
# Before:
if cmd_basename not in self._ALLOWED_COMMANDS:
    logger.warning(...)
    return  # Silent failure

# After:
if cmd_basename not in self._ALLOWED_COMMANDS:
    raise HttpStartupError(
        f"Command '{cfg.cmd[0]}' is not in the allowed commands list. "
        f"Resolved path: {cmd_path}"
    )
```

## Acceptance Criteria

1. Symlinked commands are resolved before whitelist check
2. Empty `cfg.cmd[0]` raises an explicit error
3. Non-existent command paths raise an explicit error
4. Normal command startup is unaffected — no regression
