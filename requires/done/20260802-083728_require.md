Medium

- `docs/00_governance_02_canonical-source-rule.md` (lines 63-73) — replace with reference

`docs/00_governance_08_known-issues-migration-plan.md` also has an equivalent "Related

requirement (see Implementation instructions).

## Background
Each of `docs/00_governance_01` through `docs/00_governance_07` ends with a `##
Related Governance Documents` section: the heading, the sentence "Cross-cutting
documentation rules and policies:", and a Markdown list linking to the other governance
docs among 01-07 (each file self-excludes its own entry, and none of 01-07 link to 08).
This was verified directly against current file content via grep — the section exists,
in this exact form, in all 7 files as of this check. `docs/00_governance_08` carries an
analogous section but is out of scope here per the source issue.

## Problem
The same template-level list (6 entries per file, only the self-excluded entry
differing) is maintained independently in 7 files. Adding, removing, or renaming a
governance doc requires editing all 7 lists in lockstep to stay accurate, and nothing
enforces that consistency — the lists can silently drift out of sync.

## Reason for change
Consolidating to a single canonical list removes the update-drift risk: future changes
to the set of governance docs only require editing one file instead of seven.

## Implementation intent
Treat `docs/00_governance_01_documentation-governance.md` as the canonical holder of the
full list (it already lists all of 02-07). Replace the "Related Governance Documents"
section content in `00_governance_02` through `00_governance_07` with a single reference
line pointing readers to `00_governance_01` for the full list, instead of repeating it.
Do not alter the list's content, item names, or ordering in the canonical file. Do not
touch `00_governance_08` or `docs/00_index.md`.

## Implementation instructions
1. Re-grep `docs/00_governance_*.md` for `^## Related Governance Documents` immediately
   before editing to reconfirm the block still exists at the line ranges above (content
   may have shifted since this requirement was written).
2. Leave `docs/00_governance_01_documentation-governance.md` unchanged — it remains the
   canonical full list.
3. In each of `00_governance_02` through `00_governance_07`, replace the section body
   (the "Cross-cutting documentation rules and policies:" line plus the following
   bullet list) under the existing `## Related Governance Documents` heading with a
   single reference line, e.g.:
   `関連文書一覧は \`docs/00_governance_01_documentation-governance.md\` を参照。`
   Keep the wording identical across all 6 files touched.
4. Keep the `## Related Governance Documents` heading itself in each file (do not
   remove the section, only its duplicated body).
5. Do not modify any other section of these files, and do not touch
   `docs/00_governance_08_known-issues-migration-plan.md` or `docs/00_index.md`.
6. This is a documentation-only change with no code or behavior impact.

## Acceptance criteria
- `docs/00_governance_01_documentation-governance.md` still contains the full 6-item
  list, unchanged.
- Each of `docs/00_governance_02` through `docs/00_governance_07` contains exactly one
  reference line (no bullet list) under its `## Related Governance Documents` heading,
  using consistent wording across all six.
- `docs/00_governance_08_known-issues-migration-plan.md` and `docs/00_index.md` are
  unmodified.
- No links are broken: the reference line's path to `00_governance_01` resolves
  correctly from each file's location.
