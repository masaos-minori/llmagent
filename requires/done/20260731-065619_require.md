# Requirement: Enforce Deny-All Policy When Security Audit Config Is Missing in Local Mode

## Priority

High

## Target Files

- `scripts/agent/security_audit_config.py`
- `scripts/agent/repl_health.py`

## Background

In LOCAL mode, when security audit configuration files are missing, the shell command allowlist check is silently skipped. This happens because `shell_cfg` becomes `None`, and subsequent checks that depend on it (e.g., `shell_cfg.command_allowlist`) are bypassed.

## Problem

When running in LOCAL mode without security audit config files:

1. `load_shell_audit_config()` returns `None` instead of raising an error
2. `repl_health.py:489-497` skips sandbox backend check when `shell_cfg is None`
3. `repl_health.py:525` skips empty allowlist check when `shell_cfg is None`
4. Result: ALL shell commands are allowed without any policy enforcement

This is unintentionally insecure — users expect allowlist checks to be active even in LOCAL mode.

## Reason for Change

Silent failure of security checks violates the principle of least privilege. Even in LOCAL mode, there should be a default deny-all policy as a safety baseline.

## Implementation Intent

Ensure that when security audit config files are missing in LOCAL mode, a default deny-all policy is applied rather than silently skipping all checks.

## Implementation Instructions

### Option A: Default deny-all policy in LOCAL mode

In `security_audit_config.py`:

```python
def load_shell_audit_config() -> Optional[ShellAuditConfig]:
    if not os.path.exists(SHELL_AUDIT_CONFIG_PATH):
        if mode == "LOCAL":
            logger.warning("Security audit config not found, applying deny-all policy")
            return ShellAuditConfig(command_allowlist=set())  # Empty set = deny all
        else:
            raise RuntimeError(...)
```

An empty `command_allowlist` means no commands are allowed (deny-all).

### Option B: Explicit warning + deny-all in repl_health.py

In `repl_health.py`, after loading config:

```python
shell_cfg = load_shell_audit_config()

if shell_cfg is None and mode == "LOCAL":
    logger.error("Security audit config unavailable in LOCAL mode — enforcing deny-all")
    # Apply deny-all: treat as empty allowlist
    effective_allowlist = set()
else:
    effective_allowlist = shell_cfg.command_allowlist if shell_cfg else set()
```

Then use `effective_allowlist` instead of `shell_cfg.command_allowlist`.

### Recommendation

Option A is preferred because it centralizes the logic in the config layer. Option B can be added as a defensive fallback in `repl_health.py`.

## Acceptance Criteria

1. In LOCAL mode, when security audit config files are missing, no shell commands are allowed (deny-all)
2. A clear log message indicates that deny-all policy is being enforced due to missing config
3. In PRODUCTION mode, behavior remains unchanged (RuntimeError raised, startup blocked)
4. When security audit config files exist, normal allowlist checking works correctly
