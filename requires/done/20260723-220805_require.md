## Title

Improve config error messages in AgentContext.__init__()

## Priority

High

## Target files

- scripts/agent/context.py

## Background

`AgentContext.__init__()` calls `build_agent_config()` unconditionally. If the config loading fails, the error is displayed as-is without additional formatting or context.

## Problem

When `build_agent_config()` raises an exception (e.g., TOML parse error, missing required key), the error message includes raw details like file paths and line numbers but lacks user-friendly framing. The user sees something like:

```
tomllib.TOMLDecodeError: Expected '=' after a key in a key-value pair at line X column Y
```

This is technically accurate but doesn't guide the user toward resolution.

## Reason for change

1. **User guidance**: Users need to know where to look for the problem (which config file).
2. **Actionability**: Users need to know what to do next (edit the config file, check syntax).
3. **Consistency**: Other startup errors (e.g., session schema missing) provide specific remediation steps.

## Implementation intent

Catch exceptions from `build_agent_config()` in `AgentContext.__init__()` and re-raise with a formatted message that includes the config file path and a brief description of the error type.

## Implementation instructions

Change the code from:

```python
# Before (context.py ~line 183):
def __init__(self) -> None:
    self.conv = ConversationState()
    self.turn = TurnState()
    self.stats = RuntimeStats()
    self.workflow = WorkflowState()
    self.cfg = build_agent_config()
    self.session = AgentSession()
```

To:

```python
# After:
def __init__(self) -> None:
    self.conv = ConversationState()
    self.turn = TurnState()
    self.stats = RuntimeStats()
    self.workflow = WorkflowState()
    try:
        self.cfg = build_agent_config()
    except Exception as e:
        config_path = os.path.join(os.getenv("AGENT_CONFIG_DIR", "/opt/llm/config"), "agent.toml")
        raise RuntimeError(
            f"Failed to load agent config ({config_path}): {e.__class__.__name__}: {e}"
        ) from None
    self.session = AgentSession()
```

Note: The actual config path should be determined from the same source as `load_config()` uses. Review `load_config()` to find the correct path variable.

## Acceptance criteria

1. Config loading errors display a clear message with the config file path and error type.
2. Existing behavior for valid configs is unchanged.
3. No mypy errors introduced by the change.
4. All existing tests pass without modification.
