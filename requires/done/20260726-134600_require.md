# Add guard tests for tool argument injection prevention

## Priority

High

## Target Files

- `scripts/agent/tool_runner.py:139-141` — MCP tool execution
- `scripts/shared/tool_executor.py:209-218` — ToolExecutor.execute()

## Background

Tool call arguments generated by the LLM can have additional fields or values injected. After parsing via orjson.loads(), they are sent directly to MCP servers without sandboxing. If the LLM intentionally generates malicious arguments, they are sent as-is to MCP servers and executed.

## Problem

No validation of LLM-generated tool arguments before sending to MCP servers.

## Reason for Change

Establish behavioral baseline through guard tests before any refactoring of these components.

## Implementation Intent

Create comprehensive guard tests covering:
- Unexpected field injection detection
- Schema validation enforcement
- Whitelist-based argument filtering
- Malicious argument rejection
