# Requirement: Fail Fast on Tool Discovery Failure Even in Development Mode

## Priority

Medium — silent failure causes confusing downstream errors and makes debugging difficult

## Target Files

- `scripts/agent/startup.py` (lines 293-319)

## Background

In `_check_services()`, when MCP tool discovery fails:

```python
except Exception as exc:
    msg = f"MCP tool discovery failed - ALL tool calls will fail this session: {exc}"
    if production_mode:
        pipeline.add_fatal(...)
    else:
        pipeline.add_skipped(...)
```

In development mode, the exception is caught and marked as "skipped" rather than failing fast. The agent starts with zero tools available.

## Problem

When tool discovery fails in dev mode:
1. The agent starts without any MCP tools
2. The LLM attempts to use tools that don't exist
3. Downstream errors are confusing and hard to debug
4. The error message "ALL tool calls will fail" is misleading — the real problem is that NO tools are available

## Reason for Change

Fail fast during startup so developers can immediately identify and fix configuration or connectivity issues instead of encountering cryptic errors later.

## Implementation Intent

Treat tool discovery failures as fatal errors regardless of production mode. Improve error messaging to clearly indicate the root cause.

## Implementation Instructions

1. Remove the dev/prod distinction for tool discovery failures:
   ```python
   except Exception as exc:
       msg = f"MCP tool discovery failed: {exc}. No MCP tools will be available this session."
       pipeline.add_fatal("mcp_tool_discovery", msg, remediation="Check MCP server connectivity and configuration.")
   ```

2. Update the error message to be more accurate:
   - Replace "ALL tool calls will fail" with "No MCP tools will be available this session"
   - Add a remediation hint

3. Ensure the logging level reflects the severity (ERROR level, not WARNING)

## Acceptance Criteria

- [ ] Tool discovery failure always results in a fatal error, regardless of production mode
- [ ] Error message clearly states no MCP tools will be available
- [ ] Remediation guidance is provided
- [ ] Logging uses ERROR level for this condition

## Tests

- Integration test verifying agent refuses to start when tool discovery fails
