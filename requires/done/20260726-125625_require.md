# Add guard test for security_profile fallback in config_reload.py

## Priority

Medium

## Target Files

## Background

The security_profile fallback in `config_reload.py` is unverified:

```python
if (vs := _get_str(new_cfg, "security_profile")) is not None:
    try:
        ctx.cfg.mcp.security_profile = SecurityProfile(vs)
    except ValueError:
        # Fallback behavior unclear
        pass
```

If an invalid value is provided, the fallback silently ignores it without logging or using a default value.

## Problem

No verification that the fallback behaves correctly when an invalid `security_profile` value is injected. The silent ignore could mask configuration errors.

## Reason for Change

Establish behavioral baseline through a guard test before any refactoring of this component.

## Implementation Intent
