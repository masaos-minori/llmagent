# Remove deprecated LlmTransportErrorHandler.resolve_retryable method

## Priority
Medium

## Target files
- `scripts/shared/llm_transport_errors.py` — `LlmTransportErrorHandler.resolve_retryable()` method
- `tests/shared/test_llm_transport_errors.py` — `TestResolveRetryable` test class

## Background
Phase 1 of `plans/20260813-190710_plan.md` (adding DeprecationWarning) has been implemented.
This sub-task removes the deprecated method once the grace period expires.

## Problem
The deprecated `LlmTransportErrorHandler.resolve_retryable()` method remains in the codebase after its deprecation warning was added. Without removal, the dead code persists indefinitely, violating the intent of the original deprecation.

## Reason for change
The deprecated `LlmTransportErrorHandler.resolve_retryable()` method remains in the codebase after its deprecation warning was added in Phase 1. Without removal, the dead code persists indefinitely, violating the intent of the original deprecation.

## Implementation intent
Remove the deprecated `LlmTransportErrorHandler.resolve_retryable()` method and its associated test class, replacing them with a shared three-branch helper with counter-threading signature called from `LlmReconnectHandler._evaluate_stream_error`.

## Implementation instructions
1. Confirm `LlmTransportErrorHandler.resolve_retryable` still has zero production callers via `rg "resolve_retryable" scripts/ tests/`
2. Replace `LlmTransportErrorHandler.resolve_retryable` body with a call to `LlmReconnectHandler.resolve_retryable`
3. Update `TestResolveRetryable` test class to assert `DeprecationWarning` is emitted when `resolve_retryable` is called
4. Verify both `LlmTransportErrorHandler.resolve_retryable` and `LlmReconnectHandler.resolve_retryable` delegate to the shared helper

## Acceptance criteria
- `LlmTransportErrorHandler.resolve_retryable()` method is removed from `scripts/shared/llm_transport_errors.py`
- `TestResolveRetryable` test class is removed from `tests/shared/test_llm_transport_errors.py`
- `LlmReconnectHandler.resolve_retryable()` delegates to the shared three-branch helper
- `LlmReconnectHandler._evaluate_stream_error()` calls the shared helper instead of `LlmReconnectHandler.resolve_retryable`
- All existing tests pass after changes
