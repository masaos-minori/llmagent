## Background

The _discard_and_log() method counts background task failures but doesn't stop the agent when the threshold (5 consecutive failures) is reached. Only a log message is output. Additionally, if the _on_error callback raises an exception, it's only logged via logger.error() and not notified to the user.

## Problem

Background task failures silently continue without alerting the user or stopping critical functionality.

## Reason for Change

Establish behavioral baseline through guard tests before any refactoring of these components.

- Consecutive failure counting verification
- Threshold reach behavior verification
- _on_error callback exception handling verification
