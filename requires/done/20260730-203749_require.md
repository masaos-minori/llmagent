# Requirement: Cooldown Timer Overflow Mitigation

## Priority

Low — theoretical concern only, no practical impact on current deployments

## Target Files

- `scripts/agent/factory.py` (lines 97-112)

## Background

The `_ServerLifecycleRouter` class tracks failed MCP server startup attempts in `_failed_starts` dictionary, storing `time.monotonic()` values. The `_in_cooldown()` method computes elapsed time since failure to determine if a server should be in cooldown.

## Problem

On 64-bit systems, `time.monotonic()` can represent approximately 584 years of monotonic time. While this is far beyond any realistic deployment duration, there is a theoretical overflow concern if a process runs continuously for decades.

## Reason for Change

No change is required at this time. The risk is negligible for all practical purposes.
