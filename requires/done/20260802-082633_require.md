# Name and link the "separate migration plan" reference in the Known Issues Template's Migration Notes

## Priority
Low

## Target files
- `docs/00_governance_04_known-issues-template.md` (primary edit target — Migration Notes section, line 89)

## Background
`docs/00_governance_04_known-issues-template.md` defines the common Known Issues entry template used across all documentation areas. Its "Migration Notes" section states that existing entries "should be migrated gradually using a separate migration plan," but does not name or link that plan, leaving readers to guess which document is meant.

`docs/00_governance_08_known-issues-migration-plan.md` was verified to be the intended referent: its Purpose section explicitly states it "defines the migration plan for transitioning existing Known Issues / Inconsistencies documents across all areas to the new common template defined in `00_governance_04_known-issues-template.md`," and its Migration Policy section says to "Preserve all existing entry IDs during migration" — matching the Migration Notes bullet "Preserve original IDs during migration." The scope is confirmed to match, not just by name similarity.

## Problem
The Migration Notes section in `docs/00_governance_04_known-issues-template.md` (line 89) contains a dangling, unnamed reference: "using a separate migration plan." A reader cannot tell which document this refers to without independently searching the governance docs and comparing scopes.

## Reason for change
An unnamed cross-reference forces readers (human or AI) to guess or search for the correct document, risking wasted time or accidental reliance on the wrong document. Since the correct target (`00_governance_08`) has been confirmed to exist and match in scope, the reference should be made explicit now.

## Implementation intent
Replace the vague phrase "a separate migration plan" in the Migration Notes section of `docs/00_governance_04_known-issues-template.md` with an explicit reference (title and relative path/link) to `docs/00_governance_08_known-issues-migration-plan.md`, consistent with how other cross-references are formatted elsewhere in the same document's "Related Governance Documents" section (e.g., `[Documentation Governance](00_governance_01_documentation-governance.md)` style links).
