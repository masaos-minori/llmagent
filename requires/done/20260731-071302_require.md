# Requirement: No Action Required — Banner Chunk Count Fallback Is Sufficient

## Priority

Low

## Target Files

- `scripts/agent/repl.py`

## Background

When RAG chunk count retrieval fails during agent startup banner display, "?" is shown instead of the actual count. This is a cosmetic issue only — functionality is not affected.

## Problem

In `repl.py`:

```python
def _get_chunk_count() -> str:
    try:
        return str(chunk_count)
    except (sqlite3.Error, OSError, RuntimeError):
        return "?"
```

The "?" placeholder prevents users from knowing whether RAG is working correctly. However, this is a non-functional issue.

## Reason for Change

No change is required. The current fallback behavior is acceptable because:

1. It does not affect functionality
2. Users can check RAG status through other means (e.g., diagnostic commands)
3. Adding more sophisticated fallback would increase complexity without meaningful benefit

## Implementation Intent

No implementation needed. This issue is acknowledged but deferred.
