# Requirement: Preserve Session ID on Existing Session Resume

## Priority

Medium

## Target Files

- `scripts/agent/workflow/workflow_engine.py`
- `scripts/agent/session.py`

## Background

When starting a workflow, a new UUID is always generated as the session ID regardless of whether an existing session is being resumed. This causes session divergence where the user's intent to resume a session is ignored.

## Problem

In `workflow_engine.py`, the session ID is unconditionally regenerated:

```python
session_id = str(uuid.uuid4())
```

This means:

1. User starts workflow in Session A
2. User interrupts (Ctrl+C)
3. User resumes in Session A
4. A new Session B is created instead of resuming Session A
5. Session A's workflow state becomes unreachable

## Reason for Change

Session persistence is broken when sessions are resumed. Users expect their conversation context and workflow state to be preserved across restarts.

## Implementation Intent

Modify `start_workflow()` to check for an existing session first, and reuse its workflow ID if found. Only generate a new UUID when no existing session exists.

## Implementation Instructions

### Step 1: Add `_get_existing_session()` method

In `workflow_engine.py`, add a method to look up existing sessions:

```python
async def _get_existing_session(self, session_id: Optional[str]) -> Optional[WorkflowSession]:
    """Look up an existing workflow session by session_id."""
    if session_id is None:
        return None
    
    # Query database for existing session
    cursor = self.db.execute("""
        SELECT * FROM workflow_sessions
        WHERE session_id = ? AND status != 'completed'
        LIMIT 1
    """, (session_id,))
    
    row = cursor.fetchone()
    if row:
        return WorkflowSession.from_row(row)
    return None
```

### Step 2: Modify `start_workflow()` to use existing session

```python
async def start_workflow(self, session_id: Optional[str] = None) -> str:
    # Check for existing session first
    existing_session = await self._get_existing_session(session_id)
    
    if existing_session:
        # Reuse existing session ID
        workflow_session_id = existing_session.workflow_id
        logger.info(f"Resuming existing session: {workflow_session_id}")
    else:
        # Create new session
        workflow_session_id = str(uuid.uuid4())
        logger.info(f"Creating new session: {workflow_session_id}")
    
    return workflow_session_id
```

## Acceptance Criteria

1. When resuming an existing session, the original workflow ID is reused
2. A new session ID is only generated when no existing session is found
3. Session history remains consistent after resume
4. Normal (first-time) session creation is unaffected — no regression
