## Problem

Every row includes per-file function/DTO descriptions that contradict the memo's explicit instruction to redirect such detail to Reference rather than design body.

## Reason for change
The document violates the design-doc reduction policy established in `memo-doc-shared-review.md`. Detail should be redirected to the source files rather than deleted, ensuring no loss of information for readers who need it.

## Implementation intent
Keep this chapter focused on "what belongs to which layer's responsibility." Per the memo's explicit note: describe "which layer owns what," not "which file has which function" (that belongs in Reference).
