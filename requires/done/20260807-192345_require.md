## Problem
The document currently contains an overly detailed File Index (lines 68–117), an AI Query Routing Table with excessive granularity (e.g., pointing to `...core-types.md §3-4 / ...reference.md(02) §10`), keyword enumeration outside YAML front-matter tags (lines 150–158), and a "Guidance for Safe AI Use" section that includes item 1 (`load_all()` only including `agent.toml`, referencing line numbers) which duplicates code-level facts rather than design intent.

Additionally, the issue incorrectly states that `LLMMessage` has 7 fields — the current `scripts/shared/types.py` defines it with 11 fields total: `role` (required from parent `_LLMMessageRequired`), plus 10 optional fields (`content`, `tool_calls`, `tool_call_id`, `name`, `importance`, `pinned`, `_ephemeral`, `_skill_ephemeral`, `_memory_injected`, `source`). If this claim is used as a reference point during cleanup, it should be updated to reflect the current field count.

## Reason for change
The document violates the design-doc reduction policy established in `memo-doc-shared-review.md`. Detail should be redirected to the source files rather than deleted, ensuring no loss of information for readers who need it.
