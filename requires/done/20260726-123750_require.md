# Add command validation for subprocess execution (optional)

## Priority

Low-Medium — requires admin-level access to exploit

## Target Files

- `scripts/agent/http_lifecycle.py:230-236` — Subprocess launch
- `scripts/agent/http_lifecycle.py:224-226` — Environment variable merge

## Background

The subprocess command (`cfg.cmd`) is loaded directly from configuration without validation. If an attacker modifies the config file, arbitrary commands could execute.

## Problem

```python
proc = subprocess.Popen(
    cfg.cmd,
    stdout=subprocess.DEVNULL,
    stderr=stderr_fh,
    env=env,
    start_new_session=True,
)
```

No validation that `cfg.cmd` contains only expected commands.

## Reason for Change

Prevent potential command injection via config file modification.

## Implementation Intent

Add a whitelist or pattern validation for allowed subprocess commands before executing them.

## Implementation Instructions

1. Define a list of allowed commands or patterns
2. Validate `cfg.cmd` against the whitelist before execution
3. Only implement if time permits — this is optional

## Acceptance Criteria

- [ ] Only whitelisted commands can be executed as subprocesses
- [ ] Non-whitelisted commands produce an error
