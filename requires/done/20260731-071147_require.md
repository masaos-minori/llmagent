# Requirement: Add Logging and Default Policy Check for Repository Writes

## Priority

Medium

## Target Files

- `scripts/agent/repository_gateway.py`
- `scripts/agent/tool_policy.py`

## Background

When `policy_check_required` is False, repository writes bypass preflight checks entirely. This may be intentional but lacks documentation and visibility.

## Problem

In `repository_gateway.py`:

```python
if not policy_check_required:
    return True  # Allowed without any check
```

This means:

1. Writes that skip policy checks go undetected
2. No audit trail for unchecked writes
3. Security risk if `policy_check_required` is accidentally set to False
4. Default value of `False` means policy checks are opt-in rather than opt-out

## Reason for Change

Unchecked writes undermine the security model. Even when skips are intentional, they should be logged and auditable. The default should favor safety over convenience.

## Implementation Intent

Add logging for skipped policy checks and change the default behavior to require policy checks by default.

## Implementation Instructions

### Step 1: Add logging for skipped checks

```python
async def write_to_repository(self, path: str, content: str, policy_check_required: bool = True):
    """Write to repository with optional policy check."""
    
    if not policy_check_required:
        logger.warning(
            f"Policy check SKIPPED for write to {path} "
            "(policy_check_required=False — this is a security concern)"
        )
    
    if policy_check_required:
        await self._check_policy(path, content)
    
    await self._perform_write(path, content)
```

### Step 2: Change default to `True`

Change the parameter default from `False` to `True`:

```python
# Before:
async def write_to_repository(self, path: str, content: str, policy_check_required: bool = False):

# After:
async def write_to_repository(self, path: str, content: str, policy_check_required: bool = True):
```

### Step 3: Document the parameter

Add docstring explaining the parameter:

```python
async def write_to_repository(self, path: str, content: str, policy_check_required: bool = True) -> None:
    """Write content to the repository.
    
    Args:
        path: File path within the repository.
        content: Content to write.
        policy_check_required: If True (default), perform a preflight policy check.
            Only set to False for trusted internal operations where the caller
            has already validated the write. WARNING: Skipping the check is a
            security concern and will be logged at WARNING level.
    """
```

## Acceptance Criteria

1. Skipped policy checks are logged at WARNING level
2. Default behavior requires policy checks (`policy_check_required=True`)
3. Docstring documents the security implications of skipping checks
4. Normal writes with policy checks are unaffected — no regression
