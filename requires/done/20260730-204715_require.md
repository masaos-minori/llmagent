# Requirement: Fix SIGINT Handler Race Condition During Shutdown

## Priority

High — signal handler corruption can cause unintended behavior and incomplete shutdown

## Target Files

- `scripts/agent/http_lifecycle.py` (lines 421-438)

## Background

In `HttpServerLifecycleManager.shutdown_all()`:

```python
old_sigint = signal.getsignal(signal.SIGINT)
if old_sigint is not None:
    try:
        signal.signal(signal.SIGINT, self._absorb_sigint_during_shutdown)
    except ValueError as exc:
        logger.debug("could not install SIGINT guard handler: %s", exc)

try:
    keys = list(self._http_procs.keys())
    for key in keys:
        # ... cleanup ...
finally:
    if old_sigint is not None:
        signal.signal(signal.SIGINT, old_sigint)
```

Two race conditions exist:

1. If `signal.signal()` fails with `ValueError`, `old_sigint` remains set but the new handler was never installed. The finally block then restores a handler that was never replaced, potentially overwriting a newly installed handler.

2. If `signal.getsignal()` returns `None` (default handler already replaced), `signal.signal(signal.SIGINT, None)` is an invalid call per Python docs — it should only be used to restore a previously saved handler, not to reset to default.

## Problem

Signal handler corruption during shutdown can cause:
- Ctrl-C behavior to change unexpectedly
- Subsequent shutdown attempts to fail silently
- Incomplete subprocess termination

## Reason for Change

Ensure signal handlers are correctly managed throughout the shutdown lifecycle to prevent corruption.

## Implementation Intent

Fix both race conditions by properly tracking whether the handler was successfully installed before attempting restoration.

## Implementation Instructions

1. Track whether the new handler was successfully installed:
   ```python
   old_sigint = signal.getsignal(signal.SIGINT)
   handler_installed = False
   
   if old_sigint is not None:
       try:
           signal.signal(signal.SIGINT, self._absorb_sigint_during_shutdown)
           handler_installed = True
       except ValueError as exc:
           logger.debug("could not install SIGINT guard handler: %s", exc)
   
   try:
       # ... cleanup ...
   finally:
       if handler_installed:
           signal.signal(signal.SIGINT, old_sigint)
   ```

2. Only attempt restoration if the handler was successfully installed. This prevents restoring a handler when no replacement was made.

## Acceptance Criteria

- [ ] Signal handler is restored only if it was successfully replaced
- [ ] No ValueError raised from `signal.signal(signal.SIGINT, None)`
- [ ] Shutdown completes correctly even when `signal.getsignal()` returns `None`
- [ ] Shutdown completes correctly when `signal.signal()` raises `ValueError`
