# Add guard tests for diagnostic store sensitive data handling

## Priority

Medium

## Target Files

## Background

Session diagnostics are saved to DiagnosticStore without encryption or filtering of sensitive data. The artifacts field contains URI lists from `store.get_artifact_uris(sid)` which may include file paths and URLs containing confidential information. Additionally, rag_stage_outcomes contains search results that may include retrieved content, and latency_summary provides internal system behavior insights.

## Problem

Sensitive data persisted in plaintext on the filesystem without any filtering or encryption.

## Reason for Change

Establish behavioral baseline through guard tests before any refactoring of these components.

## Implementation Intent

Create comprehensive guard tests covering:
- Artifact URI sanitization verification
- RAG outcome data masking verification
- Latency summary sensitivity verification
- Encryption status verification
