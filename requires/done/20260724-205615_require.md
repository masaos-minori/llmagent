# Allowed tools override not atomic — value permanently overwritten on post-finally exceptions

## Priority

Medium

## Target Files

- `scripts/agent/orchestrator.py` — Orchestrator._process_turn()

## Background

`_process_turn()` temporarily overrides `ctx.cfg.tool.allowed_tools` to enforce tool restrictions for the current turn. It saves the original value before overriding and restores it in a finally block.

## Problem

In `orchestrator.py:461-482`:

```python
original_allowed = ctx.cfg.tool.allowed_tools
if self._allowed_tools is not None:
    ctx.cfg.tool.allowed_tools = self._allowed_tools
try:
    ...
finally:
    ctx.cfg.tool.allowed_tools = original_allowed  # always restore
```

The `original_allowed` variable is local to `_process_turn()`. If an exception occurs after the finally block completes (e.g., in `_handle_turn_end` or elsewhere in the caller), there is no way to restore the original value because `original_allowed` has gone out of scope.

Additionally, if `_process_turn()` returns normally and the caller modifies `ctx.cfg.tool.allowed_tools` before the next call, the override is silently applied without awareness.

## Reason for Change

Permanently overwriting configuration values breaks the principle of least surprise and can cause subtle bugs where tool restrictions persist beyond their intended scope.

## Implementation Intent

Ensure the allowed_tools override is scoped to the turn lifecycle and always restored, regardless of where exceptions occur within the turn processing pipeline.

## Implementation Instructions

Option A (Recommended): Use context manager pattern

1. Create a context manager that handles the override and restoration:
   ```python
   @contextmanager
   def _tool_override(self, allowed: list[str] | None):
       original = self._ctx.cfg.tool.allowed_tools
       if allowed is not None:
           self._ctx.cfg.tool.allowed_tools = allowed
       try:
           yield
       finally:
           self._ctx.cfg.tool.allowed_tools = original
   ```
2. Replace the try/finally in `_process_turn()` with `with self._tool_override(self._allowed_tools):`.

Option B: Store original value as instance variable

1. Add `self._original_allowed_tools: list[str] | None = None` to `__init__()`.
2. In `_process_turn()`, save `original_allowed` to `self._original_allowed_tools` instead of a local variable.
3. Restore from `self._original_allowed_tools` in the finally block.
4. Ensure thread safety if concurrent turns are possible.

## Acceptance Criteria

- [ ] allowed_tools value is always restored after _process_turn(), even if exceptions occur after finally
- [ ] No permanent state mutation outside the intended scope
- [ ] No race conditions with concurrent turn execution

- Integration test: run multiple turns with different allowed_tools configurations; verify isolation between turns
