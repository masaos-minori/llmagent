# Add fix_scripts_docstring_paths.py entry to tools/TOOL_DESCRIPTIONS.md

## Priority
Low

## Target files
- `tools/TOOL_DESCRIPTIONS.md` (needs new entry)
- `tools/fix_scripts_docstring_paths.py` (target file to be documented)

## Background
The `tool-descriptions-sync` pre-commit hook enforces that every Python file under `tools/`
is documented in `tools/TOOL_DESCRIPTIONS.md`. A new tool script (`fix_scripts_docstring_paths.py`)
was added but its documentation entry was never created, causing the hook to fail.

## Problem
Pre-commit fails with:
```
Found 1 error(s).
[ERROR] fix_scripts_docstring_paths.py: exists in tools/ but is not mentioned in TOOL_DESCRIPTIONS.md
```

## Reason for change
The tool script exists and works correctly but lacks documentation in the project's canonical
tool inventory. Without this entry, the sync check will always fail and the tool's purpose
remains undocumented.

## Implementation intent
Add a row to the "ドキュメント構造検証・整形補助スクリプト" section of `tools/TOOL_DESCRIPTIONS.md`
with an entry for `fix_scripts_docstring_paths.py`, matching the existing table format:
- Column 1: filename
- Column 2: Japanese description of what the tool does (consistent with other entries in this section)

The new row should be inserted **before** the `check_tool_descriptions_sync.py` entry (the last
row in the section), since `check_tool_descriptions_sync.py` is about verifying TOOL_DESCRIPTIONS.md
itself rather than documenting a tool.

## Implementation instructions
1. Read `tools/fix_scripts_docstring_paths.py` to confirm its current functionality.
2. Read `tools/TOOL_DESCRIPTIONS.md` to find the appropriate section (currently "ドキュメント構造検証・整形補助スクリプト").
3. Add a row to the table **before** the `check_tool_descriptions_sync.py` row with:
    - Filename: `fix_scripts_docstring_paths.py`
    - Description: `scripts/**/*.py のモジュールレベルdocstringヘッダーパスをリポジトリルートからの相対パス（scripts/<relpath>形式）に書き換える。--dry-run で変更内容を表示、--apply で実際に適用。`
4. Run `uv run python -m tools.check_tool_descriptions_sync` to verify the error is resolved.

## Acceptance criteria
- `uv run python -m tools.check_tool_descriptions_sync` returns clean.
- `tools/TOOL_DESCRIPTIONS.md` contains a row for `fix_scripts_docstring_paths.py` in the appropriate section.
- No other entries in TOOL_DESCRIPTIONS.md are affected.

- No new tests needed — this is a documentation-only change.
