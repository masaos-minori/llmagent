# Harden ephemeral message filtering against key manipulation

## Priority

Low

## Target Files

- `scripts/agent/orchestrator.py:542-553` — Ephemeral message filtering

## Background

The ephemeral message filter uses `.get("_ephemeral")` and `.get("_memory_injected")` which can be bypassed by changing the key names.

## Problem

```python
def _clear_previous_turn_ephemeral_messages(self) -> None:
    ctx.conv.history = [
        m
        for m in ctx.conv.history
        if not m.get("_ephemeral") and not m.get("_memory_injected")
    ]
```

If an attacker adds messages with modified key names (e.g., `_ephemeral_` instead of `_ephemeral`), they would bypass the filter.

## Reason for Change

Prevent potential bypass of ephemeral message cleanup through key name manipulation.

## Implementation Intent

Use a whitelist approach: only accept known ephemeral keys rather than checking specific keys individually.

## Implementation Instructions

1. Define a constant set of valid ephemeral keys:
   ```python
   EPHEMERAL_KEYS = {"_ephemeral", "_memory_injected"}
   ```
2. Update the filter to use `any(k in EPHEMERAL_KEYS for k in m.keys())`
3. Run tests to confirm no regressions

## Acceptance Criteria

- [ ] Messages with any ephemeral key are filtered regardless of exact key name
- [ ] No regressions in message history handling
