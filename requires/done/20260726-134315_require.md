# Add guard tests for ephemeral message filtering hardening

## Priority

Medium

## Target Files

- `scripts/agent/orchestrator.py:542-553` — _clear_previous_turn_ephemeral_messages()
- `scripts/agent/commands/cmd_skill.py:47-56` — ephemeral filtering

## Background

The _clear_previous_turn_ephemeral_messages() method filters based on _ephemeral and _memory_injected keys. These key settings rely on trust with no schema validation. Similarly, cmd_skill.py filters based on _skill_ephemeral key. If the LLM generates fake system messages with these keys, filtering could malfunction. Additionally, messages without these keys won't be filtered, allowing the LLM to intentionally leave persistent messages as permanent.

## Problem

Ephemeral message filtering depends solely on key presence, which the LLM can manipulate.

## Reason for Change

Establish behavioral baseline through guard tests before any refactoring of these components.

## Implementation Intent

Create comprehensive guard tests covering:
- Fake ephemeral key injection detection verification
- Message structure validation verification
- Ephemeral message generation source restriction verification
- Filtering correctness verification
