# Clean up dead code in `shell/subprocess_runner.py` and `shell_service.py`

## Priority
Medium

## Target files
- `scripts/mcp_servers/shell/subprocess_runner.py` (`__init__`'s `self._timeout_sec`)
- `scripts/mcp_servers/shell/shell_service.py` (module docstring)

## Background
Several small, deferred cleanups from the `scripts/mcp_servers/shell/` subsystem's 2026-08-16 refactor cycles:
1. **`SubprocessRunner.kill_timed_out_process` is NOT dead**: Confirmed via `rg "kill_timed_out_process"` that there are two test callers (`tests/mcp_servers/shell/test_subprocess_runner.py:54,62`). This method is part of the public API and should NOT be removed without explicit approval.
2. **`SubprocessRunner.__init__` stores `timeout_sec` into `self._timeout_sec`, but it is never read anywhere in the class** — confirmed via `rg "_timeout_sec"` across `scripts/mcp_servers/shell/`: only one write site (`subprocess_runner.py:33`) and zero read sites. The per-call timeout is always passed explicitly to `run_subprocess` instead.
3. **`shell_service.py`'s module docstring references a stale filename ("`service.py`")** instead of the current `shell_service.py`. Line 10 of the docstring says "service.py — ShellService class + dispatch table factory + build_service".

## Problem
Item (2): Dead store adds confusion about which timeout value is authoritative. Item (3): Stale documentation misleads developers reading the file.

## Reason for change
Dead store removal reduces cognitive load and prevents confusion about timeout semantics. Docstring fix eliminates stale reference. Both were flagged as likely dead code but not removed because item (2) was left alone specifically because the orchestrating session flagged *all* timeout-related code in `subprocess_runner.py` as maximally behavior-sensitive.

## Implementation intent
For (2): confirm via `rg "_timeout_sec"` that no subclass or external caller reads the attribute, then remove the dead store. For (3): fix the docstring reference directly (no risk). Do NOT touch `kill_timed_out_process` — confirmed alive by tests.
