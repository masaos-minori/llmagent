# Add guard tests for WAL file backup path traversal prevention

## Priority

Low

## Target Files

## Background

When constructing the WAL file backup path in _close_resources(), the database file path is used directly without validation. If the database file is a symbolic link pointing to an external directory, the WAL file backup destination could become unexpected. Additionally, if backup_dir is a system directory like /tmp, race conditions with other processes creating files with the same name may occur.

## Problem

Path traversal risk through unvalidated symlink targets and potential race conditions in shared directories.

## Reason for Change

Establish behavioral baseline through guard tests before any refactoring of these components.

- Symlink target validation verification
- Path normalization verification
