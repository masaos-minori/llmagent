# Memory snippet injection influences LLM behavior

## Priority

Medium

## Target Files

- `scripts/agent/orchestrator.py` — `_handle_memory_injection()`
- `scripts/agent/memory/injection.py` — `on_user_prompt()`, snippet construction logic

## Background

When processing user prompts, the orchestrator retrieves relevant memory snippets via `MemoryInjectionService.on_user_prompt()` and injects them as `"role": "system"` messages into the conversation history.

## Problem

In `orchestrator.py:373-391`:

```python
memory_block = "[Relevant memories]\n" + "\n".join(
    f"- {snippet.text}" for snippet in memory_snippets
)
ctx.conv.history.append(
    {
        "role": "system",
        "content": memory_block,
        "_memory_injected": True,
    }
)
```

The retrieved snippets are injected as system-level messages, which influence the LLM's response. Since the LLM can intentionally generate queries that trigger memory search, it could cause unwanted snippets to be injected. Additionally, when `entry.summary` is missing, `entry.content[:100]` is used as a prefix (`injection.py:84`, `100`), truncating important information.

## Reason for Change

Unfiltered memory snippets injected as system messages can manipulate LLM behavior. The LLM can exploit this by generating queries designed to retrieve specific snippets, effectively injecting its own context. Without filtering or length limits, this creates a potential prompt injection vector.

## Implementation Intent

Add filtering policies for memory snippets before injection. Limit snippet length to prevent excessive context injection. Explicitly mark system message priority lower than user messages.

## Implementation Instructions

1. Add a filtering layer that removes sensitive content (PII, credentials, etc.) from snippets before injection.
2. Implement a maximum snippet length limit (e.g., 500 characters per snippet).
3. Add a priority marker to the system message indicating it has lower priority than user messages.
4. Log warnings when snippets are filtered or truncated.

## Acceptance Criteria

- [ ] Sensitive content filtered from snippets before injection
- [ ] Snippet length limited to prevent excessive context injection
- [ ] System message priority explicitly marked as lower than user messages
- [ ] Warnings logged when snippets are filtered or truncated

## Tests

- Unit test: pass snippet with PII data; verify it is filtered before injection
- Unit test: pass oversized snippet; verify truncation occurs with warning
- Integration test: simulate LLM generating query designed to retrieve malicious snippets; verify filtering works
