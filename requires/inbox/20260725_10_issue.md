## [repl] Diagnostic store persists sensitive data without encryption

### Summary

セッションの診断情報が `DiagnosticStore` に保存されるが、機密データが含まれる可能性があり、暗号化されていない。

### Problem

`repl.py:148-244` でセッション診断情報が保存される：

```python
summary = {
    "session_id": session_id,
    "timestamp": time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime()),
    "turns": stats.stat_turns,
    "tool_calls": stats.stat_tool_calls,
    "tool_errors": stats.stat_tool_errors,
    "partial_completions": stats.stat_partial_completions,
    "parse_errors": llm.stat_parse_errors if llm is not None else 0,
    "heartbeat_timeouts": (
        llm.stat_heartbeat_timeouts if llm is not None else 0
    ),
    "reconnects": llm.stat_reconnects if llm is not None else 0,
    "semantic_cache_hits": stats.stat_semantic_cache_hits,
    "input_tokens": stats.stat_input_tokens,
    "output_tokens": stats.stat_output_tokens,
    "compress_count": (
        hist_mgr.stat_compress_count if hist_mgr is not None else 0
    ),
    "fallback_truncate_count": (
        hist_mgr.stat_fallback_truncate_count if hist_mgr is not None else 0
    ),
    "latency_summary": latency_summary,
    "workflow_count": workflow_count,
    "task_count": task_count,
    "approval_events": approval_events,
    "retry_count": retry_count,
    "artifacts": artifacts,
    "rag_query_count": rag_query_count,
    "rag_stage_outcomes": rag_stage_outcomes,
}
```

`artifacts` フィールドは `store.get_artifact_uris(sid)` から取得される URI のリストであり、これにはファイルパスやURLが含まれる可能性がある。これらのURIは機密情報を含むことができる。

また、`rag_stage_outcomes` は RAG クエリの結果を含み、これには検索されたコンテンツの一部が含まれる可能性がある。

さらに、`latency_summary` には各ステップのレイテンシ統計が含まれ、これによりシステムの内部動作が推測できる。

### Affected Files

- `scripts/agent/repl.py:148-244` — `_persist_session_diagnostics()`
- `scripts/agent/diagnostic_store.py` — `DiagnosticStore.save()`

### Attack Scenario

1. セッション終了時に診断情報が保存される
2. 保存されたファイルから artifact URIs を抽出し、機密ファイルの場所を特定する
3. RAG クエリの結果から検索されたコンテンツを復元する

### Severity

Medium — 診断情報に機密データが含まれる可能性があり、ファイルシステムに平文で保存される。

### Mitigation

- 機密データをフィルタリングしてから保存する
- 保存前にデータの暗号化を検討する
- 保存期間の設定を追加し、古いデータを自動的に削除する
