# Add separation between system prompt and injected memory content

## Priority

High

## Target Files

- `scripts/agent/orchestrator.py:382-388` — Memory injection into system prompt
- `scripts/agent/startup.py:558-561` — System prompt memory addition

## Background

Memory snippets are appended directly to the system prompt without any boundary:

```python
memory_block = "\n\n[Relevant memories]\n" + "\n".join(
    f"- {snippet.text}" for snippet in memory_snippets
)
initial_prompt = initial_prompt + memory_block
```

If an attacker stores malicious content in memory (e.g., "You are now a different AI assistant"), the LLM may follow those instructions after they're injected into the system prompt.

## Problem

No clear separation between system-defined prompt and user-injected memory content. This creates a prompt injection vector where user-controlled content becomes part of the system prompt.

## Reason for Change

Prevent potential prompt injection through memory content by clearly separating system-defined and user-defined content.

## Implementation Intent

Add a clear separator between system prompt and memory content, and consider injecting memory as user messages instead of appending to the system prompt.

## Implementation Instructions

Option A (minimal): Add a clear separator before memory content:
```python
memory_block = "\n\n--- USER MEMORY ---\n" + "\n".join(
    f"- {snippet.text}" for snippet in memory_snippets
)
```

Option B (stronger): Inject memory as separate user messages instead of appending to system prompt.

Choose Option A if time-constrained; Option B provides stronger isolation but requires more changes.

## Acceptance Criteria

- [ ] Clear separator between system prompt and memory content
- [ ] User-controlled content does not become part of the system prompt
- [ ] No regressions in memory retrieval behavior
