# Add rationale for the "do not load all docs/*.md" rule and a maintenance note to the タスク別ドキュメント参照 tables in docs/00_index.md

## Priority
Low

## Target files
- `docs/00_index.md` (~line 59: the "do not load all docs/*.md" instruction; ~lines 61-149: the タスク別ドキュメント参照 section, specifically the text immediately above the tables)

## Background
`docs/00_index.md` is the top-level navigation hub for the documentation set. Its タスク別ドキュメント参照 section (added by migration from `routing.md`) instructs readers/agents to load only the documents relevant to a given task and explicitly not to load all `docs/*.md` files. It then lists several tables mapping task scope to specific reference doc filenames.

## Problem
Two informational gaps exist in this section as currently written:
1. The instruction "`docs/*.md` を全件読み込まないこと" (line 59) states a rule but gives no reason, making it easy for a future reader or agent to misunderstand or dismiss as arbitrary.
2. The tables (lines 61-149) hard-code specific file names that must be kept in sync whenever the referenced docs are renamed, split, or restructured, but there is no explicit note establishing this as an ongoing operational responsibility. This risk is not hypothetical: the table currently contains a stale reference at line 128 (`03_rag_90_inconsistencies_and_known_issues-part1.md`), which does not match the actual file on disk (`03_rag_90_inconsistencies_and_known_issues.md`, no `-part1` suffix) — confirming the table has already gone stale at least once.

## Reason for change
An unexplained "must not" rule invites future readers/agents to disregard it or work around it without understanding the cost it prevents (excessive context consumption, irrelevant-content noise). Separately, since the table has already been shown to drift out of sync with actual file names, that risk should be called out explicitly as something maintainers must actively guard against, rather than left as an implicit expectation.

## Implementation intent
Add two short, single-sentence explanatory notes to `docs/00_index.md`:
1. Immediately after (or appended to) the existing "do not load all docs/*.md" instruction near line 59, add one sentence stating the context-budget/noise-reduction rationale for selective loading.
2. Immediately above the タスク別ドキュメント参照 tables (before the first table, i.e., before or as part of the introductory text around lines 59-61), add one sentence establishing that the tables are an operational artifact that must be kept in sync with the actual file names/structure of the referenced documents, and should be periodically verified against reality.

Both additions must be minimal — one sentence each — and must not restructure the existing tables, change any table content, or correct the line-128 filename discrepancy (that discrepancy is tracked as a separate, already-known issue and is out of scope here).
