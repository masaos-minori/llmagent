# Add missing schema_version to rag_pipeline MCP server /v1/tools endpoint

## Priority

High

## Target Files

- `scripts/mcp_servers/rag_pipeline/rag_pipeline_server.py:163-167` — list_tools() missing schema_version
- `scripts/mcp_servers/server.py:224-233` — build_tools_response() standard pattern

## Background

The rag_pipeline MCP server's `/v1/tools` endpoint does not include the `schema_version` key that all other MCP servers include. This violates the MCP tool discovery contract.

## Problem

```python
# scripts/mcp_servers/rag_pipeline/rag_pipeline_server.py:163-167
@app.get("/v1/tools")
async def list_tools() -> dict[str, Any]:
    """List available RAG tools with server_key="rag_pipeline"."""
    return {
        "tools": [{**t, "server_key": "rag_pipeline"} for t in TOOL_LIST],
    }
```

Other MCP servers use `build_tools_response()` which includes `schema_version`:

```python
# scripts/mcp_servers/server.py:224-233
def build_tools_response(tools: Sequence[Any], server_key: str) -> dict[str, Any]:
    return {
        "schema_version": MCP_TOOL_SCHEMA_VERSION,
        "tools": [{**t, "server_key": server_key} for t in tools],
    }
```

## Reason for Change

Clients that validate the `schema_version` field will fail when querying the rag_pipeline server. This is a breaking contract violation.

## Implementation Intent

Replace the manual dict construction in `list_tools()` with a call to `build_tools_response()`, matching the pattern used by all other MCP servers.

## Implementation Instructions

1. In `scripts/mcp_servers/rag_pipeline/rag_pipeline_server.py`, add import:
   ```python
   from mcp_servers.server import build_tools_response
   ```

2. Replace the `list_tools()` function body:
   ```python
   # Before:
   return {
       "tools": [{**t, "server_key": "rag_pipeline"} for t in TOOL_LIST],
   }

   # After:
   return build_tools_response(TOOL_LIST, "rag_pipeline")
   ```

3. Run `uv run pytest -k "schema_version" tests/test_mcp_tools_validation.py -v` to confirm pass
4. Run `uv run mypy scripts/mcp_servers/rag_pipeline/rag_pipeline_server.py` to confirm no type errors
5. Run `uv run ruff check scripts/mcp_servers/rag_pipeline/rag_pipeline_server.py` to confirm clean
