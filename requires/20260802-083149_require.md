# Fix scope mismatch in docs/00_governance_06 and add missing cross-link from docs/00_governance_01

## Priority
Medium

## Target files
- `docs/00_governance_06_ai-reading-metadata.md`
- `docs/00_governance_01_documentation-governance.md`

## Background
`docs/00_governance_06_ai-reading-metadata.md` is scoped (per its own Purpose section) to metadata conventions that let AI agents select relevant documents. Verified against the current file, it contains a trailing `## Markdown記法ルール` section (lines 134-153) covering code-block fencing, table formatting, keyword conventions, and section-boundary rules — none of which relate to AI-reading metadata. The same file also contains a `## 実装参照で確認できる情報の記載方針` section (lines 155-187) that defines the delete/compress/replace/keep/known-issues/needs-confirmation classification criteria for implementation-detail content in design docs. This is a high-value, cross-cutting rule, but `docs/00_governance_01_documentation-governance.md` (the file governing cross-cutting documentation rules) only links to `00_governance_06` generically from its "Related Governance Documents" list — it does not link to this specific section, so a reader looking for core documentation-writing rules in 01 would not discover it there.

## Problem
1. `docs/00_governance_06_ai-reading-metadata.md` mixes two unrelated concerns: AI-reading metadata (its declared scope) and generic Markdown formatting conventions (out of scope for this file).
2. The `実装参照で確認できる情報の記載方針` classification rule in 06 is not cross-linked from `docs/00_governance_01_documentation-governance.md`, so it is easy to miss.

Both conditions were re-verified against the current repository state on 2026-08-02 and still hold; no prior fix has been applied.

## Reason for change
The scope mismatch makes `00_governance_06` harder to navigate (a reader looking for AI-reading-metadata content has to skip past unrelated Markdown style rules), and the important 記載方針 rule risks going unnoticed by readers who start from `00_governance_01` expecting to find core documentation-writing rules there.

## Implementation intent
- Relocate the `Markdown記法ルール` content out of `00_governance_06_ai-reading-metadata.md`. Preferred target: `docs/00_governance_01_documentation-governance.md`, since it already owns cross-cutting documentation conventions — but note `00_governance_01`'s own "Non-Goals" section (line 86) currently states "Document formatting conventions within Specification documents" is explicitly out of scope for that file. If the implementer places the relocated content in 01, that Non-Goals line must be reconciled (e.g., narrowed or removed) so the file does not contradict its own stated scope. If reconciling that scope statement is undesirable, use a new dedicated style-guide document instead and link to it from both 01 and 06.
- Leave a single-line pointer in place of the removed section in 06, referencing wherever the content lands.
- Add a cross-reference from `00_governance_01_documentation-governance.md` to the `実装参照で確認できる情報の記載方針` section in 06 (an anchor link to that specific section, not merely the existing generic file-level link already present in 01's "Related Governance Documents" list).
- Do not duplicate full rule text in two places, and do not rewrite the substance of either the Markdown rules or the 記載方針 rule — only their location and cross-references change.

1. Read both `docs/00_governance_06_ai-reading-metadata.md` and `docs/00_governance_01_documentation-governance.md` in full before editing, to avoid losing content during the move.
2. Remove the `## Markdown記法ルール` section (currently lines 134-153 of 06) and relocate its content to its new home (01 or a new dedicated style-guide doc, per the decision made under Implementation intent above). Preserve the existing wording; adjust only what is needed to fit the new location's surrounding context (e.g., heading level).
3. In `00_governance_06_ai-reading-metadata.md`, replace the removed section with a one-line pointer to the new location of the Markdown notation rules.
4. In `00_governance_01_documentation-governance.md`, add a specific cross-reference (anchor link) to the `実装参照で確認できる情報の記載方針` section of `00_governance_06_ai-reading-metadata.md`, placed where a reader looking for core documentation-writing rules would naturally find it (e.g., near the Update Rule / Related Governance Documents area).
5. If the Markdown rules are relocated into 01, update 01's "Non-Goals" line about "Document formatting conventions within Specification documents" so it no longer contradicts the newly added content.
