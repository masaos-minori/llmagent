## Problem
The RAG domain has no functioning Known Issues consolidation point right now: the file exists,
follows the correct template, but has no entries to consolidate anything into. At the same
time, the original issue's premise — that this review found 7 cross-cutting confirmed errors
plus additional confirmed errors and Needs Confirmation items, all still needing a tracking
entry — is now known to be partially stale, because several of those items were fixed by
commits that predate this issue batch's filing. Populating the file by blindly copying the
original review's list would re-introduce already-fixed items as if they were still open,
undermining the exact "one source of truth" discipline this issue is trying to establish.

## Reason for change
An empty Known Issues file means every confirmed error and open question this review (and any
future review) surfaces has no central home and stays scattered across individual doc files
and issue files, repeating the fragmentation problem this review criticizes elsewhere (e.g.
Fail-Open/Closed tables, port numbers duplicated across domains). The file must be populated
now, but with entries whose status reflects the current, true state of the codebase and docs —
not the state as it was when the original review ran.

   original issue's list (see `## Implementation instructions` below for the full list),
   against current source and current docs — do not treat the original review's "confirmed

2. Prefer the sibling requirement/issue outcomes from this same batch as the primary status
   signal per item, since they represent more recent, already-completed verification work:
   - If a sibling issue for the item is already in `issues/done/` with no corresponding
     `requires/20260802-*_require.md` doc (i.e. it was skipped at the issue-to-require step

     treat that item as a genuinely open Known Issue and add a full 17-field entry for it,

   removed by commit `646152e61` per the project's resolved-entry-pruning convention, and (b)
   that this population pass re-verified the original review's list against current source
