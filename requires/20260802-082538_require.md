# Add a state-transition table to the Known Issue Lifecycle section

## Priority
Low

## Target files
- `docs/00_governance_04_known-issues-template.md` (Lifecycle section, lines ~79-85)

## Background
`docs/00_governance_04_known-issues-template.md` defines the lifecycle for known-issue
entries: Open → Investigating → Fixed/Deferred/Wontfix → Deprecated. This lifecycle is
currently documented only as prose bullet points describing each transition.

## Problem
Prose-only state machine descriptions are more error-prone to follow correctly than an
explicit table or diagram, especially when the lifecycle rule needs to be applied
mechanically (e.g., by an AI agent or a contributor triaging an issue). A reader must
parse five bullet points to reconstruct the full set of valid states and transitions,
which increases the risk of misapplying a transition (e.g., skipping a state or applying
an invalid one).

## Reason for change
Making the state machine explicit as a table reduces misreading risk and gives both human
and AI readers a single, unambiguous reference for valid transitions, without requiring
any change to the underlying lifecycle semantics.

## Implementation intent
Add a state-transition table directly below (or immediately after) the existing prose in
the Lifecycle section of `docs/00_governance_04_known-issues-template.md`. The table
supplements the prose — it does not replace or remove it. The table must be derivable
strictly from the current prose; no new states or transitions should be introduced.

## Implementation instructions
1. Open `docs/00_governance_04_known-issues-template.md` and locate the `## Lifecycle`
   section (currently lines 79-86).
2. Keep the existing prose bullets unchanged.
3. Immediately after the prose, add a Markdown table with columns: `現在の状態` (current
   state) / `遷移条件` (transition condition) / `遷移先` (next state).
4. Populate the table with one row per transition currently described in the prose:
   - Open / investigation begins / Investigating
   - Investigating / resolved / Fixed
   - Investigating / not resolvable now / Deferred
   - Investigating / not resolvable now (abandoned) / Wontfix
   - Deferred / eventually addressed / Fixed
   - Deferred / abandoned / Wontfix
   - (any state) / underlying feature removed / Deprecated
5. Do not invent additional states, transitions, or conditions beyond what the prose
   already describes. Do not alter the prose text itself except to add the table
   adjacent to it.
6. Do not modify any other section of the file (Migration Notes, Related Governance
   Documents, etc.).

## Acceptance criteria
- The Lifecycle section contains both the original prose and a new state-transition
  table.
- The table has exactly the columns 現在の状態 / 遷移条件 / 遷移先.
- Every transition mentioned in the prose has exactly one corresponding table row, and
  the table introduces no transitions absent from the prose (no discrepancy between the
  two representations).
- No other section of `docs/00_governance_04_known-issues-template.md` is changed.

## Tests
Not applicable — documentation-only change. Verification is manual: diff the table
rows against the prose bullets to confirm full coverage with no additions or omissions.
