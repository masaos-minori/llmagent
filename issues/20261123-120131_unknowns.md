# Unresolved blocking unknown: state-dependent retention changes ADR-008's Decision Details

## Summary

`UNK-01` / `U-1` in the plan remains unresolved. A state-dependent retention rule (REQ-005)
changes ADR-008 Decision Detail #23, which defines retention cleanup as deleting terminal rows
past the retention window, and INV-09, which accepts unbounded growth for the dedup store
because it is classified as a disposable cache. Purging only terminal rows cannot retain
unresolved states, so either the ADR changes or the Plan must. `rules/ai-execution.md` Conflict
Resolution requires a maintainer approval record for a decision that changes an ADR, and an AI
cannot create one, so the conflict is reported here instead of resolved. This was recorded as an
Unknown, not an assumption, because an assumption would silently decide the ADR question.

1. The repository owner (`@lead` in the `governance_05` RACI Model) decides whether ADR-008 is

   bounded by another mechanism, and the plan's phase 5 and its `U-1` row are revised by the

   requirements.
