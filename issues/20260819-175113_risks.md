# [FOLLOW-UP] agent-docs-consistency.yml and mcp-docs-consistency.yml invoke deleted per-domain scripts

## Priority
Medium

## Background
While verifying `plans/20260819-174858_plan.md` (Risks section), the same CI
breakage found and fixed in-scope for `overview-docs-consistency.yml`,
`deployment-docs-consistency.yml`, and `rag-docs-consistency.yml` was also found
in two workflows that are **not** in this requirement's target-file list:

- `.github/workflows/agent-docs-consistency.yml` runs
  `python tools/check_agent_docs_consistency.py`
- `.github/workflows/mcp-docs-consistency.yml` runs
  `python tools/check_mcp_docs_consistency.py`

Both scripts were consolidated into `tools/check_docs_consistency.py` (its own
module docstring says "Consolidated from: ... tools/check_agent_docs_consistency.py
... tools/check_mcp_docs_consistency.py") and no longer exist on disk:

```
$ ls tools/check_agent_docs_consistency.py tools/check_mcp_docs_consistency.py
ls: cannot access 'tools/check_agent_docs_consistency.py': No such file or directory
ls: cannot access 'tools/check_mcp_docs_consistency.py': No such file or directory
```

These two CI workflows are therefore currently failing (or have been silently
broken) on every run that reaches this step, for reasons unrelated to actual
doc content.

## Required Action
Update both workflow files to call the consolidated script with the domain flag,
matching the fix applied to overview/deployment/rag in this cycle:

```yaml
run: |
  set -euo pipefail
  python tools/check_docs_consistency.py --domain agent
```
```yaml
run: |
  set -euo pipefail
  python tools/check_docs_consistency.py --domain mcp
```

## Why not fixed in this pass
`plans/20260819-174858_plan.md` scopes its CI-workflow fix to
`overview-docs-consistency.yml`, `deployment-docs-consistency.yml`, and
`rag-docs-consistency.yml` only, because those three are the workflows relevant
to the model/embedding-reference consistency check being added by that plan.
Fixing `agent`/`mcp` as well would be unrelated scope creep for that specific
plan, but the defect is real and independent of this requirement — it should be
picked up as its own small fix.
