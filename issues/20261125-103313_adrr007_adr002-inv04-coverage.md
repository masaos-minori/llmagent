# Register and test ADR-002 INV-04 configuration isolation

## Priority
Medium

## Summary
ADR-002 INV-04 (the Agent configuration holds no MCP-server-owned settings) is approved as Non-Blocking and Not Verified, but it is missing from the ADR index matrix and the coverage manifest and has no dedicated test.

## Background
Verified against master on 2026-11-25 (source: local note `memo-issue.md`, issue 013):
- Confirmed: the index matrix lists ADR-002 INV-01 to INV-03 only (`docs/10_adr/adr_01_index.md:187-189`) and the manifest has no INV-04 entry for ADR-002.
- Confirmed: the ADR's own table records INV-04 as Non-Blocking and "Not verified (no complete automated test proves the amended contract)" (`adr_02_01_002_platform-config-isolation.md:232`), and its Approval Record (previously `AAL-030` and `AAL-032`) approves exactly that status.

## Problem

## Reason for Change

## Implementation Intent
