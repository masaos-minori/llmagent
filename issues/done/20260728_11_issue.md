# Extend RAG consistency checks to detect document-level and URL-level integrity problems

## Priority
Medium

## Type
Data integrity / Operations

## Background
The current RAG consistency check compares chunks, chunks_fts_docsize, and chunks_vec counts. It also detects orphan vector rows, FTS gaps, and FTS orphan counts.

## Problem
The current consistency check does not detect:

- documents with zero chunks
- chunks without vector rows
- duplicate chunk_index values within the same document
- URL-level mismatches between chunks, vectors, and FTS rows

These issues can occur after partial ingestion failures or interrupted re-ingestion.

## Fix Intent
The intent is to make the consistency report useful for detecting incomplete or partially failed ingestion, not only index count mismatches.

## Implementation Tasks
- Add documents_without_chunks_count.
- Add chunks_without_vec_count.
- Add duplicate_chunk_index_count.
- Add optional URL-level counts:
  - document URL
  - chunk count
  - vector count
  - FTS count
- Include affected doc_ids and URLs where possible.
- Update summarize_issues() with clear severity and repair guidance.
- Consider whether UNIQUE(doc_id, chunk_index) should be added in a later migration.

## Acceptance Criteria
- Empty documents are detected.
- Chunks without vectors are detected.
- Duplicate chunk_index values are detected.
- URL-level inconsistencies can be reported.
- Existing FTS gap and orphan vector checks continue to work.
- Repair guidance is actionable.

## Tests
- Add a test for documents with zero chunks.
- Add a test for chunks without vectors.
- Add a test for duplicate chunk_index values.
- Add a test for URL-level chunk/vector/FTS mismatches.
- Add regression tests for existing orphan vector and FTS gap behavior.

## Out of Scope
- Automatic repair implementation.
- Schema migration for UNIQUE(doc_id, chunk_index), unless separately approved.
