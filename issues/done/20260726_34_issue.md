## eventbusのレイヤー独立性違反 (TASK-H5 / EVENTBUS-1)

### Summary

`.importlinter` の `eventbus-is-isolated` 契約違反。`db.helper` / `shared.json_utils` への依存が重複コード削減リファクタの副作用として混入。`rules/env.md` の「eventbus→他の全レイヤーから完全に独立」という設計方針とも矛盾。

### Problem

```
eventbus → db.helper (PRAGMA設定の一元化)
eventbus → shared.json_utils (now_iso/dumps)
```

コミット追跡:
- `db.helper.apply_connection_pragmas`: コミット `d2067882` (2026-07-12)
- `shared.json_utils.now_iso` / `dumps`: コミット `4bdcb014` / `381ba262`
- Event Bus基盤導入時 (`6153338f`, 2026-06-22) から当初設計

### Affected Files

- `scripts/eventbus/db.py:8` — `db.helper` 依存
- `scripts/eventbus/{ack,dlq,publish,replay,subscribe}_route.py` — `shared.json_utils` 依存
- `.importlinter` — `eventbus-is-isolated` 契約
- `rules/env.md` — 設計方針記載

### Severity

High — アーキテクチャ違反。eventbus層が独立層であるべきという契約に反している

### Root Cause

重複コード削減リファクタの副作用として意図せず混入。契約自体は当初設計であり、後付けではない

### Mitigation

1. `db.helper.apply_connection_pragmas` 相当の軽量関数をeventbus内に複製
2. `shared.json_utils` の `now_iso` / `dumps` (eventbusが使う2関数のみ) を同様に複製
3. eventbusの各ファイルのimportを複製実装に切り替え

### Acceptance Criteria

- `PYTHONPATH=scripts uv run lint-imports` が5契約すべてKEEP
- lint-imports pass、既存eventbusテスト全てpass
- 複製関数に対する最小限のユニットテスト追加

### Dependencies

TASK-M2(eventbus移行ガードテスト)より先に実施推奨。同一ファイル(db.py)への変更が重なるため
