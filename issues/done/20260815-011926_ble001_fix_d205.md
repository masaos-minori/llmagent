# ruff BLE001: tools/fix_d205.py line 128 catches all exceptions

## Priority
Medium

## Summary
`tools/fix_d205.py:128` uses bare `except Exception:` which triggers ruff BLE001
(catching all exceptions without specific handling). Similar to the check_all_docstrings
issue — the broad catch is intentional because `Path.read_text()` can raise various
OS-level errors and the code simply skips files it cannot read.

## Reason for Change
The bare `except Exception:` is deliberate: `Path.read_text()` can raise multiple
OS-level errors (PermissionError, FileNotFoundError, UnicodeDecodeError, etc.) and
there is no meaningful distinction between them at this level — the tool should skip
any unreadable file and continue processing others. However, ruff flags this as a
potential bug because catching all exceptions can mask unexpected errors.
