# Normalize all embedding request paths for Qwen3 raw-text embeddings

## Priority

High

## Summary

Remove all E5-specific request transformations and make all embedding calls send raw text to the embedding endpoint.

This issue also normalizes `embed_url` handling and sets conservative ingestion concurrency for the Qwen3 embedding server.

## Background

The current embedding paths still contain E5-oriented behavior:

- RAG ingestion sends `passage: {text}`.
- RAG query embedding sends `query: {text}`.
- Memory embedding uses `EmbeddingClientConfig.query_prefix = "query: "`.
- Memory embedding has `embed_dim = 384` and dimension mismatch handling.
- `ingester.toml` uses `/embedding` in `embed_url`, while `build_embed_url()` already appends `/embedding`.
- `ingester.toml` sets `embed_workers = 4`.

These are not appropriate for a Qwen3-only raw-text embedding contract.

## Fix Intent

Use one embedding contract across the system:

- Input: raw text
- Endpoint configuration: base URL only
- Endpoint path construction: handled by `build_embed_url()`
- Initial ingestion concurrency: one worker
- Dimension mismatch handling: removed because dimensions are fixed by code constant

## Required Changes

### RAG ingestion

- Update `RagIngester._get_embedding()`.
- Change the payload from:

  `json={"content": f"passage: {text}"}`

  to:

  `json={"content": text}`

- Remove `self._expected_dims`.
- Remove `cfg.get("embedding_dims", 384)`.
- Remove embedding length mismatch retry logic.
- Keep validation for:
  - empty input
  - HTTP failure
  - invalid response
  - missing or empty `embedding`

### RAG query embedding

- Update `rag/llm_client.py:get_embedding()`.
- Change the payload from:

  `json={"content": f"query: {text}"}`

  to:

  `json={"content": text}`

- Remove E5-specific docstring text.

### Memory embedding

- Update `agent/memory/embedding_client.py`.
- Remove `EmbeddingClientConfig.query_prefix`.
- Remove `EmbeddingClientConfig.embed_dim`.
- Remove `_fetch_embedding()` parameters for `query_prefix` and `embed_dim`.
- Change the payload to:

  `json={"content": text}`

- Remove dimension mismatch handling.
- Review `EmbeddingErrorKind.DIMENSION_MISMATCH` and delete it if unused.

### URL configuration

- Update `config/ingester.toml`:

  `embed_url = "http://192.168.11.238:8081"`

- Confirm `config/agent.toml` uses a base URL.
- Confirm `config/rag_pipeline_mcp_server.toml` uses a base URL.
- Do not allow `/embedding`-suffixed values in config.

### Ingestion concurrency

- Update `config/ingester.toml`:

  `embed_workers = 1`

## Files to Update

- `scripts/rag/ingestion/ingester.py`
- `scripts/rag/llm_client.py`
- `agent/memory/embedding_client.py`
- `agent/memory/types.py`
- `config/ingester.toml`
- `config/agent.toml`
- `config/rag_pipeline_mcp_server.toml`

## Acceptance Criteria

- No embedding request sends `query:` prefix.
- No embedding request sends `passage:` prefix.
- Memory embedding no longer supports `query_prefix`.
- Memory embedding no longer supports `embed_dim`.
- Dimension mismatch retry logic is removed from RAG ingestion.
- Dimension mismatch handling is removed from memory embedding.
- `ingester.toml` uses a base URL for `embed_url`.
- `embed_workers` is set to `1`.
- Final embedding URL resolves to exactly one `/embedding` suffix.
