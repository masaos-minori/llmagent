# [LOW] Standardize terminology and repair documentation quality defects

## Priority

Low

## Background

The documentation contains inconsistent terminology, typographical errors, encoding artifacts, malformed Markdown, duplicate links, incorrect Part links, empty Keywords sections, and unstable source references.

## Reason for Change

These defects reduce readability, navigation quality, search accuracy, AI retrieval quality, and automated processing reliability.

Machine-readable category values are especially important because they affect document routing.

## Intent

Apply one terminology and Markdown-quality standard without changing runtime identifiers, filenames, class names, or API names.

## Tasks

1. Create a terminology glossary.
2. Standardize:

   - Agent terminology
   - EventBus terminology
   - Ingestion terminology
   - Shared/DB metadata categories
   - Canonical-source terminology
   - Known Issue and Needs Confirmation terminology

3. Correct typographical and encoding errors.
4. Standardize table-heading language.
5. Deduplicate Related Documents.
6. Select one canonical related-link representation.
7. Correct Part links.
8. Remove or consolidate empty Keywords sections.
9. Repair code fences.
10. Replace unstable line-number references with symbols, configuration keys, or test identifiers.
11. Validate titles, filenames, source references, dates, and links.

## Acceptance Criteria

- [ ] A terminology glossary exists.
- [ ] Preferred English and Japanese forms are documented.
- [ ] Machine-readable categories use one vocabulary.
- [ ] Typographical and encoding defects are corrected.
- [ ] Runtime identifiers remain unchanged.
- [ ] Related links are not duplicated.
- [ ] Part links are correct.
- [ ] No empty Keywords heading remains.
- [ ] Code fences use correct language identifiers.
- [ ] Evidence references use stable symbols where practical.
- [ ] Titles and source references are valid.
- [ ] Dates use ISO 8601 format.
- [ ] Markdown lint and link validation pass.

## Validation

1. Search for deprecated terminology.
2. Search for known typographical artifacts.
3. Validate category metadata.
4. Run Markdown lint.
5. Run link validation.
6. Verify runtime identifiers were not changed.

## Out of Scope

- Renaming runtime symbols
- Renaming API endpoints
- Architectural content changes
