## エージェント起動フェーズ: モード分類によるプロンプトインジェクション

### Summary

`mode_classification.py:36-38` で、クエリの分類に基づいてシステムヒントがプロンプトに挿入される。LLMが誤ったモードを返す場合、ツール呼び出しの意図的なバイパスが可能になる。

### Problem

`mode_classification.py:36-38` で定義：

```python
hint = _mode_hint(mode)
if hint:
    ctx.conv.history.append({"role": "system", "content": hint, "_ephemeral": True})
```

クエリの分類に基づいてシステムヒントがプロンプトに挿入される。LLMが誤ったモードを返す場合、ツール呼び出しの意図的なバイパスが可能になる。

### Affected Files

- `scripts/agent/mode_classification.py:36-38` — モード分類とシステムヒントの挿入

### Attack Scenario

1. 攻撃者がLLMに誤ったモードを返させる
2. 誤ったモードに基づくシステムヒントがプロンプトに挿入される
3. ツール呼び出しの意図的なバイパスが可能になる
4. セキュリティポリシーが回避される

### Severity

Low — モード分類はLLMの出力に基づくため、信頼できる。ただし、誤分類の可能性を考慮する必要がある。

### Mitigation

- モード分類の精度を向上させる
- 誤分類の場合のフォールバックメカニズムを導入する
- モード分類の結果を検証する
