# Fix duplicate keyword arguments in `scripts/agent/tool_audit.py`

## Priority
High

## Summary
Remove duplicate keyword arguments (`idempotency_key`, `task_linkage`) in the
`audit_tool_exec()` call inside `scripts/agent/tool_audit.py`, which causes a
SyntaxError under Python 3.14+ and blocks pytest test collection.

## Background
During execution of `implementations/20260916-140718_04_scripts_agent_tool_loop_guard.py`,
adversarial review findings identified two blockers:

1. pytest collection fails because `scripts/agent/tool_audit.py:202` has a
   SyntaxError — keyword argument repeated: `idempotency_key`.
2. mypy reports a source-file-found-twice error for `shared.tool_constants.py`
   vs `scripts/shared/tool_constants.py` (environment-dependent, not blocking
   the same way).

This issue addresses the first blocker, which is a real bug preventing any
test execution involving the agent module.

## Problem
`scripts/agent/tool_audit.py` passes `idempotency_key` and `task_linkage` twice
to the `audit_tool_exec()` function call at lines 199–202:

```python
        idempotency_key=idempotency_key,   # L199
        task_linkage=task_linkage,          # L200
        artifact_uri=artifact_uri,
        idempotency_key=idempotency_key,   # L202 — duplicate
        task_linkage=task_linkage,          # L203 — duplicate
```

Python 3.14 raises `SyntaxError: keyword argument repeated: idempotency_key`
when importing this file, which cascades to all modules that import anything
from `scripts.agent` (including `tests/agent/test_tool_loop_guard.py`).

## Reason for Change
Without fixing this, the entire agent test suite cannot run. Any PR touching
agent-related code will fail test collection. This is a correctness bug — the
duplicate arguments were likely introduced by a merge conflict resolution or
copy-paste error.

## Implementation Intent
Remove the duplicate keyword arguments at lines 202–203. Keep only one copy
of each: `idempotency_key` and `task_linkage`. Preserve `artifact_uri` at line
201. No behavioral change expected since the duplicates had no effect anyway.
