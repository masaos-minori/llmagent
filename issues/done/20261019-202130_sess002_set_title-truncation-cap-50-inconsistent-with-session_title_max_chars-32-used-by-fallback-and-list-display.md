# set_title truncation cap (50) inconsistent with SESSION_TITLE_MAX_CHARS (32) used by fallback and list display

## Priority
Low

## Summary
Align the session-title length caps so there is a single authoritative maximum. Currently `AgentSession.set_title` stores up to 50 characters while the fallback generator and the `/session list` view cap at `SESSION_TITLE_MAX_CHARS` (32), producing titles longer than the displayed convention.

## Background
Session titles are stored via `AgentSession.set_title`, which truncates to 50 characters. LLM title generation (`SessionTitleService`) returns a title and delegates truncation to `set_title`. When generation fails, `SessionTitleGen` falls back to a truncated version of the first input using `SESSION_TITLE_MAX_CHARS` (32) / `SESSION_TITLE_TRUNCATE_AT` (29). The `/session list` command also truncates any stored title longer than `SESSION_TITLE_MAX_CHARS` (32) for display.

## Problem
The stored hard cap (50) and the display/fallback cap (32) disagree. An LLM-generated title of 33-50 characters is stored as-is (up to 50 chars) but the `/session list` view truncates it at 29 characters plus `"..."`, and the fallback path would have capped it at 32. The stored value can therefore exceed the 32-character convention that the rest of the title subsystem assumes.

## Reason for Change
Two different maximums for the same field are a latent inconsistency: a title can be stored longer than the UI convention expects, and the list view silently truncates it again. The caps should resolve to one value so storage, fallback, and display agree.

## Implementation Intent
Introduce a single authoritative title-length constant and reference it from both `AgentSession.set_title` and the `SessionTitleGen`/display code, or otherwise reconcile the two caps. Decide the intended maximum (32 to match the established `SESSION_TITLE_MAX_CHARS` convention, or 50 if the longer store is intentional) and apply it consistently. Do not introduce a second magic number.

## Target Files or Areas
- `scripts/agent/session.py` (`AgentSession.set_title`)
- `scripts/agent/commands/session_title.py` (`SESSION_TITLE_MAX_CHARS`, `SESSION_TITLE_TRUNCATE_AT`, fallback, `_session_list` display)

## Required Changes
- Make the stored truncation in `set_title` use the same maximum as `SESSION_TITLE_MAX_CHARS` (or document explicitly why a different cap is required and apply it everywhere).
- Ensure no other literal title-length constant diverges from the single authoritative value.
