## db/maintenance.pyのpurge_old_sessionsに境界値テスト追加 (TASK-M5 / DB-5)

### Summary

`len(rows) == cfg.max_sessions`ちょうどの境界テストが無い。off-by-oneリグレッション検知不能。

### Problem

`db/maintenance.py:143-151` (`purge_old_sessions`):

```python
def purge_old_sessions(db, cfg):
    rows = db.fetchall("SELECT * FROM sessions ORDER BY last_accessed ASC")
    if len(rows) > cfg.max_sessions:  # 境界条件: len(rows) == cfg.max_sessions
        to_remove = rows[:len(rows) - cfg.max_sessions]
        ...
```

`len(rows) == cfg.max_sessions` の場合、削除件数0になるが、この境界値は未検証。

### Affected Files

- `scripts/db/maintenance.py:143-151` — purge_old_sessions
- `tests/test_db_maintenance.py` — 境界値テスト追加

### Severity

Medium — off-by-oneのリスクがあるが、現在は正常系のみでテストされている

### Root Cause

ちょうど境界のケースが無い

### Mitigation

境界値ケースを `test_db_maintenance.py` に追加:

- `max_sessions - 1` → 削除件数0
- `max_sessions` → 削除件数0（境界値）
- `max_sessions + 1` → 削除件数1

- 既存テストと合わせてpass
