## [orchestrator] Background task failure threshold does not stop the agent

### Summary

`_discard_and_log()` で背景タスクの失敗がカウントされるが、閾値（5回）に達してもエージェントの動作は停止しない。単にログのみが出力される。

### Problem

`orchestrator.py:580-614` で背景タスクの失敗が処理される：

```python
def _discard_and_log(self, task: asyncio.Task[Any]) -> None:
    exc = task.exception()
    if exc is not None:
        if isinstance(exc, asyncio.CancelledError):
            self._consecutive_bg_failures = 0
        else:
            self._consecutive_bg_failures += 1
            if self._consecutive_bg_failures == 1:
                logger.warning("First background task failure: %s", exc)
                if isinstance(exc, Exception) and self._on_error is not None:
                    try:
                        self._on_error(exc)
                    except Exception as notif_err:
                        logger.error(...)
            elif self._consecutive_bg_failures >= BG_FAILURE_THRESHOLD:
                logger.error(
                    "Consecutive background task failures (%d): %s",
                    self._consecutive_bg_failures,
                    exc,
                )
            else:
                logger.warning(...)
```

`BG_FAILURE_THRESHOLD` は 5 回に設定されている（`orchestrator.py:51`）。5回の連続した失敗が発生しても、エージェントは正常に動作し続ける。これは、背景タスクが重要な機能（例: 初回メッセージの自動生成）を提供している場合、ユーザーに気づかれずに機能が停止することを意味する。

また、`_on_error` コールバックが例外を発生させた場合、その例外は `logger.error()` でのみ記録され、ユーザーには通知されない。

### Affected Files

- `scripts/agent/orchestrator.py:580-614` — `_discard_and_log()`
- `scripts/agent/orchestrator.py:51` — `BG_FAILURE_THRESHOLD`
- `scripts/agent/orchestrator.py:573-578` — 初回背景タスクの作成

### Attack Scenario

1. 背景タスクが連続して5回失敗する
2. エージェントは正常に動作し続けるが、背景タスクの機能は提供されない
3. ユーザーは背景タスクの失敗に気づかない可能性がある

### Severity

Low-Medium — エージェントの主要な機能には影響しないが、背景タスクの重要な機能（例: 初回メッセージの自動生成）が提供されなくなる。

### Mitigation

- 背景タスクの失敗が閾値に達した場合、エージェントに警告を表示する
- 重要な背景タスクの失敗の場合は、エージェントの動作を一時停止するオプションを追加
- `_on_error` コールバックの例外をユーザーに通知する
