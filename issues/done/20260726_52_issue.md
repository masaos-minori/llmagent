## db層: PRAGMA設定のf-string組立とnosec注釈漏れ (DB-4)

### Summary

db/helper.pyのPRAGMA busy_timeout/wal_checkpointのf-string組立がnosec未注釈。値はホワイトリスト/int変換済みで実害なしだが、一貫性の欠如。

### Problem

```python
# db/helper.py:36
PRAGMA busy_timeout={self._busy_timeout_ms}  # nosec未注釈
# db/helper.py:276
wal_checkpoint(...)  # nosec未注釈
```

### Affected Files

- `scripts/db/helper.py:36` — busy_timeout f-string
- `scripts/db/helper.py:276` — wal_checkpoint f-string

### Severity

Low — 値はホワイトリスト/int変換済みで実害なし

### Root Cause

nosec注釈の一貫性欠如。他の同様の箇所には既に注釈が付与済み

### Mitigation

同様のパターンに対し既に`# nosec B608`が付与済みの箇所に合わせて注釈を追加

### Acceptance Criteria

- nosec注釈の一貫性が確保される
- bandit pass
