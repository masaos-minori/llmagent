## 「workflow optional mode」の廃止項目でStatusとEvidenceが矛盾している

### Summary

`00_governance_05_deprecated-items.md` の「workflow optional mode」廃止項目は、`Status: Needs confirmation` と記録されているにもかかわらず、同じエントリの `Evidence` 欄には「Confirmed by current implementation」(現行実装により確認済み)と書かれており、内容が矛盾している。

### Problem

- `docs/00_governance_05_deprecated-items.md:25-29`:
  ```
  - **workflow optional mode**
    - Current Replacement: none (replacement unknown)
    - Status: Needs confirmation
    - Notes: WorkflowEngine is now required, not optional
    - Evidence: Confirmed by current implementation
  ```
  `Status` は未確認を意味するが、`Evidence` は既に確認済みであることを示している。これは [ADR-Workflow-Mandatory](../docs/05_agent_03_03_turn-processing-flow-workflow-engine-part1.md#ワークフロー実行必須化-adr-workflow-mandatory) によって「ワークフロー実行は常に必須」と正式に決定・文書化されている内容とも一致しており、実質的に確認済みと判断できる。

### Affected Files

- `docs/00_governance_05_deprecated-items.md`(§Deprecated Concepts、25-29行目)

### Classification

**Low** — 実害はないが、`Needs confirmation` 項目としてカウントされ続けることで、他の真に未確認な項目の優先度判断を曖昧にする。

### Evidence

- Documentation only — 同一エントリ内の `Status` と `Evidence` フィールドの矛盾を直接確認済み。
- [ADR-Workflow-Mandatory](../docs/05_agent_03_03_turn-processing-flow-workflow-engine-part1.md#ワークフロー実行必須化-adr-workflow-mandatory) により「ワークフロー実行必須」が正式決定済みであることも裏付けとなる。

### Recommended next action

- `Status` を `Needs confirmation` から解決済みの状態(例: 該当なし、またはこのドキュメントのStatus値一覧に合わせた表現)に更新する。
- `00_governance_07_needs-confirmation-inventory.md` の「四半期ごとのレビュー」ルール(§Maintenance Rule)の対象として、`00_governance_05_deprecated-items.md` 内の `Needs confirmation` 項目も定期的に照合する運用を検討する。
