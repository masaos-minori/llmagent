# `tools/check_no_compat.py`'s `--help` text for `files` omits `tools/` from the stated default scan scope

## Priority
Low

## Summary
`tools/check_no_compat.py`'s argparse setup for the `files` positional argument has help text
reading `"Files to check (default: scripts/, docs/, tests/)"`. The actual no-args scan path
(`dirs_to_scan` in `main()`) scans four directories — `scripts/`, `docs/`, `tests/`, and
`tools/` — so the help text is missing `tools/` and understates what a no-args invocation
actually covers.

## Evidence
- Confirmed by reading `tools/check_no_compat.py`'s argparse `help=` string for `files` against
  the `dirs_to_scan` list in the no-args branch of `main()`, which includes
  `ROOT_DIR / "tools"` alongside `scripts`, `docs`, and `tests`.
- Discovered incidentally while implementing `plans/20260809-170033_plan.md` (the
  `IsADirectoryError` fix for positional directory arguments), and explicitly deferred as a
  separate concern to avoid scope creep in that fix, per that plan's Risks section and the
  originating requirement's instruction to fix only the positional-file-argument handling.

## Reason for Change
Inaccurate `--help` output is misleading to anyone manually invoking the tool, and could cause
someone to believe `tools/` (including `check_no_compat.py` itself) is not covered by a default
scan when it in fact is.

## Target Files or Areas
- `tools/check_no_compat.py` (the `help=` string on the `files` argparse argument)

## Required Changes
- Update the `help=` text for the `files` positional argument to list all four directories
  actually scanned by the no-args path (`scripts/`, `docs/`, `tests/`, `tools/`), or otherwise
  phrase it so it does not enumerate a subset that omits one.

## Acceptance Criteria
- `uv run python -m tools.check_no_compat --help` output for the `files` argument accurately
  reflects the directories scanned by the no-args `dirs_to_scan` path.

## Testing Expectations
- No behavior change; a visual/manual check of `--help` output is sufficient. If a test already
  asserts on the help text, update it; otherwise no new test is required.

## Out of Scope
- Any change to the actual scan behavior, `ROOT_DIR`, `COMPAT_PATTERNS`, `DEFAULT_ALLOWLIST`, or
  the positional-directory-argument handling — those are addressed separately in
  `plans/20260807-100914_plan.md` and `plans/20260809-170033_plan.md`.

## AI Implementation Instruction
Fix only the `help=` string. Do not change any scanning logic, arguments, or defaults.
