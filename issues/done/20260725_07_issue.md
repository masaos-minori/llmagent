## [tool_executor] Cache stampede protection can cause cascading failures

### Summary

`_execute_with_stampede_protection()` は同時実行のリクエストに対して共有 future を使用して stampede 防止を行うが、`_raw_execute()` が例外を発生させた場合、すべての待機中のリクエストに例外が伝播する。これにより、一時的な障害が複数のツール呼び出しに波及する可能性がある。

### Problem

`tool_executor.py:164-195` で stampede 保護が実装されている：

```python
async def _execute_with_stampede_protection(
    self, cache_key: str, tool_name: str, args: dict[str, Any]
) -> ToolCallResult:
    inflight = self._inflight.get(cache_key)
    if inflight is not None and not inflight.done():
        return await inflight
    ...
    try:
        result = await self._raw_execute(tool_name, args)
    except Exception as exc:
        if not inflight.done():
            inflight.set_exception(exc)
        raise
    else:
        if not inflight.done():
            inflight.set_result(result)
        return result
```

`_raw_execute()` が TransportError を発生させた場合、`inflight.set_exception(exc)` ですべての待機中のリクエストに例外が伝播する。これは意図された動作だが、一時的なネットワーク障害の場合、同じキャッシュキーのすべてのリクエストが同時に失敗する。

さらに、`_record_transport_error()` はサーバーのヘルスレジストリに障害を記録するため、同じサーバーの他のツール呼び出しにも影響を与える可能性がある。

### Affected Files

- `scripts/shared/tool_executor.py:164-195` — `_execute_with_stampede_protection()`
- `scripts/shared/tool_executor.py:91-134` — `_raw_execute()`

### Attack Scenario

1. 複数の同時リクエストが同じツール呼び出し（同じツール名＋引数）を送信
2. 最初の要求が `_raw_execute()` で TransportError を発生させる
3. すべての待機中のリクエストが同じ例外を受け取る
4. サーバーのヘルスレジストリに障害が記録され、同じサーバーの他のツール呼び出しにも影響

### Severity

Medium — 一時的なネットワーク障害が複数のツール呼び出しに波及する可能性がある。特に、同じサーバー上の複数のツールが同時に失敗する可能性がある。

### Mitigation

- stampede 保護されたリクエストの結果を個別に処理し、一部のリクエストが成功した場合でも他のリクエストが失敗しないようにする
- TransportError の場合、サーバーのヘルスレジストリへの記録を遅延させる
- 再試行ポリシーを追加し、一時的な障害に対する耐性を高める
