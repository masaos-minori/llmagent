## [NC-004] knn_searchの距離指標がコサインかL2か本モジュール単体からは判別不能

### Summary

`knn_search` メソッドの `MemoryHit.score` は `mv.distance` を符号反転した値を格納するが、コード上のコメントは "Negate distance" とあるのみで、距離指標がコサインかL2かは `memories_vec` テーブル定義に依存しており、本モジュール単体からは確認できない。

### Problem

- `docs/05_agent_12_04_memory-module-ref-retrieval-and-injection.md:66`:
  > `knn_search(embedding, memory_type, limit, branch="")` | `list[MemoryHit]` | KNN 検索。`MemoryHit.score` には `mv.distance` を符号反転した値（`-distance`）を格納する（コード上のコメントは "Negate distance" であり、距離指標がコサインか L2 かは `memories_vec` テーブル定義依存で本モジュールからは確認できない＝Needs confirmation）。

### Affected Files

- `docs/05_agent_12_04_memory-module-ref-retrieval-and-injection.md`(§knn_search method、66行目付近)
- 実装側: `memories_vec` テーブル定義(距離指標の仕様確認対象)

### Classification

**Medium** — 距離指標を誤認識すると検索結果のランキング解釈を誤る可能性があり、メモリ検索の品質評価に影響する。

### Evidence

- Documentation only — ドキュメント上に明示的な `Needs confirmation` ラベルとして記載。

### Recommended next action

- `memories_vec` テーブルのスキーマ定義(sqlite-vec拡張の設定)を確認し、距離指標(コサイン/L2/内積等)を特定する。
- 確認結果をドキュメントに反映する。
