## eventbus層: 回復/フォールバックテスト不足 (EVENTBUS-5)

### Summary

eventbus/dlq.pyの_atomic_writeで「JSON書き込み失敗時はDB行を更新しない」という一貫性保証が未テスト。OSError注入テストが必要。

### Problem

`eventbus/dlq.py:147-162` (_atomic_write):

```python
def _atomic_write(self, path, data):
    try:
        with open(path, 'w') as f:
            json.dump(data, f)
    except OSError:
        return False  # DB行は更新しない
    return True
```

OSError発生時にDB行が更新されないことを検証するテストがない。

### Affected Files

- `scripts/eventbus/dlq.py:147-162` — _atomic_write
- `tests/test_eventbus_dlq.py` — OSError注入テスト追加

### Severity

Medium — 一貫性保証が未検証のため、障害時のデータ不整合リスクがある

### Root Cause

OSError注入テストが見当たらない

### Mitigation

OSErrorを注入するテストケースを追加:

1. JSON書き込み失敗時にFalseが返ること
2. DB行が更新されないこと（一貫性保証）

### Acceptance Criteria

- OSError注入テストがpass
- 既存DLQテストに影響なし
