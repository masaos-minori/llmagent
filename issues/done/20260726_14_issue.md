## [tool_runner] Double execution of tool approval flow

### Summary

ワークフローモードが有効な場合、`tool_approval.py:200-202` で `_run_approval_checks()` がスキップされるが、`repository_gateway.py` のゲートは独立して動作するため、ワークフローモードでも二重承認が行われる可能性がある。

### Problem

`tool_runner.py:457` で `_run_approval_gate()` が呼ばれる：

```python
approved_calls, denied_ids = await _run_approval_gate(ctx, tool_calls)
```

`repository_gateway.py:106` でも同じく `run_approval_checks()` が呼ばれる：

```python
result = await run_approval_checks(self._ctx, name, args)
```

ワークフローモード中は `tool_approval.py:200-202` で `_run_approval_checks()` がスキップされるが、`repository_gateway.py` のゲートは独立して動作するため、ワークフローモードでも二重承認が行われる可能性がある。

### Affected Files

- `scripts/agent/tool_runner.py:457` — `_run_approval_gate()` 呼び出し
- `scripts/agent/repository_gateway.py:106` — `run_approval_checks()` 呼び出し
- `scripts/agent/tool_approval.py:200-202` — ワークフローモード中のスキップ条件

### Attack Scenario

1. ワークフローモードが有効な状態でツール呼び出しが行われる
2. `tool_approval.py` で `_run_approval_checks()` がスキップされる
3. しかし `repository_gateway.py` のゲートが独立して動作し、二重承認が行われる
4. 承認フローの混乱と、ワークフローの意図しないバイパスが発生する

### Severity

High — 承認フローの混乱と、ワークフローの意図しないバイパス。

### Mitigation

- ワークフローモード中は `repository_gateway._gate_write()` も承認チェックをスキップするフラグを設定する
