## agent層: 負のパステスト不足と過度なモック (AGENT-1, AGENT-2, AGENT-3, AGENT-4)

### Summary

agent層のテストはMagicMockで全面モックしており、実結合検証が不足している。また、security_profile不正値時のフォールバックやrecency_boostの境界値、force/overwriteフラグの誤適用が未検証。

### Problem

| ID | カテゴリ | 対象 | 説明 |
|---|---|---|---|
| AGENT-1 | Missing negative-path test | `agent/services/config_reload.py:447-453` | security_profile不正値時にValueErrorを握り潰し現状維持するフォールバック未検証 |
| AGENT-2 | Missing boundary-condition test | `agent/memory/scoring.py:22-34`(recency_boost) | age_days >= recency_daysの境界(ちょうど7日)未検証 |
| AGENT-3 | Excessive mocking | test_orchestrator.py, test_lifecycle.py | ctxをMagicMock()で全面モック(70-80件規模)。実DB/実サブプロセス結合の非検知リスク |
| AGENT-4 | Missing negative-path test | `agent/tool_policy.py:110-131`(_special_case_risk) | force/overwrite/clobberが全ツール共通でHIGH昇格。read系ツールへの誤適用は未確認 |

### Affected Files

- `agent/services/config_reload.py:447-453` — security_profileフォールバック
- `agent/memory/scoring.py:22-34` — recency_boost境界
- `test_orchestrator.py`, `test_lifecycle.py` — 過度なモック
- `agent/tool_policy.py:110-131` — tool_policyリスク評価

### Severity

Medium — 実結合検証皆無のため、リファクタリング前にガードテストが必要

### Mitigation

1. AGENT-1: security_profile不正値注入テストを追加
2. AGENT-2: recency_daysちょうど7日の境界テストを追加
3. AGENT-3: 実DB/実サブプロセス結合のintegration characterization testを追加
4. AGENT-4: read系ツールへの誤適用テストを追加

### Acceptance Criteria

- 各テストケースが存在しpass
- 過度なモックの削減が進む
