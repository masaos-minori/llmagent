## [orchestrator] Error threshold for first-turn background task is too low

### Summary

`orchestrator.py:51` で `BG_FAILURE_THRESHOLD: int = 5` が定義されている。5回の連続失敗でエラーロギングが開始されるが、ネットワークの一時的な問題などで5回の失敗が累積すると、誤って重大な障害として認識される。

### Problem

`orchestrator.py:51` で定義：

```python
BG_FAILURE_THRESHOLD: int = 5
```

`orchestrator.py:600-605` で使用：

```python
elif self._consecutive_bg_failures >= BG_FAILURE_THRESHOLD:
    logger.error(
        "Consecutive background task failures (%d): %s",
        self._consecutive_bg_failures,
        exc,
    )
```

最初の背景タスク（セッションタイトル生成）が5回連続で失敗すると、重大なエラーとしてログに記録される。

### Affected Files

- `scripts/agent/orchestrator.py:51` — `BG_FAILURE_THRESHOLD` の定義
- `scripts/agent/orchestrator.py:600-605` — エラー閾値のチェック

### Attack Scenario

1. ネットワークの一時的な問題などでセッションタイトル生成が失敗する
2. 5回の失敗が累積すると、重大なエラーとしてログに記録される
3. システムの正常な動作が誤って障害として認識される

### Severity

Medium — 背景タスクごとに異なる閾値が必要か、失敗カウントのリセット条件を明確にする必要がある。

### Mitigation

- 背景タスクごとに異なる閾値を設定するか、失敗カウントのリセット条件を明確にする
