Title: [DOCS] Consolidate duplicated design-doc sections
Labels: priority/medium, type/docs, area/docs

## Summary
Several design-doc sections repeat their full body two or three times.

## Rationale
- Duplicated bodies mean a one-sided edit silently creates drift: readers cannot tell which copy is authoritative, and reviewers cannot see divergence at a glance.
- Examples include agent sections covering tool execution and command registry, shared-layer sections, and the rag section.

## Intent
Give every topic a single canonical location so future edits happen once and cannot desync.

## Tasks
- [ ] Merge duplicate bodies into one canonical section per topic.
- [ ] Replace the removed repeats with a reference/link to the canonical section.

## Acceptance criteria
- No design-doc body is duplicated; each topic has exactly one canonical location.
