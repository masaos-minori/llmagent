## エージェント起動フェーズ: ツール引数の検証不足

### Summary

`tool_runner.py:131-136` で、ツールの引数はJSONパースのみで検証され、スキーマベースの検証はすべての実行パスで適用されていない可能性がある。

### Problem

`tool_runner.py:131-136` で定義：

```python
args_str = func.get("arguments", "{}")
try:
    args = orjson.loads(args_str)
except orjson.JSONDecodeError as e:
    raise ToolArgumentsDecodeError(...)
```

ツールの引数はJSONパースのみで検証され、スキーマベースの検証は `tool_arg_validator.py` で行われる。ただし、この検証は `repository_gateway.py` でのみ呼び出されており、通常のツール実行では呼び出されていない可能性がある。

### Affected Files

- `scripts/agent/tool_runner.py:131-136` — ツール引数のデコード
- `scripts/agent/tool_arg_validator.py` — スキーマベースの検証
- `scripts/agent/repository_gateway.py` — 検証の呼び出し場所

### Attack Scenario

1. 攻撃者がLLMに不正なツール呼び出しを生成させる
2. ツール呼び出しの引数がスキーマの制約に違反する
3. スキーマベースの検証が適用されない実行パスを通る
4. 不正な引数でツールが実行される

### Severity

Medium — スキーマ検証がすべての実行パスで適用されているか確認が必要。

### Mitigation

- すべてのツール実行パスでスキーマベースの検証を適用する
- ツール呼び出しの検証を強制するインターセプターを追加する
- スキーマ検証の結果をログに記録し、監査可能にする
