# Verify memory and search integration after Qwen3 embedding cleanup

## Priority

Medium

## Summary

Verify that memory retrieval and RAG search still work after removing configurable dimensions and E5 prefixes.

This issue is mainly an integration verification and cleanup task.

## Background

Memory and search components depend on embedding behavior:

- `MemoryInjectionService.on_user_prompt()` calls `EmbeddingClient.fetch(query)` and passes the result to `HybridRetriever.search()`.
- `MemoryServices` switches activation mode based on the embedding client state.
- `HybridRetriever` / `VectorRetriever` use `memories_vec` for vector retrieval.
- `search.py` calls `rag.llm_client.get_embedding()` for query embeddings and records embedding failures.

After removing `query_prefix`, `embed_dim`, dimension mismatch handling, `query:`, and `passage:`, these paths must be verified.

## Fix Intent

Ensure the Qwen3 raw-text embedding contract works consistently across:

- RAG ingestion
- RAG search
- memory injection
- memory retrieval

## Required Changes

- Find where `EmbeddingClientConfig` is constructed.
- Remove any `query_prefix` argument.
- Remove any `embed_dim` argument.
- Confirm `EmbeddingClient.fetch()` sends raw text.
- Confirm `MemoryInjectionService` still receives embeddings from `EmbeddingClient.fetch()`.
- Confirm `HybridRetriever.search()` still works with the returned embedding.
- Confirm `search.py` still records embedding failures without dimension mismatch handling.
- Keep search failure diagnostics minimal:
  - HTTP failure
  - invalid JSON
  - empty embedding

## Files to Inspect or Update

- Memory ingestion implementation
- Memory service construction or factory code
- `agent/memory/embedding_client.py`
- `agent/memory/injection.py`
- `agent/memory/retriever.py`
- `agent/memory/services.py`
- `agent/memory/types.py`
- `scripts/rag/stages/search.py`

## Acceptance Criteria

- No memory code passes `query_prefix`.
- No memory code passes `embed_dim`.
- `EmbeddingErrorKind.DIMENSION_MISMATCH` is removed if unused.
- Memory retrieval still supports hybrid mode when embeddings are available.
- Memory retrieval still supports fallback modes when embeddings are unavailable.
- RAG search continues to degrade gracefully on embedding failure.
- No dimension mismatch diagnostic branch remains.
