- GV-016: "No unimplemented auto-checks documented as implemented" — Manual review、Status: Missing

これらは全て Manual review かつ Missing だが、Follow-up Work Needed に具体的な実装タスクが記載されている。

## Problem
Missing ステータスのルールに Follow-up で具体的な実装タスクが記載されているが、それが "Register Known Issue" として正式に登録されていない。実装担当者がどのタスクを実装すべきか判断できない。

## Reason for Change
Missing ステータスのルールについて、Follow-up Work Needed に記載されているタスクを正式な Known Issue として登録するか、または実装済みのものを Status を更新するか、のいずれかの処理が必要。

## Implementation Intent
各ルールについて以下のいずれかの対応を行う：
1. Follow-up Work Needed に記載されているタスクを正式な Known Issue として登録
2. 既に実装済みのものがある場合、Matrix の Status を更新
3. Follow-up Work Needed のエントリを削除（不要な場合）
