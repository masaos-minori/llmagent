## エージェント起動フェーズ: Ephemeralメッセージのフィルタリング不備

### Summary

`orchestrator.py:542-553` で、`_ephemeral` および `_memory_injected` キーを持つメッセージをフィルタリングしているが、これらのキーが存在しないメッセージはフィルタリングされない。

### Problem

`orchestrator.py:542-553` で定義：

```python
def _clear_previous_turn_ephemeral_messages(self) -> None:
    ctx.conv.history = [
        m
        for m in ctx.conv.history
        if not m.get("_ephemeral") and not m.get("_memory_injected")
    ]
```

`_ephemeral` および `_memory_injected` キーを持つメッセージをフィルタリングしているが、これらのキーが存在しないメッセージはフィルタリングされない。攻撃者がこれらのキーを追加してメッセージを消去できる可能性はあるが、逆（フィルタリングを回避）も可能。

### Affected Files

- `scripts/agent/orchestrator.py:542-553` — ephemeralメッセージのフィルタリング

### Attack Scenario

1. 攻撃者がメッセージに `_ephemeral` または `_memory_injected` キーを追加する
2. フィルタリングロジックがキー名の変更で回避される
3. 本来フィルタリングされるべきメッセージが保持される
4. メッセージ履歴の整合性が損なわれる

### Severity

Low — フィルタリングロジック自体は正しいが、キー名の変更で回避可能。

### Mitigation

- メッセージのフィルタリングキー名を変更できないようにする
- フィルタリングロジックをより堅牢にする
- メッセージの整合性を検証する
