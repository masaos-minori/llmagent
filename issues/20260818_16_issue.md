### ISSUE-M1: 旧ルーティング権威データ (ToolRegistry / tool_constants フォールバック / config tool_names) の整理 `[確認済]

優先度: Medium
対象ファイル: `scripts/shared/tool_registry.py`, `scripts/shared/tool_constants.py`, `scripts/shared/tool_routing_validation.py`, `config/agent.toml` (`tool_names` 記述), `scripts/agent/tool_policy.py` (参照範囲確認)
集約理由: いずれも「ルーティング権威が `RuntimeToolRegistry` に一本化された結果、旧来の権威データが検証・フォールバック用途へ格下げされた」という同一テーマである。同じモジュール群を横断して整合を取る必要があり、別々に着手すると同一ファイルへ二重に手を入れることになるため 1 issue に集約する。

#### 修正理由
ライブ `/v1/tools` discovery と `RuntimeToolRegistry` がルーティングの唯一の権威となった後、次の三つが旧権威の名残として残っている。

- `ToolRegistry` (`tool_registry.py`): docstring で「serves only as drift-detection input」と格下げが明記されている。
- `tool_constants.py` の frozenset 群: docstring で「these frozensets become fallback/compatibility data ... never the first-checked source」とされている。ただし `tool_executor_helpers._SIDE_EFFECT_TOOLS` が frozenset を実データとして使用しているため、完全撤去はできない。
- config `tool_names`: `tool_registry.py` / `route_resolver.py` / `tool_routing_validation.py` の三箇所で一貫して「NOT a routing input; drift validation metadata only」と記述されている。

#### 修正意図
ドリフト検証という現行機能を保ちつつ、「これは互換のための検証専用データであってルーティング入力ではない」という位置づけをコードと設定の両面で明確化する。あわせて、検証機能そのものを今後も維持するのか廃止するのかを一度で意思決定し、中途半端な二重権威状態を解消することが狙いである。

#### 作業内容
1. ドリフト検証 (`validate_routing_against_config` / `validate_routing_against_live` / `validate_all_routing` / `check_tool_safety_tiers` / `check_unknown_tool_safety_tiers`) を今後も維持するか廃止するかを決定する。
2. 維持する場合: `ToolRegistry` と config `tool_names` を「検証専用」と明示する記述整理に留める。
3. 廃止する場合: `tool_routing_validation.py` の各関数、`ToolRegistry`、config `tool_names` をまとめて撤去する。
4. `tool_constants.py` の frozenset は side-effect 判定 (ISSUE-H2 の結論) と risk 分類の実利用範囲を `tool_policy.py` で確認し、フォールバック依存として残す範囲を確定する。

#### 依存関係
- ISSUE-H2 の結論 (side-effect 判定を registry / frozenset のどちらへ寄せるか) に影響を受ける。H2 を先行させること。
- `tool_policy.py` (未提供) の risk 分類における frozenset 参照範囲の確認が必要。

#### 受け入れ条件
- ドリフト検証の存続方針が決定され、コードへ反映されている。
- `ToolRegistry` / config `tool_names` の位置づけが検証専用として一貫している。
- `tool_constants.py` の frozenset が「first-checked source ではない」ことがコード上保証されている。
- 既存テストが通る。
