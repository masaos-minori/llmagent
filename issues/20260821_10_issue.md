## Summary
Documentation mixes embedding dimensions (canonical 384 for multilingual-E5-small vs. a
`blob_bytes != 1536` troubleshooting note) and chat model names (`Qwen3.6-Instruct` in the overview
vs. `gemma-4-e4b-it` / `Qwopus3.6-35B-A3B-v1` in the deployment model table).

## Rationale (Why this matters — detailed)
- Inconsistent numbers and names create config-drift and misconfiguration risk. In particular, an
  embedding-dimension mismatch directly causes vector-insertion errors, so the stray `1536` reference
  is not merely cosmetic — following it would break ingestion. Divergent chat-model names also
  confuse deployment.

## Fix Intent (How — detailed)
- Align all references to the canonical sources: `config/agent.toml::embedding_dims` for the
  dimension and the deployment §1.4 model table for model names. Fix the troubleshooting `1536` to
  `384`, and make chat model-name references consistent with the canonical deployment table.

- [ ] Chat model names are consistent with the canonical deployment table.
