**Title:** [Low][agent] Fix slash-completion drift, /skill ephemeral clearing, and remove dead RETENTION_DAYS

**Labels:** bug, cleanup, low-priority, agent, cli, memory
**Covers:** L-4, L-5, L-7
**Area / Component:** `agent/repl.py`, `agent/commands/command_defs_list.py`, agent skill mixin +
`append_message` logic, `scripts/agent/memory/`

## Summary
Three small, independent agent-side defects grouped into one low-risk cleanup PR.

## Rationale (Why this matters — detailed)
- **Completion drift (L-4):** Tab-completion `SLASH_COMMANDS` omits `/memory`, `/audit`, `/plan`,
  `/skill`, `/mdq`, which are dispatchable but not completable. Two separately maintained lists have
  drifted — a minor UX defect and an ongoing drift hazard.
- **Skill ephemeral not cleared (L-5):** `_ephemeral` is stripped by `append_message` validation
  (not in TRUSTED_SOURCES), leaving only `_skill_ephemeral`, so the orchestrator's generic ephemeral
  clearing no longer removes injected skill messages at the next turn. Injected skills can linger
  longer than intended — counter-intuitive behavior.
- **Dead retention (L-7):** `RETENTION_DAYS` is defined but referenced only by
  `JsonlMemoryStore.read_active()`, which has no callers repo-wide (NC-007). The unreachable
  retention filter misleads readers into thinking retention is enforced.
- All three are small agent-layer fixes/cleanups that can be verified independently but reviewed
  together with minimal risk.

## Fix Intent (How — detailed)
- **L-4:** Generate both lists from a single source, or synchronize the completion list with
  `_COMMANDS`; guard with a test that asserts parity.
- **L-5:** Reconcile ephemeral handling on the skill path so the injected message is cleared at the
  intended turn boundary — either authorize the `_ephemeral` flag for the skill source or align the
  clearing logic with `_skill_ephemeral`.
- **L-7:** Implement the retention policy where intended, or remove the unused definition/method.

## Sub-tasks
- [ ] (L-4) Sync tab-completion list with dispatchable commands (+ parity test).
- [ ] (L-5) Fix /skill ephemeral clearing at the next-turn boundary (+ test).
- [ ] (L-7) Enforce or remove `RETENTION_DAYS` / `read_active()`.
