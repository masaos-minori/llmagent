# Unresolved blocking unknown: external-behavior canonical source differs between the Policy's two canonical-source matrices

## Summary
In `docs/00_governance/governance_01_documentation-policy.md`, the external-behavior claim type has different values in the two matrices. This is UNK-01 of the source Plan.
- In `### Resolution Matrix`, the canonical source kind is "Specification + Integration Test" and the auxiliary evidence is "Runtime Log, Test".
- In `### Decision Target Canonical Source Matrix`, the "Requirements, External Behavior" row has canonical `docs/{area}_*_specification.md` and auxiliary evidence "Acceptance Test".

Both matrices are normative within the same Policy, so one Decision Target has two different canonical-source definitions. That is the condition the Policy's own Routing Rules call a "multiple normative sources" conflict. The `docsize001` Plan deliberately left both rows unchanged.

## Evidence Missing
- `grep` of the Policy confirmed both rows: the `external-behavior` row of `### Resolution Matrix` and the "Requirements, External Behavior" row of `### Decision Target Canonical Source Matrix`.
- The `### external-behavior` subsection definition ("Specification documents and integration tests") agrees with the Resolution Matrix, not with the Decision Target matrix.
- No ADR, Specification, or registry entry (`config/documentation_canonical_sources.toml`) settles which definition is intended. The Decision Target matrix row also merges functional requirements and external behavior into one target, so it may be intentionally coarser rather than conflicting.

## Resolution Path
1. Ask the governance owner whether integration tests are part of the canonical source for external behavior, or only auxiliary evidence.
2. If the two matrices are meant to agree, correct the non-intended row. If the Decision Target matrix is intentionally coarser, state that explicitly in the Policy so the two are not read as competing definitions.
3. If the answer remains undecided, register a Canonical Source Conflict in `docs/00_governance/governance_03_issue-and-uncertainty-management.md` Part 3, per the Policy's Routing Rules ("multiple normative sources").
