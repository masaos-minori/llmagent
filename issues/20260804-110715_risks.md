# Stale `EmbeddingClientConfig` field list in `docs/05_agent_12_05_memory-module-ref-extraction-and-facade.md`

## Priority
Low

## Context
While planning the fix for the stale `embed_dim=0` keyword argument in
`tests/agent/commands/test_memory_status.py` (see
`plans/20260804-110548_plan.md`, source requirement
`requires/done/20260804-100820_require.md`), a repo-wide grep for `embed_dim` confirmed a
pre-existing, unrelated documentation/code mismatch that is explicitly out of scope for that fix
and for the `require-to-plan` workflow (document-only planning phases in this repo cannot edit
`docs/*.md`).

## Description
`docs/05_agent_12_05_memory-module-ref-extraction-and-facade.md` line 67 reads:

```
`EmbeddingClientConfig`: embed_url, timeout=5.0, max_retries=2, circuit_open_after=3, circuit_reset_sec=60.0, query_prefix="query: ", embed_dim=384, local_only=False。
```

This lists `query_prefix="query: "` and `embed_dim=384` as fields of `EmbeddingClientConfig`.
Neither field exists on the current dataclass. The verified current definition
(`scripts/agent/memory/embedding_client.py` lines 30-39) has exactly six fields:

```python
@dataclass
class EmbeddingClientConfig:
    embed_url: str = ""
    timeout: float = 5.0
    max_retries: int = 2
    circuit_open_after: int = 3
    circuit_reset_sec: float = 60.0
    local_only: bool = False
```

The doc line should be corrected to list only these six fields and drop `query_prefix` and
`embed_dim` entirely.

## Evidence Missing
- No open issue or in-flight plan/requirement was found elsewhere in the repo tracking this
  specific doc/code mismatch (repo-wide grep for `embed_dim` shows no other reference to this doc
  line outside the two documents that surfaced it).
- Whether this doc line was ever accurate for an earlier version of `EmbeddingClientConfig`, or
  was always aspirational/incorrect, is unknown — git blame on the doc file was not run as part of
  this planning cycle (out of scope for a document-only phase focused on the test fix).

## Resolution Path
File a requirement (via `issue-to-require`) to correct
`docs/05_agent_12_05_memory-module-ref-extraction-and-facade.md:67` so it lists exactly the six
current `EmbeddingClientConfig` fields (`embed_url`, `timeout`, `max_retries`,
`circuit_open_after`, `circuit_reset_sec`, `local_only`) and removes `query_prefix` and
`embed_dim`. This is a pure documentation correction with no source-code or test impact.
