## エージェント起動フェーズ: シークレットのログ出力

### Summary

`startup.py:156-166` と `http_lifecycle.py:274-279` で、MCPサーバーのエラーログが最大500文字までログに記録される。サーバーが認証トークンやシークレットを含むエラーメッセージを出力した場合、それがログに残る。

### Problem

`http_lifecycle.py:274-279` で定義：

```python
logger.error(
    "Lifecycle: %r exited early; stderr (%s chars): %s",
    server_key,
    len(stderr_full),
    stderr_full[:500],
)
```

stderrログが最大500文字までログに記録される。攻撃者がMCPサーバーを改竄し、シークレットを含むエラーメッセージを出力させることで、ログにシークレットが残る可能性がある。

### Affected Files

- `scripts/agent/startup.py:156-166` — エラーログの出力
- `scripts/agent/http_lifecycle.py:274-279` — stderrログのキャプチャと出力

### Attack Scenario

1. 攻撃者がMCPサーバーを改竄し、シークレットを含むエラーメッセージを出力させる
2. MCPサーバーが異常終了した際、stderrログがキャプチャされる
3. キャプチャされたstderrログがログファイルに記録される
4. ログファイルにアクセス可能な攻撃者がシークレットを取得する

### Severity

Medium — シークレット漏洩の潜在的な原因。ログファイルへのアクセス権限を制限する必要がある。

### Mitigation

- エラーログにシークレットが含まれる可能性を考慮し、ログファイルへのアクセス権限を制限する
- シークレット検出ロジックをログ出力前に追加する
- ログファイルの暗号化を検討する
