## WorkflowTimeoutErrorがOrchestratorでキャッチされずREPLループへ無制御に伝播しうる

### Summary

`WorkflowEngine` はステージタイムアウト発生時に `WorkflowTimeoutError` を送出するが、`Orchestrator._handle_workflow_engine()` はこの例外クラスを個別に捕捉していない。`WorkflowHaltError` とは異なるクラスのため、`except WorkflowHaltError` にもマッチせず、`handle_turn()` の呼び出し元まで無制御に伝播する可能性がある。

### Problem

- `scripts/agent/workflow/workflow_engine.py:148-150`:
  ```python
  except (WorkflowHaltError, WorkflowTimeoutError):
      self._store.update_task_status(task.task_id, "halted")
      raise
  ```
  `WorkflowEngine.run()` は両方の例外を同列に扱い、ステータスを `halted` にしてから再送出する。
- `scripts/agent/orchestrator.py:291-294` (`_handle_workflow_engine()`) は次の2つの `except` 節のみを持つ:
  ```python
  except WorkflowPendingApprovalError as exc:
      self._handle_workflow_approval_pending(exc, session_id)
  except WorkflowHaltError as exc:
      self._handle_workflow_halt(exc)
  ```
  `WorkflowTimeoutError` は `WorkflowHaltError` のサブクラスではない独立した例外クラス(`scripts/agent/workflow/workflow_engine.py:81-82`)であり、どちらの `except` にもマッチしない。
- ステージ(`plan`/`execute`/`verify`)が `timeout_sec` を超過すると `WorkflowTimeoutError` が送出され、`Orchestrator` の `except` 節をすり抜けて `handle_turn()` の呼び出し元(`scripts/agent/repl.py` の `_dispatch_line`/`_repl_loop`)まで伝播する。呼び出し元にはこの例外専用のハンドラが見当たらない。

### Affected Files

- `scripts/agent/orchestrator.py` — `_handle_workflow_engine()`(291-307行目付近)
- `scripts/agent/workflow/workflow_engine.py` — `WorkflowTimeoutError` の定義・送出箇所(81-82行目、148-150行目、274-284行目)
- `scripts/agent/repl.py` — `_dispatch_line()`/`_repl_loop()`(未捕捉時の伝播先)

### Classification

**Medium / Needs confirmation** — ステージタイムアウト発生時にREPLループ自体が予期しない例外で終了する可能性があるが、実際に未捕捉例外が `_repl_loop` まで到達してプロセスをクラッシュさせるか、それとも他の層(`asyncio.wait_for` 等)で吸収されるかは未確認。

### Evidence

- Strongly implied by code (Medium confidence) — 制御フロー上の欠落は静的に確認済みだが、実地での再現確認が必要。

### Recommended next action

- `execute`/`verify` ステージの `timeout_sec` を意図的に短く設定した統合テストで `WorkflowTimeoutError` を発生させ、実際にREPLループがクラッシュするか、どこかで捕捉されて継続するかを確認する。
- 未捕捉であることが確認された場合、`Orchestrator._handle_workflow_engine()` に `except WorkflowTimeoutError` 節を追加し、`WorkflowHaltError` と同様にユーザー通知・ターン終了処理を行うようにする。
