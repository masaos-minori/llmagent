## エージェント起動フェーズ: 環境変数注入

### Summary

`http_lifecycle.py:224-226` で、設定ファイルから読み込まれた環境変数がシステムの環境変数を上書きできる。

### Problem

`http_lifecycle.py:224-226` で定義：

```python
env = None
if cfg.env:
    env = {**os.environ, **cfg.env}
```

`cfg.env` が設定ファイルから読み込まれた環境変数を上書きする。`**os.environ` を先に展開しているため、`cfg.env` の値がシステムの環境変数を上書きできる。

### Affected Files

- `scripts/agent/http_lifecycle.py:224-226` — 環境変数のマージ処理
- `scripts/agent/http_lifecycle.py:230-236` — サブプロセス起動時の環境変数適用

### Attack Scenario

1. 攻撃者が設定ファイルを改竄し、`cfg.env` に `PATH` や `PYTHONPATH` を含むようにする
2. MCP サーバーのサブプロセスが起動される際、上書きされた環境変数が適用される
3. 悪意のあるライブラリやコマンドが優先的にロードされる
4. MCP サーバーの動作が乗っ取られる

### Severity

Medium — 攻撃者が設定ファイルを改竄できる場合、環境変数の上書きによりMCPサーバーの動作に影響を与える可能性。

### Mitigation

- 環境変数の上書きを制限するホワイトリストを導入する
- 重要な環境変数（`PATH`, `PYTHONPATH` など）の上書きを禁止する
- 設定ファイルの整合性を検証する
