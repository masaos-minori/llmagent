## エージェント起動フェーズ: サブプロセス注入

### Summary

`http_lifecycle.py:230-236` で、設定ファイルから読み込まれた `cfg.cmd` がそのままサブプロセスの起動コマンドとして使用される。攻撃者が設定ファイルを改竄すると、任意のサブプロセスが実行される可能性がある。

### Problem

`http_lifecycle.py:230-236` で定義：

```python
proc = subprocess.Popen(
    cfg.cmd,
    stdout=subprocess.DEVNULL,
    stderr=stderr_fh,
    env=env,
    start_new_session=True,
)
```

`nosec B603` のコメントがあり、「cmd comes from admin-controlled config」とあるが、設定ファイルの改竄が可能であれば任意のサブプロセスが実行される。

### Affected Files

- `scripts/agent/http_lifecycle.py:230-236` — サブプロセスの起動
- `scripts/agent/http_lifecycle.py:224-226` — 環境変数のマージ

### Attack Scenario

1. 攻撃者が設定ファイルを改竄し、`cfg.cmd` に悪意のあるコマンドを挿入する
2. MCPサーバーのサブプロセスが起動される際、改竄されたコマンドが実行される
3. 任意のコマンドが実行され、システムが侵害される

### Severity

Low-Medium — 設定ファイルは管理者のみが編集可能だが、攻撃者が設定ファイルを改竄できる場合、任意のサブプロセスが実行される。

### Mitigation

- 設定ファイルの整合性を検証する
- 許可されたコマンドのホワイトリストを導入する
- サブプロセスの起動前にコマンドを検証する
