### ISSUE-L1: テスト互換の再エクスポートシム撤去 (TransportError) `[確認済]

優先度: Low
対象ファイル: `scripts/shared/tool_executor.py`, `tests/shared/test_tool_executor.py

#### 修正理由
`tool_executor.py` は `TransportError` を本来の定義元 `shared/http_transport` から import しつつ、テスト後方互換のためだけに再エクスポートしている。該当行にコメントが明記されている。
`# noqa: F401 -- re-exported: tests/shared/test_tool_executor.py imports TransportError from this module`

#### 修正意図
テストが実装モジュール経由でシンボルを取得している依存を断ち、`TransportError` の import 元を本来の定義元へ揃える。「未使用に見えるが消すとテストが壊れる」という将来の混乱要因を除去することが狙いである。

#### 作業内容
1. `tests/shared/test_tool_executor.py` の `TransportError` の import 元を `shared/http_transport` へ変更する。
2. `tool_executor.py` の `TransportError` 再エクスポート (および対応する `# noqa: F401`) を撤去する。

#### 受け入れ条件
- テストが `shared/http_transport` から `TransportError` を import している。
- `tool_executor.py` に互換目的の再エクスポートが残っていない。
- 既存テストが通る。
