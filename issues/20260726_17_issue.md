## [tool_runner] Per-turn character limit for tool results is partially applied

### Summary

`tool_runner.py:231-245` で `_apply_turn_char_limit()` がターンごとの文字数制限を適用するが、制限超過時には TURN_LIMIT_HINT に置き換えられる。LLM は実際の結果内容を見ずに次のアクションを決定しなければならない。

### Problem

`tool_runner.py:231-245` で定義：

```python
def _apply_turn_char_limit(
    llm_text: str,
    turn_chars: int,
    limit: int,
) -> str:
    """Apply per-turn char limit; return hint if exceeded."""
    if limit > 0 and (turn_chars + len(llm_text)) > limit:
        logger.info(
            "Per-turn tool result limit reached: %s chars > %s; result replaced with hint",
            turn_chars + len(llm_text),
            limit,
        )
        hint: str = TURN_LIMIT_HINT
        return hint
    return llm_text
```

制限超過時にヒントテキストに置き換わるが、LLM は実際の結果内容を見ずに次のアクションを決定しなければならない。

### Affected Files

- `scripts/agent/tool_runner.py:231-245` — `_apply_turn_char_limit()` の定義
- `scripts/agent/tool_result_formatter.py` — `TURN_LIMIT_HINT` の定義

### Attack Scenario

1. ツール結果がターンごとの文字数制限を超える
2. ヒントテキストに置き換わってしまうため、LLM は実際の結果内容を見れない
3. LLM がツール結果の内容を把握できず、誤った判断を下す可能性がある

### Severity

Medium — ヒントテキストに実際の行数と文字数を明示し、LLM が推論可能な情報を提供する必要がある。

### Mitigation

- ヒントテキストに実際の行数と文字数を明示し、LLM が推論可能な情報を提供する
