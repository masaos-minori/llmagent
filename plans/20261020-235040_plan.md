## Goal
Remove the twelve component classes and the `AgentREPL` facade that `scripts/agent/__init__.py` re-exports "for backward compatibility", so the package no longer exposes an alternate public import path for its submodules — but only after the owner confirms nothing outside the repository imports those twelve names from `agent`. Add a regression test that locks the removal so the re-exports and their import side effect cannot return unnoticed.

## Problem
The package exposes two import paths for each component: the canonical submodule and the re-exported name on `agent`. The re-export path has no in-repository user, adds import side effects at package load, and is a public API surface whose external consumers cannot be seen from the repository. Keeping it past its useful life is dead surface area; removing it without confirming there is no external user risks breaking an operator script, plugin, or tool that imports `agent.AgentREPL` etc.

## Reason for Change
Dead public surface: twelve re-exports with zero in-repository users that still run import side effects on every `import agent`. Removing them narrows the package's public API to the canonical module paths. The risk is external consumers, which is exactly why the removal is gated on owner confirmation rather than on the in-repository reachability check alone.

## Implementation Intent
- Treat this as a guarded deletion. The in-repository evidence shows zero callers, and the owner's confirmation of no external users and no notice policy is recorded (see Background), which authorizes the removal.
- Change only `scripts/agent/__init__.py`, the locking test, and the one Glossary row that quotes the removed docstring. Do not add forwarding, aliases, or deprecation scaffolding.
- If any test, tool, or module fails because it relied on a removed name or the import side effect, fix that caller to import from the canonical module; do not restore the re-export.
- Preserve the runtime contract: the REPL, startup, and shutdown paths must work unchanged, including `python -m agent`.
