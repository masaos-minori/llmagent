## Goal

Prevent LLM manipulation of ephemeral message filtering by wiring up existing message_schema validation to all conversation history insertion points.

## Scope

**In-Scope**:
- Wire up `message_schema.validate_message()` in orchestrator.py message insertion paths
- Add `source` field to ephemeral messages created by command handlers
- Restrict ephemeral key injection to trusted sources via message_schema
- Validate messages before appending to conv.history

**Out-of-Scope**:
- Adding new ephemeral key types beyond _ephemeral, _memory_injected, _skill_ephemeral
- Modifying the message_schema.py validation logic itself
- Changes to tool result message handling (already validated at creation time)

## Assumptions

1. `message_schema.py` is a newly added module not yet integrated into the codebase
2. The existing ROLE_KEY_WHITELIST covers all valid message roles
3. The TRUSTED_SOURCES mapping correctly identifies all ephemeral key injection sources
4. Existing callers of conv.history.append() do not depend on bypassing schema validation

## Implementation Steps

1. **Phase 1: Wire message_schema into orchestrator.py**
   - Import `validate_message` from `message_schema` in orchestrator.py
   - In `_clear_previous_turn_ephemeral_messages()`: validate each remaining message passes schema
   - In `_sync_system_prompt()`: validate before inserting/updating system message
   - In `_append_user_message()`: validate before appending user message
   - In `_handle_memory_injection()`: validate before appending memory block

2. **Phase 2: Add source field to ephemeral messages**
   - In `cmd_skill.py`: add `"source": "skill_mixin"` to ephemeral message dict
   - In `mode_classification.py`: add `"source": "cmd_handler"` to ephemeral message dict
   - In `orchestrator.py`: add `"source": "memory_injection"` to memory-injected message dict

3. **Phase 3: Add rejection logging**
   - When `validate_message()` returns failure, log warning with rejection reason
   - Skip adding invalid messages to history rather than crashing
