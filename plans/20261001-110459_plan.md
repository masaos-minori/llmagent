## Background

- governance_02 Usage Rules item 3: "Bilingual text: Use English preferred form with Japanese alternative in parentheses on first occurrence." It was introduced in `fa824caa2` (2026-08-18), alongside item 6's example `"Needs Confirmation (要確認)"`. Commit `c15d152c8` (2026-08-20, the same day as the DESIGN.md rule) changed item 6's example to the English `"Needs Confirmation (Requires Confirmation)"` but left item 3 unchanged. - Area guides must reference ADRs by their canonical English titles after `langadr001`.
