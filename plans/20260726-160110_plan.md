## Goal

Add user notification and configurable pause behavior when background task failures reach the threshold, ensuring users are aware of degraded functionality and can take corrective action.

## Scope

**In-Scope:**
- Add user warning at `BG_FAILURE_THRESHOLD` consecutive failures
- Add configurable option to pause agent operation on critical background task failures
- Ensure error notifications always reach the user even if `_on_error` callback fails
- Log specific background task name alongside failure count

**Out-of-Scope:**
- Adding new configuration options beyond what's needed for pause behavior
- Modifying the `_on_error` callback contract
- Changing how background tasks are created or managed

## Assumptions

1. The `_on_error` callback is responsible for notifying the user, so we need to ensure its output reaches the user regardless of whether it raises
2. A configurable pause option should be per-task-type, not global
3. The task type can be identified by the callback function name (`_generate_session_title`)
