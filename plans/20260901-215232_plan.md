## Background
ADR-004 states that production deployment must use FAIL_FAST exclusively and local/dev mode is not supported. However, ADR-004 also notes that some Specification documents may still reference local/dev mode behavior that contradicts this policy. Three specific Specification documents were identified as potentially containing stale local/dev mode references.

## Problem
After ADR-004 Production-only revision, three Specification documents may still contain local/dev mode references that contradict the production-only policy. These include:
- Documents that describe environment-specific behavior differences (local vs production)
- Documents that mention local/dev mode as an alternative execution path
- Documents that reference conditional logic based on security_profile values

## Reason for change
Stale local/dev mode references in Specification documents can mislead implementers into thinking these modes are officially supported, which contradicts ADR-004's production-only policy.

## Implementation intent
Re-read each of the three Specification documents, identify any local/dev mode references that contradict production-only policy, and update them to reflect the current production-only stance.

- `REQ-002`: Update affected documents to remove or correct stale local/dev mode references
- `REQ-003`: Ensure updated documents accurately reflect production-only policy per ADR-004
