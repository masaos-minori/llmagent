# Plan: StartupOrchestrator includes remediation steps in FATAL error message

## Goal
- Ensure `StartupOrchestrator._check_services()` includes remediation steps in the FATAL error message, enabling users to resolve errors without consulting separate documentation.

## Priority
Low

## Scope
- **In-Scope**: Modify `_check_services()` to include remediation steps in the error message; update logging to match display format
- **Out-of-Scope**: Changes to the validation pipeline itself; changes to the remediation content generation

## Background
`StartupOrchestrator._check_services()` in `scripts/agent/startup.py` raises a `RuntimeError` when the validation pipeline has FATAL outcomes.

## Problem
The error message only includes the fatal outcome messages but not their associated remediation steps. Users see the error but don't know how to fix it. CI/CD pipelines cannot parse remediation steps from error output. Support burden increases because users must consult documentation separately.

## Reason for change
Including remediation steps in error messages improves user experience and reduces support burden. Users should be able to resolve errors directly from the exception message.

## Implementation intent
Include remediation steps in the error message. Format the message consistently with the display format used in `startup_reporter.py`. Update logging to include both source and remediation information.

- `REQ-002`: Test verifies error message contains remediation text
- `REQ-003`: Test verifies formatting matches existing display format
- `REQ-004`: No regression in error parsing by external tooling

## Design
### Current Behavior (Verified Against Source)
1. `startup.py` line 115-121: Raise RuntimeError with fatal messages joined by "; "
2. Line 116: `pipeline.fatal_messages()` returns only messages, no remediation
3. `startup_reporter.py` line 26-29: Display includes remediation on separate line
4. Inconsistency: error message lacks remediation while display includes it

### Proposed Change
```python
if pipeline.has_fatal:
    fatal_parts = []
    for o in pipeline.outcomes:
        if o.status == StartupCheckStatus.FATAL:
            part = o.message
            if o.remediation:
                part += f"\n  Remediation: {o.remediation}"
            fatal_parts.append(part)
    fatal_str = "\n".join(fatal_parts)
    logger.error(
        "FATAL pipeline outcomes: %s",
        [(o.source, o.status, o.message) for o in pipeline.outcomes],
    )
    raise RuntimeError(f"Startup validation failed:\n{fatal_str}")
```

Key changes:
1. Iterate over `pipeline.outcomes` instead of using `fatal_messages()`
2. Include remediation on a new line with "Remediation: " prefix
3. Join parts with newline instead of "; " separator
4. Update log message to include source information
