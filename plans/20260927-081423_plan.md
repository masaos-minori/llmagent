## Background
`scripts/agent/http_lifecycle.py`'s module docstring documents that `HttpServerLifecycleManager` was refactored into "a true composition facade delegating all concern-specific work to six modules with zero pure-delegation wrappers." Commit `d98dda9a` ("refactor: eliminate circular imports and pure delegation wrappers in http_lifecycle", 2026-09-20) explicitly removed the `_open_stderr_log`, `_terminate_with_timeout`, and `_close_and_forget_stderr` wrapper methods from `HttpServerLifecycleManager`, replacing all production call sites with direct component invocations (`self._stderr_log_manager.open_log(...)`, `self._process_terminator.terminate_with_timeout(...)`). That same commit updated 3 test files (`tests/agent/test_http_lifecycle_integration.py`, `tests/agent/test_http_lifecycle_shutdown_coordinator.py`, `tests/agent/test_http_lifecycle_warning.py`) to match — confirmed via `git show --stat d98dda9a` — but its commit message's claim "Update test mocks to use component-level targets" was incomplete: it did not touch `tests/agent/test_lifecycle.py` or `tests/integration/test_mcp_transport_crash.py`, both of which still reference the removed methods.
