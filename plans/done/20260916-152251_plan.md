## Background
This Plan is derived from `issues/20260915-200530_gov04_assign-owners-resolution-targets-and-discovery-dates.md`, itself derived from a consolidated governance-documentation audit (`memo3.md`, repository root — not used as evidence in this Plan per standing instruction to exclude that file).

## Problem
Most active Part 1/Part 2 entries in `docs/00_governance_03_issue-and-uncertainty-management.md` carry `Owner: Unassigned`/`Assigned To: Unassigned` and many carry `First Found: Unconfirmed`, leaving the Resolution Rules with no accountable party and no way to measure inventory age.

## Reason for change
The document's own Temporary Exception Process already treats `Unassigned` as an unacceptable terminal state for an owner; applying a weaker standard to the inventory itself is inconsistent. Discovery dates without evidence violate the document's own Evidence-Required Rule.

## Implementation intent
Recover owners from the RACI Model (matching each surviving entry's `Area` field to its RACI-area lead) and recover dates from repository history (`git log -S"{ID}" --all`) rather than inventing either. Where a clean RACI match does not exist — found during this Plan's own verification to be the case for `CI-008`–`CI-016`, which span five different RACI areas despite the source issue's "one initiative" framing — leave an explicit `TODO(owner)` marker and report the gap, per the source issue's own stated fallback, rather than assigning an ill-fitting role.
