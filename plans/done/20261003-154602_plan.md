# Plan: Add unit tests for MCP server call edge cases

## Goal
Add unit tests for MCP server call edge cases (retry exhaustion, semaphore contention, strict_mode error messages) to ensure correct behavior in production environments.

## Priority
High

## Scope
- **In-Scope**: Adding unit tests for MCP server call edge cases; updating test coverage reports if needed.
- **Out-of-Scope**: Changing the retry logic itself; modifying other transport layers; changing error handling behavior.

## Background
The following files have complex paths that need test coverage:
- `scripts/shared/http_transport.py` — retry logic
- `scripts/shared/tool_transport_invoker.py` — semaphore processing
- `scripts/shared/route_resolver.py` — strict_mode path

Currently, there's no dedicated test file for `http_transport.py`. The existing test files are:
- `tests/shared/test_tool_transport_invoker.py`
- `tests/shared/test_route_resolver.py`
- `tests/integration/test_mcp_transport_crash.py`

However, these test files may not cover all edge cases.

## Problem
Edge case behavior cannot be verified without adequate test coverage. This increases the risk of unexpected behavior in production environments and prolongs incident recovery time.

## Reason for change
