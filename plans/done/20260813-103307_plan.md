## 6. Design
### Schema Constraints
The `_RAG_SCHEMA_TEMPLATE` currently defines the `chunks` table without constraints on `chunk_index`, `chunk_type`, or `content`. Adding:
```sql
UNIQUE (doc_id, chunk_index),
CHECK (chunk_index >= 0),
CHECK (chunk_type IN ('text', 'code')),
CHECK (length(content) > 0)
```
These constraints are enforced at the SQLite level, preventing malformed data regardless of application-layer failures.

### Config Validator Cleanup
Remove lines 36-39 in `config_validator.py`:
```python
# Embedding dimension consistency
embed_dim = rag.get("embedding_dim")
vec_dim = rag.get("vec_dim")
if embed_dim and vec_dim and embed_dim != vec_dim:
    errors.append(f"embedding_dim={embed_dim} != vec_dim={vec_dim}")
```
Since dimensions are hardcoded to 1024 in `store_protocols.py`, this validation is obsolete.

### Test Updates
- `test_embedding_dim_mismatch` in `test_config_validator.py` should be removed.
- `test_embedding_dim_match` should be updated to not include `embedding_dim`/`vec_dim` keys.
- Any other tests referencing these keys must be reviewed and updated.
