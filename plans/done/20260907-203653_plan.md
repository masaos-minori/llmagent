original Plan never generated procedures for.

## Design
### REQ-003: Fail-closed for falsy `own_config_file`
In `MCPServer.run_http()`, add an `else` branch after the existing `if self.own_config_file:` guard:
```python
if self.own_config_file:
    ConfigLoader.restrict_to(self.own_config_file)
else:
    raise ConfigIsolationError("Config Isolation: own_config_file is falsy — cannot start without config isolation")
```
The exception type should match existing Config Isolation violation handling in `config_loader.py`.

### REQ-004: Unknown top-level key rejection
Add a new method `_check_unknown_top_level_keys()` in `ProductionConfigValidator` that:
1. Uses `dataclasses.fields()` on the relevant dataclass(es) from `config_dataclasses.py`
2. Compares against the config's top-level keys
3. Returns errors for any keys not found in the dataclass field names
4. Calls this method from `validate()` alongside existing checks

### REQ-005: Per-process required-file/required-key table
Add a new section in ADR-002 titled "Per-Process Required Files and Keys" with a table showing:
- Process name
- Required config files
- Required keys within each file
- Empty-allowed keys (keys that can be absent without triggering error)

### REQ-006: Update ADR-004 INV-07 status
Update the INV-07 verification row's Status from "Needs confirmation" to "Confirmed", citing
the new tests added in REQ-003 implementation.
