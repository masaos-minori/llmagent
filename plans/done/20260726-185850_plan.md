## Design

Recommend Option B (fallback validation):

```python
def _validate_tool_args(ctx: AgentContext, name: str, args: dict) -> ToolCallResult | None:
    ...
    registry = ctx.services_required.runtime_tools
    if registry is None:
        # Fallback: try gateway for schema
        rt_tool = ctx.services_required.gateway.get_tool_by_name(name) if ctx.services_required.gateway else None
    else:
        try:
            rt_tool = registry.get(name)
        except KeyError:
            rt_tool = ctx.services_required.gateway.get_tool_by_name(name) if ctx.services_required.gateway else None
    
    if rt_tool is not None and rt_tool.input_schema is not None:
        result = validate_tool_arguments(...)
        if not result.success:
            return ToolCallResult(...)
    return None
```
