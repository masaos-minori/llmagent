## Goal

Restrict environment variable overrides for subprocesses to prevent subversion of MCP server behavior.

## Scope

**In-Scope:**
- Define PROTECTED_ENV_VARS constant
- Filter out protected variables before merging with os.environ

**Out-of-Scope:**
- Changes beyond this single filtering addition
- Any changes to production code beyond the filtering logic

## Assumptions

1. Common protected variables include PATH, PYTHONPATH, LD_LIBRARY_PATH, HOME, USER
2. Config-provided env vars should only be additive, never overriding critical system vars
3. Existing subprocess startup behavior should be preserved for non-protected vars

## Design

Add protected variables and filter:
```python
_PROTECTED_ENV_VARS = frozenset({"PATH", "PYTHONPATH", "LD_LIBRARY_PATH", "HOME", "USER"})

if cfg.env:
    safe_env = {k: v for k, v in cfg.env.items() if k not in _PROTECTED_ENV_VARS}
    if len(cfg.env) != len(safe_env):
        logger.warning("Protected env vars rejected from config: %s", ...)
    env = {**os.environ, **safe_env}
```
