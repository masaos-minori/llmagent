# Plan: Run cited ADR invariant tests in CI, not only verify cited paths exist (GV-012)

## Goal
Extend the CI `lint` job to actually execute the pytest node ids cited in the ADR Invariant
Verification Matrix (`docs/10_adr/adr_01_index.md`), failing on any missing, skipped, or
failing citation. This strengthens GV-012 from structural (path exists) to behavioral (test
passes) and clears the optional follow-up. Status remains `Existing`.

## Priority
Low

## Scope
- **In-Scope**:
  - Extract the cited pytest node ids from the ADR Invariant Verification Matrix.
  - Run them in the CI `lint` job, failing on missing, skipped, or failing citations.
  - Preserve the existing path-existence verification in `check_adr_invariant_matrix.py`.
  - Reuse the existing `integration` pytest marker as the skip-annotation convention for
    integration-only cited tests.
  - Clear the GV-012 optional follow-up note.
- **Out-of-Scope**:
  - Changing the ADR Invariant Verification Matrix schema.
  - Extending to non-matrix-cited tests.
  - Changing `check_adr_invariant_matrix.py`'s path-existence behavior.

## Background
`governance_04_documentation-checks.md` maps GV-012 ("Code is NOT canonical for adopted design
decisions") to `check_compat_shims.py`, `check_adr_invariant_matrix.py`, and
`check_adr_reference.py`, gate `Warning`, status `Existing`, with the optional follow-up:
"run cited tests in CI, not just verify path existence." Currently the matrix check confirms a
cited test path exists but never executes it.

## Problem
A cited test path can exist yet pass trivially or assert nothing about the invariant. "Path
exists" verification therefore does not prove the invariant is enforced; only running the cited
test in CI catches a passing-but-meaningless citation.

## Reason for change
Strengthening GV-012 from structural (path exists) to behavioral (test passes) closes the
optional gap without changing what is documented as canonical.

## Implementation intent
Add a CI step (in the existing `lint` job) that reads the test node ids/paths cited in the ADR
Invariant Verification Matrix and runs them, failing if any cited test is missing, skipped, or
failing. Use the matrix as the citation source; do not change the matrix schema or the existing
path-existence check.

## Design
Extend the existing `lint` job; do not add a new workflow.

1. **Citation extraction (UNK-01).** Obtain the cited node ids from
   `docs/10_adr/adr_01_index.md` by reusing `check_adr_invariant_matrix.py`'s node-id
   definition (`_TEST_PATH_RE` / `ADR_INDEX`) so the source of truth stays single. If
   import-linter forbids importing a private symbol across tools, duplicate the node-id regex
   in the CI helper under a pinned comment referencing the checker and add a regression test
   pinning the two patterns equal.
2. **Run per node id.** For each cited node id, run `pytest <nodeid> -m "not integration"`
   (UNK-03: a class citation runs the class). Fail the step if any node id collects to zero
   tests (missing), fails, or remains skipped after deselection (UNK-02).
3. **Skip convention (REQ-003).** Cited tests marked `@pytest.mark.integration` are
   intentionally deselected by `-m "not integration"` — not failed, not silently ignored.
4. **Preserve path-existence (REQ-005).** Do not touch `check_adr_invariant_matrix.py`; the
   existing path-existence step continues to run.
