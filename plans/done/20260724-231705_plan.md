## Goal

Ensure all resources acquired during the startup phase are released regardless of whether startup succeeds or fails.

## Scope

**In**: `scripts/agent/repl.py` (AgentREPL.run(), _run_repl_loop()), `scripts/agent/startup.py` (StartupOrchestrator.run())
**Out**: Changes to resource lifecycle management outside the startup path

## Assumptions

1. `_close_resources()` already handles partial startup correctly — `self._ctx.services` is None when `build_agent_context()` hasn't completed
2. `httpx.AsyncClient.aclose()` is safe to call multiple times
3. `lifecycle.shutdown_all()` is idempotent — safe to call even if subprocesses were already terminated

## Design

Add a finally block in `AgentREPL.run()` that calls `_close_resources()` unconditionally. This covers both success and failure paths uniformly. No changes needed to `_close_resources()` — it already handles partial startup. No changes needed to `StartupOrchestrator.run()` — its inner cleanup is preserved.

## Implementation steps

### Target file

`scripts/agent/repl.py`

### Procedure

#### Step A: Modify AgentREPL.run() — add finally block

Current code (lines 506-512):

```python
        startup = StartupOrchestrator(self._ctx, self._view)
        try:
            self._cmds, self._orchestrator = await startup.run()
        except Exception as e:
            self._view.write_fatal(f"Startup failed: {e}")
            raise
        await self._run_repl_loop()
```

Change to:

```python
        startup = StartupOrchestrator(self._ctx, self._view)
        try:
            self._cmds, self._orchestrator = await startup.run()
        except Exception as e:
            self._view.write_fatal(f"Startup failed: {e}")
            raise
        finally:
            await self._close_resources()
        await self._run_repl_loop()
```

Key points:
- Finally block ensures `_close_resources()` runs regardless of startup outcome
- Covers both success path (REPL loop entered normally) and failure path (exception caught and re-raised)
- No changes to `_close_resources()` needed — already handles partial startup via `if svc is not None:` check
