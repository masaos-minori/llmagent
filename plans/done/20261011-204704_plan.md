## Background
- A schema change replaced the `consumer_delivery.acked_at` timestamp with the boolean `acked` and removed the event-level `events.acked_at` column (a migration drops it); the repository function that wrote the event-level column was removed.
- The ACK/NACK endpoint reference and ADR-006 already describe the new model. The delivery-semantics document, the persistence-schema document, and the reference API still describe the old one.
- The reference API's class/function table is an auto-generated block produced by `tools/generate_reference_table.py --type eventbus`; the removed function remains listed because the block was not regenerated.
- First noticed as UNK-02 of `plans/done/20261011-201351_plan.md` and filed as the source issue.

## Problem
- A reader looks for a timestamp column and an event-level ACK column that do not exist; the state-transition tables define "ACKed" with a predicate (`acked_at IS NOT NULL`) that does not match the schema; the reference API lists a function that no longer exists.

## Reason for change
- Documentation/code mismatch on persisted state in documents implementers use as the source for ACK semantics; they also contradict the endpoint reference and ADR-006.

## Implementation intent
- Describe the current model in behavioral terms: ACK state is a per-consumer boolean, set on the first ACK and never lowered; "ACKed" means the boolean is set; there is no event-level ACK state. Regenerate the auto-generated block instead of editing it by hand. Follow the docs content policy (no line numbers, no implementation counts).

## Requirements
- `REQ-001`: Correct the delivery-semantics document so every current-behavior statement about ACK state, ACK postconditions, NACK interaction, resume position, and the state table uses the boolean `acked` and no longer mentions a timestamp or an event-level ACK column.
- `REQ-002`: Correct the persistence-schema document's `events` key-column list and `consumer_delivery` description (columns and idempotent upsert) to the current schema.
- `REQ-003`: Refresh the reference API's auto-generated block so the removed repository function is not listed and the remaining rows match the live code.
- `REQ-004`: Keep the three documents consistent with the endpoint reference and ADR-006, with no remaining `acked_at` description of current behavior.
