## Background
The Manual Checks section lists entries numbered 9 through 14. Items 1-8 are missing from this section, suggesting either deletion without renumbering or omission during creation. The issue claims that "Evidence Label Validation" and "ADR Section Header Compliance" are unnumbered, but verification shows these are actually numbered as items 10 and 11 respectively.

**Confirmed evaluation outcome (plan-to-implementation-procedure Step 3a adversarial verification, 2026-09-27)**: items 1-8 are **not missing** — they exist in the preceding `## Automated Checks` section (items 1-8, `### 1. Document Quality Check` through `### 8. Documentation Structure Validation`). The numbering is a single **continuous scheme spanning both sections** (`## Automated Checks` then `## Manual Checks`), not independent per-section numbering. However, `## Automated Checks` itself also contains items 15 and 16 (`### 15. Docs Content Policy Check`, `### 16. ADR Structure Check`) positioned *after* item 8 but *before* `## Manual Checks`'s items 9-14 in document order — i.e. the full sequence 1-16 is used exactly once each, but items 15-16 (added later, once 9-14 had already been assigned to the not-yet-written Manual Checks section) appear out of numeric order relative to 9-14 in the document body. REQ-001's "intentionally deleted or accidentally omitted" question is answered: **neither** — this is a numbering-allocation-by-creation-order scheme, not a deletion. REQ-002/REQ-003 (explain-if-deleted / restore-if-omitted) do not apply. The only potentially-relevant remaining action is REQ-004 (add a brief clarifying note about the continuous cross-section numbering, so a reader of Manual Checks alone does not assume items 1-8 are missing) — a minimal, low-risk addition, not a renumbering (renumbering would break the "numbers assigned in creation order" scheme intentionally used elsewhere in this Matrix-adjacent document).

## Problem
The numbering gap makes it unclear whether items 1-8 were intentionally removed or accidentally omitted. Without clarification, implementers cannot determine which items exist versus which were deleted.

## Reason for change
Resolving the numbering gap ensures implementers can easily determine which items exist in the Manual Checks list.

## Implementation intent
Investigate and resolve the numbering gap by one of the following approaches:
1. If items 1-8 were intentionally deleted, add a note explaining their removal
2. If items 1-8 should exist, restore them
3. Renumber the remaining items to start from 1
