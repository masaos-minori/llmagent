## Goal
Fix critical inconsistencies in the `docs/` folder: remove references to deleted files, correct incorrect port numbers, update or remove references to non-existent configuration files and Python modules, and clarify CLI command references.

## Priority
High

## Scope
- **In-Scope**: Fixing documentation references to match current repository state
- **Out-of-Scope**: Modifying source code, adding new features, restructuring documentation organization, fixing underlying source code issues (missing files, undefined functions)

## Background
The documentation consistency checker (`tools/check_docs_consistency.py`) identified 3 ERROR-level findings and numerous WARNING-level findings across the docs folder. The errors include references to files that were deleted during restructuring, a port number mismatch, and multiple warnings about missing files and undefined symbols.

## Problem
Documentation claims existence of resources (files, ports, config keys, functions, commands) that do not exist in the current codebase, leading to developer confusion and false positives in automated validation tools.

## Reason for change
These inconsistencies undermine trust in the documentation set. Developers relying on doc references will encounter dead ends. Automated tools that validate doc-source alignment will produce noise, reducing signal quality for real issues.

## Implementation intent
For each finding category:
1. Remove references to deleted files and update migration notes to reflect current state
2. Correct the git-mcp port number to match `config/agent.toml`
3. Update or remove references to non-existent configuration files, noting which ones replaced them
4. Replace undefined function names with correct names or remove references where the functions no longer exist
5. Clarify CLI command references — distinguish between top-level commands and subcommands

## Requirements
- `REQ-001`: Remove references to deleted files (`06_ref-mcp.md`, `04_spec_mcp.md`, `04_mcp-protocol.md`, `04_mcp_04_06_browser.md`) or update Migration Notes to reflect their deletion
- `REQ-002`: Correct git-mcp port number from 8000 to 8014 in `docs/04_mcp_05_02_auth-profiles-and-sandboxing.md`
- `REQ-003`: Update or remove references to non-existent configuration files (`rag_pipeline.toml`, `common.toml`, `embedding.toml`, `tool_registry.json`, `workflows/production.json`)
- `REQ-004`: Update or remove references to non-existent Python modules (`models_audit.py`, `http_lifecycle_process_snapshot.py`, `service_pull_requests.py`)
- `REQ-005`: Clarify CLI command references — distinguish between top-level commands and subcommands where the consistency checker flagged false positives
