## Goal

Surface first-turn background task exceptions to the user immediately, regardless of whether subsequent tasks also fail.

## Scope

**In**: `scripts/agent/orchestrator.py` (Orchestrator._discard_and_log())
**Out**: Changes to LLMTurnRunner, other background task handling paths

## Assumptions

1. `_on_first_turn` runs as an asyncio background task and may raise during initialization
2. `_on_error` callback exists in Orchestrator and can be used to notify the user
3. First-turn failures have high impact on session behavior and should be surfaced immediately

## Implementation Steps

1. In `Orchestrator._discard_and_log()`, when `self._consecutive_bg_failures == 1` and the exception is NOT `asyncio.CancelledError`, add a call to `self._on_error(exc)` to surface the error to the user.
2. Ensure the notification is idempotent — only emit once per unique first-turn failure. The existing counter already prevents re-notification on consecutive failures from the same source.
3. Optionally set `ctx.conv.is_processing = False` or similar flag to indicate the session is in a degraded state after first-turn failure.
4. Verify no duplicate notifications occur if the same task fails multiple times.
