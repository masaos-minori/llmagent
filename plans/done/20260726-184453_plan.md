## Design

Add masking function:
```python
_SECRET_PATTERNS = [
    r'(?i)(?:api[_-]?key|token|secret|password)\s*[:=]\s*\S+',
    r'Bearer\s+[A-Za-z0-9\-._~+/]+=*',
    r'(?:AKIA|GSK)[A-Z0-9]{16,}',
]

def _mask_secrets(text: str) -> str:
    for pattern in _SECRET_PATTERNS:
        text = re.sub(pattern, lambda m: m.group(0)[:10] + '***', text)
    return text
```

Apply to stderr logging:
```python
logger.error(
    "Lifecycle: %r exited early; stderr (%s chars): %s",
    server_key,
    len(stderr_full),
    _mask_secrets(stderr_full[:500]),  # <-- added masking
)
```
