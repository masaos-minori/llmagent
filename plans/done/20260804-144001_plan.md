## Design

Change (scripts/agent/startup.py, lines 348-359):

```python
        # 6. RAG consistency
        try:
            rag_check = RagMaintenanceService().consistency()
            if rag_check.is_consistent:
                pipeline.add_ok("rag_consistency")
            else:
                for issue in rag_check.issues:
                    pipeline.add_warning(
                        "rag_consistency", f"[RAG] Consistency issue: {issue}"
                    )
        except Exception as exc:  # noqa: BLE001 — non-critical maintenance check must not abort startup
            logger.warning("RAG consistency check failed: %s", exc)
            pipeline.add_skipped(
                "rag_consistency", f"RAG consistency check skipped: {exc}"
            )
```

Rationale for each element, tied to the requirement's Implementation instructions (1-4):
1. `except Exception as exc:` — binds the exception (instruction 1); broad `Exception` type is
   kept unchanged (instruction 4) — this is a deliberate choice already present and not narrowed.
2. Inline justification text after `# noqa: BLE001` — satisfies `rules/coding.md` §Suppression
   governance ("Every `# noqa`... requires an inline justification. Suppressions without
   explanation are prohibited."). Wording explains *why broad Exception is intentional here*
   (non-critical check, must not abort startup), matching the existing repo convention seen at
   `scripts/agent/startup.py:112` (`# noqa: PLC0415 — lazy: deferred to avoid circular import at
   module level`).
3. `logger.warning("RAG consistency check failed: %s", exc)` — `%s` lazy formatting, consistent
   with all other `logger.*` calls in this file (e.g. line 268). Severity choice: `warning` (see
   UNK-03 resolution above).
4. `pipeline.add_skipped("rag_consistency", f"RAG consistency check skipped: {exc}")` — keeps the
   SKIPPED status (instruction 4: no control-flow change), but the message now carries `exc`
   content, so it also reaches the console via `_display_pipeline_results()` →
   `self._view.write_warning(f"{OutputTag.SKIPPED} {outcome.message}")`
   (`scripts/agent/startup.py:382-383`).

No other line in `_check_services()` changes. No change to `RagMaintenanceService`,
`StartupValidationResult`, `_display_pipeline_results()`, or `_report_readiness()`.
