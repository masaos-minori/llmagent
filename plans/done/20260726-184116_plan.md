## Design

Add validation before subprocess launch:

```python
_ALLOWED_SUBPROCESS_CMDS = frozenset({"uvicorn", "gunicorn", "python"})

if not any(cfg.cmd.startswith(cmd) for cmd in _ALLOWED_SUBPROCESS_CMDS):
    raise ValueError(f"Unauthorized subprocess command: {cfg.cmd}")

proc = subprocess.Popen(
    cfg.cmd,
    ...
)
```
