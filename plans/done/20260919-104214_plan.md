   - [x] Step 2: Recompute a current-state line-count band per mechanical-content
     category (`REQ-002`; recorded in this Plan's Design section). The 2
     tool-based rows reuse `tools/check_docs_content_policy.py`'s existing
     `check_index_table`/`check_full_file_tree`. The 5 remaining rows use this
     exact, reproducible Python script (run once per pattern, substituting the
     fence/regex noted in the Design table's Method column):

     ```python
     import re
     from pathlib import Path
     docs = Path("docs")
     header_re = re.compile(r"^\s*\|.*\b(Default|デフォルト)\b.*\|", re.IGNORECASE)
     total_lines = total_tables = 0
     for p in sorted(docs.rglob("*.md")):
         lines = p.read_text(encoding="utf-8").splitlines()
         i = 0
         while i < len(lines):
             if header_re.match(lines[i]):
                 total_tables += 1
                 j = i
                 while j < len(lines) and lines[j].lstrip().startswith("|"):
                     j += 1
                 total_lines += j - i
                 i = j
             else:
                 i += 1
     print(total_tables, total_lines)
     ```

     (The config-field-bullet, CLI-bash-fence, and SQL-fence rows use the same
     traversal shape with the regex/fence-marker swapped, per the Design table's
     Method column.)
   - [x] Step 3: Record the corrected figures in this Plan document as the
     citable replacement for the stale figures (`REQ-003`).
