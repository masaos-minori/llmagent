## Reason for change
Without a stated completion condition, an agent drafting an issue through Phases 3-8
has no explicit checkpoint to confirm each field is actually filled (or correctly
marked `N/A`) before moving to the next Phase. This is exactly the kind of silent gap
Phase 9's own Step 9c Final Checklist exists to catch retroactively — catching it only
at the end, rather than per-Phase, means a Phase 3-8 defect is found later and farther
from its cause.

## Implementation intent
Add one "Completed when" line to each of Phase 3 through 8, following the style
already used in Phase 1/Phase 2 (a single sentence starting with "**Completed when**:"
stating the minimum condition for that Phase's fields to be considered drafted — each
field filled, or explicitly marked `N/A: {reason}` per `templates/issue.md`'s own
convention). Do not add a "Stop and ask" condition to any of Phase 3-8, per Scope
Out-of-Scope above.
