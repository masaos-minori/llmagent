## Problem

This matches the Issue's own Evidence, which quotes existing text from the document rather than reporting genuinely absent content.

## Reason for change
Per the Issue's Impact: operators may assume all values are TOML-configurable when some are not, may be confused when an "operational" value doesn't match a documented "default", and risk deploying incorrect configuration if precedence is unclear. Consolidating the already-correct-but-scattered information into one dedicated subsection directly addresses this confusion risk without requiring any new investigation.
