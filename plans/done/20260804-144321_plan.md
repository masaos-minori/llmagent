# Plan: Remove dead `ctx.workflow is None` guard in `_recover_pending_approvals()`

## Goal
Delete the unreachable `if ctx.workflow is None: return` guard at the top of
`StartupOrchestrator._recover_pending_approvals()` (`scripts/agent/startup.py`), since
`AgentContext.__init__()` unconditionally assigns `self.workflow = WorkflowState()` and no code
path anywhere in the codebase can set `ctx.workflow` back to `None`.

## Scope

**In scope**
- `scripts/agent/startup.py` — delete the two-line dead guard (currently lines 518-519:
  `if ctx.workflow is None:` / `return`) inside `_recover_pending_approvals()`.

**Out of scope**
- `scripts/agent/context.py` / `WorkflowState` / `AgentContext.__init__()` — reference-only,
  no change.
- Any new flag, config option, or alternate gating condition in place of the removed check.
- Any other line of `_recover_pending_approvals()` (approval fetch, selection, warning
  messages, store lifecycle) — unchanged.
- Test additions for a "workflow is None" scenario — that state cannot occur, so a test for
  it would test an impossible state (per requirement's explicit instruction).

## Assumptions
1. `AgentContext.__init__()` remains the sole construction path for `ctx.workflow` for the
   lifetime of this change (verified: only one assignment site in the codebase, see Affected
   Areas evidence below). Falsifiable: a future `rg "\.workflow\s*=" scripts/agent` finding a
   second assignment site (e.g. `ctx.workflow = None`) would invalidate this.
2. No test in `tests/agent/test_startup.py` relies on the removed `None` branch (verified by
   reading all 8 test methods in `TestStartupOrchestratorRecoverPendingApprovals`; every one
   sets `ctx.workflow = MagicMock()` — a non-`None` object — before calling the method).
3. Removing the guard is a pure dead-code deletion with no observable behavior change for any
   currently reachable code path (the guard's body — a bare `return` — never executes today).

## Design
No design change. This is dead-code removal, not a behavior change:

Before (`scripts/agent/startup.py:515-524`):
```python
async def _recover_pending_approvals(self) -> None:
    """Restore workflow approval-pending state from a previous session."""
    ctx = self._ctx
    if ctx.workflow is None:
        return
    store = StateStore()
    try:
        results = find_all_pending_approvals(store.get_connection())
    finally:
        store.close()
```

After:
```python
async def _recover_pending_approvals(self) -> None:
    """Restore workflow approval-pending state from a previous session."""
    ctx = self._ctx
    store = StateStore()
    try:
        results = find_all_pending_approvals(store.get_connection())
    finally:
        store.close()
```

`WorkflowState` (`scripts/agent/context.py:204-218`) remains a plain (non-`Optional`)
dataclass-like field; `AgentContext.__init__()` (`scripts/agent/context.py:271-276`) remains
unchanged and continues to unconditionally construct it. No typing changes are needed on
`ctx.workflow` since its declared type was never `WorkflowState | None` — the dead check was
inconsistent with its own type, not just with runtime behavior.
