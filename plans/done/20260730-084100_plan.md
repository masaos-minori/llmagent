## Goal

Connect MCP `/health` schema, probe model, and status interpretation so the Agent can consistently interpret and display dependency failures, readiness state, restart recommendations, and operator-action requirements.

## Scope

**In-Scope:**
- Add health body interpretation helpers for McpHealthProbeResult.body
- Define health reason extraction with priority order (reason → message → dependencies → details → operator_action_required → restart_recommended)
- Support structured dependencies alongside legacy string dependencies
- Distinguish server self-reported health from Agent observed health
- Surface interpreted health fields to /mcp status, startup summary, operational logs, and runbooks

**Out-of-Scope:**
- Changes to MCP transport layer (SSE/HTTP)
- Changes to MCP authentication protocol itself
- Changes to make_health_response() in mcp_servers

## Assumptions

1. The common /health schema from make_health_response() is stable and will not change frequently.
2. Structured dependencies should be preferred over legacy string dependencies but both must be supported.
3. Parse failures should never crash the Agent — they should be logged and surfaced as warnings.

### Phase 2: Define health reason extraction

- [ ] 2.1 Implement priority-based reason extraction:
  ```python
  def extract_health_reason(body: Dict[str, Any]) -> Optional[str]:
      """Extract health reason using priority order."""
      if "reason" in body:
          return body["reason"]
      if "message" in body:
          return body["message"]
      dep_summary = summarize_dependencies(body.get("dependencies", []))
      if dep_summary:
          return f"Dependency failure: {dep_summary}"
      detail_summary = summarize_details(body.get("details", []))
      if detail_summary:
          return f"Issue: {detail_summary}"
      if body.get("operator_action_required"):
          return "Operator action required"
      if body.get("restart_recommended"):
          return "Restart recommended"
      return None
  ```

  ```python
  def summarize_dependencies(dependencies: List[Any]) -> List[str]:
      """Summarize dependencies supporting both string and structured forms."""
      summaries = []
      for dep in dependencies:
          if isinstance(dep, dict):
              # Structured form
              name = dep.get("name", dep.get("status", "unknown"))
              reason = dep.get("reason", "")
              required = dep.get("required", False)
              if required and not dep.get("status", "").startswith("ok"):
                  summaries.append(f"{name}: {reason}")
          else:
              # Legacy string form
              summaries.append(str(dep))
      return summaries
  ```
