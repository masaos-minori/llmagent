## Design
The existing `TestRestrictToIsolation` class in `tests/shared/test_config_loader.py` (lines 92-137) covers:
- Denying unauthorized loads under `restrict_to()`
- Allowing authorized loads under `restrict_to()`
- Class-level restriction affecting all instances
- ValueError on empty args to `restrict_to()`

However, the adr-index.md still marks INV-003 as "test pending", suggesting incomplete coverage. The gap analysis focuses on:
1. **Basename extraction correctness**: `_check_permission()` uses `Path(name).name` to extract basenames (line 120). Tests should verify this works correctly for paths containing directory components (e.g., `"subdir/a.toml"` should match `"a.toml"` in the allowed set).
2. **Edge case: partial filename matching**: Ensure `"a.toml"` in the allowed set does NOT match `"a_backup.toml"` — the basename comparison must be exact.
3. **Cross-method permission enforcement**: Verify that both `load()` and `load_all()` respect the same `restrict_to()` boundary consistently.
