## Design

For each service module, add test classes following the existing pattern:

```python
class TestServiceFile:
    def test_get_file_success(self) -> None: ...
    def test_get_file_404(self) -> None: ...
    def test_get_file_500(self) -> None: ...
    
class TestServiceIssues:
    def test_list_issues_success(self) -> None: ...
    def test_list_issues_403(self) -> None: ...
    def test_list_issues_500(self) -> None: ...
    
# Similar for service_pull_requests and service_repository
```

Each test mocks the GitHub API client (`gh` parameter) via MagicMock to return controlled responses.
