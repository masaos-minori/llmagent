# Plan: Extend `stale_patterns` to detect references to non-existent canonical documents (GV-011)

## Goal
Extend the `stale_patterns` custom rule in `tools/check_docs_quality.py` to flag references to
canonical documents that are absent from the corpus (never created, removed, or renamed), then
mark GV-011 `Existing`. Keep the gate at `Warning` severity.

## Priority
Low

  - Update the GV-011 matrix row to `Existing` and clear its follow-up note.
- **Out-of-Scope**:

## Background
`governance_04_documentation-checks.md` maps GV-011 ("References to non-existent canonical
documents") to `check_docs_structure.py` + `check_docs_quality.py`, gate `Warning`, status
`Partial`, with the follow-up "Extend `stale_patterns` custom rule config". The
`stale_patterns` custom rule covers several staleness cases but not references to canonical
documents that do not exist in the corpus.

## Problem
A document can reference a canonical document path that was never created, removed, or renamed
without being flagged, because `stale_patterns` does not cover this case and link-reachability
alone may not distinguish canonical-document references from other internal links.

## Reason for change
Dangling canonical references mislead readers and weaken the cross-reference graph. Extending
`stale_patterns` closes the documented `Partial` gap at the existing `Warning` severity.

## Implementation intent
Add a `stale_patterns` entry that flags references whose target canonical document is absent
from the corpus (or points to a removed/renamed path). Coordinate with
`check_docs_structure.py` link-reachability so the two checks do not duplicate each other.
Preserve the `Warning` severity for this finding.

## Design
Extend (do not rewrite) `check_stale_patterns`.

1. **Scope the pattern (UNK-02/03).** Detect Markdown link/reference syntax
   (`[text](path)` / `[text][ref]` resolved against the corpus) whose target path does not
   exist AND which appears in canonical language ("the canonical source for", "authoritative
   source for", "normative reference for"). This distinguishes it from a generic dangling
   internal link handled by `check_docs_structure.check_links` (UNK-02).
2. **Severity (UNK-01).** Emit the new finding at `Warning`. Reconcile with the existing
   `ERROR` emission by adding per-pattern severity to `check_stale_patterns` (the new pattern
   is `Warning`; existing patterns keep their behavior) rather than changing the global
   severity.
3. **Dedup (REQ-003).** Do not re-implement reachability; rely on `check_links` for generic
   dangling links and restrict the new pattern to canonical-language references.
4. **Config location.** Add the pattern within `check_stale_patterns`'s `default_patterns`
   mechanism (currently empty) or the custom-rule extension point, per the existing design.

No change to `check_docs_structure.py`.
