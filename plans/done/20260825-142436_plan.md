## Problem
`scripts/agent/services/config_reload.py:402-403` の `_apply_tool_params()` に、もう存在しない`ToolExecutor`のキャッシュ機構向けの diff-apply処理が残っている。この処理自体はクラッシュを起こさないが、`ToolConfig.tool_cache_ttl` フィールドが今後削除される予定(`plans/20260827-121312_plan.md`)であるため、削除の順序を誤ると `dataclasses.replace()` が `TypeError` を送出するようになる。

## Reason for change
無意味になった設定反映ロジックを放置すると、(1) 操作者に「`tool_cache_ttl` を `/reload` で変更できる」という誤った印象を与え続ける、(2) `plans/20260827-121312_plan.md` がフィールド自体を削除した際に `dataclasses.replace()` がクラッシュする実行時エラーの原因になる。

## Implementation intent
`_apply_tool_params()` から `tool_cache_ttl` の diff-apply処理(2行)のみを削除する。`serial_tool_calls`/`tool_definitions_strict`/`plan_blocked_tools` の処理は変更しない。
