## Design

### Approach: Add asyncio.Lock to TurnState and wrap field access

After reviewing the code, the current `TurnState` class exists but doesn't have explicit locking. However, the actual risk depends on whether there's real concurrent access.

### Implementation Steps

#### Step 1: Verify concurrent access exists

Check if multiple coroutines can access the same `TurnState` simultaneously. If no concurrent access exists, no changes needed.

#### Step 2: Add lock to TurnState

If concurrent access exists, add:

```python
import asyncio

class TurnState:
    def __init__(self):
        self.turn_count = 0
        self.tool_calls: list[str] = []
        self._lock = asyncio.Lock()
    
    async def add_tool_call(self, call_id: str):
        """Thread-safe addition of a tool call."""
        async with self._lock:
            self.tool_calls.append(call_id)
            self.turn_count += 1
    
    async def get_tool_calls(self) -> list[str]:
        """Return a copy of tool calls."""
        async with self._lock:
            return list(self.tool_calls)
```

#### Step 3: Update callers to use locked methods

Replace direct attribute access with locked method calls.

#### Step 4: Add tests

| Risk | Mitigation |
