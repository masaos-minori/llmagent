## Design

Recommend Option B (stronger isolation):

```python
# In orchestrator.py:
if memory_snippets:
    memory_block = "\n\n--- USER MEMORY ---\n" + "\n".join(
        f"- {snippet.text}" for snippet in memory_snippets
    )
    ctx.conv.append_message(
        {
            "role": "user",  # Changed from "system" to "user"
            "content": memory_block,
            "_ephemeral": True,  # Added ephemeral flag
        },
        source="memory_injection",
    )

# In startup.py:
memory_block = "\n\n--- USER MEMORY ---\n" + "\n".join(...)
# Instead of appending to initial_prompt, append as separate message
ctx.conv.append_message(
    {"role": "user", "content": memory_block, "_ephemeral": True},
    source="memory_injection",
)
```
