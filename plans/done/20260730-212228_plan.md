# Work Plan: Implement Log Rotation for MCP Server Stderr Logs

## Goal

Add built-in log rotation support to prevent unbounded growth of MCP server stderr log files that can exhaust disk space.

## Scope

**In-Scope:**
- Add configuration parameters `max_stderr_log_size_mb` and `max_stderr_log_files` to `McpServerConfig`
- Check log file size before opening and rotate if exceeding max size
- Keep up to configured number of rotated copies, delete oldest when limit exceeded

**Out-of-Scope:**
- Configuring external logrotate integration (separate concern)
- Rotating logs during runtime (only at open time)
- Compressing rotated log files

## Assumptions

1. Default max log size of 100 MB provides reasonable protection without frequent rotation
2. Default of 3 rotated files balances retention needs with disk usage
3. Atomic rename (os.replace) ensures no data loss during rotation

     ```python
     def _open_stderr_log(self, server_key: str) -> IO[bytes]:
         safe_key = re.sub(r"[^A-Za-z0-9_-]", "_", server_key)
         log_dir = Path("/opt/llm/logs/mcp_servers")
         log_dir.mkdir(parents=True, exist_ok=True)
         
         # Check if rotation needed
         log_path = log_dir / f"{safe_key}.stderr.log"
         if log_path.exists():
             size_bytes = log_path.stat().st_size
             max_bytes = int(self._cfg.max_stderr_log_size_mb * 1024 * 1024)
             if size_bytes > max_bytes:
                 self._rotate_log(log_dir, safe_key, max_bytes)
         
         fh = log_path.open("ab")
         self._stderr_log_paths[server_key] = str(log_path)
         return fh
     
     def _rotate_log(self, log_dir: Path, safe_key: str, max_bytes: int) -> None:
         """Rotate stderr log file."""
         for i in range(self._cfg.max_stderr_log_files - 1, 0, -1):
             old_path = log_dir / f"{safe_key}.stderr.log.{i}"
             new_path = log_dir / f"{safe_key}.stderr.log.{i + 1}"
             if old_path.exists():
                 try:
                     os.replace(str(old_path), str(new_path))
                 except OSError:
                     pass
         
         current_path = log_dir / f"{safe_key}.stderr.log"
         rotated_path = log_dir / f"{safe_key}.stderr.log.1"
         try:
             os.replace(str(current_path), str(rotated_path))
         except OSError:
             logger.warning("Failed to rotate log file %s", current_path)
     ```

## Risks & Mitigations

- **Risk:** Rotation could fail silently if disk is full → **Mitigation:** Log warning on rotation failure; current file remains open for continued writing
- **Risk:** Rotated file naming convention conflicts with existing files → **Mitigation:** Use numbered suffix (.1, .2, etc.) which is standard convention
- **Risk:** `os.replace()` may not be atomic across filesystem boundaries → **Mitigation:** Ensure rotation happens within same directory (log_dir)
