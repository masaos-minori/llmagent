# Follow-up Work Needed — 番号付けの欠番

## Goal

Resolve the numbering gap in the Follow-up Work Needed section of `governance_04_documentation-checks.md`: entries start at 4 instead of 1, indicating items 1-3 may have been deleted without renumbering.

## Priority
Low

## Scope
- **In-Scope**: Investigating and resolving the numbering gap in the Follow-up Work Needed section
- **Out-of-Scope**: Changing the content of existing entries; modifying any section other than Follow-up Work Needed

## Background
The Follow-up Work Needed section lists rules marked "Missing" or "Partial" that need new inspection tools or processes. The section currently contains entries numbered 4 through 14, with items 1-3 missing. This suggests items may have been deleted without renumbering, which makes it difficult for implementers to determine which items were removed.

## Problem
The numbering gap makes it unclear whether items 1-3 were intentionally removed or accidentally omitted. Without clarification, implementers cannot determine which items exist versus which were deleted.

## Reason for change
Resolving the numbering gap ensures implementers can easily determine which items exist in the Follow-up Work Needed list.

## Implementation intent
Investigate and resolve the numbering gap by one of the following approaches:
1. If items 1-3 were intentionally deleted, add a note explaining their removal
2. If items 1-3 should exist, restore them
3. Renumber the remaining items to start from 1

## Requirements
- REQ-001: Determine whether items 1-3 were intentionally deleted or accidentally omitted
- REQ-002: If intentionally deleted, add a note explaining their removal
- REQ-003: If accidentally omitted, restore the missing items
- REQ-004: If renumbering is appropriate, update all item numbers sequentially starting from 1
- REQ-005: Do not alter the content of existing entries
- REQ-006: Keep changes isolated to `governance_04_documentation-checks.md`
