## Goal

Persist memory injection failure state across sessions so users are aware memory is unavailable.

## Scope

**In-Scope**:
- Add `memory_disabled` flag to `ConversationState`
- Set flag in `StartupOrchestrator._setup_prompt()` when memory injection fails
- Display one-time warning on first tool call after failure

**Out-of-Scope**:
- Modifying memory injection logic itself
- Adding new configuration options
- Changing other error handling paths

## Assumptions

1. Setting `ctx.conv.memory_disabled = True` in `_setup_prompt()` propagates correctly to the REPL loop.
2. The "warn-on-first-use" approach (displaying warning only on first tool call) is acceptable — it avoids spamming the user with warnings on every turn.
3. The warning should be displayed via `self._view.write_warning()` with `OutputTag.NON_FATAL`.
