## 8. Risks & Mitigations
- **Risk**: Consolidated truncation utility produces slightly different output at boundary conditions. → **Mitigation**: Sub-task A requires byte-for-byte identical output verification at all tested boundaries.
- **Risk**: Unifying dry-run wordings breaks caller expectations or test assertions. → **Mitigation**: Sub-task B requires explicit maintainer sign-off before proceeding; all 32 tests must be updated to match the new wording.
- **Risk**: New formatter modules added later won't use the shared utilities. → **Mitigation**: Document the shared utilities' existence in a central location (e.g., `scripts/mcp_servers/models.py` or a design note).
