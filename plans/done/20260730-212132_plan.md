# Work Plan: Fail Fast on Tool Discovery Failure Even in Development Mode

## Goal

Treat tool discovery failures as fatal errors regardless of production mode, improving error messaging to clearly indicate the root cause.

## Scope

**In-Scope:**
- Remove dev/prod distinction for tool discovery failures in `_check_services()`
- Update error message to be more accurate ("No MCP tools will be available this session")
- Ensure logging uses ERROR level for this condition

**Out-of-Scope:**
- Modifying the tool discovery mechanism itself
- Adding retry logic to tool discovery
- Changing the security audit or readiness check behavior

## Assumptions

1. Developers prefer to fail fast rather than start with zero tools and debug later
2. The error message should clearly state the consequence (no tools available) rather than the symptom (tool calls will fail)
3. A remediation hint helps developers resolve the issue quickly
