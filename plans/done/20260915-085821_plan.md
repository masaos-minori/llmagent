## Reason for change

"I ran the remediation steps once" or "the underlying check now passes" is the
intended stopping point — these are not always the same (e.g. Step 3's remediation
could still leave `lint-imports` failing if the contract update itself was wrong).

## Implementation intent

check now passes (not merely that the remediation procedure was run once), following
