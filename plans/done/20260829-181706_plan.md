5. Write tests in `tests/test_ingester_embedding.py`

## Risk Assessment

| Risk | Impact | Mitigation |
|------|--------|------------|
| Circular imports between new modules | High | Use dependency injection; avoid cross-module imports where possible |
| Breaking existing callers of `RagIngester` | High | Maintain public API contract; update callers incrementally |
| Loss of transactional integrity during split | High | Preserve `TransactionManager` as single source of truth for commits |
| Embedding cache inconsistency | Medium | Ensure `EmbeddingService` uses shared cache instance |
| Test flakiness due to async operations | Medium | Use deterministic mocks for time-dependent operations |
| Performance regression from delegation overhead | Low | Profile after each phase; compare against baseline |
