# Plan: Normalize all embedding request paths for Qwen3 raw-text embeddings

## Metadata

- **Generated at:** 20260802-102821
- **Source requirement:** requires/20260802-070538_require.md
- **Task type:** Refactoring (E5-era conventions removal)
- **Priority:** High

## Architecture Analysis

### Current architecture

Three independent embedding HTTP paths, each carrying E5-era conventions:

1. **RAG ingestion path:** `RagIngester._get_embedding()` — sends `"passage: {text}"`, validates dimension against `self._expected_dims` from `cfg.get("embedding_dims", 384)`
2. **RAG query path:** `rag.llm_client.get_embedding()` — sends `"query: {text}"`
3. **Agent memory path:** `EmbeddingClient.fetch()` → `_fetch_embedding()` — sends `{query_prefix}{text}` where `query_prefix="query: "`, validates dimension against `embed_dim=384`

All three paths are built on `EmbeddingClientConfig` dataclass which carries `query_prefix` and `embed_dim` fields.

### Target architecture

Single uniform contract across all paths: send raw text with no prefix. Remove all dimension-mismatch validation since dimension is now a fixed code constant. Fix the active bug in `config/ingester.toml` where `embed_url` already includes `/embedding` but `build_embed_url()` appends another one.
