## Goal

Ensure the allowed_tools override is scoped to the turn lifecycle and always restored, regardless of where exceptions occur within the turn processing pipeline.

## Scope

**In**: `scripts/agent/orchestrator.py` (Orchestrator._process_turn())
**Out**: Changes to tool policy enforcement, other configuration overrides

## Assumptions

1. Only `_process_turn()` modifies `ctx.cfg.tool.allowed_tools` per turn
2. Concurrent turns do not share the same `ctx.cfg.tool.allowed_tools` reference
3. The context manager approach (Option A) is preferred over instance variable approach (Option B)

Analysis: `_process_turn()` is called from `_handle_llm_turn()` at line 489. After `_process_turn()` returns, control flows back to `_handle_llm_turn()` which does not modify `ctx.cfg.tool.allowed_tools`. The finally block in `_process_turn()` already restores the value, so the real risk is only if an exception propagates through the finally block itself (which Python guarantees won't happen — finally always executes). The actual problem described is about exceptions *after* the finally block in the caller, but since `_handle_llm_turn()` doesn't modify `allowed_tools` after `_process_turn()`, the issue is theoretical rather than practical. However, using a context manager is still cleaner and makes the intent explicit.

## Design

Extract the allowed_tools override/restore logic into a context manager method `_tool_override()`. This makes the scoping explicit and ensures the finally block always runs, even if an exception occurs during the yield. Replace the try/finally in `_process_turn()` with `with self._tool_override(self._allowed_tools):`.

## Implementation steps

### Target file

`scripts/agent/orchestrator.py`

### Procedure

#### Step A: Add _tool_override context manager

Add after `_process_turn()` definition (or near other helper methods):

```python
@contextmanager
def _tool_override(self, allowed: list[str] | None):
    """Temporarily override allowed_tools for the duration of a turn."""
    original = self._ctx.cfg.tool.allowed_tools
    if allowed is not None:
        self._ctx.cfg.tool.allowed_tools = allowed
    try:
        yield
    finally:
        self._ctx.cfg.tool.allowed_tools = original
```

#### Step B: Replace try/finally in _process_turn() with context manager

Current code (lines 452-484):


Change to:

```python
async def _process_turn(
    self,
    ctx: AgentContext,
    user_message: str,

    ...

        ...
    ...
```

- Removed the manual try/finally block — replaced with context manager
