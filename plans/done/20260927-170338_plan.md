## Background
NC-031 (`docs/00_governance/governance_03_issue-and-uncertainty-management.md`) tracked
whether the front-matter `related` field and the body `## Related Documents` heading
were expected to match. During
`implementations/done/20260927-124641_01_docs_00_governance_governance_02_documentation-metadata.md.md`'s
execution, the owner ruled: this is drift, not intentional duality — front-matter
`related:` is authoritative, and body `## Related Documents` headings should be
reconciled to match it going forward. This Plan is the reconciliation work filed as a
follow-up from that cycle.

**Correction note (2026-09-27, this Plan's own Step 3a adversarial verification, before
`plan-to-implementation-procedure` began generating documents)**: this Plan's original
version claimed 42 divergent files based on a corpus-comparison script with two bugs —
(1) it treated the ADR documents' entire `## Related Documents` block (including
`### Specifications`/`### Operations`/etc. subsections) as a flat comparison list,
producing false-positive divergence for all 12 ADR-00X documents whose actual
`### Related ADRs` subsection in fact matches front matter; (2) it only recognized
`[text](path)`-style body links, missing the equally common bare `` `path` `` citation
style, undercounting real divergence elsewhere. Both bugs are fixed in this corrected
version: the ADR documents are now excluded from scope entirely (see Scope), and the
corrected scan found **64** genuinely divergent files (not 42) — a substantially
different file set, confirmed with the owner via this Plan's own re-verification cycle.

## Problem
A corrected full-corpus scan (Python script reading every `docs/*.md` file; extracting
the front-matter `related:` list; extracting the body `## Related Documents` section
only up to its first subsequent heading of any level; recognizing both
`[text](path)` and bare `` `path` `` body-reference styles; and excluding any file whose
`## Related Documents` section itself contains `### `-level subsections as
structurally non-comparable) found:
- 117 `docs/*.md` files have both a front-matter `related:` list and a body
  `## Related Documents` heading.
- 12 of those (all ADR documents, `ADR-001` through `ADR-014`) use a structured
  `## Related Documents` section (`### Related ADRs`, `### Specifications`,
  `### Operations`, `### Known Issues`, `### Implementation References` subsections) —
  excluded from this Plan's scope (see Scope).
- Of the remaining 105 flat-list files, **64 diverge** (the two lists are not the same
  set) and **37 already match**. 4 files have an empty or unparseable body list and are
  excluded from automated comparison (out of scope, per this Plan's In-Scope
  definition, which requires both fields present and comparable).
- Confirmed example: `docs/00_governance/governance_01_documentation-policy.md`:
  front matter lists `../00_index.md`, `../01_overview/overview_00_document-guide.md`;
  body lists `governance_02/03/04_*.md` and `../10_adr/adr-index.md` — no overlap.

## Reason for change
`docs/00_governance/governance_02_documentation-metadata.md`'s `related` field
description now states that front-matter `related:` is authoritative over the body
heading when they diverge, and points to this Plan's originating issue as the
follow-up. Leaving the 64 confirmed-divergent documents unreconciled means the stated
policy does not yet match actual document content.

## Implementation intent
For each of the 64 target files, replace the body `## Related Documents` heading's link
list so it contains exactly the same target set as the file's own front-matter
`related:` list (same relative paths). Link text (the visible title in each new/changed
body entry) and citation style (markdown link vs. backtick-only) are derived at
implementation time from each target file's own convention and the surrounding file's
existing style — this Plan does not pre-resolve titles or force a single citation
style, since that is per-target-file lookup work suited to the implementation phase.
Process files grouped by directory for review-sized batches, then run the two docs
checkers across all 64 as a final pass.

- `REQ-001`: For each of the 64 confirmed-divergent, flat-list `docs/*.md` files,
  reconcile the body `## Related Documents` heading's link list to exactly match the
  front-matter `related:` list.
