## Background
`docs/00_governance_01_documentation-policy.md`'s Document Classification defines a
"Reference" class (API/command/configuration reference material), but a proposed
documentation-slimming policy's mechanical-content removal criteria conflict with
hand-written Reference documents by design — their entire content is exactly the
kind of code-derivable listing the policy wants removed. Three options exist: (A)
retire the Reference class; (B) treat Reference documents as generated artifacts;
(C) keep the status quo and accept drift. `tools/generate_reference_table.py`
already implements option (B)'s pattern for MCP/RAG/deployment reference tables
(confirmed: guard-comment format `<!-- AUTO-GENERATED: <generator>.py <purpose>
-->`, e.g. `GUARD_START_MCP`/`GUARD_START_DEPLOYMENT`). `GV-021`
(`tools/check_docs_content_policy.py`) documents an intent to exempt this guarded
content, but confirmed: the exemption is currently implemented only in
`check_literal_port_number` (`tools/check_docs_content_policy.py:180-183`, checking
the literal string `"<!-- AUTO-GENERATED -->"`, which does not match the actual
`<!-- AUTO-GENERATED: gen_mcp_reference.py port-tool-reference -->` format) — a
separate issue (`issues/20260918-130159_docschk01_...`) already targets this fix.

## Problem
Without this decision, mechanical-content removal work cannot proceed against
Reference-class documents without first knowing whether their content should be
deleted, generated, or left alone.

## Reason for change
This decision gates several other follow-up items: extending
`tools/generate_reference_table.py`'s coverage
(`issues/20260918-130225_docsref01_...`), deciding which Reference documents are
in-scope for mechanical-content removal, and how `class: Reference` documents
should be detected (relates to
`issues/20260918-130249_docsmeta01_add-class-front-matter-field.md`).

## Implementation intent
Write an ADR under `docs/adr/`, following
`docs/00_governance_01_documentation-policy.md`'s ADR Section Header
Standardization (Context, Assumptions, Decision, Rationale, Alternatives
Considered, Consequences, Invariants, Verification, Implementation Notes, Known
Deviations, Review Triggers, Approval, Related Documents, Completion Checklist),
recommending Option B (generated artifact) on the grounds that it preserves the
"one place to look" value Reference documents provide while keeping the canonical
source unique, consistent with `GV-021`'s existing exemption precedent. Register
the new ADR in `docs/adr-index.md`'s ADR List, following its existing row format.
The ADR's own review/approval step decides the actual outcome — this Plan does not
force Option B.
