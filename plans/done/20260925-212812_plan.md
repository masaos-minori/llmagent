# Plan: Fix pre-commit hooks expecting non-existent docs/adr-index.md path

## Goal
Fix the path mismatch in pre-commit hooks `adr-invariant-matrix` and `adr-reference-scoped` which hardcode `docs/10_adr/adr-index.md` as the expected ADR index location, while the actual file resides at `docs/10_adr/adr-index.md` (the Issue's claim about `docs/adr-index.md` being the actual location was incorrect — the file was moved during a prior reorganization).

## Priority
High

## Scope
- **In-Scope**:
  - Update `tools/check_adr_invariant_matrix.py` to use `docs/10_adr/adr-index.md`.
  - Update `tools/check_adr_reference.py` to use `docs/10_adr/adr-index.md`.
  - Update error messages in both tools to reference the correct path.
- **Out-of-Scope**:
  - Moving the ADR index file back to `docs/adr-index.md`.
  - Restructuring the ADR directory layout beyond resolving this specific path mismatch.
  - Adding new ADR-related hooks or checks.
  - Modifying the content or schema of `adr-index.md`.

## Background
Two local pre-commit hooks invoke Python tools that check ADR infrastructure:
- `adr-invariant-matrix` runs `tools/check_adr_invariant_matrix.py`
- `adr-reference-scoped` runs `tools/check_adr_reference.py`

Both tools contain a hardcoded path check for `docs/10_adr/adr-index.md` (see `check_adr_invariant_matrix.py` line 116 and `check_adr_reference.py` line 163). However, the Issue incorrectly states the actual file exists at `docs/adr-index.md` — verification confirms the file is at `docs/10_adr/adr-index.md` and `docs/adr-index.md` does not exist on the filesystem.

The Issue also notes that multiple references across the codebase use `docs/adr-index.md` (without the `10_` prefix), including in TOOL_DESCRIPTIONS.md, ADR documents, and other governance documents. These references need to be unified.

## Problem
The pre-commit hooks enforce ADR-related invariants but cannot do so because they reference a non-existent file path. Every commit involving markdown files triggers hook failures, making the governance guardrails effectively disabled. This violates the principle that automated checks should block incorrect commits, not silently fail or require workarounds.

## Reason for Change
The hooks are designed to provide real governance value (verifying ADR invariant matrices and scoped ADR references). Fixing the path restores their functionality. Without this fix, the ADR governance layer has no automated enforcement at commit time.

## Implementation intent
Choose Approach 1 (move the file): Create `docs/10_adr/` directory if needed, move `docs/adr-index.md` to `docs/10_adr/adr-index.md`, and update all cross-references. This aligns the filesystem with the hooks' expectations and follows the repo's numbering convention for doc directories (`10_*` matches `00_governance/`, `21_rag/`, etc.).

However, verification shows `docs/10_adr/adr-index.md` already exists and `docs/adr-index.md` does not. Therefore, the approach is: update all references from `docs/adr-index.md` to `docs/10_adr/adr-index.md` across the codebase. No file movement is needed since the canonical location is already established.
