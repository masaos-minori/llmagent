## Design

Recommend Option B (exponential backoff):

```python
BG_FAILURE_THRESHOLD: int = 5  # unchanged

# In _handle_background_failure():
if self._consecutive_bg_failures == 1:
    logger.warning("Background task failed: %s", exc)
elif self._consecutive_bg_failures == BG_FAILURE_THRESHOLD:
    logger.error(
        "Consecutive background task failures (%d): %s",
        self._consecutive_bg_failures,
        exc,
    )
elif self._consecutive_bg_failures > BG_FAILURE_THRESHOLD and \
     self._consecutive_bg_failures % 5 == 0:
    logger.error(
        "Continued background task failures (%d): %s",
        self._consecutive_bg_failures,
        exc,
    )
```

This logs:
- Warning at first failure
- Error at 5th consecutive failure
- Error every 5 failures after that (10, 15, 20, ...)
