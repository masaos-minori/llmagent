## Design

Replace:
```python
def _clear_previous_turn_ephemeral_messages(self) -> None:
    ctx.conv.history = [
        m
        for m in ctx.conv.history
        if not m.get("_ephemeral") and not m.get("_memory_injected")
    ]
```

With:
```python
_EPHEMERAL_KEYS = frozenset({"_ephemeral", "_memory_injected", "_skill_ephemeral"})

def _clear_previous_turn_ephemeral_messages(self) -> None:
    ctx.conv.history = [
        m
        for m in ctx.conv.history
        if not any(k in _EPHEMERAL_KEYS for k in m.keys())
    ]
```
