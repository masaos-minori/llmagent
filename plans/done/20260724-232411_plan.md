## Design

Add `self._on_error(exc)` call in `_discard_and_log` when `self._consecutive_bg_failures == 1`, right before the log warning. This surfaces the error to the user via the existing error notification mechanism. No new methods or flags needed — reuse existing infrastructure.

        """Callback for first-turn background task completion."""
        exc = task.exception()

Change to:

```python
    def _discard_and_log(self, task: asyncio.Task[Any]) -> None:
        """Callback for first-turn background task completion."""
        exc = task.exception()
        if exc is not None:
            if isinstance(exc, asyncio.CancelledError):
                # Task was cancelled — reset counter, do not log as error.
                self._consecutive_bg_failures = 0
            else:
                self._consecutive_bg_failures += 1
                if self._consecutive_bg_failures == 1:
                    # Surface first-turn failure to user via the error callback
                    if self._on_error:
                        self._on_error(exc)
                    logger.warning("First background task failure: %s", exc)
                elif self._consecutive_bg_failures >= BG_FAILURE_THRESHOLD:
                    logger.error(
                        "Consecutive background task failures (%d): %s",
                        self._consecutive_bg_failures,
                        exc,
                    )
                else:
                    logger.warning(
                        "Background task failure #%d: %s",
                        self._consecutive_bg_failures,
                        exc,
                    )
        else:
            # Task completed successfully — reset counter
            self._consecutive_bg_failures = 0
        self._background_tasks.discard(task)
```

Key points:
- Added `if self._on_error: self._on_error(exc)` at the first-failure branch
- Call happens before logging — user sees the error message immediately
- Idempotent by design — only fires once because `_consecutive_bg_failures` increments past 1
- Reuses existing `_on_error` callback — no new methods or flags needed
