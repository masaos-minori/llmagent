## Goal

Ensure the allowed_tools override is scoped to the turn lifecycle and always restored, regardless of where exceptions occur within the turn processing pipeline.

## Scope

**In**: `scripts/agent/orchestrator.py` (Orchestrator._process_turn())
**Out**: Changes to AgentConfig internals, other configuration override patterns

## Assumptions

1. `_process_turn()` is called sequentially per turn (no concurrent turns)
2. The context manager approach is acceptable for scoping configuration changes
3. `ctx.cfg.tool.allowed_tools` is a mutable reference that can be safely overridden

## Implementation Steps

1. Create a context manager method `_tool_override(self, allowed: list[str] | None)` using `@contextmanager`:
   ```python
   @contextmanager
   def _tool_override(self, allowed: list[str] | None):
       original = self._ctx.cfg.tool.allowed_tools
       if allowed is not None:
           self._ctx.cfg.tool.allowed_tools = allowed
       try:
           yield
       finally:
           self._ctx.cfg.tool.allowed_tools = original
   ```
2. Replace the try/finally in `_process_turn()` with `with self._tool_override(self._allowed_tools):`.
3. Remove the `original_allowed` local variable and the explicit restoration at line 482.
4. Verify the context manager handles all code paths including early returns inside the `with` block.
