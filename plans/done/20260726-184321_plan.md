## Goal

Add TTL (Time-To-Live) to pending approvals so expired approvals are rejected during session startup.

## Scope

**In-Scope:**
- Add `expires_at` field to `ApprovalRecord` model
- Update `find_all_pending_approvals()` to filter out expired approvals
- Update `_recover_pending_approvals()` to reject expired approvals with warning

**Out-of-Scope:**
- Database migration for existing records (handled separately)
- Any changes beyond this TTL feature

## Assumptions

1. Default TTL can be configured via settings
2. Existing pending approvals without `expires_at` should be treated as non-expired (backward compatible)
3. The TTL is based on creation time + configurable duration

2. Update `find_all_pending_approvals()`:
```python
def find_all_pending_approvals(db: SQLiteHelper) -> list[ApprovalRecord]:
    results = []
    now = datetime.now(timezone.utc).isoformat()
    for r in db.fetch_all(...):
        if r.get("expires_at") and r["expires_at"] < now:
            continue  # skip expired
        results.append(...)
    return results
```

3. Update `_recover_pending_approvals()`:
```python
async def _recover_pending_approvals(self) -> None:
    results = find_all_pending_approvals(store.get_connection())
    if not results:
        return
    task_id, approval = results[-1]
    if approval.expires_at and approval.expires_at < now():
        logger.warning("Recovered approval has expired; rejecting")
        return
    ctx.workflow.approval_pending = True
    ctx.turn.pending_approval_id = approval.approval_id
```
