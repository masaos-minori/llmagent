## Problem
Confirmed by reading `tools/check_docs_content_policy.py`: `check_index_table`
(lines 134-151) only matches a table header naming Function/Method/Class alongside
Signature/Description (`_INDEX_TABLE_HEADER_RE`, lines 44-47) — it does not match a
plain field/type/default-value table. `check_full_file_tree` (lines 77-111) only
fires near a File Structure/Directory/File Tree heading
(`_FILE_TREE_HEADING_RE`, lines 37-40). No existing `check_*` function detects:
default-value restatement outside a table, a configuration-file-to-doc
correspondence table, a CLI-command enumeration, environment-setup command
sequences, or a DDL/schema block restated in prose.

Separately, confirmed: `check_literal_port_number`'s auto-generated-block
exemption (lines 180/183: `if "<!-- AUTO-GENERATED -->" in line:` /
`if "<!-- END AUTO-GENERATED -->" in line:`) does not match the actual
guard-comment format `tools/generate_reference_table.py` emits
(`GUARD_START_MCP = "<!-- AUTO-GENERATED: gen_mcp_reference.py
port-tool-reference -->"`, confirmed at `tools/generate_reference_table.py:48-51`)
— the END marker literal string does match (`GUARD_END = "<!-- END AUTO-GENERATED
-->"`, confirmed identical), but the START marker does not, so a guarded block
using the real generator output is treated as still "outside" a guard from the
moment its END comment is read backwards — in practice, since `in_auto_generated`
never becomes `True`, the entire guarded region is scanned as ungenerated. Only
`check_literal_port_number` has any guard-awareness; `check_full_file_tree`,
`check_index_table`, and `check_location_mapping` have none.

## Reason for change
A second, separately-registered tool covering overlapping ground duplicates
`GV-021`'s existing role in the Governance Verification Matrix and its existing
Warning/`report_and_exit` conventions.

## Implementation intent
Add new check functions to `tools/check_docs_content_policy.py`, following its
existing pattern (one `check_*(files: list[DocFile]) -> list[Issue]` function per
category, each appended to `main()`), for: default-value restatement, plain
field/type/default tables, configuration-file inventory correspondence tables,
CLI-command enumerations, environment-setup command sequences, and DDL/schema
blocks. Extract the guard-comment detection into a shared helper recognizing any
line starting with `<!-- AUTO-GENERATED` (not only the exact bare string), and
apply it consistently to every guard-aware check, including the 3 existing checks
that currently have none. Keep each new check's severity `WARNING`.
