## Design

Add timeout to PASSIVE checkpoint:
```python
WAL_CHECKPOINT_TIMEOUT_SEC = 5

def _wal_checkpoint_sync(self) -> tuple[bool, list[tuple[str, str]]]:
    ...
    try:
        await asyncio.wait_for(db.checkpoint("PASSIVE"), timeout=WAL_CHECKPOINT_TIMEOUT_SEC)
        logger.info("WAL checkpoint completed (PASSIVE) on shutdown")
        return True, errors
    except asyncio.TimeoutError:
        logger.warning("WAL PASSIVE checkpoint timed out, falling back to TRUNCATE")
    except sqlite3.Error as passive_err:
        ...
```

Note: Since `_wal_checkpoint_sync()` runs synchronously in executor, need to use threading timer instead:
```python
import threading

def _check_wal_timeout(timeout_sec: float) -> bool:
    """Return True if timeout elapsed, False otherwise."""
    event = threading.Event()
    def _set():
        time.sleep(timeout_sec)
        event.set()
    t = threading.Thread(target=_set, daemon=True)
    t.start()
    return event.wait(timeout=timeout_sec)
```

Or simpler approach using signal-based timeout for synchronous code.
