## Implementation Steps

### Phase 1: Verify no new callers have appeared

2. If callers exist, evaluate whether to proceed with removal or switch to the "reinstated caller" branch.

### Phase 2: Remove dead members from `McpServerHealthRegistry`
1. Delete `record_degraded(self, server_key, reason=None)` method from `scripts/shared/mcp_health.py`.
2. Delete `get_degraded_reason(self, server_key)` method from `scripts/shared/mcp_health.py`.
3. Delete `self._degraded_reasons: dict[str, str] = {}` from `__init__`.
4. Delete `self._degraded_reasons.pop(server_key, None)` from `record_success()`.
5. Review module/class docstrings in `mcp_health.py` for references to the degraded-reason mechanism and update accordingly.

### Phase 3: Simplify `_write_servers_in_state()` in cmd_mcp.py
1. Remove `reason = registry.get_degraded_reason(key) if registry else None` from `_write_servers_in_state()`.
2. Remove `reason_str = f": {reason}" if reason else ""`.
3. Change `f"    [{label.upper()}] {key}{reason_str}"` to `f"    [{label.upper()}] {key}"`.

### Phase 4: Update tests
1. Remove `tests/shared/test_mcp_health_degraded.py` entirely (it exercises only the removed methods).
2. Update `tests/agent/commands/test_cmd_mcp.py` to stop mocking `get_degraded_reason` and assert plain `[DEGRADED] {key}` output without reason suffix.

### Phase 5: Validate
1. Run `uv run pytest` to confirm full test suite passes.
2. Specifically verify no regressions in:
