## 1. Goal
Introduce a shared base class/mixin carrying the `repo_path` field across all 10 Pydantic request models in `git_models.py`, reducing remaining duplication while ensuring byte-identical JSON Schema output before and after the change.

## 2. Scope
- **In-Scope**: Introducing a mixin/base class for `repo_path` field in git_models.py's 10 request models; schema-diff verification against baseline; validation of downstream consumers.
- **Out-of-Scope**: Changing any model's runtime validation behavior (field name, type, requiredness); modifying git_server.py or git_tools.py beyond what's necessary for schema compatibility; extending to other MCP servers' models.

## 3. Assumptions
- The existing `_REPO_PATH_DESC` constant (`"Absolute path to the git repository"`) will remain unchanged.
- Pydantic v2's `model_json_schema()` behavior with inheritance can be controlled via `model_config` settings (e.g., `populate_by_name`).
- The `TOOL_LIST` in `git_tools.py` is the primary consumer of these models' schemas and must not change shape.
- No caller relies on the exact structure of `model_fields` ordering for any of the 10 models.

## 8. Risks & Mitigations
- **Risk**: Pydantic v2 generates different JSON Schema structure when fields come from a base class (e.g., `$defs`/`allOf` referencing). → **Mitigation**: Phase 2 includes explicit schema-diff verification; proceed only if diff shows zero unintended changes or acceptable restructuring.
- **Risk**: `model_fields` ordering changes affect downstream consumers relying on field order. → **Mitigation**: Secondary baseline captures `model_fields` key ordering; diff against it.
- **Risk**: MCP clients parse the JSON Schema structure (not just tool names/descriptions) and break on structural changes. → **Mitigation**: Phase 3 includes explicit verification of `TOOL_LIST` compatibility; document any structural differences.
- **Risk**: Adding inheritance breaks existing imports or subclassing patterns. → **Mitigation**: Only 10 models affected; verify each model's public API remains identical.
