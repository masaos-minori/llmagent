## Goal

Improve config loading error messages by wrapping them with user-friendly framing including the config file path and error class name.

## Scope

**In-Scope**:
- Wrap `build_agent_config()` call in `AgentContext.__init__()` with try/except
- Re-raise with formatted message containing config file path and error class name

**Out-of-Scope**:
- Modifying `ConfigLoadError` or `build_agent_config()` itself
- Adding new configuration options
- Changing other startup error handling

## Assumptions

1. `ConfigLoadError` wraps the original exception as `cause`; `e.__class__.__name__` returns "ConfigLoadError".
2. The config file path can be derived from `ConfigLoader().load_all()` source; using `/opt/llm/config/agent.toml` as default is acceptable.
3. The error message format follows the pattern: `"Failed to load agent config ({path}): {error_class}: {message}"`.
