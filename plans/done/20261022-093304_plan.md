## Background
`governance_04_documentation-checks.md` states that `--domain` accepts only agent, mcp, rag, deployment, and overview, so EventBus and Shared/DB documents are not covered. `docs/` contains `24_eventbus/`, `40_shared/`, and `41_db/`, and `governance_05` lists EventBus and Shared/DB among the five in-scope nodes of the change-impact graph. The tool maps each domain to a docs subfolder (`DOMAIN_SUBFOLDERS`) and runs a generic check set.

## Problem
Doc claims in the three uncovered folders (links, `scripts/` path references, function references, command drift) are never cross-checked by this tool. The governance document records the gap as a fact, not as a decision, so it is unknown whether the gap is deliberate.

## Reason for Change
These documents carry ownership and DB-boundary claims. Without an automated cross-check, stale references go unnoticed, and the docs cleanup verification had to leave them unrun.

## Implementation Intent
Measurement on live data (Step 3 of this plan cycle) shows the five generic checks already run on every domain and produce no errors on the three folders and four warnings in total. Adding the domains is therefore a registration-only change: extend the domain keys and subfolder map, extend the argparse choices through the existing `DOMAIN_PREFIXES` keys, and add no new `elif` branch because no domain-specific check exists. Record the decision in `governance_04`. If the owner instead prefers no coverage, the same governance statement is rewritten as a design decision and the tool and test steps are dropped (UNK-01).

## Design
- Path B (more than three files; the `--domain` CLI contract gains values).
- `main()` hardcodes the five generic checks for every domain and only branches by domain for domain-specific checks. `DOMAIN_GENERIC_CHECKS` is defined but referenced nowhere else in the repository, and `DOMAIN_PREFIXES` values are used only as a key set for `choices`. New domains therefore need table entries only; no `elif` branch is added (this also avoids raising `main()`'s cyclomatic complexity, currently grade D).
- Dry measurement (current code, read-only): `24_eventbus` 13 files, `40_shared` 9 files, `41_db` 8 files; links, removedfiles, commanddrift, filerefs report 0 findings; funcrefs report 4 warnings (`to_thread()`, `isinstance()`, `copy2()` are stdlib names; `_insert_chunk()` has no matching `def` under `scripts/`).
- Decision framing: UNK-01 keeps the owner decision explicit rather than assumed.
