## Background
`uv` deprecated the `UV_NATIVE_TLS` environment variable and recommends `UV_SYSTEM_CERTS` instead. Every deploy script sets `UV_NATIVE_TLS=true` immediately before `uv run python ...`. Because AgentREPL startup runs `uv` through these scripts, the deprecation warning is emitted on every startup. The workflow validation step does not trigger the warning (it runs `uv` differently), which is why the warning is observed specifically during AgentREPL startup.

The four deploy scripts are the only locations in the repository that set `UV_NATIVE_TLS`. No documentation currently references either variable.

## Problem
Startup output includes:

```
warning: The `UV_NATIVE_TLS` environment variable is deprecated and will be removed in a future release. Use `UV_SYSTEM_CERTS` instead.
```

This appears during AgentREPL startup. When a future `uv` release removes `UV_NATIVE_TLS`, the deploy scripts break.

## Reason for change
The deprecated variable will break in future `uv` versions. Replacing it now avoids future breakage and removes the per-startup deprecation warning. `UV_SYSTEM_CERTS` is uv's recommended replacement and provides equivalent system-certifact-handling behavior.

## Implementation intent
A uniform find-and-replace of `UV_NATIVE_TLS=true` → `UV_SYSTEM_CERTS=true` across the four deploy scripts. Each occurrence is preceded by a `PYTHONPATH="${...}"` assignment; that prefix is preserved. No logic, control flow, or other settings change.

## Design
This is a data-only, mechanical rename of one environment-variable name across four shell scripts. None of the four files is part of the Python import-layer architecture (they are orchestration/deploy scripts invoked by the shell), so the Path B architecture and dependency-graph analyses are N/A: there are no `import` boundaries, module cycles, or Python symbols involved. The historical and operational analyses are likewise minimal — this is not a regression, no dependency version is changing (so `pip-audit` is not applicable), and no database/MCP lock is held at planning time.

The change is a uniform textual substitution `UV_NATIVE_TLS=true` → `UV_SYSTEM_CERTS=true`. Each occurrence is immediately preceded by a `PYTHONPATH="${...}"` assignment; the substitution touches only the variable name, leaving the `PYTHONPATH` prefix intact (REQ-005). The three `echo` example lines in `setup_services.sh` (112-114) are updated together with the executable lines so user-facing copy-paste guidance does not retain the deprecated variable.
