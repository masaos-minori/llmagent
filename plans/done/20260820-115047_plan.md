   - [ ] Read current tools/check_docs_consistency.py to understand main() signature and argument handling.

2. **Phase 2: Core Logic Implementation**
   - [ ] Add main_mcp() and main_agent() wrapper functions to tools/check_docs_consistency.py.
     **Bug found in the source requirement's own proposed code during
     implementation-procedure review**: the requirement's suggested
     `return main((argv or []) + ["--domain", "mcp"])` silently drops real CLI
     arguments (e.g. `--skip ...`) when invoked as a console-script, because
     setuptools' generated entry-point wrapper calls `main_mcp()` with no arguments, so
     `argv` is always `None` there — `sys.argv[1:]` (the actual CLI args) is never
     consulted. Use instead:
     ```python
     def main_mcp(argv: list[str] | None = None) -> int:
         return main((argv if argv is not None else sys.argv[1:]) + ["--domain", "mcp"])

     def main_agent(argv: list[str] | None = None) -> int:
         return main((argv if argv is not None else sys.argv[1:]) + ["--domain", "agent"])
     ```
     (`sys` is already imported in this file.) This satisfies this plan's own Risk #1
     ("wrappers may not correctly pass through additional CLI arguments") for real,
     rather than only in the case where `argv` happens to be explicitly passed (e.g. in
     a test calling `main_mcp(["--skip", "portdrift"])` directly, which the
     requirement's original form would have passed too, masking the bug).
   - [ ] Add `check-mcp-docs = "tools.check_docs_consistency:main_mcp"` and
     `check-agent-docs = "tools.check_docs_consistency:main_agent"` to pyproject.toml's
     `[project.scripts]` table (a restoration/addition, not an edit of an existing line
     — see Assumptions).
   - [ ] **Corrected**: `rules/toolchain.md` does not currently mention `check-mcp-docs`/
     `check-agent-docs` at all (see Assumptions) — add a brief mention of the two
     restored convenience commands in its "Documentation consistency" section,
     alongside the existing `uv run python tools/check_docs_consistency.py --domain
     <domain>` form.
