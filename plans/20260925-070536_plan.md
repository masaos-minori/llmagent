## Goal
Move 14 ADR files from `docs/adr/` plus `docs/adr-index.md` into a new `docs/10_adr/` subfolder, folding the existing subfolder into the area-numbered scheme.

## Priority
Medium

## Scope

## Background
Same `docs/` reorganization effort as `docsreorg05`; see that issue's Background for full context. This issue covers the `10_adr` area — the only area move that changes an *existing* subfolder's name (`docs/adr/` → `docs/10_adr/`), not a flat-to-subfolder move.

## Problem
`docs/adr/ADR-001-workflow-engine-mandatory.md` through `ADR-015-...md` (14 files, IDs 001-010, 012-015 — ADR-011 does not exist, it was merged into ADR-008 per an earlier, unrelated decision) live in `docs/adr/`, and `docs/adr-index.md` lives directly under `docs/`. `tools/check_adr_structure.py` and `tools/check_known_deviation_sync.py` have `ADR_DIR` constants pointing at `docs/10_adr/` per `docsreorg02`; `.github/workflows/governance-docs-consistency.yml` still references `docs/adr/*.md`.

## Reason for change
Same rationale as `docsreorg05`: fold this existing subfolder into the new area-numbered scheme so `docs/` has one consistent top-level structure.

## Implementation intent
Use `git mv` only — do not rename any file (the `ADR-NNN-slug.md` names are unaffected, and `adr-index.md` keeps its current bare name). Move the entire contents of `docs/adr/` plus `docs/adr-index.md` into `docs/10_adr/`.

## Requirements
- `REQ-001`: All 14 ADR files must be moved to their correct destinations using `git mv`.
- `REQ-002`: `docs/adr-index.md` must be moved to `docs/10_adr/adr-index.md`.
- `REQ-003`: Test baseline `EXPECTED_WITHIN_FILE_PAIRS` must be updated for the 54 entries keyed to ADR files (ADR-001 through ADR-010, ADR-012 through ADR-014; confirmed during adversarial validation).
