## Problem
Adversarial verification (Step 2) confirmed, via a full read of
`skills/python-code-review/workflow.md` lines 1-130: Phase 1 (line 35) and Phase 10
each already have an explicit "Completed when" line, but Phase 2 (lines 43-53), Phase 3
(55-62), Phase 4 (64-71), Phase 5 (73-82), Phase 6 (85-92), Phase 7 (94-101), Phase 8
(103-110), and Phase 9 (112-118) each present a "Do:" checklist (or, for Phase 8/9, an
equivalent per-finding/per-report requirement list) with no stated completion
condition. This matches the Issue's claim exactly.

## Reason for change
A checklist Phase with no completion condition risks an agent treating "I read the
list" as equivalent to "I checked every item against the actual diff" — the two are
not the same, and only the latter is the intended completion state.

## Implementation intent
Add one "Completed when" line to each of Phase 2 through 9, stating that every "Do:"
item in that Phase has been checked against the actual diff (not merely read),
following Phase 1/Phase 10's existing phrasing style.

## Requirements
- `REQ-001`: Phase 2 — add "**Completed when**: every check above has been applied to
  each changed function in the diff, and `ruff check`/`mypy`/`pyright` have been run on
  touched files."
- `REQ-002`: Phase 3 — add "**Completed when**: dependency direction and
  abstraction-introduction checks have been applied to every changed import/interface
  in the diff."
- `REQ-003`: Phase 4 — add "**Completed when**: every changed `async def`/
  resource-acquiring code path in the diff has been checked for blocking calls and
  cleanup on both normal and exception paths."
- `REQ-004`: Phase 5 — add "**Completed when**: every changed error-handling/config/
  logging code path has been checked, and `bandit` has been run where available."
- `REQ-005`: Phase 6 — add "**Completed when**: test coverage has been checked for
  every critical/edge/failure path touched by the diff, and `pytest` has been run to
  confirm the claimed pass/fail state."
- `REQ-006`: Phase 7 — add "**Completed when**: every doc claim about the changed
  behavior has been checked against the current implementation, not against a
  prior-version recollection."
- `REQ-007`: Phase 8 — add "**Completed when**: every finding carried forward from
  Phases 2-7 has concrete evidence, an evidence label/confidence level, and a severity
  assigned."
- `REQ-008`: Phase 9 — add "**Completed when**: the report follows `SKILL.md`'s Output
  Format, findings are grouped by severity, and no style-only issue is over-reported."
