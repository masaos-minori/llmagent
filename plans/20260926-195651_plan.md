# Governance Verification Matrix — GV-008 / GV-009 ステータスと Follow-up の矛盾

## Goal

Resolve the status inconsistency between the Governance Verification Matrix and the Follow-up Work Needed section for GV-008 and GV-009 in `governance_04_documentation-checks.md`: the Matrix marks both as `Existing` but the Follow-up list still contains implementation tasks for each.

## Priority
Medium

## Scope
- **In-Scope**: Evaluating the current coverage of `check_issue_inventory_conformance.py` and `check_needs_confirmation_inventory.py`; updating either the Matrix Status or the Follow-up Work Needed section to reflect the true state
- **Out-of-Scope**: Modifying the tools' functionality; changing any other rule's status

## Background
- GV-008: "Issue inventory conformance: vocabulary, template, referential integrity" — Matrix shows `Existing`, Follow-up shows `Broaden to cover full issue inventory conformance scope (vocabulary, template, referential integrity)`
- GV-009: "Needs Confirmation owner and deadline" — Matrix shows `Existing`, Follow-up shows `Implement Needs Confirmation owner and deadline validation`

Both tools exist (`check_issue_inventory_conformance.py`, `check_needs_confirmation_inventory.py`) but the Follow-up lists additional implementation tasks.

## Problem
The Matrix Status is `Existing` but the Follow-up contains incomplete tasks, making it unclear what the existing tool covers versus what remains unimplemented.

## Reason for change
Resolving the status/Follow-up contradiction ensures implementers can accurately determine the implementation scope.

## Implementation intent
Evaluate the current coverage of each tool and reconcile the status/Follow-up mismatch by one of the following approaches:
1. Remove the GV-008/GV-009 entries from the Follow-up Work Needed section (if fully implemented)
2. Update the Matrix Status to `Partial` (if partially implemented)
3. Modify the Follow-up Work Needed descriptions to match the current state
