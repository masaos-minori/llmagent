# Plan: AppServices validates required services are non-None

## Goal
- Ensure `AppServices.__init__()` rejects `None` values for required services, preventing silent creation of invalid objects.

## Priority
Low

## Scope
- **In-Scope**: Add constructor validation for required services; update docstring to clarify required vs optional
- **Out-of-Scope**: Changes to service initialization order in `factory.py`; changes to type annotations

## Background
`AppServices` in `scripts/agent/context.py` represents fully-initialized service references built by `factory.py`. Its docstring states: "All required services are non-None."

## Problem
The constructor accepts `None` for all parameters including required ones (`http`, `llm`, `tools`, `lifecycle`, `hist_mgr`, `audit_logger`). There is no runtime validation that required services are present. A caller passing `None` for a required service creates an invalid object. Errors manifest later at access time, far from the root cause. Type hints suggest required services but enforcement is absent.

## Reason for change
Silent creation of invalid objects is a reliability concern. Errors manifesting far from the root cause make debugging difficult. Runtime validation provides early failure detection.

## Implementation intent
Add validation in the constructor for required services. Raise `RuntimeError` when any required service is `None`. Update docstring to clarify which services are optional vs required.

## Requirements
- `REQ-001`: Constructor raises `RuntimeError` when any required service is `None`
- `REQ-002`: Test verifies error message includes the service name
- `REQ-003`: Existing callers reviewed for compatibility
- `REQ-004`: Docstring updated to clarify which services are optional vs required

## Design
### Current Behavior (Verified Against Source)
1. `context.py` line 256-281: `AppServices.__init__()` accepts all parameters without validation
2. Line 264: `memory: MemoryServices | None` has NO default value — technically required despite being documented as optional
3. No validation of any required parameter — silently accepts `None`

### Proposed Change
```python
class AppServices:
    """Fully-initialized service references built by factory.py.

    Required services (must be non-None): http, llm, tools, lifecycle, hist_mgr, audit_logger
    Optional services (may be None): memory, health_registry, gateway, runtime_tools
    """

    def __init__(
        self,
        http: httpx.AsyncClient,
        llm: LLMClient,
        tools: ToolExecutor,
        lifecycle: LifecycleManagerProtocol,
        hist_mgr: HistoryManager,
        audit_logger: Logger,
        memory: MemoryServices | None,
        health_registry: McpServerHealthRegistry | None = None,
        gateway: RepositoryGateway | None = None,
        runtime_tools: RuntimeToolRegistry | None = None,
    ) -> None:
        """Initialize all required service references for the agent runtime."""
        required = {
            "http": http,
            "llm": llm,
            "tools": tools,
            "lifecycle": lifecycle,
            "hist_mgr": hist_mgr,
            "audit_logger": audit_logger,
        }
        for name, value in required.items():
            if value is None:
                raise RuntimeError(f"Required service '{name}' is None")
        self.http = http
        self.llm = llm
        self.tools = tools
        self.lifecycle = lifecycle
        self.hist_mgr = hist_mgr
        self.audit_logger = audit_logger
        self.memory = memory
        self.health_registry = health_registry
        self.gateway: RepositoryGateway | None = gateway
        self.runtime_tools: RuntimeToolRegistry | None = runtime_tools
        self.serialization_events: int = 0
        self.serialization_tools_affected: int = 0
```

Key changes:
1. Add `_REQUIRED_SERVICES` dict mapping names to values
2. Iterate over required services and validate each is non-None
3. Update docstring to explicitly list required vs optional services
