# Work Plan: Fix Command Whitelist Symlink Bypass

## Goal

Resolve symlinks before checking against the whitelist, and raise an error when `cfg.cmd[0]` is empty or invalid.

## Scope

- Modify `scripts/agent/http_lifecycle.py` to resolve symlinks before whitelist check
- Ensure proper error handling for empty/invalid commands

## Assumptions

1. The current `_ALLOWED_COMMANDS` whitelist exists but doesn't resolve symlinks
2. Adding symlink resolution won't break existing functionality
3. Raising errors for empty/invalid commands is acceptable behavior

## Unknowns

1. **Are there any legitimate use cases for symlinked commands?** May need to allow specific symlinks.
2. **What is the impact of resolving symlinks on cross-platform compatibility?** Need to test on Windows/macOS/Linux.
3. **Is there a performance impact from resolving symlinks?** May affect startup time.

## Affected Areas

- `scripts/agent/http_lifecycle.py` — Core logic change
- `tests/test_http_lifecycle.py` — New test coverage

## Design

### Approach: Add symlink resolution and error handling

After reviewing the code, the current implementation has a symlink bypass vulnerability. Need to add symlink resolution and improve error handling.

### Implementation Steps

#### Step 1: Add symlink resolution and absolute path validation

Replace the current check:

```python
cmd_basename = os.path.basename(cfg.cmd[0])
if cmd_basename not in self._ALLOWED_COMMANDS:
    logger.warning(...)
    return  # Silent failure
```

With:

```python
# Resolve symlinks to prevent bypass and get absolute path
cmd_path = os.path.realpath(cfg.cmd[0])

# Verify the resolved path exists and is a regular file
if not os.path.isfile(cmd_path):
    raise HttpStartupError(
        f"Command not found or not a regular file: {cfg.cmd[0]}"
    )

# Check against whitelist using the full absolute path
if cmd_path not in self._ALLOWED_COMMANDS:
    raise HttpStartupError(
        f"Command '{cfg.cmd[0]}' (resolved to '{cmd_path}') is not in the allowed commands list."
    )
```

#### Step 2: Add empty command check

Add check for empty `cfg.cmd`:

```python
if not cfg.cmd or not cfg.cmd[0]:
    raise HttpStartupError("Empty command configuration")
```

#### Step 3: Add tests

- Test that symlinked commands are blocked
- Test that empty commands raise errors
- Test that non-existent commands raise errors

## Validation Plan

1. Unit tests: Verify each security scenario works correctly
2. Integration tests: Verify normal command startup still works
3. Manual testing: Test with various symlink configurations
4. Regression testing: Verify no breaking changes

## Risks

| Risk | Mitigation |
|------|------------|
| Legitimate symlinked commands may be blocked | Users must add the resolved absolute path to the whitelist instead of just the basename |
| Cross-platform compatibility issues | Test on all supported platforms before deployment |
| Performance impact from symlink resolution | Monitor startup time; consider caching resolved paths |
