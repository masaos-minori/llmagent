# Plan: Add guard tests for dlq write-failure, helper reuse_connection, and chunk_splitter output

## Goal

Add three characterization/guard tests confirmed still missing after re-verifying the
original 9-target requirement against current code: `dlq.py::promote_single()`'s
DB-non-update-on-write-failure invariant, `db/helper.py`'s `reuse_connection` behavior,
and `chunk_splitter.py::process_file()`'s end-to-end chunk output — establishing
behavioral baselines before any future refactor of these paths, with no production code

## Assumptions

- `dlq.py::promote_single()` (not `promote_batch`, though both share the same
  write-then-update pattern) is the right target for the guard test: it is the
  inline/single-event path exercising the same `_atomic_write()` → `UPDATE ... SET
  dlq_at` sequence, and is simpler to set up than the batch path.
- `SQLiteHelper._connect()` can be monkeypatched or its call count tracked to verify
  `reuse_connection=True` skips it on a second `open()` call — confirmed by reading
  `scripts/db/helper.py:166-195` in full.
- `chunk_splitter.py::process_file()` dispatches internally to
  `ChunkEnglishMixin`/`ChunkJapaneseMixin` methods (both mixed into the same class per
  `scripts/rag/ingestion/chunk_splitter.py`'s class definition), so a single
  `process_file()` test with mixed English/Japanese input content exercises all three
  files without needing separate per-language test files.

## Design

1. **`dlq.py`** (`tests/eventbus/test_eventbus_dlq.py`):
   - `test_atomic_write_failure_leaves_db_row_unchanged` — insert a live event row,
     monkeypatch `eventbus.dlq._atomic_write` to raise `OSError`, call
     `promote_single(db, deadletter_dir, event_id)` inside `pytest.raises(OSError)`,
     then query the row and assert `dlq_at IS NULL` (unchanged).
2. **`db/helper.py`** (`tests/db/test_sqlite_helper.py`):
   - `test_reuse_connection_skips_reconnect` — call `.open(reuse_connection=True)`
     twice on the same `SQLiteHelper` instance; assert `helper.conn` is the *same
     object* (`is`) after the second call, and that `_connect()` was not called a
     second time (patch/spy on `self._connect`).
   - `test_reuse_connection_skips_close_on_exit` — use `with
     helper.open(reuse_connection=True): ...`; after the `with` block exits, assert
     `helper.conn is not None` and a subsequent query on `helper.conn` still succeeds
     (connection was not closed).
3. **`chunk_splitter.py`** (`tests/rag/ingestion/test_chunk_splitter.py`):
   - `test_process_file_end_to_end_mixed_language` — write a small temp file mixing
     English and Japanese headed sections, call `process_file(path)`, and assert on the
     actual returned/stored chunk count, that each chunk's `source_path`/heading
     metadata is correct, and that concatenating all chunks' content reproduces the
     original text with no loss or duplication (exact assertion shape depends on
     `process_file()`'s actual return type — inspect its signature before writing the
     test body, since Design here specifies intent, not exact code).
