## 6. Design
### Core Problem
The current implementation has two critical issues:
1. **Brittle Cache Handling**: `SemanticCache` uses hard exceptions for dimension mismatches, forcing the caller to manage these critical runtime issues rather than treating them as simple cache misses.
2. **Redundant Orchestration**: Multiple code paths exist for searching, leading to potential inconsistencies in how errors are caught and how diagnostics are reported.

### Solution: Graceful Degradation + Consolidated Search

#### Step 1: Modify `SemanticCache.lookup()` to Return `None` on Mismatch

```python
def lookup(self, embedding: list[float], history_context: str = "") -> str | None:
    """Return cached context for the nearest embedding with matching history_context, or None on miss.

    Returns None if embedding dimension differs from stored entries (treated as cache miss).
    """
    with self._lock:
        if self._dim is not None and len(embedding) != self._dim:
            logger.warning(
                "SemanticCache dimension mismatch: expected %d, got %d",
                self._dim, len(embedding),
            )
            return None  # Treat as cache miss
        # ... rest of method unchanged
```

#### Step 2: Modify `SemanticCache.put()` to Handle Mismatch

For `put()`, we have two options:
1. Raise `ValueError` (current behavior) — forces caller to handle it explicitly.
2. Return `False` or `None` to indicate failure without crashing.

Since the requirement says "establish a robust, graceful degradation policy", option 2 seems more appropriate:

```python
def put(
    self, embedding: list[float], history_context: str, context_str: str
) -> bool:
    """Store an embedding-context pair in the cache.
    
    Returns True on success, False if dimension mismatch prevents insertion.
    """
    with self._lock:
        if self._dim is None:
            self._dim = len(embedding)
        elif len(embedding) != self._dim:
            logger.warning(
                "SemanticCache dimension mismatch during put: expected %d, got %d",
                self._dim, len(embedding),
            )
            return False  # Don't insert incompatible entry
        # ... rest of method unchanged
```

#### Step 3: Invalidate Incompatible Cache Entry Upon Detection

When a dimension mismatch is detected in `lookup()`, consider invalidating the cache:

```python
if self._dim is not None and len(embedding) != self._dim:
    logger.warning(
        "SemanticCache dimension mismatch: expected %d, got %d",
        self._dim, len(embedding),
    )
    # Invalidate cache since entries are incompatible
    self.invalidate()
    return None
```

However, this might be too aggressive — it would invalidate ALL cache entries even though only some are incompatible. A better approach might be to just return `None` without invalidating.

#### Step 4: Consolidate Search Orchestration

Review `RagPipeline.search_queries()` vs `SearchStage.run()`:
- Determine which should be canonical.
- Ensure both provide standardized `SearchDiagnostics`.
- Refactor callers to use the canonical path.
