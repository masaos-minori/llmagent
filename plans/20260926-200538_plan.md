# Terminology Glossary — 用語の一貫性の確認

## Goal

Verify the terminology consistency between the Terminology Glossary in `governance_02_documentation-metadata.md` and the Evidence Label Validation in `governance_04_documentation-checks.md`: specifically, whether "Deprecated" in the Evidence Label Validation has the same meaning as "Obsolete" in the Terminology Glossary.

## Priority
Low

## Scope
- **In-Scope**: Verifying the relationship between "Deprecated" and "Obsolete"; confirming consistency across other documents
- **Out-of-Scope**: Changing the terminology definitions; modifying any governance rules beyond the terminology consistency

## Background
The Terminology Glossary defines:
- **Obsolete**: A named entity that still exists in source and remains callable, but is no longer the current production path for its original purpose — superseded by a different mechanism.
- **Dead Code**: A named entity that exists in source with zero current callers anywhere in the codebase — distinct from Obsolete, which may still be reachable via a legacy path.

The Evidence Label Validation defines "Deprecated" as an evidence label: "Describes an obsolete feature no longer in use."

## Problem
Without clarification, it is unclear whether "Deprecated" in the Evidence Label Validation has the same meaning as "Obsolete" in the Terminology Glossary. Additionally, it is unclear whether the same definition is used consistently across other documents.

## Reason for change
Ensuring terminology consistency allows implementers to understand the correct meaning of each term.

## Implementation intent
Investigate and resolve the terminology inconsistency by one of the following approaches:
1. If "Deprecated" and "Obsolete" have the same meaning, document this fact
2. If they have different meanings, clarify the distinction
3. Verify that the same definition is used consistently across other documents

## Requirements
- REQ-001: Determine whether "Deprecated" in the Evidence Label Validation has the same meaning as "Obsolete" in the Terminology Glossary
- REQ-002: If they have the same meaning, document this fact
- REQ-003: If they have different meanings, clarify the distinction
- REQ-004: Verify that the same definition is used consistently across other documents
- REQ-005: Do not alter the terminology definitions
- REQ-006: Keep changes isolated to `governance_02_documentation-metadata.md` and `governance_04_documentation-checks.md`
