## Background
`prompts/05_skills.md` defines the same Step 1-5 workflow procedure twice: once in
`### Step Responsibilities` (lines 271-298) and again in `### Tasks` (lines
331-400, subsections `#### Step 0` through `#### Step 5`). `Tasks` is the more
complete, currently-invoked definition (`### Tasks`' own steps are what an
executing agent actually follows); `Step Responsibilities` restates the same
procedural detail in a second location.

## Problem
Two sections independently define the same execution procedure. An edit to one
(e.g. adding a new constraint to Step 3) can be made without updating the other,
silently producing two diverging descriptions of the same step. This is a
correctness risk for any AI agent following this prompt file, since it is unclear
which section governs if they ever disagree, and a maintenance/context cost since
`prompts/05_skills.md` is loaded in full by its own Step 0 on every invocation.

## Reason for change
- Maintenance risk: two independent copies of the same procedure must be kept in
  sync by hand indefinitely.
- Context cost: duplicated procedural text is pure per-invocation overhead.
- Correctness risk: ambiguity between two step definitions can change what an
  executing agent actually does.

## Implementation intent
Keep `### Tasks` (`#### Step 0` through `#### Step 5`) as the single canonical,
procedural definition of the five-step workflow. Rewrite `### Step
Responsibilities` so each bullet states only the step's purpose (a sentence or
two) plus a one-line cross-reference to the corresponding `#### Step N`
subsection — do not restate the procedural "must do"/"must not do" content
there. Preserve the closing cross-step constraint paragraph as-is; it is a
distinct rule (do not skip/merge steps), not a per-step procedural restatement,
and is not duplicated elsewhere.

## Risks

  actually adds a constraint absent from `Tasks`, and gets deleted by mistake
  during consolidation → **Mitigation**: Phase 1's sentence-by-sentence
  equivalence check (UNK-01) before any deletion in Phase 2; when in doubt, keep
  the sentence.

  headings are renamed in a future edit → **Mitigation**: use heading-text
  references per `### Canonical References` (not line numbers), consistent with
  that section's own stated rationale ("line numbers... may change after
  editing").
