## 6. Design
### Core Problem
The current implementation uses `-1` as a sentinel value for `n_failed` to encode unexpected URL-level failures. This approach mixes error signaling with quantitative data, making aggregations unreliable and forcing downstream consumers to implement specialized logic to handle the sentinel.

### Solution: Explicit Status Enumeration

#### Step 1: Add `UNEXPECTED_FAILURE` to `IngestionFailureReason`

```python
class IngestionFailureReason(StrEnum):
    """Reason why a chunk ingestion failed."""

    PARSE_FAILED = "parse_failed"
    VALIDATION_FAILED = "validation_failed"
    EMBEDDING_FAILED = "embedding_failed"
    STORAGE_FAILED = "storage_failed"
    UNEXPECTED_FAILURE = "unexpected_failure"  # New
```

#### Step 2: Replace Sentinel Usage

Replace `n_failed = -1` with appropriate `status` assignment and `n_failed = 0`:

```python
# Before:
IngestUrlResult(url=url, n_success=0, n_failed=-1, skipped=False)

# After:
IngestUrlResult(url=url, n_success=0, n_failed=0, skipped=False, failure_reason=IngestionFailureReason.UNEXPECTED_FAILURE)
```

#### Step 3: Update Aggregation Logic

Ensure `ingest_all()` handles the new `UNEXPECTED_FAILURE` status appropriately:

```python
def ingest_all(self, ...) -> list[IngestUrlResult]:
    ...
    results: list[IngestUrlResult] = []
    for url in urls:
        try:
            result = self.ingest_url_group(...)
            results.append(result)
        except Exception as e:
            logger.error(f"Unexpected error ingesting {url}: {e}")
            results.append(IngestUrlResult(
                url=url,
                n_success=0,
                n_failed=0,
                skipped=False,
                failure_reason=IngestionFailureReason.UNEXPECTED_FAILURE,
            ))
    return results
```

#### Step 4: Update Logging

Include the explicit status in logging:

```python
logger.info("Ingestion completed: %d succeeded, %d failed, %d skipped", 
            sum(r.n_success for r in results),
            sum(r.n_failed for r in results),
            sum(1 for r in results if r.skipped))
```
