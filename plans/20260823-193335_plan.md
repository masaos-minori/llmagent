## Design

Plain function-level unit tests (no fixtures needed — `get_str` takes a plain dict):

1. `test_get_str_returns_string_value` — `get_str({"k": "v"}, "k")` returns `"v"`.
2. `test_get_str_raises_on_non_string_value` — `get_str({"k": 1}, "k")` raises
   `ValueError` whose message contains the key name (matches the f-string in the source).
3. `test_get_str_returns_default_on_missing_key` — `get_str({}, "k", default="x")`
   returns `"x"`.
4. `test_get_str_returns_default_on_none_value` — `get_str({"k": None}, "k",
   default="x")` returns `"x"` (covers the `v is None` branch distinctly from the
   missing-key branch).
5. `test_get_str_default_is_empty_string_when_unset` — `get_str({}, "k")` returns `""`
   (covers the function's own default parameter value, not a caller-supplied one).
