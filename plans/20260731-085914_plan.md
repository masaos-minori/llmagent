# Work Plan: Complete Resource Cleanup on System Shutdown

## Goal

Ensure all runtime resources are properly cleaned up during system shutdown, regardless of how shutdown is triggered.

## Scope

- Modify `scripts/agent/repl.py` to add comprehensive cleanup logic
- Ensure signal handlers call cleanup methods

## Assumptions

1. The current signal handlers exist but may not call all necessary cleanup methods
2. Adding task cancellation won't break existing error handling
3. Database session cleanup can use existing commit/rollback mechanisms
