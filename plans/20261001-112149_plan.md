## Reason for change
- Several issues (`canon001`, `govpath001`, `langdoc001`) edit this file. Without a size reduction, each of them inherits a failing structure check.
- `AGENTS.md` Global Rule 1 (selective loading) favors smaller, topic-scoped governance documents.

## Implementation intent
- Remove only statements that are duplicated in the same file.
- Move a cohesive cluster that is already self-contained. `## Change Impact Rule` selects among the three graphs and the Governance Applicability Matrix. `## Change-Impact Matrix` and `## RACI Model` define the approval side of the same process. `## Update Rule` defines which documents change per change type.
- Move the text verbatim. Edit only relocation-required references: "above"/"below" become links, and the Change Impact Rule reference to `### Decision Target Canonical Source Matrix` becomes a cross-document link.
- Update every consumer of the moved sections in the same change, so no reference or tool points at a section that no longer exists.
