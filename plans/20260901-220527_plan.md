# Plan: ingest001 — Fix RagIngester ingestion-split tests for stale private method references

## Goal
Update both test files to exercise the post-split API surface instead of RagIngester's removed private methods:
- Tests currently calling `ingester._embed_and_store(doc_id, path)` directly should either construct an `EmbeddingService`/`ChunkFactory` and call `embed_service.embed_and_store(...)` / `chunk_factory._embed_and_store(...)`, or restructure as an integration-style test that drives the behavior through `RagIngester`'s current public entry point (e.g. `ingest_url_group()`) and asserts on its observable result instead of reaching into a removed private method.
- Tests using `patch.object(ingester, "_prepare_chunks", ...)` (or similar) should patch the corresponding method on the `ChunkFactory` instance `RagIngester` now holds, not on `RagIngester` itself.
- Tests directly assigning to `ingester._client` (or other moved fields) should either construct the real `EmbeddingService`/`ChunkFactory` collaborators with a mock HTTP client, or patch/mock at the collaborator boundary `RagIngester` now uses to reach them.
- Confirm `RagIngester`'s current `__init__` signature and attribute names (which collaborator instances it holds, under what attribute names) before rewriting — do not guess.

## Design
(Correction, `plan-to-implementation-procedure` Step 3 adversarial verification,
2026-09-02: this section previously contained unrelated content copied from an
`itp007`-family workflow-procedure plan — replaced with the actual design for this Plan.)

Re-reading `scripts/rag/ingestion/ingester.py` in full confirms `RagIngester.__init__`
(lines 91-114) holds only `self._embedding_service` (an `EmbeddingService` instance,
line 106) as a persistent collaborator attribute — `ChunkFactory` and `TransactionManager`
are NOT `__init__` attributes. Both are constructed as call-scoped local variables inside
the ingest path (`factory = ChunkFactory(self._embedding_service, self._embed_workers)` at
line 248; `tx_mgr = TransactionManager(db, doc_mgr, doc_store)` at line 254) — the same
per-call construction pattern the file's own comment documents for `DocumentStore`/
`DocumentManager`. This means a test cannot simply reach `ingester._chunk_factory` or
`ingester._transaction_manager` the way it could reach a persistent attribute; the rewrite
must either patch the `ChunkFactory`/`TransactionManager` constructors at their import
location in `rag.ingestion.ingester` (module-level patch, since they are called as
bare names there per the `from rag.ingestion.chunk_preparation import ChunkFactory` /
`from rag.ingestion.transaction_commit import TransactionManager` imports), or restructure
as an integration-style test through `RagIngester`'s public `ingest_url_group()` entry
point and assert on its observable result — exactly the two options the Issue's
Implementation Intent already names for the `_embed_and_store` case, now confirmed to
apply identically to `ChunkFactory`/`TransactionManager` access.

`_embed_and_store` (confirmed at `scripts/rag/ingestion/chunk_preparation.py` line 76) is a
private method on `ChunkFactory`, reached only through a per-call instance — not a
persistent attribute of `RagIngester` a test can access after construction. `prepare()`
(the public replacement for the old `_prepare_chunks`, confirmed at
`scripts/rag/ingestion/chunk_preparation.py` line 34) is likewise only reachable through a
per-call `ChunkFactory` instance, not `ingester._prepare_chunks`/`ingester._chunk_factory`.
