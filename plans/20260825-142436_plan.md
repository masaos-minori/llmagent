## Goal
- `ToolExecutor` のTTLキャッシュ削除が実施された際に、`ConfigReloadService` に残る当該キャッシュへの配線(`cache_ttl` の diff-apply と `apply_config(cache_ttl=...)` 呼び出し)を同時に削除し、`/reload` が `AttributeError` を送出する状態を防ぐ。

## Priority
High

## Scope
- **In-Scope**:
  - `scripts/agent/services/config_reload.py`: `_sync_services()` の `tools.apply_config(cache_ttl=...)` ブロックと `_apply_tool_params()` の `tool_cache_ttl` diff-apply行の削除
- **Out-of-Scope**:
  - `ToolExecutor` キャッシュ実装自体の削除(前提となる別の未作成issueの対象)
  - `_sync_services()`/`_apply_tool_params()` の他のフィールド

## Background
本Planは、`ToolExecutor` のTTLキャッシュ(`_cache`、`_execute_with_cache`、`stat_cache_hits`)およびその `apply_config(cache_ttl=...)` パラメータを削除する、別の未作成の前提変更に依存する。issue本文および `plans/` 全体を再検索した結果、この前提となるキャッシュ削除自体を提案するissueまたはplanは現時点で存在しないことを確認した(`issues/20260821_09_issue.md` は `ToolResultCache` と `ToolExecutor` 内部キャッシュの統一を提案する別の狭い範囲のissueであり、キャッシュの全面削除ではない)。

## Problem
現在のソースを再確認した結果、`scripts/shared/tool_executor.py:70` に `def apply_config(self, *, cache_ttl: float | None = None) -> None:` が依然として存在し、キャッシュは削除されていない。
- `scripts/agent/services/config_reload.py:_sync_services()` は `ctx.services_required.tools.apply_config(cache_ttl=ctx.cfg.tool.tool_cache_ttl)` を呼び出し `result.applied.append("tools")` を実行している。
- `_apply_tool_params()` は `_apply_float(new_cfg, "tool_cache_ttl", lambda v: setattr(cfg.tool, "tool_cache_ttl", v))` を実行している。
これらはキャッシュが削除されて初めて意味を持つ変更であり、現時点では適用できない。

## Reason for change
キャッシュと `ToolExecutor.apply_config` が削除された後にこの配線を放置すると、`/reload` の呼び出しごとに `AttributeError` が発生する。この修正はキャッシュ削除と同時に着地しなければならない。

## Implementation intent
キャッシュ削除が着地した時点で、以下の2箇所を削除する:
1. `_sync_services()` の `tools.apply_config(cache_ttl=...)` ブロック(`result.applied.append("tools")` を含む)。ただし `ToolExecutor` がキャッシュ削除後も `apply_config` 経由で同期すべき他の設定値を保持している場合は、`"tools"` の呼び出し自体は残存パラメータのみで維持する。
2. `_apply_tool_params()` の `_apply_float(new_cfg, "tool_cache_ttl", ...)` 行。

## Requirements
- `REQ-001`(前提条件付き、キャッシュ削除着地後に実施): `_sync_services()` から `tools.apply_config(cache_ttl=...)` ブロックを削除する。`ToolExecutor.apply_config` が他のパラメータのために存続する場合は、`cache_ttl` 引数のみを取り除く。
- `REQ-002`(前提条件付き): `_apply_tool_params()` から `tool_cache_ttl` の diff-apply行を削除する。
- `REQ-003`(前提条件付き): `/reload` がキャッシュ削除後もエラーなく完了し、`"tools"` が正しく(削除または再定義された形で)reportされることを確認する回帰テストを追加する。

## Acceptance criteria

- AC-02(REQ-003対応): キャッシュ削除後、`/reload` がエラーなく完了することをテストで確認できる。
