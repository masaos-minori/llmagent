## Problem
Three entries in the Agent Known Issues document quote invariant text that does not appear anywhere in the current `docs/adr/ADR-001-workflow-engine-mandatory.md`:

- **WF-001** (Status: `open`): Claims INV-01 = "All execution paths must flow through the Workflow Engine" and INV-05 = "The Workflow Engine is the sole orchestrator of tool execution". Current ADR-001 has INV-01 = "ワークフロー定義ファイルが欠落している場合、Agentの起動を中止する" (If workflow definition file is missing, abort Agent startup) and INV-05 = "ワークフロー定義ファイルの検証失敗時は起動を中止する" (When workflow definition file validation fails, abort startup). These are completely different — WF-001 quotes text that doesn't exist in the current ADR-001.
- **WF-002** (Status: `open`): Claims INV-03 = "When the Workflow Engine reports successful execution, the corresponding document state must reflect that execution." Current ADR-001 has INV-03 = "実行成功と検証成功は区別され、それぞれ独立して検証される。" (Execution success and verification success are distinguished and verified independently.) Again, completely different. Additionally, the test `tests/agent/workflow/test_workflow_engine.py::test_execute_success_verify_failure_marks_task_failed` directly verifies INV-03, suggesting WF-002 is stale.
- **WF-003** (Status: `open`): Claims Decision #5 = "simple Q&A single-stage workflow". Current ADR-001 has Decision #5 = "すべてのAgent処理は、単純な質問応答を含め、Workflow Engineの管理下に置かれる。処理が単純であることは、Workflow Engineを迂回する理由にはならない。" (All Agent processing, including simple Q&A, is under Workflow Engine management.) This is completely different — Decision #5 says ALL Agent processing (including simple Q&A) goes through the Workflow Engine; it doesn't specify a single-stage workflow.
