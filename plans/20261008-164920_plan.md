# Plan: Add INV-02 regression test and keep original Japanese text on empty normalization

## Goal

Add the missing regression test for ADR-014 INV-02 and stop discarding Japanese sentences (original text included) whose normalized form is empty.

## Background

Source: local investigation notes (memo1.md, ISSUE-14), from AGENT-002 and RAG-002. ADR-014 was created to prevent duplicate LlmTurnExecutor ownership; ADR-009's purpose is not to lose original text through normalization.

## Problem

- No regression test checks ADR-014 INV-02 (the Orchestrator creates exactly one LlmTurnExecutor) (AGENT-002).
- A Japanese sentence whose normalized result is empty is dropped together with its original text (RAG-002).

## Reason for change

- Without the test, refactoring can reintroduce the duplicate-executor defect unnoticed.
- RAG-002 contradicts ADR-009's intent that normalization must not lose original text.

## Implementation intent

- Pin the invariant with a test and mark it verified in adr-index.
- On normalization failure, keep the original text and exclude nothing from search.

- **Acceptance criterion**: Japanese sentence with empty normalization is kept with original text (test)
- **Test**: Unit test in `tests/rag/test_fts_japanese.py`

The `chunks_ai`/`chunks_au` triggers use `COALESCE(new.normalized_content, new.content)` (`scripts/db/schema_sql.py:65`); only NULL falls back to original `content`, while `""` indexes empty. - **Evidence**: Confirmed by repository evidence — `chunk_japanese.py` line 54: `if normalized:` discards empty pairs; `store_impl.py:147-160` accepts `normalized: str | None`; `schema_sql.py:65` uses `COALESCE(new.normalized_content, new.content)`.

## Design

### Decision matrix

| Condition | Outcome |
|---|---|
| Normalization yields empty string | Keep original text in `content`, set `normalized_content` to NULL |
| Normalization yields non-empty string | Keep existing behavior (unchanged) |
| Orchestrator creates multiple LlmTurnExecutors | Test fails (regression detected) |
| Orchestrator creates exactly one LlmTurnExecutor | Test passes |

### Decision details

1. **Add ADR-014 INV-02 regression test**: Create a test that verifies the Orchestrator creates exactly one LlmTurnExecutor and all components share that instance. This test should be placed in `tests/agent/test_orchestrator.py`.
2. **Fix empty normalization in `chunk_japanese.py`**: Change `_split_into_ja_sentences()` to keep the original text even when normalization yields empty. Append the pair unconditionally and ensure an empty normalized result becomes NULL (not `""`) before `chunk_insert`, so the FTS `COALESCE(new.normalized_content, new.content)` falls back to the original text.
3. **Add empty normalization test**: Create a test that verifies Japanese sentences with empty normalization results are kept with their original text.
4. **Update documentation**: Remove AGENT-002 and RAG-002 from Known Issues; update ADR-014 INV-02 verification status.
