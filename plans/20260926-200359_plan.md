# NC-027 / NC-028 / NC-029 / NC-033 / NC-034 / NC-035 の Priority 値と NC-036 の不一致

## Goal

Resolve the Priority value inconsistency in the Needs Confirmation Inventory of `governance_03_issue-and-uncertainty-management.md`: NC-027 through NC-035 are all marked `Low`, but NC-036 is marked `High`. Determine whether this difference is intentional or inconsistent.

## Priority
Low

## Scope
- **In-Scope**: Investigating and resolving the Priority value difference between NC-036 and the other NC items
- **Out-of-Scope**: Changing the Needs Confirmation Inventory structure; modifying any governance rules beyond the Priority values

## Background
The Needs Confirmation Inventory defines Priority values as follows:
- **High** — Must resolve before next release
- **Medium** — Resolve within sprint
- **Low** — Nice-to-have

NC-036 concerns "Is the parse-error-triggers-fallback behavior an intentional refinement of Decision #9 or an unintended deviation?" — it shows a contradiction between ADR-010's Decision #9 and the actual behavior. In contrast, NC-027 through NC-035 concern questions about constant rationale and configuration values.

## Problem
Without clarification for why NC-036 is marked `High` while the others are marked `Low`, it is unclear whether the difference is intentional or an inconsistency. Additionally, it is unclear whether other NC items should also be elevated to `High`.

## Reason for change
If the Priority difference is intentional, the reason should be documented within the inventory. If it is inconsistent, the Priority values should be reconciled.

## Implementation intent
Investigate and resolve the Priority inconsistency by one of the following approaches:
1. If the Priority difference is intentional, document the reason within the Needs Confirmation Inventory
2. If the Priority difference is inconsistent, update the Priority values to be consistent
3. Clarify the reason for NC-036's `High` status

## Requirements
- REQ-001: Determine whether the Priority difference between NC-036 and the other NC items is intentional or inconsistent
- REQ-002: If intentional, add an explanation in the Needs Confirmation Inventory
- REQ-003: If inconsistent, update the Priority values to be consistent across all items
- REQ-004: Do not alter the Needs Confirmation Inventory structure
- REQ-005: Keep changes isolated to `governance_03_issue-and-uncertainty-management.md`
