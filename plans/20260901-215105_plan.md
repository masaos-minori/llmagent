## Background
ADR-001 defines INV-01 and INV-05 as workflow-engine mandatory invariants. Agent Known Issues documents WF-001 claiming these invariants are duplicated ("same invariant condition"). ## Problem
Agent Known Issues claims WF-001 involves duplicate INV-01/INV-05 entries describing the same invariant condition. However, the actual texts differ:
- ADR-001 INV-01: "ワークフロー定義ファイルが欠落している場合、Agentの起動を中止する。" (startup abort on missing workflow definition file)
- ADR-001 INV-05: "ワークフロー定義ファイルの検証失敗時は起動を中止する。" (startup abort on validation failure of workflow definition file)
- Agent Known Issues INV-01: "ワークフロー定義ファイルの欠落または検証失敗は、Agentの起動を中止する。" (combined statement covering both conditions)
- Agent Known Issues INV-05: Same as INV-01 above

The question is whether INV-01 and INV-05 in Agent Known Issues are truly duplicates (both saying the same thing) or whether they should distinguish between "missing file" and "validation failure" like ADR-001 does.

## Reason for change
If the known issue is valid (duplication), the Agent Known Issues document should be corrected. If the claim is inaccurate, the known issue itself should be closed.

## Implementation intent
Compare the invariant texts side-by-side, determine whether they represent genuine duplication or contextually distinct conditions, and update the Agent Known Issues document with accurate status.
