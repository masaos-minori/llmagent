# Plan: AgentContext preserves original traceback on config load failure

## Goal
- Ensure `AgentContext.__init__()` preserves the original exception traceback when `build_agent_config()` fails, enabling proper debugging of configuration errors.

## Priority
Medium

## Scope
- **In-Scope**: Change `from None` to `from e` in `AgentContext.__init__()`
- **Out-of-Scope**: Changes to `build_agent_config()` error messages; changes to logging format

## Background
`AgentContext.__init__()` in `scripts/agent/context.py` loads the agent configuration via `build_agent_config()`. On failure, it wraps the exception in a `RuntimeError` with context about the config directory.

## Problem
The `from None` clause suppresses the original traceback, making it impossible to determine the root cause of configuration loading failures. Debugging configuration errors requires manual inspection of logs. Stack traces show only the wrapper exception, not the actual failure. CI/CD pipelines cannot parse the real error from test output.

## Reason for change
Configuration errors are critical startup failures. Without the original traceback, operators cannot quickly identify whether the issue is a missing file, invalid TOML syntax, or a permission error. This increases mean time to resolution.

## Implementation intent
Remove `from None` to preserve the original traceback chain. Use `from e` to explicitly link the wrapper exception to the original.

## Requirements
- `REQ-001`: Original exception chain is preserved in stack traces
- `REQ-002`: Test verifies traceback includes both wrapper and original frames
- `REQ-003`: Existing error handling at callers reviewed for compatibility

## Design
### Current Behavior (Verified Against Source)
1. `context.py` line 307-313: Try to load config via `build_agent_config()`
2. Line 309: Catch all exceptions with `except Exception as e`
3. Line 311-313: Wrap in `RuntimeError` with `from None` — suppresses original traceback

### Proposed Change
```python
try:
    self.cfg = build_agent_config()
except Exception as e:  # noqa: BLE001 — any config-load failure must be wrapped into one RuntimeError with context
    config_dir = Path(__file__).resolve().parent.parent.parent / "config"
    raise RuntimeError(
        f"Failed to load agent config ({config_dir}): {e.__class__.__name__}: {e}"
    ) from e  # Keep original traceback for debugging
```

Key change: Replace `from None` with `from e` to preserve the exception chain.
