# Plan

## Goal
Make every compatibility exception of `tools/check_compat_shims.py` carry an owner, reason, expiry date, and removal condition (an expired or incomplete entry fails the check), and add a report-only check that reports documentation function references to symbols that do not exist in source.

## Priority
Medium

## Scope
- **In-Scope**:
  - A manifest file `tools/compat_exceptions.toml` with validation in `tools/check_compat_shims.py`; migrate the current `DEFAULT_ALLOWLIST` entries into it and drop the entries that are no longer needed.
  - A report-only `--check-doc-symbols` stage that reuses `check_function_references` of `tools/_docs_consistency_lib.py`.
  - Regression tests, the CI workflow step, and the tool description.
- **Out-of-Scope**:
  - Removing the compatibility features themselves, runtime telemetry, general documentation lint.
  - Making the symbol stage blocking (Unknown UNK-03).
  - Any change to `tools/_docs_consistency_lib.py` or to the existing pattern checks.

## Background
`tools/check_compat_shims.py` holds a static `DEFAULT_ALLOWLIST` set of file paths with comments only. Adversarial verification against the repository found:
- The set holds 24 paths (the issue's source memo implied more); measuring each path with `check_all(..., allowlist=set(), include_removed_names=True)` shows 20 paths still produce findings and 4 do not: `docs/22_mcp/mcp_03_06_tool-runtime-availability-metadata.md`, `tests/shared/test_rag_tools_consistency.py`, `tests/shared/test_route_resolver.py` produce no finding, and `tests/agent/test_startup_routing_drift.py` no longer exists. Those 4 are dropped, not migrated.
- CI already runs `python tools/check_compat_shims.py --check-removed-names` (`.github/workflows/backward-compat-check.yml`, `set -euo pipefail`), so the removed-name stage is blocking; only the new symbol stage and the manifest path filter are missing there.
- `check_function_references(docs_dir, files, repo_root)` already compares backtick-quoted function references in docs with names defined under `scripts/`; a measurement over all docs reports 12 findings (for example `check_port_drift()` defined under `tools/`, `apply_workflow_migrations()` in ADR-008, `retry_once_with_delay()`, `load_vec()`, builtins such as `isinstance()`), so a report-only stage is correct and some findings are false positives that need an allowance.
- The repository has TOML precedent (`config/documentation_canonical_sources.toml`, read via `tomllib` on Python 3.13) and non-deployed tool data under `tools/` (`tools/*_baseline.txt`).

## Problem
An allowlist entry never expires, so a temporary exception can stay forever, and a documentation reference to a deleted function is found only if a person adds its name to a pattern list first. The former Glossary example was found by manual review.

## Reason for Change
Compatibility leftovers are removed on the owner's schedule only if each exception is tracked with an owner and a deadline, and the stale-reference class that already occurred should be reported mechanically.

## Implementation Intent
- Replace the in-code set with a manifest loaded by the checker; keep `--allowlist` (test injection) and the `allowlist` parameter of `check_all` unchanged.
- Entry fields: `id`, `path`, `reason`, `owner`, `expires` (ISO date, a review-by date), `removal_condition`, `category` in `compatibility`, `migration`, `fallback`, `fixture`. All fields are required; an unknown category, an unparseable date, a duplicate id, or `expires` earlier than today is a finding and exit code 1.
- `owner` is the governance owner value already used in the repository ("Repository owner"); no per-person owner is invented (the issue instructs to stop when no owner is identifiable, and the governance documents define this value).
- The symbol stage calls the library function, drops names defined under `tools/` and a small named-allowance set kept in the manifest, prints findings as Warning, and never changes the exit code.

## Requirements
- `REQ-001`: `tools/compat_exceptions.toml` defines every exception with the required fields; the checker validates required fields, category, date, and id uniqueness.
- `REQ-002`: An expired or incomplete entry fails the run (exit code 1) with a message naming the entry id.
- `REQ-003`: The 20 needed `DEFAULT_ALLOWLIST` paths are migrated into the manifest with reason and removal condition taken from the existing comments; the 4 unneeded paths are removed; `DEFAULT_ALLOWLIST` no longer exists as a literal set in code.
- `REQ-004`: `--check-doc-symbols` reports documentation function references to symbols absent from `scripts/` as Warning, reusing `check_function_references`, with an allowance mechanism and no exit-code effect.
- `REQ-005`: The CI workflow runs the symbol stage as a non-blocking step and triggers when the manifest changes.
- `REQ-006`: Regression tests cover manifest validation, expiry, migration parity, stale reference, valid reference, and historical-context cases; existing tests pass unchanged.
- `REQ-007`: `tools/TOOL_DESCRIPTIONS.md` describes the manifest and the new flag and stays in sync with the tool.

## Design
- Path B (five files including one new data file and a CLI surface change); baseline: `check_compat_shims.py --check-removed-names` exits 0 and the 41 tests pass before the change.
- Add small helpers (`load_exceptions`, `validate_exceptions`, `check_doc_symbols`) rather than growing `main`, to avoid raising its complexity.
- `main()` loads the manifest only when `--allowlist` is not given, so tests that inject an allowlist keep their behavior.
- The symbol stage post-filters the library result: names defined under `tools/` and manifest-listed allowances are dropped; remaining findings print as `WARNING`.

## Risks
- **Risk**: The manifest date makes CI fail on the expiry day without a code change → **Mitigation**: the failure is the intended signal; the message names the entry and the date to renew.

- **Risk**: The symbol stage prints false positives that people ignore → **Mitigation**: allowance set in the manifest and a later blocking decision (UNK-03).
