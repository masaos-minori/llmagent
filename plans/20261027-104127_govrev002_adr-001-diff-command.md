## Background
- ADR-001 Negative Consequences says "reviewing a turn relies on the diff command and the audit log". The phrase appears nowhere else under `docs/`.
- A `/diff` slash command existed and was removed: commit `43cc7c3f1` dropped its handler, and `tools/check_compat_shims.py` lists `/diff` among the removed command names guarded by `GV-017`. The command registry and the registered commands contain no diff command.
- The mechanisms that record a turn today are the audit-log events (workflow events and the per-turn `turn_end` event) and the `tool_approval` event defined by ADR-001 Decision 10. `/history` shows only recent user and assistant messages.

## Problem
The ADR names a compensating control for the missing human checkpoint ("no human checkpoint for the combined result of a turn") that no longer exists. An operator or implementer reading ADR-001 may believe a review command is available, and the ADR's own justification for omitting an approval stage then rests on a removed mechanism.

## Reason for Change
ADR-001 is an Accepted ADR and a governing document for the workflow design. A compensating control that cannot be found weakens its Negative Consequences. The removed-name check does not catch the natural-language form, so the stale phrase will not be flagged by tooling. Nothing makes the change time-sensitive beyond that.

## Implementation Intent
Replace only the stale phrase. Name the audit log as the review source and state its limit: no command presents the combined result of a turn. Do not introduce a new command or requirement, and do not change any Decision, Invariant or Approval record. Keep the sentence in the existing style of the Negative Consequences list.

## Requirements
- `REQ-001`: Remove the phrase "the diff command" from ADR-001 Negative Consequences and replace it with wording that cites only mechanisms defined in the current documents (the audit log), stating that no command presents the combined result of a turn.
- `REQ-002`: Leave every Decision, Invariant, Gate, Approval record and other ADR-001 section unchanged, and leave the documentation checkers without findings.
